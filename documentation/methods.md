# Methods

We used GPT 6 Astra with medium reasoning effort for the following tasks:

- Extracting theorems and their proofs from Wikipedia.
  We worked offline with articles exported from a single local Kiwix ZIM archive of Wikipedia's mathematics content: `wikipedia_en_mathematics_nopic_2026-09.zim`.
- Creating metadata according to the [metadata rules](metadata.md).
- Vibe coding an HTML generator (not yet included in the repository).
