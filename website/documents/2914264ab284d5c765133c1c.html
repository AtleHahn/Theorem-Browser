Statement

Let k,r\ge1 be integers, and color every k-element subset of the positive integers with one of r colors. There exists a sequence (a_n)_{n\ge0} of positive integers and a color c such that for every choice of nonempty finite sets F_1,\ldots,F_k\subseteq\{0,1,2,\ldots\} with \max F_j<\min F_{j+1} for 1\le j<k, the set

\left\{\sum_{t\in F_1}a_t,\ldots,\sum_{t\in F_k}a_t\right\}

has exactly k elements and has color c. Thus every set of sums over successive disjoint index blocks is monochromatic in the same color.
