Statement

Let G be a finitely generated group. Choose a finite symmetric generating set S, and form its undirected Cayley graph with vertex set G and edges joining g to gs for s\in S. Say that G has more than one end if deleting some finite set of edges leaves at least two infinite connected components; this property is independent of the chosen finite generating set.

Then G has more than one end if and only if it admits an action by graph automorphisms on a tree T with all of the following properties:

  • no vertex is fixed by every element of G;
  • no group element interchanges the two endpoints of an edge that it preserves;
  • for every edge e, the stabilizer \{g\in G:g(e)=e\} is finite.

Here a tree is a connected graph with no cycles; it need not be finite or locally finite.

Within undergraduate level
Level justification

Undergraduate group theory and graph theory plus explicit definitions of ends and tree actions suffice. Bass–Serre machinery is not needed to understand this equivalent formulation.
