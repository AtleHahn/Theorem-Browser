Statement

Let X,Y be second countable Baire spaces and A\subseteq X\times Y. Set A_x=\{y\in Y:(x,y)\in A\}. If A has the Baire property, then A is meager in X\times Y if and only if \{x\in X:A_x\text{ is meager in }Y\} is comeager in X. Likewise A is comeager if and only if \{x\in X:A_x\text{ is comeager in }Y\} is comeager in X. Each forward implication holds even without the Baire-property assumption.

Second countable means having a countable base of open sets. A nowhere dense set has closure with empty interior; a meager set is a countable union of nowhere dense sets, and a comeager set has meager complement. A Baire space is one in which every countable intersection of dense open sets is dense. A set has the Baire property if its symmetric difference with some open set is meager. The product has the product topology.
