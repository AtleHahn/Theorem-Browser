Statement

All graphs here are finite and simple. A clique is a set of pairwise adjacent vertices, an independent set a set of pairwise nonadjacent vertices, and a proper coloring partitions vertices into independent color classes. Write \omega(G) for the largest clique size, \chi(G) for the minimum number of colors and \alpha(G) for the largest independent-set size. A graph is perfect when \chi(H)=\omega(H) for every induced subgraph H, including the empty graph with both quantities zero. Replacing any vertex of a perfect graph by a nonempty clique, all of whose vertices have the original vertex’s neighbors outside that clique, preserves perfection.

Level
High school only
Level justification

The replacement and perfection conditions are explicitly finite graph constructions and coloring counts.

Proof 1: Doubling a vertex and recoloring

Replacing vertices by nonempty cliques with the same neighbors outside the clique may be broken down into repeated steps of doubling a vertex, adding an adjacent copy with the same other neighbors. If the doubled vertex belongs to a maximum clique of the graph, it increases both the clique number and the chromatic number by one. If, on the other hand, the doubled vertex does not belong to a maximum clique, form a graph {\displaystyle H} by removing the vertices with the same color as the doubled vertex (but not the doubled vertex itself) from an optimal coloring of the given graph. The removed vertices meet every maximum clique, so {\displaystyle H} has clique number and chromatic number at most one less than that of the given graph. The removed vertices and the new copy of the doubled vertex can then be added back as a single color class, showing that in this case the doubling step leaves the chromatic number unchanged. For every induced subgraph containing both copies, the same argument shows that doubling preserves the equality of the clique number and the chromatic number; an induced subgraph containing at most one copy is isomorphic to an induced subgraph of the original perfect graph. Thus each doubling step preserves the perfection of the graph.

Level justification

Reduce clique replacement to doubling, recolor according to whether the doubled vertex lies in a maximum clique, and repeat the argument for induced subgraphs. School finite set and graph counting suffice; no advanced external framework is used.
