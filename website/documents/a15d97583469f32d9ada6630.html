Proof 1: Bourbaki–Witt on the poset of chains — outline

Chain-complete maximal-element lemma

Assuming the axiom of choice, every nonempty partially ordered set in which every chain has a least upper bound has a maximal element.

Assume for contradiction that the nonempty chain-complete poset X has no maximal element. Let g be a choice function on {\displaystyle P(X)-\{\varnothing \},} where P(X) is the power set of X. Define a function {\displaystyle f:X\to X} by

{\displaystyle f(x)=g(\{y\ :\ y>x\}).}

This is allowed as, by assumption, the set is non-empty. Then f(x) > x, so f is an inflationary function with no fixed point, contradicting the Bourbaki–Witt theorem: every inflationary self-map of a nonempty chain-complete poset has a fixed point.

The maximal-element result just proved is then applied to the set {\displaystyle P'} of all chains in a given poset {\displaystyle P}, ordered by set inclusion. We get a maximal element in {\displaystyle P'}; i.e., a maximal chain in {\displaystyle P}. This proves the Hausdorff maximality principle, that every poset has a maximal chain.

Proof 2: Apply the downward-family maximality lemma — outline

Use the following downward-family maximality lemma, assuming the axiom of choice.

Lemma—Let {\displaystyle F} be a set consisting of subsets of some fixed set {\displaystyle P} such that {\displaystyle F} satisfies the following properties:

  1. {\displaystyle F} is nonempty.
  2. The union of each totally ordered subsets of {\displaystyle F} is in {\displaystyle F}, where the ordering is with respect to set inclusion.
  3. For each set {\displaystyle S} in {\displaystyle F}, each subset of {\displaystyle S} is in {\displaystyle F}.

Then {\displaystyle F} has a maximal element with respect to set inclusion.

The maximal principle follows from the above since the set of all chains in {\displaystyle P} satisfies the above conditions.

Proof 3: Well-ordered recursive chain selection — outline

Let {\displaystyle P'} be the set of all chains in {\displaystyle P}. By the well-ordering theorem, we find a well-ordering {\displaystyle \preceq } on {\displaystyle P}. We shall construct the function

{\displaystyle f:P\to P'}

recursively with respect to {\displaystyle \preceq } as follows. For an element {\displaystyle x} in {\displaystyle P}, suppose we are given an arbitrary function

{\displaystyle g:\{y\in P\mid y\prec x\}\to P'.}

Then let

{\displaystyle f(x)=(\cup \operatorname {im} (g))\cup \{x\}}

if the set on the right is totally ordered; i.e., an element of {\displaystyle P'} and {\displaystyle f(x)=\emptyset } otherwise. If {\displaystyle g} itself is also required to satisfy the above recursive condition, then the transfinite recursion theorem ensures this defines the function {\displaystyle f} uniquely (in a nutshell, if {\displaystyle x} is a {\displaystyle \preceq }-least element, the domain of {\displaystyle g} above is the empty set and thus {\displaystyle f(x)} is uniquely determined and in general, the recursion condition ensures the unique {\displaystyle g} is used to define {\displaystyle f(x)}.) We note

  1. The image of {\displaystyle f} is totally ordered, with respect to set inclusion.
  2. If {\displaystyle D} is a chain containing {\displaystyle \bigcup_{x\in D}\bigcup_{y\prec x}f(y)}, then {\displaystyle x\in f(x)} for each {\displaystyle x\in D}.

Indeed, (1) holds since if {\displaystyle y\prec x}, and f(x) is given by the nonempty branch, then

{\displaystyle f(x)=(\cup \{f(y)\mid y\prec x\})\cup \{x\}}

which contains {\displaystyle f(y)} as a subset. If f(x)=\emptyset, it is instead a subset of every f(y). Thus the two values are comparable in either case. (2) holds since

{\displaystyle (\cup \{f(y)\mid y\prec x\})\cup \{x\}\subset D}

is a chain as it is a subset of a chain.

Finally, by (1), the union {\displaystyle C} of the image of {\displaystyle f} is a chain and it is maximal by (2), since if {\displaystyle D\supset C} is another chain, then {\displaystyle x\in f(x)\subset C} for each {\displaystyle x\in D}. {\displaystyle \square }
