Statement

Let F(x)=\sum_{k=1}^n a_ke^{\lambda_kx} with a_k,\lambda_k\in\mathbb C, n\ge2 an integer, on a bounded interval J\subset\mathbb R of positive length L. Put A=\max_k|\operatorname{Re}\lambda_k| and M=\sup_J|F|>0. Let C>0 be the absolute constant in Nazarov’s inequality M\le e^{AL}(CL/|B|)^{n-1}\sup_B|F| for measurable B\subset J of positive Lebesgue measure. For t>0, the set E_t=\{x\in J:|F(x)|\le t\} satisfies |E_t|\le CL\left(\frac{te^{AL}}M\right)^{1/(n-1)}.

Level
Within undergraduate level
Level justification

Complex exponentials, suprema and continuous sublevel sets fit undergraduate analysis; measurable length is a short extension here, and the full Nazarov bound is supplied rather than proved.

Proof 1: Apply Nazarov to a sublevel set

Applying Nazarov's inequality to E_t=\{x\in J:|F(x)|\leq t\}, t>0, leads to

M\leq e^{AL}\left(\frac{CL}{|E_t|}\right)^{n-1} \sup_{x\in E_t}|F(x)| \leq e^{AL}\left(\frac{CL}{|E_t|}\right)^{n-1}t,

thus

|E_t|\leq CL\left(\frac{te^{AL}}{M}\right)^{1/(n-1)}.

If |E_t|=0, the last estimate holds directly.

Level
Within undergraduate level
Level justification

Apply the explicitly given supremum bound to a continuous-function sublevel set and rearrange positive powers, treating zero measure separately. Undergraduate real/complex analysis suffices with the small extension of measurable length; this application uses no Lebesgue integration or advanced measure convergence theory.
