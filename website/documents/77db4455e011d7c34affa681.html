Statement

For a prime p and nonzero integer u, let \nu_p(u) be the largest k\ge0 with p^k\mid u. Let x,y\in\mathbb Z, n\ge1 odd, p\nmid xy, p\mid x+y, p\nmid n, and x^n+y^n\ne0. Then \nu_p(x^n+y^n)=\nu_p(x+y).

Level
High school only
Level justification

The valuation is explicitly defined using elementary divisibility; the result is high-school number theory.

Proof 1: Substitute the negative of the second base

Use the coprime-exponent formula: if q is prime, q\nmid uv, q\mid u-v, and q\nmid m, then \nu_q(u^m-v^m)=\nu_q(u-v), for nonzero valuation arguments. Apply the difference formula for exponents prime to p to x and -y. Because n is odd, x^n-(-y)^n=x^n+y^n, while x-(-y)=x+y. These substitutions give the result.

Level
High school only
Level justification

Replace the second base by its negative and use odd parity of the exponent. Elementary integer powers and divisibility suffice.
