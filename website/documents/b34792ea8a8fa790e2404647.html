Statement

Let \Omega be a set and D\subseteq\mathcal P(\Omega). Call D a Dynkin system when it contains \Omega, is closed under B\setminus A for A,B\in D with A\subseteq B, and contains the union of each increasing sequence of its members. Then D is a Dynkin system if and only if it contains \varnothing, is closed under complements relative to \Omega, and is closed under countable unions of pairwise disjoint members.

Level
Within undergraduate level
Level justification

The Dynkin-system axioms are explicit closure conditions on a family of subsets. Sigma-algebra means closure under complements and countable unions; ordinary set operations and sequences suffice, with no measure or integration theory.

Proof 1: Complement and disjoint-increment constructions

Assume first D satisfies the Dynkin axioms in the statement. Complement closure: This follows from the universe and nested-difference axioms by using {\displaystyle B:=\Omega .} Taking A=\Omega also gives \varnothing\in D. The following lemma will be used to prove disjoint-union closure. Lemma: If {\displaystyle A,B\in D} are disjoint then {\displaystyle A\cup B\in D.}

Proof of Lemma: {\displaystyle A\cap B=\varnothing } implies {\displaystyle B\subseteq \Omega \setminus A,} where {\displaystyle \Omega \setminus A\in D } by complement closure. Now the nested-difference axiom implies that D contains {\displaystyle (\Omega \setminus A)\setminus B=\Omega \setminus (A\cup B)} so that complement closure guarantees that {\displaystyle A\cup B\in D,} which proves the lemma. Disjoint-union closure: Assume that {\displaystyle A_{1},A_{2},A_{3},\ldots } are pairwise disjoint sets in {\displaystyle D.} For every integer {\displaystyle n>0,} the lemma implies that {\displaystyle D_{n}:=A_{1}\cup \cdots \cup A_{n}\in D} where because {\displaystyle D_{1}\subseteq D_{2}\subseteq D_{3}\subseteq \cdots } is increasing, increasing-union closure guarantees that D contains their union {\displaystyle D_{1}\cup D_{2}\cup \cdots =A_{1}\cup A_{2}\cup \cdots ,} as desired.

Conversely, assume D contains the empty set and is closed under complements and countable disjoint unions. Complementing the empty set gives \Omega\in D. Nested-difference closure: If {\displaystyle A,B\in D} satisfy {\displaystyle A\subseteq B} then complement closure implies {\displaystyle \Omega \setminus B\in D} and since {\displaystyle (\Omega \setminus B)\cap A=\varnothing ,} disjoint-union closure implies that D contains {\displaystyle (\Omega \setminus B)\cup A=\Omega \setminus (B\setminus A)} so that finally complement closure guarantees that {\displaystyle \Omega \setminus (\Omega \setminus (B\setminus A))=B\setminus A} is in {\displaystyle D.} Increasing-union closure: Assume {\displaystyle A_{1}\subseteq A_{2}\subseteq \cdots } is an increasing sequence of subsets in {\displaystyle D,} let {\displaystyle D_{1}=A_{1},} and let {\displaystyle D_{i}=A_{i}\setminus A_{i-1}} for every {\displaystyle i>1,} where the established nested-difference closure guarantees that {\displaystyle D_{2},D_{3},\ldots } all belong to {\displaystyle D.} Since {\displaystyle D_{1},D_{2},D_{3},\ldots } are pairwise disjoint, disjoint-union closure guarantees that their union {\displaystyle D_{1}\cup D_{2}\cup D_{3}\cup \cdots =A_{1}\cup A_{2}\cup A_{3}\cup \cdots } belongs to {\displaystyle D,} which proves increasing-union closure.
