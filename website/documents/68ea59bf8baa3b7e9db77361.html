Statement

SAT asks whether a Boolean expression has a truth assignment making it true. A decision problem belongs to NP if a nondeterministic Turing machine decides it in polynomial time. Let P be the class of decision problems decidable by deterministic Turing machines in polynomial time. Then SAT has a deterministic polynomial-time algorithm if and only if P = NP.

Proof 1: Compose a SAT algorithm with the universal reduction

By the Cook–Levin theorem, used here as an external theorem, every problem in NP can be reduced in polynomial time to an instance of the Boolean satisfiability problem. This means that if the Boolean satisfiability problem could be solved in polynomial time by a deterministic Turing machine, then all problems in NP could be solved in polynomial time, and so the complexity class NP would be equal to the complexity class P.

Conversely, SAT is in NP: a proposed truth assignment can be verified in polynomial time, using the certificate characterization of NP. Thus P = NP implies a polynomial-time algorithm for SAT.
