Statement

Let p_1,\ldots,p_n,q_1,\ldots,q_n\ge0 with \sum_i p_i=\sum_iq_i=1, and let b>1. Define H_b(P)=-\sum_i p_i\log_b p_i with 0\log_b0=0, and H_b(P,Q)=-\sum_i p_i\log_bq_i, where a term with p_i=0 is 0, and one with p_i>0,q_i=0 is +\infty. Then H_b(P)\le H_b(P,Q), with equality if and only if P=Q. Equivalently, D_b(P\Vert Q)=\sum_{p_i>0}p_i\log_b(p_i/q_i)\ge0, using the same infinite-value convention.

Level
Within undergraduate level
Level justification

Relative entropy, total variation, product distributions or infinite-value conventions require introductory undergraduate probability/information theory, even when given by finite sums. A bright US college student should be able to understand the statement after about 30 minutes of focused background research; this rating concerns understanding the claim, not proving it.

Proof 1: Sum the scalar logarithm bound

For simplicity, we prove the statement using the natural logarithm, denoted by \ln, since

\log_b a=\frac{\ln a}{\ln b},

so the particular logarithm base b>1 that we choose only scales the relationship by the positive factor 1/\ln b.

Let I denote the set of all i for which p_i is nonzero. If q_i=0 for some i\in I, the cross entropy is infinite and the inequality is strict. Otherwise, since \ln x\le x-1 for all x>0, with equality if and only if x=1, we have:

\begin{aligned} -\sum_{i\in I}p_i\ln\frac{q_i}{p_i} &\ge-\sum_{i\in I}p_i\left(\frac{q_i}{p_i}-1\right)\\ &=-\sum_{i\in I}q_i+\sum_{i\in I}p_i =-\sum_{i\in I}q_i+1\ge0. \end{aligned}

The last inequality is a consequence of the p_i and q_i being part of a probability distribution. Specifically, the sum of all nonzero values is 1. Some nonzero q_i, however, may have been excluded since the choice of indices is conditioned upon the p_i being nonzero. Therefore, the sum of the q_i over I may be less than 1.

So far, over the index set I, we have:

-\sum_{i\in I}p_i\ln\frac{q_i}{p_i}\ge0,

or equivalently

-\sum_{i\in I}p_i\ln q_i\ge-\sum_{i\in I}p_i\ln p_i.

Both sums can be extended to all i=1,\ldots,n, including p_i=0, using the zero conventions in the statement. The expression p\ln p tends to 0 as p tends to 0, and -\ln q tends to +\infty as q tends to 0. We arrive at

-\sum_{i=1}^n p_i\ln q_i\ge-\sum_{i=1}^n p_i\ln p_i.

For equality to hold, we require

  1. \frac{q_i}{p_i}=1 for all i\in I so that the equality \ln\frac{q_i}{p_i}=\frac{q_i}{p_i}-1 holds;
  2. \sum_{i\in I}q_i=1, which means q_i=0 if i\notin I, that is, q_i=0 if p_i=0.

This can happen if and only if p_i=q_i for i=1,\ldots,n.
