Recognizing busy beavers is undecidable

There is no general algorithm recognizing Busy Beaver champions under the stated machine conventions. Even finitely described optimization questions can therefore exceed universal algorithmic decision procedures.

Statement

For an integer n\ge1, use deterministic Turing machines with n operational states, a separate Halt state, one starting state, a two-way unbounded tape over \{0,1\}, and a transition for each operational state and scanned symbol. Each transition writes a bit, moves one cell left or right, and enters a state (possibly Halt). The machine starts on an all-zero tape. Among machines that halt, \Sigma(n) is the largest number of ones left on the tape, and S(n) the largest number of transitions, including the halting transition. There is no algorithm that decides whether an arbitrary machine is a halting machine attaining \Sigma(n) for its number n of operational states.

Level
Within undergraduate level
Level justification

The machine model, starting configuration and score are explicitly described through finite transition rules. Understanding computability here means whether such a finite program always returns the required value; the maxima and eventual comparisons use elementary functions and quantifiers. A small machine trace is enough to illustrate the new model, without formal arithmetic or incompleteness theory.

Proof 1: Enumerating tables and simulating a recognized champion

It is undecidable by a general algorithm whether an arbitrary Turing machine is a busy beaver. (Such an algorithm cannot exist, because its existence would allow Σ to be computed, which is impossible by the uncomputability of Σ. In particular, such an algorithm could be used to construct another algorithm that would compute Σ as follows: for any given n, each of the finitely many n-state 2-symbol Turing machines would be tested until an n-state busy beaver is found; this busy beaver machine would then be simulated to determine its score, which is by definition Σ(n).)

Level
Within undergraduate level
Level justification

This is a direct algorithmic reduction: enumerate finitely many transition tables, recognize a champion under the hypothetical decider, and simulate that known-halting machine. Computability and reduction are a small related extension of undergraduate discrete mathematics, and no proof of the imported uncomputability theorem is needed.
