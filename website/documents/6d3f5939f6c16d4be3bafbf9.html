Statement

Let k be a field, H\le G a subgroup of finite index, M a finite-dimensional kG-module and N a finite-dimensional kH-module. Write \operatorname{Res}_H^G M for restriction and \operatorname{Ind}_H^G N=kG\otimes_{kH}N for induction. There is an isomorphism \operatorname{Hom}_{kG}(M,\operatorname{Ind}_H^G N)\cong\operatorname{Hom}_{kH}(\operatorname{Res}_H^G M,N).

Level
Beyond undergraduate level
Level justification

The assertion uses induction, restriction and module homomorphisms over group algebras, requiring representation theory.

Proof 1: Degree-zero specialization

Use the external Ext reciprocity formula \operatorname{Ext}_{kG}^n(M,\operatorname{Ind}_H^G N)\cong\operatorname{Ext}_{kH}^n(\operatorname{Res}_H^G M,N). Set n=0. Since \operatorname{Ext}^0=\operatorname{Hom}, this is the required reciprocity isomorphism.

Level
Beyond undergraduate level
Level justification

The actual proof specializes an Ext reciprocity theorem, so it requires derived Ext groups as well as group algebras, induced tensor modules and restriction. Degree zero does not remove these homological-algebra prerequisites.
