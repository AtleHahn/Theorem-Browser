Statement

All graphs are finite, simple and undirected; containing a graph means containing an isomorphic subgraph, not necessarily induced. K_r(t) is the complete r-partite graph with t vertices per part: edges join precisely vertices in different parts. Let r\geq2,t\geq1 be integers. For a graph G, form an r-uniform hypergraph F with the same vertices and a hyperedge for every r-element clique of G (a set all of whose distinct vertices are adjacent). If F has disjoint vertex classes A_1,\ldots,A_r of size t such that every set choosing one vertex from each class is a hyperedge, then G contains K_r(t). Thus K_r(t)-free G gives a hypergraph avoiding that complete multipartite configuration.

Level justification

The statement defines the multipartite graph, cliques and hyperedges as finite subsets, and gives the cross-class choice condition explicitly. The conclusion asserts existence of specified pairwise edges among those same vertices. Understanding these finite definitions and their quantifiers requires elementary set reasoning.

Proof 1: Read each cross-part pair inside a clique

Write H=K_r(t) and K_{t,\dots,t}^{(r)} for the complete r-partite r-uniform hypergraph with t vertices per part.

Note that if {\displaystyle F} contains a copy of {\displaystyle K_{t,\dots ,t}^{(r)}}, then the original graph {\displaystyle G} contains a copy of {\displaystyle H}, as every pair of vertices in distinct parts must have an edge. Thus, if G is K_r(t)-free, {\displaystyle F} contains no copies of {\displaystyle K_{t,\dots ,t}^{(r)}}.
