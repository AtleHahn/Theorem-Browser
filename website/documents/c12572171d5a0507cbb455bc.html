Statement

Let X be a real or complex Banach space and A:D(A)\subseteq X\to X a linear operator on a linear subspace. A strongly continuous semigroup is a family of bounded linear maps T(t):X\to X, t\ge0, with T(0)=I, T(s+t)=T(s)T(t) and norm-continuous t\mapsto T(t)x for each x. Its generator has domain exactly the x for which \lim_{h\downarrow0}(T(h)x-x)/h exists in norm, and assigns that limit to x. An operator is closed if its graph is closed in X\times X. For real \lambda, belonging to the resolvent set means \lambda I-A:D(A)\to X is bijective with bounded inverse R(\lambda,A):X\to X. The operator A generates a strongly continuous semigroup with \|T(t)\|\le1 for every t\ge0 if and only if A is closed, D(A) is dense in X, and every real \lambda>0 belongs to the resolvent set with \|R(\lambda,A)\|\le\lambda^{-1}. The norm is the operator norm.
