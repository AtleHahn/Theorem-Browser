Statement

Let U be a finite set of random variables with strictly positive joint mass or density p on their Cartesian product of value spaces. For S\subseteq U, write x_S for an assignment restricted to S. Suppose \Theta,\Phi_1,\ldots,\Phi_n,\Psi_1,\ldots,\Psi_m\subseteq U and real-valued factors satisfy, for every assignment x, p(x)=f(x_\Theta)\prod_{i=1}^n g_i(x_{\Phi_i})=\prod_{j=1}^m h_j(x_{\Psi_j}). Then there are factors g_i' on \Phi_i and h_j' on \Theta\cap\Psi_j such that p(x)=\prod_{j=1}^m h_j'(x_{\Theta\cap\Psi_j})\prod_{i=1}^n g_i'(x_{\Phi_i}).

Level
Within undergraduate level
Level justification

The full statement includes joint mass or density functions, whose meaning adds a limited finite-dimensional probability/integration definition to multivariable functions. The factorizations themselves are pointwise algebra.

Proof 1: Freeze the variables outside the factor being refined

In order to use \prod_{j=1}^m h_j(x_{\Psi_j}) as a template to further factorize f(x_\Theta), all variables outside of \Theta need to be fixed. To this end, let \bar\theta be an arbitrary fixed assignment to the variables from U\setminus\Theta (the variables not in \Theta). For an arbitrary set of variables S, let x_S^* denote the assignment on S that uses x on S\cap\Theta and \bar\theta on S\setminus\Theta.

Moreover, to factorize only f(x_\Theta), the other factors g_1(x_{\Phi_1}),g_2(x_{\Phi_2}),\ldots,g_n(x_{\Phi_n}) need to be rendered moot for the variables from \Theta. To do this, the factorization

p(x)=f(x_\Theta)\prod_{i=1}^n g_i(x_{\Phi_i})

will be re-expressed as

p(x)= \left(f(x_\Theta)\prod_{i=1}^n g_i(x_{\Phi_i}^*)\right) \left(\prod_{i=1}^n\frac{g_i(x_{\Phi_i})}{g_i(x_{\Phi_i}^*)}\right).

For each i=1,2,\ldots,n, g_i(x_{\Phi_i}^*) is g_i(x_{\Phi_i}) where all variables outside of \Theta have been fixed to the values prescribed by \bar\theta. The denominators are nonzero, since the given product equals the strictly positive p at every assignment.

Let

f'(x_\Theta)=f(x_\Theta)\prod_{i=1}^n g_i(x_{\Phi_i}^*), \qquad g_i'(x_{\Phi_i})=\frac{g_i(x_{\Phi_i})}{g_i(x_{\Phi_i}^*)}

for each i=1,2,\ldots,n, so

p(x)=f'(x_\Theta)\prod_{i=1}^n g_i'(x_{\Phi_i}) =\prod_{j=1}^m h_j(x_{\Psi_j}).

What is most important is that

g_i'(x_{\Phi_i}) =\frac{g_i(x_{\Phi_i})}{g_i(x_{\Phi_i}^*)}=1

when the values assigned to \Phi_i do not conflict with the values prescribed by \bar\theta, making g_i'(x_{\Phi_i}) “disappear” when all variables not in \Theta are fixed to the values from \bar\theta.

Fixing all variables not in \Theta to the values from \bar\theta gives

p(x_U^*)=f'(x_\Theta)\prod_{i=1}^n g_i'(x_{\Phi_i}^*) =\prod_{j=1}^m h_j(x_{\Psi_j}^*).

Since g_i'(x_{\Phi_i}^*)=1,

f'(x_\Theta)=\prod_{j=1}^m h_j(x_{\Psi_j}^*).

Letting h_j'(x_{\Theta\cap\Psi_j})=h_j(x_{\Psi_j}^*) gives

f'(x_\Theta)=\prod_{j=1}^m h_j'(x_{\Theta\cap\Psi_j}),

which finally gives

p(x)=\left(\prod_{j=1}^m h_j'(x_{\Theta\cap\Psi_j})\right) \left(\prod_{i=1}^n g_i'(x_{\Phi_i})\right).
