Statement

Let G be a finite group and \theta:G\to\mathbb C a class function. A virtual character is an integer combination of irreducible complex characters. An elementary subgroup is a direct product of a cyclic group and a group of prime-power order. Then \theta is a virtual character of G if and only if its restriction to every elementary subgroup is a virtual character.

Proof 1: Brauer induction and Frobenius reciprocity — outline

Brauer's induction theorem states that the character ring is generated, as an abelian group, by characters induced from one-dimensional representations of elementary subgroups.

Using Frobenius reciprocity, Brauer's induction theorem leads easily to the characterization: a complex-valued class function of G is a virtual character if and only if its restriction to each Brauer elementary subgroup of G is a virtual character.

Level justification

Brauer induction and Frobenius reciprocity turn the local hypothesis into integer inner products with every irreducible character. This requires induced representations, restrictions and character orthogonality, a substantial representation-theory framework.
