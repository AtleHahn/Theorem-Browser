Even a small choice assertion can entail excluded middle in the constructive setting described. The result shows that seemingly harmless selection principles may carry substantive commitments about what counts as a valid proof.

Statement

Work in constructive set theory with pairing, extensionality and separation for the formulas used below, and with the distinct finite ordinals 0=\varnothing, 1=\{0\} and 2=\{0,1\}. For a proposition P allowed in separation, put

U=\{x\in2:x=0\lor P\},\qquad V=\{x\in2:x=1\lor P\},\qquad X=\{U,V\}.

A choice function on X is a function f:X\to2 satisfying f(U)\in U and f(V)\in V. A choice function on X exists if and only if P\lor\neg P.

Level
Beyond undergraduate level
Level justification

The result is an intuitionistic equivalence for sets defined by an arbitrary separation formula; it does not assume global excluded middle.

Proof 1: Combine the choice disjunction with the two explicit assignments

Both {\displaystyle U} and {\displaystyle V} are inhabited, as witnessed by {\displaystyle 0\in U} and {\displaystyle 1\in V}. If the proposition {\displaystyle P} can be proven, then both of these sets equal {\displaystyle \{0,1\}}. In particular, {\displaystyle P\,\to \,U=V} by extensionality. In turn, for any mathematical function {\displaystyle g} that can take both of these sets as an argument, one finds {\displaystyle P\,\to \,g(U)=g(V)}, the contrapositive of which is {\displaystyle g(U)\neq g(V)\,\to \,\neg P}.

The rest of the proof concerns the pair {\displaystyle X:=\{U,V\}}, a set of inhabited sets. (Indeed, {\displaystyle X} is itself inhabited and even validates {\displaystyle X\leq ^{*}2}, meaning that 2 surjects onto X (it is finitely indexed). However, note that when excluded middle is not assumed, {\displaystyle X} need not be provably finite, in the bijection sense.)

A choice function {\displaystyle f} on {\displaystyle X} by definition has to map into the general union, which here is {\displaystyle \{0,1\}}, and fulfill

{\displaystyle f(U)\in U\,\land \,f(V)\in V.}

Using the definition of the two subsets and the function's established codomain, this reduces to

{\displaystyle {\big (}f(U)=0\lor P{\big )}\land {\big (}f(V)=1\lor P{\big )}.}

Using the law of distributivity, this in turn implies {\displaystyle P\lor {\big (}f(U)\neq f(V){\big )}}. By the previous comment on functions, the existence of a choice function on this set thus implies the disjunction {\displaystyle P\lor \neg P}. This proves one direction.

Conversely, suppose P\lor\neg P. {\displaystyle P} implies that both defined sets equal {\displaystyle \{0,1\}}. In that case, the pair {\displaystyle \{U,V\}} equals the singleton set {\displaystyle \{\{0,1\}\}} and there are two possible choice functions on that domain, picking either {\displaystyle 0} or {\displaystyle 1}. If, instead, {\displaystyle P} can be rejected, i.e. if {\displaystyle \neg P} holds, then {\displaystyle U=\{0\}} and {\displaystyle V=\{1\}}. So in that case {\displaystyle U\neq V}, and on the proper pair {\displaystyle \{\{0\},\{1\}\}} there is only one possible choice function, picking the unique inhabitant of each singleton set.

Thus in either case there is a choice function on X.
