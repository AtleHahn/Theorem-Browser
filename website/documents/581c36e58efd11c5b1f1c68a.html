Statement

Work in ZFC. The constructible universe is L=\bigcup_{\alpha\in\mathrm{Ord}}L_\alpha, where L_0=\varnothing, L_{\alpha+1}=\operatorname{Def}(L_\alpha), and L_\lambda=\bigcup_{\alpha<\lambda}L_\alpha at limit ordinals. Here \operatorname{Def}(Y) consists of subsets of Y definable over (Y,\in) by first-order formulas with parameters in Y. Assume 0^\sharp does not exist. Equivalently, there is no uncountable set of ordinal order-indiscernibles for L: such a set is one for which every parameter-free set-theoretic formula has the same truth value in L on all increasing tuples of a fixed finite length from the set. Then for every uncountable set A of ordinals, there is a set B\in L with A\subseteq B and |A|=|B|, where cardinalities are computed in the ambient universe.
