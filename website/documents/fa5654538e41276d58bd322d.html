Statement

A square block upper triangular matrix B is invertible if and only if every square diagonal block B_i is invertible.

Level
Within undergraduate level
Level justification

Understanding the statement involves block matrices; invertibility. These prerequisites fit undergraduate coursework or a brief extension of it. A bright US college student should be able to understand this statement after approximately 30 minutes of focused background research; this assesses understanding the claim, not its proof.

Proof 1: Source matrix argument

The inverse of B (if it exists) must have diagonal blocks of the form B_i^{-1}, so if any B_i isn't invertible then neither is B.

Conversely let D be the block-diagonal matrix corresponding to B, in other words B with the off-diagonal blocks zeroised. If each B_i is invertible then so is D and D^{-1}B is equal to the identity plus a nilpotent matrix. But such a matrix is always invertible (if N^k=0 the inverse of I-N is I+N+N^2+\cdots+N^{k-1}), so B is invertible.

Level justification
