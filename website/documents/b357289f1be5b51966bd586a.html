Statement

For any finite family \mathcal F of balls in a metric space there is a pairwise disjoint subfamily \mathcal G such that \bigcup\mathcal F\subseteq\bigcup_{C\in\mathcal G}3C. Here cB has the same center and c times the radius; use either open balls throughout or closed balls throughout.

Level
Within undergraduate level
Level justification

Metric balls, bounded radii, disjointness and separability are basic analysis/topology. The enlarged balls are explicitly radius multiples, and all covering or multiplicity conditions are ordinary set inclusions/counts, without measure integration.

Proof 1: Greedy largest-radius selection

Write the family as B_1,\dots,B_n. If it is empty, choose the empty subfamily. Otherwise n>0. Let B_{j_1} be the ball of largest radius. Inductively, assume that B_{j_1},\dots,B_{j_k} have been chosen. If there is some ball in B_1,\dots,B_n that is disjoint from B_{j_1}\cup B_{j_2}\cup\dots\cup B_{j_k}, let B_{j_{k+1}} be such a ball with maximal radius (breaking ties arbitrarily); otherwise, we set m:=k and terminate the inductive definition.

Now set

X:=\bigcup_{k=1}^m3B_{j_k}.

It remains to show that B_i\subseteq X for every i=1,2,\dots,n. This is clear if i\in\{j_1,\dots,j_m\}. Otherwise, there is necessarily some k\in\{1,\dots,m\} such that B_i intersects B_{j_k}. We choose the minimal possible k and note that the radius of B_{j_k} is at least as large as that of B_i. The triangle inequality then implies that B_i\subseteq3B_{j_k}\subseteq X, as needed.

Level justification

Greedily select the largest remaining disjoint ball and apply the metric triangle inequality to each rejected ball. General metric spaces and balls are undergraduate analysis; no measure differentiation theorem is involved.
