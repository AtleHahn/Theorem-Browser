Statement

Let (X,R) be a set-sized model of ZF whose relation R is externally well-founded: every nonempty subset of X has an R-minimal element. Then it is isomorphic to a unique transitive set model of ZF.

Level

Level justification

These require substantial specialist preparation beyond a brief introduction from undergraduate mathematics. Proof 1: Apply extensional collapse to the model

Every set model of ZF is set-like and extensional. If the model is well-founded, then by the Mostowski collapse lemma it is isomorphic to a transitive model of ZF and such a transitive model is unique.

The version of Mostowski collapse used here says that a well-founded set-like extensional relation is isomorphic to membership on a unique transitive class, which is a set when the original domain is a set. Extensionality means that distinct elements have distinct predecessor sets. Transfer of the ZF axioms uses invariance of first-order truth under isomorphism; the source leaves this step implicit.
