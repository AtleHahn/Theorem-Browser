Statement

On X=\mathbb Z^{\mathbb Z} with discrete-coordinate product topology, define f(x)_i=x_{i+x_i}. With (sx)_i=x_{i-1}, the map f is continuous and commutes with s, but there is no fixed finite N\subset\mathbb Z and rule \mu:\mathbb Z^N\to\mathbb Z expressing every output as f(x)_i=\mu((x_{i+n})_{n\in N}).

Level
Within undergraduate level
Level justification

Basic topology supplies the product of discrete coordinate spaces and continuity. The sequence map and finite-neighborhood dependence are explicit coordinate rules; no cellular-automaton or dynamical-system theory is needed.

Proof 1: Fix the queried positions and observe unbounded dependence — outline

This rule is the same for each position, so it is shift-equivariant. And it can be shown to be continuous according to the discrete-coordinate product topology: for each fixed input x and finite pattern p in y=f(x), there is a pattern in x with at most twice as many positions that forces {\displaystyle f} to generate p, consisting of the cells in p together with the cells whose values are copied into p. However, despite being continuous and equivariant, {\displaystyle f} is not a cellular automaton rule, because the value of any cell can potentially depend on the value of any other cell rather than only depending on the cells in any prior-fixed finite neighborhood.

Level justification

Fix finitely many output coordinates and their finitely many queried input coordinates to obtain a cylinder neighborhood. The unbounded query index defeats a fixed finite neighborhood. Undergraduate product topology and integer-indexed functions suffice.
