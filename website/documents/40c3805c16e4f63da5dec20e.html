Statement

Let f:\mathbb R^d\to\mathbb R be continuously differentiable, with an attained global minimum f^*=f(x^*). For \mu>0, the \mu-PL condition means \frac12\|\nabla f(x)\|^2\geq\mu(f(x)-f^*) for all x. Assume that f satisfies this PL condition. The gradient is L-Lipschitz, for L>0, when \|\nabla f(x)-\nabla f(y)\|\leq L\|x-y\| for all x,y. Assume this Lipschitz condition holds. For 0<\eta<2/L, set x_{k+1}=x_k-\eta\nabla f(x_k). Then f(x_k)-f^*\leq[1-2\mu\eta(1-L\eta/2)]^k(f(x_0)-f^*). At \eta=1/L the bound is (1-\mu/L)^k(f(x_0)-f^*), and this step minimizes the displayed contraction factor.

Level justification

Proof 1: Quadratic upper bound and PL contraction

Local upper-bound lemma

If f:\mathbb R^d\to\mathbb R is continuously differentiable and its gradient is L-Lipschitz, then f(y)\leq f(x)+\langle\nabla f(x),y-x\rangle+\frac L2\|y-x\|^2 for all x,y\in\mathbb R^d.

Set {\textstyle g(t)=f(x+t(y-x))} for {\textstyle t\in [0,1]} and use the {\textstyle L} -Lipschitz continuity to show that {\textstyle f(y)-f(x)=g(1)-g(0)=\int _{0}^{1}g'(t)=\langle \int _{0}^{1}\nabla f(x+t(y-x))dt,y-x\rangle \leq \langle \nabla f(x),y-x\rangle +{\frac {L}{2}}\|y-x\|^{2}}.

Descent iteration

Since {\textstyle \nabla f} is {\textstyle L} -Lipschitz, we have the parabolic upper bound

{\displaystyle f(x_{k+1})\leq f(x_{k})+\langle \nabla f(x_{k}),x_{k+1}-x_{k}\rangle +{\frac {L}{2}}\|x_{k+1}-x_{k}\|^{2}}

Plugging in the gradient descent step,

{\displaystyle {\begin{aligned}f(x_{k+1})-f(x_{k})&\leq \langle \nabla f(x_{k}),-\eta \nabla f(x_{k})\rangle +{\frac {L}{2}}\|-\eta \nabla f(x_{k})\|^{2}\\&=(L\eta ^{2}/2-\eta )\|\nabla f(x_{k})\|^{2}\\&\leq 2\mu (L\eta ^{2}/2-\eta )\left(f(x_{k})-f(x^{*})\right)\end{aligned}}}

Thus,

{\displaystyle f\left(x_{k}\right)-f\left(x^{*}\right)\leq \left(1-2\mu \eta (1-L\eta /2)\right)^{k}\left(f\left(x_{0}\right)-f\left(x^{*}\right)\right)}
