Statement

A lattice has meet a\wedge b and join a\vee b, the greatest lower bound and least upper bound. In a lattice with bottom 0, a nonzero element x is join-irreducible if x=y\vee z implies x=y or x=z, and join-prime if x\le y\vee z implies x\le y or x\le z.

In a distributive lattice with bottom, join-prime and join-irreducible elements coincide.

Level
Within undergraduate level
Level justification

Order infima/suprema and set unions/intersections are undergraduate concepts. The lattice, lower-set and prime/irreducible conditions are explicitly defined using them; a finite ordered-set example suffices to interpret the added terminology.

Proof 1: Expand a meet with a join by distributivity

If a nonzero x is not join-irreducible, there exist y,z<x with x=y\vee z. Then x\le y\vee z while neither x\le y nor x\le z, so x is not join-prime. The bottom element is excluded from both definitions.

Conversely, suppose that x is join-irreducible, and that x ≤ y ∨ z. This inequality is equivalent to the statement that x = x ∧ (y ∨ z), and by the distributive law x = (x ∧ y) ∨ (x ∧ z). But since x is join-irreducible, at least one of the two terms in this join must be x itself, showing that either x = x ∧ y (equivalently x ≤ y) or x = x ∧ z (equivalently x ≤ z).
