Statement

Let b\ge3 be an integer. For an infinite binary sequence t=(t_k)_{k\ge1} with t_k\in\{0,1\}, define f_b(t)=\sum_{k\ge1}t_kb^{-k}. Then f_b is an injection into \mathbb R.

Proof 1: Read the same digits in base b — outline

Instead of mapping 0111... to the decimal 0.0111..., it can be mapped to the base-b number 0.0111\ldots_b. This leads to the family of functions f_b(t)=0.t_b. The functions f_b are injections for integer bases b\ge3; the base-two function is excluded.

Here 0.t_b is the positional series specified in the statement. Injectivity uses the usual uniqueness of positional expansions apart from terminating/maximal-digit-tail ambiguity.

Level justification

The proof applies positional-series uniqueness to infinite sequences. Its precise justification can be understood from convergent geometric series: at the first differing digit k, the leading difference b^{-k} exceeds the largest possible tail b^{-k}/(b-1) when b>=3. This is introductory real analysis with an elementary geometric-series estimate, without any advanced set theory.
