Statement

Let S be a semigroup, a set with an associative operation xy; a monoid is a semigroup with a two-sided identity. A homomorphism satisfies f(xy)=f(x)f(y). A congruence \sim is an equivalence relation with x\sim y,u\sim v\Rightarrow xu\sim yv. The classes [x] form a semigroup S/{\sim} under [u][v]=[uv], and x\mapsto[x] is a surjective homomorphism. If S is a monoid with identity 1, then [1] is the quotient identity.

Level
Within undergraduate level
Level justification

Semigroups and monoids are direct variants of group axioms, and their definitions are supplied. Congruences, fibers and quotients use familiar equivalence relations and multiplication compatibility, so no specialist semigroup theory is required.

Proof 1: Multiply equivalence classes — outline

Like any equivalence relation, a semigroup congruence {\displaystyle \sim } induces congruence classes

{\displaystyle [a]=\{x\in S\mid x\sim a\}}

and the semigroup operation induces a binary operation {\displaystyle \circ } on the congruence classes:

{\displaystyle [u]\circ [v]=[uv]}.

Because {\displaystyle \sim } is a congruence, the set of all congruence classes of {\displaystyle \sim } forms a semigroup with {\displaystyle \circ }, called the quotient semigroup or factor semigroup, and denoted {\displaystyle S/\!\sim }. The mapping {\displaystyle x\mapsto [x]} is a semigroup homomorphism, called the quotient map, canonical surjection or projection; if {\displaystyle S} is a monoid then quotient semigroup is a monoid with identity {\displaystyle [1]}.

Level
Within undergraduate level
Level justification

Use compatibility to define multiplication on equivalence classes and inherit associativity and identity. Introductory undergraduate abstract algebra and quotient sets suffice.
