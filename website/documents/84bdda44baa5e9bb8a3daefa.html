Statement

For any topological space X and compact space Y, the projection \pi:X\times Y\to X is a closed map: it sends every closed subset to a closed subset.

Proof 1: Apply the tube lemma to a closed set’s complement — outline

Local tube lemma

If Y is compact, X is any topological space, x\in X, and N\subseteq X\times Y is open with \{x\}\times Y\subseteq N, then some open neighborhood U of x satisfies U\times Y\subseteq N.

By the definition of the product topology, for each (x,y)\in\{x\}\times Y there are open sets U_{x,y}\subseteq X and V_{x,y}\subseteq Y such that

(x,y)\in U_{x,y}\times V_{x,y}\subseteq N.

The family \{V_{x,y}:y\in Y\} is an open cover of the compact set Y, so this cover has a finite subcover; namely, there is a finite set Y_0\subseteq Y such that \bigcup_{y\in Y_0}V_{x,y}=Y. Let

U=\bigcap_{y\in Y_0}U_{x,y},

which is an open set in X since Y_0 is finite. Moreover, the construction implies that \{x\}\times Y\subseteq U\times Y\subseteq N. If Y is empty, take U=X.

Using the concept of closed maps, the tube lemma can be rephrased as closedness of the projection. Indeed, let C\subseteq X\times Y be closed. For x\notin\pi(C), the open complement of C contains \{x\}\times Y. The tube lemma supplies an open neighborhood U of x with U\times Y disjoint from C, so U is disjoint from \pi(C). Thus \pi(C) is closed.
