Statement

Let D<0 range over discriminants of imaginary quadratic number fields, and let h(D) be their ideal class numbers. Then h(D)\to\infty as D\to-\infty. In particular, only finitely many such fields have a given class number.

Level
Beyond undergraduate level
Level justification

Ideal class numbers and discriminants of imaginary quadratic fields are algebraic-number-theory objects.

Proof 1: Hecke–Heilbronn dichotomy (outline)

By Hecke’s conditional theorem: Let D < 0 be the discriminant of an imaginary quadratic number field K. Assume the generalized Riemann hypothesis for L-functions of all imaginary quadratic Dirichlet characters. Then there is an absolute constant C>0 such that

{\displaystyle h(D)>C{\frac {\sqrt {|D|}}{\log |D|}}.}

By Heilbronn’s theorem: If the generalized RH is false for the L-function of some imaginary quadratic Dirichlet character then h(D) → ∞ as D → −∞.

In the work of Hecke and Heilbronn, the only L-functions that occur are those attached to imaginary quadratic characters, and it is only for those L-functions that “GRH is true” or “GRH is false” is intended. If GRH is true, the displayed lower bound tends to infinity; if it is false, Heilbronn’s theorem gives the same conclusion. Thus h(D)\to\infty as D\to-\infty.
