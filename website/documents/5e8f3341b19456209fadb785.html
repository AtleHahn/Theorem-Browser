Statement

A propositional proof system can equivalently be specified as (i) a polynomial-time function F from finite strings onto the encoded propositional tautologies \mathrm{TAUT}, or (ii) a polynomial-time predicate V(A,x) such that A\in\mathrm{TAUT} if and only if some string x satisfies V(A,x). Polynomial-time encodings and decoding of pairs are understood.

Level
Within undergraduate level
Level justification

Finite propositional tautologies are formulas true for every Boolean assignment. Polynomial-time function/predicate means a finite-string algorithm bounded by a fixed polynomial in input length; the pair encoding is assumed. These limited algorithm and truth-table definitions extend undergraduate functions and discrete reasoning without nondeterministic machines or proof-complexity theory.

Proof 1: Convert generators to verifiers and back

Write P_1 for a polynomial-time function onto \mathrm{TAUT} and P_2 for a polynomial-time verifier as in the statement.

If P1 is a pps according to the first definition, then P2 defined by P2(A,x) if and only if P1(x) = A is a pps according to the second definition. Conversely, if P2 is a pps according to the second definition, then P1 defined by

{\displaystyle P_{1}(\langle x,A\rangle )={\begin{cases}A&{\text{if }}P_{2}(A,x)\\\top &{\text{otherwise}}\end{cases}}}

(P1 takes pairs as input) is a pps according to the first definition, where {\displaystyle \top } is a fixed tautology.

Malformed encodings may return the same fixed tautology.

Level
Within undergraduate level
Level justification

Convert a polynomial-time output function to an equality verifier, and a verifier to a function returning either the verified formula or a fixed tautology. The encodings and polynomial runtime assumptions are supplied; basic finite-string algorithms and propositional truth suffice without NP-completeness theory.
