Statement

Let \mathcal F be a finite family of subsets of an arbitrary set U. It shatters T\subseteq U when \{S\cap T:S\in\mathcal F\} is the family of all subsets of T. Then \mathcal F shatters at least |\mathcal F| sets.

Level
Within undergraduate level
Level justification

Finite set families, intersections and power sets are elementary undergraduate foundations. Shattering is explicitly defined by obtaining every subset as an intersection, so the cardinality assertion adds only that one combinatorial definition.

Proof 1: Split at an element with both membership possibilities

The proof is by mathematical induction on |\mathcal F|. The empty family requires no shattered sets. Every family of only one set shatters the empty set.

Assume the lemma is true for all families of size less than |\mathcal F| and let \mathcal F be a family of two or more sets. Because \mathcal F has at least two distinct sets, there exists an element x that belongs to some but not all of the sets. Split \mathcal F into two subfamilies, of the sets that contain x and the sets that do not contain x. By the induction assumption, choose for each subfamily a collection of distinct sets it shatters, of size equal to that subfamily. These two collection sizes add to |\mathcal F|. None of these shattered sets contain x, since a set that contains x cannot be shattered by a family in which all sets contain x or all sets do not contain x.

Some of the chosen sets may occur in both collections. When a set S occurs in only one of the two collections, it contributes one unit both to the size of the chosen collection and to the number of shattered sets of \mathcal F. When a set S occurs in both collections, both S and S\cup\{x\} are shattered by \mathcal F, so S contributes two units to the sizes of the collections and to the number of shattered sets of \mathcal F. These contributions are distinct, since the original sets do not contain x. Therefore, the number of shattered sets of \mathcal F is at least equal to the sum of the sizes of the two chosen collections, which is |\mathcal F|.
