Statement

For a function s:\mathbb N\to\mathbb N, let \mathrm{DSPACE}(s) and \mathrm{NSPACE}(s) denote the languages decidable by deterministic and nondeterministic Turing machines, respectively, using O(s(n)) work-tape cells on inputs of length n; the read-only input tape is not counted. Nondeterministic acceptance means that some computation branch accepts.

Call f:\mathbb N\to\mathbb N space-constructible if f(n)\ge\log n and a Turing machine computes f(n) from the unary input 1^n using O(f(n)) space. For every such f and every g:\mathbb N\to\mathbb N with g(n)/f(n)\to0,

\mathrm{DSPACE}(g)\subsetneq\mathrm{DSPACE}(f),\qquad \mathrm{NSPACE}(g)\subsetneq\mathrm{NSPACE}(f).

In each of the deterministic and nondeterministic models there is a language decidable in O(f(n)) space but not in o(f(n)) space.
