Medium

More work space yields strictly more decision power when the bounds satisfy the stated constructibility and growth conditions. These hierarchies distinguish intrinsic resource limits from mere shortcomings of known algorithms, while the hypotheses prevent an unrestricted claim that every resource increase adds power.

Statement

For a function s:\mathbb N\to\mathbb N, let \mathrm{DSPACE}(s) and \mathrm{NSPACE}(s) denote the languages decidable by deterministic and nondeterministic Turing machines, respectively, using O(s(n)) work-tape cells on inputs of length n; the read-only input tape is not counted. Nondeterministic acceptance means that some computation branch accepts.

Call f:\mathbb N\to\mathbb N space-constructible if f(n)\ge\log n and a Turing machine computes f(n) from the unary input 1^n using O(f(n)) space. For every such f and every g:\mathbb N\to\mathbb N with g(n)/f(n)\to0,

\mathrm{DSPACE}(g)\subsetneq\mathrm{DSPACE}(f),\qquad \mathrm{NSPACE}(g)\subsetneq\mathrm{NSPACE}(f).

In each of the deterministic and nondeterministic models there is a language decidable in O(f(n)) space but not in o(f(n)) space.

Proof 1: Bounded universal simulation and nondeterministic complementation (external)

A link to the proof can be found here (Theorem2 and Lemmas4–6, pp.1–3, for the deterministic assertion).

The nondeterministic extension indicated by Fortnow uses space complementation, Theorem1. Let U accept a padded encoding (\langle M\rangle,w) exactly when the fixed-alphabet machine M has an accepting computation on that same input within f(n) cells. A configuration counter bounds the guessed path, so U\in\mathrm{NSPACE}(f); complement at this upper bound. An o(f) machine for \overline U contradicts its own acceptance on sufficiently long padded copies of its encoding. This gives one language outside every o(f) bound and imposes no constructibility or logarithmic lower bound on g.

In both simulations the configuration bound must include the work-head position: one may use |Q|(n+2)(f(n)+1)4^{f(n)}, whose counter still needs O(f(n)+\log n) cells. Rescan the read-only machine description instead of copying it. In the complementation proof, start the reachable-vertex count at c_0=1, add self-loops so zero-length reachability is retained at every stage, and bound every guessed path by its specified length.
