Statement

Every tournament on n\ge1 vertices contains a directed path visiting all n vertices exactly once. A tournament orients every edge of a complete graph, choosing exactly one direction for each pair.

Proof 1: Apply the orientation theorem to a complete graph — outline

Use the source’s stated consequence of the Gallai–Hasse–Roy–Vitaver theorem: every orientation of a graph with chromatic number k contains a simple directed path on at least k vertices. Apply it to the complete graph K_n, whose pairwise adjacent vertices require n colors. A tournament is an orientation of K_n, so it has a simple directed path containing all n vertices.
