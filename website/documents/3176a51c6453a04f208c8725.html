Statement

Let n\ge1 be an integer. A polynomial F in the entries of a complex n\times n matrix is conjugation invariant if F(SAS^{-1})=F(A) for every invertible complex matrix S. Restrict such a polynomial to diagonal matrices by f(x_1,\ldots,x_n)=F(\operatorname{diag}(x_1,\ldots,x_n)). This gives a bijection from conjugation-invariant matrix polynomials to complex polynomials in n variables invariant under every permutation of the variables. It preserves sums and products.

Proof 1: Diagonal density and trace-power lifts — outline

For G=\mathrm{GL}_n(\mathbb C), the Cartan subalgebra {\displaystyle {\mathfrak {t}}} can be identified with diagonal matrices, and the Weyl group W can be identified with the symmetric group acting on diagonal matrices by permutations. Therefore, {\displaystyle \mathbb {C} [{\mathfrak {t}}]\cong \mathbb {C} [x_{1},...,x_{n}]} and {\displaystyle \mathbb {C} [{\mathfrak {t}}]^{W}} can be identified with the subring of {\displaystyle \mathbb {C} [{\mathfrak {t}}]} generated by {\displaystyle e_{1},...,e_{n}} where each {\displaystyle e_{i}} is an elementary symmetric polynomial.

Identify {\displaystyle {\mathfrak {g}}} with the set of {\displaystyle n\times n} matrices. For injectivity, if we are given a {\displaystyle G}-invariant polynomial on {\displaystyle {\mathfrak {g}}} which vanishes on the set of diagonal matrices, by {\displaystyle G}-invariance, this polynomial vanishes on any matrix which is conjugate to a diagonal matrix. Since these elements are Zariski dense in {\displaystyle {\mathfrak {g}}}, this polynomial vanishes on a Zariski dense subset of {\displaystyle {\mathfrak {g}}} and thus must itself be the zero polynomial.

For surjectivity, it of course suffices to show that each {\displaystyle e_{i}} lies in the image of this map. Using Newton's identities and an inductive argument, it suffices to prove that the function {\displaystyle x_{1}^{i}+...+x_{n}^{i}} lies in the image of this map for every {\displaystyle i\in \{1,...,n\}}. However, in this case, one can explicitly construct an invariant function which restricts to {\displaystyle x_{1}^{i}+...+x_{n}^{i}} on diagonal matrices: it is given by the function {\displaystyle A\mapsto \mathrm {trace} (A^{i})}.

Here \mathbb C[\mathfrak t] denotes polynomial functions on the diagonal matrices, and its superscript W denotes invariance under permutations. Restriction preserves sums and products.
