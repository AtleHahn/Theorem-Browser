Statement

Let G=(V,E) be a finite undirected graph. It has a proper coloring with three colors if and only if it satisfies \exists A\,\exists B\,\exists C\;\forall v\bigl[(A(v)\lor B(v)\lor C(v))\land\forall w\,(E(v,w)\to(\neg(A(v)\land A(w))\land\neg(B(v)\land B(w))\land\neg(C(v)\land C(w))))\bigr], where A,B,C range over subsets of V.

Level
High school only
Level justification

The second-order variables are explicitly finite vertex subsets, so the formula is elementary subset and adjacency logic.

Proof 1: Remove surplus colors from the witnessing sets

In this formula, A,B,C are to be interpreted as the sets of vertices colored with the three colors, and E(v,w) is to be interpreted as saying the vertices v,w share an edge. The formula then states that no two adjacent vertices have the same color. A proper coloring satisfies it.

Note that there is no need to explicitly enforce each vertex to have exactly one color, just at least one color. Since, if we allow more than one color per vertex, and no two adjacent vertices have the same color, then we certainly can have each vertex have exactly one color, and still no two adjacent vertices have the same color.

High school only
Level justification

Interpret the explicit subset conditions as a cover with no shared color across an edge, and select one available color at each vertex. Elementary finite sets and logic suffice.
