Statement

The function H:(0,1)\to\mathbb R, H(x)=\tan(\pi x-\pi/2), is a bijection (one-to-one and onto).

Level
High school only
Level justification

The map uses familiar tangent, affine rescaling and the explicitly explained one-to-one and onto properties.

Proof 1: Compose the affine rescaling with tangent

Start with the tangent function \tan(x), which is a bijection from (-\pi/2,\pi/2) to \mathbb R. Next observe that the affine function h(x)=\pi x-\pi/2 is a bijection from (0,1) to (-\pi/2,\pi/2). The composite function \tan(h(x))=\tan(\pi x-\pi/2) is a bijection from (0,1) to \mathbb R.

Level justification
