Statement

Let L be first-order arithmetic, \mathbb N its standard model, and g a fixed effective Gödel numbering with its usual arithmetically definable substitution operation. There is no L-formula \mathrm{True}(n) such that for every L-sentence B, \mathbb N\models\mathrm{True}(g(B))\leftrightarrow B.

Proof 1: Diagonalize the proposed truth predicate — outline

We proceed by contradiction and assume that an L-formula \mathrm{True}(n) as in the statement exists. Restricting it to the arithmetically definable sentence codes, we may assume that it is true for the natural number n in \mathbb N if and only if n is the Gödel number of a sentence in L that is true in \mathbb N.

Using the arithmetical coding of substitution, we could then use \mathrm{True}(n) to define a new L-formula S(m) that is true for the natural number m if and only if m is the Gödel number of a formula \varphi(x) (with one free variable x) such that \varphi(m) is false when interpreted in \mathbb N (i.e. the formula \varphi(x), when applied to its own Gödel number, yields a false statement). If we now consider the Gödel number s=g(S) of the formula S(m), and ask whether the sentence S(s) is true in \mathbb N, we obtain a contradiction. This is a diagonal argument.

Level
Beyond undergraduate level
Level justification

The diagonal contradiction is short, but arithmetical representation of syntax and substitution, truth in the standard model and definability must be understood together. This is not confidently a small extension of ordinary undergraduate background.

Proof 2: Contradict strictness of the arithmetical hierarchy

Let T^* be the set of Gödel numbers of true L-sentences. An assumed truth predicate would define T^* after restriction to the arithmetically definable sentence codes.

A semantic proof from Post's theorem is obtained by contradiction as follows. Assuming T^* is arithmetically definable, there is a natural number n such that T^* is definable by a formula at level \Sigma_n^0 of the arithmetical hierarchy. However, T^* is \Sigma_k^0-hard for all k (under computable many-one reductions). Thus the arithmetical hierarchy collapses at level n, contradicting Post's theorem.
