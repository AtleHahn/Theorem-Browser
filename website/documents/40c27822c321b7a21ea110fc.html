Statement

All graphs here are finite and simple. A clique is a set of pairwise adjacent vertices, an independent set a set of pairwise nonadjacent vertices, and a proper coloring partitions vertices into independent color classes. Write \omega(G) for the largest clique size, \chi(G) for the minimum number of colors and \alpha(G) for the largest independent-set size. A graph is perfect when \chi(H)=\omega(H) for every induced subgraph H, including the empty graph with both quantities zero. In an n-vertex bipartite graph with maximum matching size M, the maximum independent-set size is n-M. A bipartite graph has its vertices partitioned into two independent sets; a matching is a set of pairwise disjoint edges.

Proof 1: Perfectness and the matching clique cover

In a bipartite graph with an edge, the optimal number of colors is (by definition) two, and (since bipartite graphs are triangle-free) the maximum clique size is also two. Also, any induced subgraph of a bipartite graph remains bipartite. For an edgeless induced subgraph, both numbers are zero or one. Therefore, bipartite graphs are perfect. In {\displaystyle n}-vertex bipartite graphs, a minimum clique cover takes the form of a maximum matching together with an additional clique for every unmatched vertex, with size {\displaystyle n-M}, where {\displaystyle M} is the cardinality of the matching. The perfect graph theorem says that the complement of a perfect graph is perfect, so the maximum independent-set size equals the minimum clique-cover size. Thus, in this case, it implies Kőnig's theorem that the size of a maximum independent set in a bipartite graph is also {\displaystyle n-M}.
