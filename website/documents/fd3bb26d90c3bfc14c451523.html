Statement

In ordinary classical set theory with separation, for a set A, write \mathcal P(A)=\{B:B\subseteq A\}. The comparison |A|<|C| means that an injection A\to C exists but no bijection does. For every set A, no map f:A\to\mathcal P(A) is surjective, and |A|<|\mathcal P(A)|.

Level
Within undergraduate level
Level justification

Undergraduate sets, functions, orders and infinite sequences suffice. Choice, well-ordering or maximal-chain principles are explicit set-selection/order assertions where invoked, not a demand to learn their independence proofs. The displayed quantifiers and constructions can be understood through familiar subsets and functions.

Proof 1: Diagonal subset and singleton injection

Let f:A\to\mathcal P(A) be any map.

The set {\displaystyle B=\{x\in A\mid x\notin f(x)\}} exists via the axiom schema of specification, and {\displaystyle B\in {\mathcal {P}}(A)} because {\displaystyle B\subseteq A}. Suppose towards a contradiction that {\displaystyle f} is surjective. Then there exists a {\displaystyle \xi \in A} such that {\displaystyle f(\xi )=B}. By the definition of {\displaystyle B}, we have {\displaystyle \xi \in B} if and only if {\displaystyle \xi \notin f(\xi )=B}. Having derived a contradiction by assuming an arbitrary map {\displaystyle f} is surjective, we conclude that no map from {\displaystyle A} to {\displaystyle {\mathcal {P}}(A)} is surjective. However, there exist injections from {\displaystyle A} to {\displaystyle {\mathcal {P}}(A)}, for instance {\displaystyle g:x\mapsto \{x\}}. Consequently, {\displaystyle \operatorname {card} (A)<\operatorname {card} ({\mathcal {P}}(A))}.

Level justification

The diagonal subset, surjectivity contradiction and singleton injection require introductory set theory and elementary logic. The stated separation principle merely permits the specified subset; neither advanced cardinal arithmetic nor a theory of formal axioms is needed.
