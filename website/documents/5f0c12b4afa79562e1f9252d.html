Statement

For a finite simple graph G=(V,E), a fractional matching assigns weights x_e\ge0 to edges with \sum_{e\ni v}x_e\le1 for every vertex. A fractional vertex cover assigns weights y_v\ge0 to vertices with y_u+y_v\ge1 on every edge uv. The maximum of \sum_ex_e equals the minimum of \sum_vy_v.

Proof 1: Identify the primal and dual linear programs

The maximum fractional matching size in a graph G=(V,E) is the solution of the following linear program:

\begin{aligned} &\text{Maximize } \mathbf1_E\cdot x\\ &\text{subject to }x\ge\mathbf0_E,\qquad A_Gx\le\mathbf1_V. \end{aligned}

Here x is a vector of size |E| in which each element represents the weight of an edge in the fractional matching. \mathbf1_E is a vector of |E| ones, so the objective indicates the size of the matching. \mathbf0_E is a vector of |E| zeros, so the first constraint indicates that the weights are non-negative. \mathbf1_V is a vector of |V| ones and A_G is the vertex-edge incidence matrix of G, so the last constraint indicates that the sum of weights near each vertex is at most 1.

Similarly, the minimum fractional vertex-cover size in G=(V,E) is the solution of the following LP:

\begin{aligned} &\text{Minimize } \mathbf1_V\cdot y\\ &\text{subject to }y\ge\mathbf0_V,\qquad A_G^Ty\ge\mathbf1_E. \end{aligned}

Here y is a vector of size |V| in which each element represents the weight of a vertex in the fractional cover. The objective is the size of the cover, the first constraint represents the non-negativity of the weights, and the last represents the requirement that the sum of weights at the endpoints of each edge must be at least 1.

Now, the minimum fractional cover LP is exactly the dual linear program of the maximum fractional matching LP. Therefore, by the LP duality theorem, both programs have the same optimal value. This fact is true not only in bipartite graphs but in arbitrary finite simple graphs.
