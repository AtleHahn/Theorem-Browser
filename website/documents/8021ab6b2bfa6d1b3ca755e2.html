Proof 1: Rational cuts and separated binary expansions — outline

Cantor's theorem states that the cardinality of any set is strictly less than that of its power set. That is, |A|<2^{|A|} (and so the power set \mathcal P(\mathbb N) of the natural numbers \mathbb N is uncountable). In fact, the cardinality of \mathcal P(\mathbb N), by definition 2^{\aleph_0}, is equal to \mathfrak c. This can be shown by providing one-to-one mappings in both directions between subsets of a countably infinite set and real numbers, and applying the Cantor–Bernstein–Schroeder theorem according to which two sets with one-to-one mappings in both directions have the same cardinality.

In one direction, reals can be equated with Dedekind cuts, sets of rational numbers; the rationals are countably infinite. In the other direction, binary expansions, viewed as sets of positions where the expansion is one, almost give a one-to-one mapping from subsets of a countable set (the set of positions in the expansions) to real numbers, but it fails to be one-to-one for numbers with terminating binary expansions, which can also be represented by a non-terminating expansion that ends in a repeating sequence of 1s. This can be made into a one-to-one mapping by adding one to the non-terminating repeating-1 expansions, mapping them into (1,2]. More explicitly, for a binary sequence (a_k)_{k\geq1} with value \sum_{k\geq1}a_k2^{-k}, add one exactly when the sequence is eventually all ones. Thus, we conclude that

\mathfrak c=|\mathcal P(\mathbb N)|=2^{\aleph_0}.

Together with Cantor's theorem, this gives \aleph_0<\mathfrak c.

Proof 2: Decimal upper bound and digits 3 and 7 — outline

Every real number has at least one infinite decimal expansion. For example,

1/2=0.50000\ldots,\qquad 1/3=0.33333\ldots,\qquad \pi=3.14159\ldots.

(This is true even in the case the expansion repeats, as in the first two examples.)

In any given case, the number of decimal places is countable since they can be put into a one-to-one correspondence with the set of natural numbers \mathbb N. This makes it sensible to talk about, say, the first, the one-hundredth, or the millionth decimal place of \pi. Since the natural numbers have cardinality \aleph_0, each real number has \aleph_0 digits in its expansion.

Since each real number can be broken into an integer part and a decimal fraction, we get:

\mathfrak c\leq\aleph_0\cdot10^{\aleph_0} \leq2^{\aleph_0}\cdot(2^4)^{\aleph_0} =2^{\aleph_0+4\cdot\aleph_0}=2^{\aleph_0},

where we used the fact that

\aleph_0+4\cdot\aleph_0=\aleph_0.

On the other hand, if we map 2=\{0,1\} to \{3,7\} and consider that decimal fractions containing only 3 or 7 are only a part of the real numbers, then we get

2^{\aleph_0}\leq\mathfrak c

and thus, by the Cantor–Bernstein theorem,

\mathfrak c=2^{\aleph_0}.

Cantor's power-set theorem gives the strict inequality \aleph_0<\mathfrak c.
