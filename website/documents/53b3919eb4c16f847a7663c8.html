Statement

If r\ge1 is an integer and x_1<\cdots<x_{2r-1} are real numbers, the sets A_i=\{x_i,x_{2r-i}\}, 1\le i\le r, form a partition into r nonempty parts whose convex hulls all contain x_r.

Level

Proof 1: Pair the extremes around the median — outline

The case d=1 of the Tverberg construction states that any 2r-1 points on the real line can be partitioned into r subsets with intersecting convex hulls. Indeed, if the points are x_1<x_2<\cdots<x_{2r-1}, then the partition into

A_i=\{x_i,x_{2r-i}\},\qquad i=1,\ldots,r,

satisfies this condition.

The common point is x_r; the source leaves the interval check implicit.

Level
High school only
Level justification

Pair each point below the median with the corresponding point above it and keep the median singleton. Each resulting interval contains the median. School real ordering and finite sets suffice.
