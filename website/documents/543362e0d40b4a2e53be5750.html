Statement

Let n\ge1 be an integer and let permutations act on \{1,\ldots,n\}. For x_1\le\cdots\le x_n and y_1\le\cdots\le y_n in \mathbb R, and any permutation \sigma, \sum_i x_i y_{n-i+1}\le\sum_i x_i y_{\sigma(i)}\le\sum_i x_i y_i. If x_1<\cdots<x_n, upper equality holds exactly when the permuted y-values are nondecreasing, and lower equality exactly when they are nonincreasing.

Level
High school only
Level justification

The inequalities and conditional equality cases use only ordered real numbers and finite permutations.

Proof 1: Place the largest pair and induct

The one-term case is immediate.

The lower bound and the corresponding discussion of equality follow by applying the results for the upper bound to {\textstyle -y_{n}\leq \cdots \leq -y_{1}}, that is, let {\displaystyle \upsilon } be any permutation of the numbers {\textstyle 1,2,\ldots n} we have {\textstyle x_{1}(-y_{\upsilon (1)})+\cdots +x_{n}(-y_{\upsilon (n)})\leq x_{1}(-y_{n})+\cdots +x_{n}(-y_{1})}. Then, {\textstyle x_{1}y_{n}+\cdots +x_{n}y_{1}\leq x_{1}y_{\upsilon (1)}+\cdots +x_{n}y_{\upsilon (n)}} for every permutation {\displaystyle \upsilon } of {\displaystyle 1,\dots ,n}.

Thus, it suffices to treat the upper bound in the statement. For a proof by mathematical induction, we start with {\displaystyle n=2.} Observe that

{\displaystyle x_{1}\leq x_{2}\quad {\text{ and }}\quad y_{1}\leq y_{2}}

implies that

{\displaystyle 0\leq (x_{2}-x_{1})(y_{2}-y_{1}),}

which is equivalent to

{\displaystyle x_{1}y_{2}+x_{2}y_{1}\leq x_{1}y_{1}+x_{2}y_{2},}

hence the upper bound in the statement is true for {\displaystyle n=2.} If {\displaystyle x_{1}<x_{2},} then we get strict inequality in the two displayed inequalities if and only if {\displaystyle y_{1}<y_{2}.} Hence only the identity, which is the only permutation here keeping the order of {\displaystyle y_{1}<y_{2},} gives the maximum.

As an induction hypothesis assume that the upper bound in the statement is true for {\displaystyle n-1} with {\displaystyle n\geq 3} and that in the case {\displaystyle x_{1}<\cdots <x_{n-1}} there is equality only when the permutation {\displaystyle \sigma } of {\displaystyle 1,\ldots ,n-1} keeps the order of {\displaystyle y_{1},\ldots ,y_{n-1}.}

Consider now {\displaystyle x_{1}\leq \cdots \leq x_{n}} and {\displaystyle y_{1}\leq \cdots \leq y_{n}.} Take a {\displaystyle \sigma } from the finite number of permutations of {\displaystyle 1,\ldots ,n} such that the rearrangement in the middle of the statement gives the maximal result. There are two cases:

  • If {\displaystyle \sigma (n)=n,} then {\displaystyle y_{n}=y_{\sigma (n)}} and, using the induction hypothesis, the upper bound in the statement is true with equality and {\displaystyle \sigma } keeps the order of {\displaystyle y_{1},\ldots ,y_{n-1},y_{n}} in the case {\displaystyle x_{1}<\cdots <x_{n}.}

  • If {\displaystyle k:=\sigma (n)<n,} then there is a {\displaystyle j\in \{1,\dots ,n-1\}} with {\displaystyle \sigma (j)=n.} Define the permutation

    {\displaystyle \tau (i)={\begin{cases}\sigma (i)&{\text{for }}i\in \{1,\ldots ,n\}\setminus \{j,n\},\\k&{\text{for }}i=j,\\n&{\text{for }}i=n,\end{cases}}}

    which arises from {\displaystyle \sigma } by exchanging the values of {\displaystyle j} and {\displaystyle n.} There are now two subcases:

  1. If {\displaystyle x_j=x_n} or {\displaystyle y_n=y_k,} then this exchange of values of {\displaystyle \sigma } has no effect on the middle term in the statement because {\displaystyle \tau } gives the same sum, and we can proceed by applying the first case to {\displaystyle \tau .} Note that in the case {\displaystyle x_{1}<\cdots <x_{n},} the permutation {\displaystyle \tau } keeps the order of {\displaystyle y_{1},\ldots ,y_{n}} if and only if {\displaystyle \sigma } does.
  2. If {\displaystyle x_{j}<x_{n}} and {\displaystyle y_{k}<y_{n},} then {\displaystyle 0<(x_{n}-x_{j})(y_{n}-y_{k}),} which is equivalent to {\displaystyle x_{j}y_{\sigma(j)}+x_{n}y_{\sigma(n)}<x_{j}y_{\tau(j)}+x_{n}y_{\tau(n)}} and shows that {\displaystyle \sigma } is not optimal, hence this case cannot happen due to the choice of {\displaystyle \sigma .}
