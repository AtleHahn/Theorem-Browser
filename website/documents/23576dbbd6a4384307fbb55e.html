Statement

For an integer n\ge1, use deterministic Turing machines with n operational states, a separate Halt state, one starting state, a two-way unbounded tape over \{0,1\}, and a transition for each operational state and scanned symbol. Each transition writes a bit, moves one cell left or right, and enters a state (possibly Halt). The machine starts on an all-zero tape. Among machines that halt, \Sigma(n) is the largest number of ones left on the tape, and S(n) the largest number of transitions, including the halting transition. Define \operatorname{space}(n) as the largest number of tape cells read before halting, excluding a cell reached only by the final move; define \operatorname{num}(n) as the largest unary block output by a halting machine (with no other ones). Each of S,\Sigma,\operatorname{space},\operatorname{num} is nondecreasing as a function of n.

Level
High school only
Level justification

The statement supplies the complete finite transition-table rules and defines all four maxima by counting steps, ones, visited cells or a unary block among halting runs. Understanding a maximum over these finitely many tables and nondecreasing dependence on the allowed state count needs elementary finite rules and comparisons; it does not require deciding which arbitrary machines halt.

Proof 1: Adding an unused operational state

Every n-state machine can be treated as an (n+1)-state machine by adding an unused operational state. Its blank-tape computation, running time, score, visited cells and unary output do not change. The maxima for (n+1) states are therefore at least those for n.

Level justification

Adding an unreachable state leaves every run unchanged. Comparing maxima over the resulting nested finite collections requires only elementary finite rules and inequalities; the machine model is fully described.
