Statement

Let f:\{0,1\}^n\to\{0,1\}, where n\ge1 is an integer. The operations + and multiplication mean OR and AND, respectively, and x^{\prime}=1-x is Boolean complementation. The function f can be expressed as a disjunction of conjunctions, each conjunction containing one literal x_j or x_j^{\prime} for each input. The empty disjunction represents the constant zero function.

Level
High school only
Level justification

The function has a finite binary input table, and the statement defines AND, OR, complementation and the empty disjunction. The claimed representation combines one literal per input into finite conjunctions and then disjoins them. Reading this construction requires elementary Boolean case reasoning with the supplied definitions, not formal-logic theory.

Proof 1: Iterate Shannon decomposition — outline

Use the Shannon expansion f(x_1,\ldots,x_n)=x_1f(1,x_2,\ldots,x_n)+x_1^\prime f(0,x_2,\ldots,x_n).

Repeated application for each argument leads to the Sum of Products (SoP) canonical form of the Boolean function {\displaystyle f}. For example, for {\displaystyle n=2} that would be

{\displaystyle {\begin{aligned}f(x_{1},x_{2})&=x_{1}\cdot f(1,x_{2})+x_{1}'\cdot f(0,x_{2})\\&=x_{1}x_{2}\cdot f(1,1)+x_{1}x_{2}'\cdot f(1,0)+x_{1}'x_{2}\cdot f(0,1)+x_{1}'x_{2}'\cdot f(0,0)\end{aligned}}}
Level
High school only
Level justification

Split on each variable using Shannon’s two-case identity. After all variables are fixed, each terminal coefficient is zero or one; discard the zero terms and retain the conjunctions for true truth-table rows. This is finite Boolean expansion.
