Statement

A finite hypergraph H=(X\sqcup Y,E) is bipartite here if every edge contains exactly one vertex of Y. A matching consists of pairwise disjoint edges and is Y-perfect if it covers Y. For S\subseteq Y, put N(S)=\{e\setminus Y:e\in E,\ e\cap S\ne\varnothing\}. Fix an integer r\ge2, put d=r-1, Y=\{0,1\} and X=\{x_{ij}:1\le i,j\le d\}. The edges tagged 0 are all \{0,x_{i1},\ldots,x_{id}\}, and those tagged 1 are all \{1,x_{1j_1},\ldots,x_{dj_d}\}, where each 1\le j_i\le d. There is no Y-perfect matching, but every N(S) has minimum vertex-cover size at least (2r-3)(|S|-1).

Level
High school only
Level justification

Hyperedges, bipartiteness, matching and neighborhood families are explicitly finite sets on a d by d array. Minimum vertex cover means a smallest set meeting each edge, clarified in the proof. Understanding the obstruction and inequality requires finite intersections and counting.

Proof 1: Relabel selected row points and count remaining columns — outline

Write \tau(N(S)) for the minimum number of vertices meeting every edge of N(S).

This H does not admit a Y-perfect matching, since every hyperedge that contains 0 intersects every hyperedge that contains 1.

However, every subset Y0 of Y satisfies the following inequality:

{\displaystyle \tau(N(Y_0))\geq (2r-3)\cdot (|Y_{0}|-1)}

To verify this, it is sufficient to check the subset Y0 = Y, since it is the only subset for which the right-hand side is larger than 0. The neighborhood-hypergraph of Y is (X, E00 ∪ E11) where:

{\displaystyle E_{00}=\{\{x_{i1},\ldots ,x_{i(r-1)}\}|1\leq i\leq r-1\}}

{\displaystyle E_{11}=\{\{x_{1j[1]},\ldots ,x_{(r-1)j[r-1]}\}|1\leq j[k]\leq r-1}

for {\displaystyle 1\leq k\leq r-1\}}

One can visualize the vertices of X as arranged on an (r – 1) × (r – 1) grid. The hyperedges of E00 are the r – 1 rows. The hyperedges of E11 are the (r – 1)r-1 selections of a single element in each row. To cover the hyperedges of E00 we need r – 1 vertices - one vertex in each row. Since column labels can be permuted independently within each row without changing the construction, we can assume that we take all the vertices in column 1 (i.e., xi1 for each i in {1, …, r – 1}). Now, since E11 contains all columns, we need at least r – 2 additional vertices - one vertex for each column {2, …, r − 1}. All in all, each transversal requires at least 2r – 3 vertices.
