Statement

For integers u>v>0 run Euclidean division with v_0=u, v_1=v, v_{n+1}=0 and

v_{i-1}=q_iv_i+v_{i+1}\quad(1\leq i\leq n),\qquad u>v>v_2>\cdots>v_n>0.

The final zero-remainder division is counted, so n is the number of divisions. Let F_0=0,F_1=1 and F_{j+1}=F_j+F_{j-1} for j≥1. Then v≥F_{n+1}.

Proof 1: Compare remainders backwards with Fibonacci numbers

If n=1, the result is v\ge1=F_2. Assume n\ge2.

The division relations show that {\displaystyle v_{n}\geq 1=F_{2},} and {\displaystyle v_{n-1}\geq 2=F_{3}.} By induction,

{\displaystyle {\begin{aligned}v_{n-i-1}&=q_{n-i}v_{n-i}+v_{n-i+1}\\&\geq v_{n-i}+v_{n-i+1}\\&\geq F_{i+2}+F_{i+1}=F_{i+3}.\end{aligned}}}

So, if the Euclidean algorithm requires n steps, one has {\displaystyle v\geq F_{n+1}.}

Start at the last two positive remainders and work backward using each quotient at least one. The resulting lower bounds obey the Fibonacci recurrence.
