Statement

For an odd prime p, write (a/p)=0 if p\mid a, 1 if a is a nonzero square modulo p, and -1 otherwise. For distinct positive odd primes p,q, (p/q)(q/p)=(-1)^{((p-1)/2)((q-1)/2)}.

Proof 1: Swap the factors in Kronecker’s sign product — outline

Use the source-cited Kronecker identity (p/q)=\operatorname{sgn}\prod_{i=1}^{(q-1)/2}\prod_{k=1}^{(p-1)/2}(k/p-i/q), obtained externally from Gauss’s lemma. Interchange p and q. Each factor changes sign, and the number of factors is ((p-1)/2)((q-1)/2), giving the stated reciprocity sign.

Level justification

Proof 2: Specialize Gauss’s multiprime parity theorem — outline

Use Gauss’s stated multiprime theorem: for distinct odd primes r_1,\ldots,r_k, put n=\prod r_j and let m count those congruent to 3 modulo 4. The number of nonresidue characters (n/r_j\,/\,r_j)=-1 is even if m\equiv0,1\pmod4 and odd if m\equiv2,3\pmod4. Restrict to the two primes p,q. The two characters are (q/p) and (p/q); their product is negative exactly when both primes are 3 modulo 4. This is the stated formula.
