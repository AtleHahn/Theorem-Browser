Statement

Let ABCD be a planar quadrilateral with no three consecutive vertices collinear, and let E,F,G,H be the consecutive midpoints of AB,BC,CD,DA. Then EFGH is a rectangle if and only if AC\perp BD.

Level
High school only
Level justification

The stated configuration and equivalence use elementary plane geometry.

Proof 1: Use the midpoint side directions — outline

Triangles ADC and HDG are similar by the side-angle-side criterion, since DH=DA/2, DG=DC/2, and the angle at D is common. So angles DAC and DHG are equal, making HG parallel to AC. In the same way EF is parallel to AC, so HG and EF are parallel to each other; the same holds for HE and GF.

A side of the Varignon parallelogram is half as long as the diagonal in the original quadrilateral it is parallel to.

The Varignon parallelogram is a rectangle if and only if the diagonals of the quadrilateral are perpendicular, that is, if the quadrilateral is an orthodiagonal quadrilateral. The final right-angle check using these side directions is implicit in the source.
