Statement

Let L(\phi^A,\partial_\nu\phi^A) be a smooth first-order Lagrangian density with no explicit coordinate dependence on a spacetime domain. Write p_A^\mu=\partial L/\partial(\partial_\mu\phi^A); repeated indices are summed. Assume the Euler–Lagrange equations \partial_\mu p_A^\mu=\partial L/\partial\phi^A. On a smooth Euler–Lagrange solution, T_\mu{}^\nu=p_A^\nu\partial_\mu\phi^A-\delta_\mu^\nu L satisfies \partial_\nu T_\mu{}^\nu=0 for each \mu.

Level
Within undergraduate level
Level justification

Understanding the statement involves Multivariable partial derivatives; Finite sums and Kronecker delta; Explicit Euler–Lagrange identities. These prerequisites fit undergraduate coursework or a brief extension of it. A bright US college student should be able to understand this statement after approximately 30 minutes of focused background research; this assesses understanding the claim, not its proof.

Proof 1: Four translation currents

Use the field Noether theorem: if a field variation \Psi_r^A changes L by \varepsilon_r\partial_\nu\Lambda_r^\nu, then j_r^\nu=\Lambda_r^\nu-p_A^\nu\Psi_r^A has zero divergence on Euler–Lagrange solutions. In the following notation \varphi=(\phi^A)_A denotes the collection of fields, and a dot contracts their field indices; a comma denotes a coordinate derivative.

An infinitesimal translation in space, {\displaystyle x^{\mu }\mapsto x^{\mu }+\varepsilon _{r}\delta _{r}^{\mu }} (with {\displaystyle \delta } denoting the Kronecker delta), affects the fields as {\displaystyle \varphi (x^{\mu })\mapsto \varphi \left(x^{\mu }-\varepsilon _{r}\delta _{r}^{\mu }\right)}: that is, relabelling the coordinates is equivalent to leaving the coordinates in place while translating the field itself, which in turn is equivalent to transforming the field by replacing its value at each point {\displaystyle x^{\mu }} with the value at the point {\displaystyle x^{\mu }-\varepsilon_r\delta_r^{\mu }} "behind" it which would be mapped onto {\displaystyle x^{\mu }} by the infinitesimal displacement under consideration. Since this is infinitesimal, we may write this transformation as

{\displaystyle \Psi _{r}=-\delta _{r}^{\mu }\partial _{\mu }\varphi .}

The Lagrangian density transforms in the same way, {\displaystyle {L}\left(x^{\mu }\right)\mapsto {L}\left(x^{\mu }-\varepsilon _{r}\delta _{r}^{\mu }\right)}, so

{\displaystyle \Lambda _{r}^{\mu }=-\delta _{r}^{\mu }{L}}

and thus Noether's theorem corresponds to the conservation law for the stress–energy tensor Tμν, where we have used {\displaystyle \mu } in place of {\displaystyle r}. To wit, by using the current formula j_r^\nu=\Lambda_r^\nu-p_A^\nu\Psi_r^A, and collecting the conserved currents (one for each {\displaystyle \mu }) into a tensor {\displaystyle T}, Noether's theorem gives

{\displaystyle T_{\mu }{}^{\nu }=-\delta _{\mu }^{\nu }{L}+\delta _{\mu }^{\sigma }\partial _{\sigma }\varphi {\frac {\partial {L}}{\partial \varphi _{,\nu }}}=\left({\frac {\partial {L}}{\partial \varphi _{,\nu }}}\right)\cdot \varphi _{,\mu }-\delta _{\mu }^{\nu }{L}}

with

{\displaystyle T_{\mu }{}^{\nu }{}_{,\nu }=0}

(we relabelled {\displaystyle \mu } as {\displaystyle \sigma } at an intermediate step to avoid conflict).
