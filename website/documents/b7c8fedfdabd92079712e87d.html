Statement

Let \tau,\sigma be topological vector space topologies on a real or complex vector space X, and suppose U is a zero neighborhood for both. Then \{f\in(X,\tau)':\sup_{u\in U}|f(u)|\le1\}=\{f\in(X,\sigma)':\sup_{u\in U}|f(u)|\le1\}.

Proof 1: Both polars equal the algebraic polar

Write X^\# for the algebraic dual, the scalar-valued linear maps on X, and put

U^\#=\{f\in X^\#:\sup_{u\in U}|f(u)|\leq1\}.

A linear functional bounded on a neighborhood of the origin is continuous. Thus, for either topology, the continuous-dual polar equals U^\#.

Denote the continuous dual space of (X,\sigma) by (X,\sigma)' and denote the polar of U with respect to (X,\sigma) by

U^{\circ,\sigma}:=\{f\in(X,\sigma)':\sup_{u\in U}|f(u)|\leq1\},

and use the analogous notation for \tau. Then U^{\circ,\tau}=U^{\circ,\sigma} because both of these sets are equal to U^\#. Said differently, the polar set U^{\circ,\sigma}'s defining requirement that it be a subset of the continuous dual space (X,\sigma)' is inconsequential and can be ignored because it does not have any effect on the resulting set of linear functionals.

Level justification

Compare algebraic and continuous dual polars using boundedness on a neighborhood in each arbitrary vector topology. General topological vector spaces and their duality are graduate functional analysis; the set equality does not eliminate those prerequisites.
