Statement

Let \nabla be a smooth affine connection on a smooth m-manifold. In a coordinate chart (x^1,\ldots,x^m) write \partial_i=\partial/\partial x^i and (\nabla_XY)^i=X^j\partial_jY^i+X^jY^k\Gamma^i_{jk}. Repeated upper/lower indices are summed from 1 to m. The connection is torsion-free, meaning \nabla_XY-\nabla_YX=[X,Y] for all smooth vector fields X,Y, if and only if \Gamma^i_{jk}=\Gamma^i_{kj} in every chart.

Proof 1: Expand the torsion in coordinates

Here the Einstein summation convention will be used, which is to say that an index repeated as both subscript and superscript is being summed over all values. Let m denote the dimension of the manifold. Recall that, relative to a local chart, a connection is given by m^3 smooth functions

\{\Gamma^l{}_{ij}\},

with

(\nabla_XY)^i=X^j\partial_jY^i+X^jY^k\Gamma^i{}_{jk}

for any vector fields X and Y. Torsion-freeness of the connection refers to the condition that \nabla_XY-\nabla_YX=[X,Y] for arbitrary X and Y. Written in terms of local coordinates, this is equivalent to

0=X^jY^k(\Gamma^i{}_{jk}-\Gamma^i{}_{kj}),

which by arbitrariness of X and Y is equivalent to the condition \Gamma^i{}_{jk}=\Gamma^i{}_{kj}.

Level justification

The coordinate cancellation takes place in an affine connection and Lie bracket of smooth vector fields on a manifold. Understanding those geometric objects and their coordinate meaning exceeds ordinary multivariable calculus.
