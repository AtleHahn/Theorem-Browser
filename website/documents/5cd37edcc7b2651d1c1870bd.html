Statement

Let G be a noncompact connected real semisimple Lie group with finite center, and let K be a maximal compact subgroup, the fixed subgroup of a Cartan involution. Write \mathfrak g=\mathfrak k\oplus\mathfrak p for the corresponding Lie-algebra decomposition, choose a maximal abelian subspace \mathfrak a\subset\mathfrak p, and fix an Iwasawa decomposition G=KAN, where A=\exp\mathfrak a. A function is K-biinvariant if f(k_1gk_2)=f(g) for all k_1,k_2\in K.

For a nonzero linear form \alpha\in\mathfrak a^* put

\mathfrak g_\alpha=\{X\in\mathfrak g:[H,X]=\alpha(H)X\text{ for all }H\in\mathfrak a\}.

The restricted roots are those \alpha with m_\alpha=\dim\mathfrak g_\alpha>0. Choose positive roots \Sigma^+, put \rho=\frac12\sum_{\alpha\in\Sigma^+}m_\alpha\alpha, and let \Sigma_0^+ consist of the positive roots for which \alpha/2 is not a root. Set m_{2\alpha}=0 when 2\alpha is not a root. Use the inner product induced by the Killing form to identify \mathfrak a with its dual, and write \alpha_0=\alpha/(\alpha,\alpha). Let \mathfrak a_+^* be a positive Weyl chamber for W=N_K(A)/C_K(A) (normalizer modulo centralizer).

For \lambda\in\mathfrak a^* let \chi_\lambda(\exp H)=e^{i\lambda(H)}, extend this character to AN by making it trivial on N, and set

\chi'_\lambda(kx)=\Delta_{AN}(x)^{1/2}\chi_\lambda(x),\qquad k\in K,\ x\in AN,

where \Delta_{AN} is the modular function of the group AN. The normalized spherical function is

\varphi_\lambda(g)=\int_K\chi'_\lambda(gk)^{-1}\,dk,

with dk the probability Haar measure on K. Define the meromorphic c-function by

c(\lambda)=c_0\prod_{\alpha\in\Sigma_0^+}\frac{2^{-i(\lambda,\alpha_0)}\Gamma(i(\lambda,\alpha_0))}{\Gamma\bigl(\tfrac12[\tfrac12m_\alpha+1+i(\lambda,\alpha_0)]\bigr)\Gamma\bigl(\tfrac12[\tfrac12m_\alpha+m_{2\alpha}+i(\lambda,\alpha_0)]\bigr)},

where \Gamma is the Euler gamma function and c_0 is chosen so that c(-i\rho)=1.

Choose compatible normalizations of Haar measure dg on G and Lebesgue measure d\lambda on the chamber in the following inversion convention. For f\in C_c^\infty(K\backslash G/K), the smooth compactly supported biinvariant functions, set

\widetilde f(\lambda)=\int_G f(g)\varphi_{-\lambda}(g)\,dg.

Then the inversion formula is

f(g)=\int_{\mathfrak a_+^*}\widetilde f(\lambda)\varphi_\lambda(g)|c(\lambda)|^{-2}\,d\lambda.

The transform extends uniquely to a unitary map

L^2(K\backslash G/K,dg)\longrightarrow L^2(\mathfrak a_+^*,|c(\lambda)|^{-2}d\lambda).

Thus it is onto and preserves the L^2 inner product. For every integrable biinvariant h, it takes convolution by h to multiplication by \widetilde h: if (h*f)(g)=\int_Gh(x)f(x^{-1}g)\,dx, then \widetilde{h*f}=\widetilde h\,\widetilde f for f\in L^2(K\backslash G/K). The chamber boundary is immaterial for these L^2 statements.
