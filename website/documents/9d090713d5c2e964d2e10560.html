Statement

Let A\in K^{m\times n} and b\in K^m over a field K. The system Ax=b is solvable iff \operatorname{rank}A=\operatorname{rank}[A\mid b]. If solvable, its solution set is an affine subspace of K^n of dimension n-\operatorname{rank}A. It has one solution if that dimension is zero, infinitely many if it is positive and K infinite, and |K|^{n-\operatorname{rank}A} solutions if K is finite.

Level
Within undergraduate level
Level justification

Matrix rank, linear equations, affine solution spaces and dimension are standard undergraduate linear algebra over a field. The finite-field solution count uses only independent coordinates.

Proof 1: Read consistency and free variables from row echelon form

The use of Gaussian elimination for putting the augmented matrix in reduced row echelon form does not change the set of solutions and the ranks of the involved matrices. The theorem can be read almost directly on the reduced row echelon form as follows.

The rank of a matrix is the number of nonzero rows in its reduced row echelon form. If the ranks of the coefficient matrix and the augmented matrix are different, then the last non zero row has the form {\displaystyle [0\ldots 0\mid 1],} corresponding to the equation 0 = 1. Otherwise, the ith row of the reduced row echelon form allows expressing the ith pivot variable as the sum of a constant and a linear combination of the non-pivot variables, showing that the dimension of the set of solutions is the number of non-pivot variables.

Assigning arbitrary field values to the non-pivot variables gives the stated solution counts.

Level justification

Read consistency, affine dimension and solution counts from Gaussian elimination. Undergraduate linear algebra over a field suffices; no finite-field extension theory is involved.
