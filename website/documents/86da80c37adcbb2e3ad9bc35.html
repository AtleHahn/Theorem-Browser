Statement

Define f:\mathbb R^2\to\mathbb R by f(0,0)=0 and f(x,y)=xy/(x^2+y^2) otherwise. This function is real analytic in each variable separately, and both partial derivatives at the origin exist, but f is not continuous at the origin. No choice of value at the origin makes the displayed rational function continuous there.

Proof 1: Explicit rational function and unequal line limits — outline

A counterexample in two dimensions is given, away from the origin, by

{\displaystyle f(x,y)={\frac {xy}{x^{2}+y^{2}}}.}

If in addition we define {\displaystyle f(0,0)=0}, this function has well-defined partial derivatives in {\displaystyle x} and {\displaystyle y} at the origin, but it is not continuous at origin. (Indeed, the limits along the lines {\displaystyle x=y} and {\displaystyle x=-y} are not equal, so there is no way to extend the definition of {\displaystyle f} to include the origin and have the function be continuous there.)
