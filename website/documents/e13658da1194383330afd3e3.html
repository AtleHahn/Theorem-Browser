Statement

Let n_1,n_2>1 be coprime integers and let a_1,a_2,m_1,m_2\in\mathbb Z satisfy m_1n_1+m_2n_2=1. Then x=a_1m_2n_2+a_2m_1n_1 satisfies x\equiv a_i\pmod{n_i} for i=1,2.

Level
High school only
Level justification

The statement gives integer coefficients and a two-modulus formula, using only elementary modular arithmetic.

Proof 1: Expand the Bézout coefficients

Set x=a_1m_2n_2+a_2m_1n_1, using the given identity m_1n_1+m_2n_2=1.

Indeed,

{\displaystyle {\begin{aligned}x&=a_{1}m_{2}n_{2}+a_{2}m_{1}n_{1}\\&=a_{1}(1-m_{1}n_{1})+a_{2}m_{1}n_{1}\\&=a_{1}+(a_{2}-a_{1})m_{1}n_{1},\end{aligned}}}

implying that {\displaystyle x\equiv a_{1}{\pmod {n_{1}}}.} The second congruence is proved similarly, by exchanging the subscripts 1 and 2.

Level
High school only
Level justification

Insert the given Bezout identity to write x-a1 as a multiple of n1, and swap indices for the second congruence. School integer algebra suffices.
