Statement

Let f:(0,\infty)\to(0,\infty) satisfy f(1)=1, f(x+1)=xf(x) for every x>0, and suppose \log f is convex. Then for every x>0, f(x)=\lim_{n\to\infty}\frac{n^xn!}{x(x+1)\cdots(x+n)}.

Level
Within undergraduate level
Level justification

Understanding the statement involves real functions; logarithmic convexity; factorials; sequence limits. These prerequisites fit undergraduate coursework or a brief extension of it. A bright US college student should be able to understand this statement after approximately 30 minutes of focused background research; this assesses understanding the claim, not its proof.

Proof 1: Squeeze between convex secant bounds

Fix 0<x\le1 and an integer n\ge2. Iterating the recurrence gives

{\displaystyle f (x+n)=(x+n-1)(x+n-2)(x+n-3)\cdots (x+1)xf (x)}

The purpose of the stipulation that f(1) = 1 forces the f(x + 1) = xf(x) property to duplicate the factorials of the integers so we can conclude now that f(n) = (n − 1)! if n ∈ N and if f(x) exists at all. Because of our relation for f(x + n), if we can fully understand f(x) for 0 < x ≤ 1 then we understand f(x) for all values of x.

For x1, x2, the slope S(x1, x2) of the line segment connecting the points (x1, log(f (x1))) and (x2, log(f (x2))) is monotonically increasing in each argument with x1 < x2 since we have stipulated that log(f(x)) is convex. Thus, we know that

{\displaystyle S(n-1,n)\leq S(n,n+x)\leq S(n,n+1)\quad {\text{for all }}x\in (0,1].}

After simplifying using the various properties of the logarithm, and then exponentiating (which preserves the inequalities since the exponential function is monotonically increasing) we obtain

{\displaystyle (n-1)^{x}(n-1)!\leq f (n+x)\leq n^{x}(n-1)!.}

Using the recurrence product, this expands to

{\displaystyle (n-1)^{x}(n-1)!\leq (x+n-1)(x+n-2)\cdots (x+1)xf (x)\leq n^{x}(n-1)!,}

and so

{\displaystyle {\frac {(n-1)^{x}(n-1)!}{(x+n-1)(x+n-2)\cdots (x+1)x}}\leq f (x)\leq {\frac {n^{x}n!}{(x+n)(x+n-1)\cdots (x+1)x}}\left({\frac {n+x}{n}}\right).}

The last line is a strong statement. In particular, it is true for all integers n ≥ 2. That is f(x) is not greater than the right hand side for any choice of n and likewise, f(x) is not less than the left hand side for any other choice of n. Each single inequality stands alone and may be interpreted as an independent statement. Because of this fact, we are free to choose different values of n for the RHS and the LHS. In particular, if we keep n for the RHS and choose n + 1 for the LHS we get:

{\displaystyle {\begin{aligned}{\frac {((n+1)-1)^{x}((n+1)-1)!}{(x+(n+1)-1)(x+(n+1)-2)\cdots (x+1)x}}&\leq f (x)\leq {\frac {n^{x}n!}{(x+n)(x+n-1)\cdots (x+1)x}}\left({\frac {n+x}{n}}\right)\\{\frac {n^{x}n!}{(x+n)(x+n-1)\cdots (x+1)x}}&\leq f (x)\leq {\frac {n^{x}n!}{(x+n)(x+n-1)\cdots (x+1)x}}\left({\frac {n+x}{n}}\right)\end{aligned}}}

It is evident from this last line that a function is being sandwiched between two expressions, a common analysis technique to prove various things such as the existence of a limit, or convergence. Let n → ∞:

{\displaystyle \lim _{n\to \infty }{\frac {n+x}{n}}=1}

Writing

A_n(x)=\frac{n^xn!}{(x+n)(x+n-1)\cdots(x+1)x},

the last inequality gives

\frac{f(x)}{(n+x)/n}\leq A_n(x)\leq f(x).

Thus A_n(x) is sandwiched between two expressions tending to f(x). This can only mean that

{\displaystyle \lim _{n\to \infty }{\frac {n^{x}n!}{(x+n)(x+n-1)\cdots (x+1)x}}=f (x).}

The remaining loose end is proving that, for all x>0, the limit

{\displaystyle \lim _{n\to \infty }{\frac {n^{x}n!}{(x+n)(x+n-1)\cdots (x+1)x}}}

exists and equals f(x). The problem is that our first double inequality

{\displaystyle S(n-1,n)\leq S(n,n+x)\leq S(n,n+1)}

was constructed with the constraint 0 < x ≤ 1. If, say, x > 1 then the fact that S is monotonically increasing would make S(n, n + 1) ≤ S(n, n + x), so the earlier upper bound is no longer supplied by monotonicity. However,

{\displaystyle {\begin{aligned}f (x+1)&=\lim _{n\to \infty }x\cdot \left({\frac {n^{x}n!}{(x+n)(x+n-1)\cdots (x+1)x}}\right){\frac {n}{n+x+1}}\\f (x)&=\left({\frac {1}{x}}\right)f (x+1)\end{aligned}}}

which demonstrates how to bootstrap the limit formula from 0<x\leq1 to all x>0.
