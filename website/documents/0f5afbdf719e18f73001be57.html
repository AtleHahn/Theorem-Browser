Statement

For a linear map T:X\to Y between Banach spaces, T is bounded if and only if its graph is closed in X\times Y. Here bounded means that some C\ge0 satisfies \|Tx\|\le C\|x\| for all x\in X.

Level
Within undergraduate level
Level justification

Real analysis supplies complete metric spaces, closedness, compactness and uniform convergence; linear algebra supplies linear maps. A Banach space is complete for its norm metric, and the operator bound or compactness condition is explicitly given. These statements use that single extension without dual spaces or weak topologies.

Proof 1: Replace continuity by boundedness

The closed graph theorem states that a linear operator between two Banach spaces is continuous if and only if the graph of the operator is closed.

Since an operator between two normed spaces is a bounded linear operator if and only if it is a continuous linear operator, one can replace “continuous” with “bounded” in this statement.

Level
Within undergraduate level
Level justification

The proof only combines two supplied implications for linear maps on complete normed spaces. From undergraduate linear algebra, analysis and basic topology, a norm gives the distance ||x-y||, Banach means complete for this distance, and a closed graph means the subset {(x,Tx)} is closed in the product metric. These related definitions are a small extension; no proof of the closed graph theorem or broader functional analysis is needed.
