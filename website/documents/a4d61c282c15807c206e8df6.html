Statement

Let f:M\to N be a smooth surjective submersion between smooth manifolds without boundary. If M is compact, then f is a locally trivial fibration.

Level

Proof 1: Compactness supplies the properness hypothesis

Ehresmann's fibration theorem states that a smooth mapping f:M\to N between smooth manifolds is a locally trivial fibration if it is a surjective submersion and a proper map. In particular, the properness condition is always satisfied if M is compact.

Level
Beyond undergraduate level
Level justification

Compactness supplies properness, but applying Ehresmann requires smooth manifolds, submersions and locally trivial fibrations. These linked differential-topology concepts exceed the agreed baseline.
