Statement

Let m be a finite measure and (\lambda_n) finite complex measures such that \lambda_n(B) converges for every measurable B. Assume uniform absolute continuity in the set-value sense: for every \varepsilon>0 some \delta>0 gives m(B)<\delta\Rightarrow|\lambda_n(B)|<\varepsilon for all n. Then \sup_n\|\lambda_n\|_{TV}<\infty.

Beyond undergraduate level
Level justification

The statement concerns a uniform complex-measure norm bound from setwise convergence and small-set control.

Proof 1: Finite indivisible partition and cellwise variation bounds

Write (S,\mathcal B) for the common measurable space. For a finite complex measure \nu, its variation is |\nu|(B)=\sup_\pi\sum_{A\in\pi}|\nu(A)|, over finite measurable partitions of B, and \|\nu\|_{TV}=|\nu|(S). We use the standard estimate |\nu|(B)\le4\sup_{A\subseteq B}|\nu(A)|.

For \delta>0, a measurable set is \delta-indivisible if it cannot be partitioned into two measurable subsets both of measure at least \delta. A finite measure m admits a finite partition into such sets, as follows.

Start with the partition {\displaystyle \pi _{1}=\{S\}}. Assume that {\displaystyle \pi _{n}} is already defined. If all sets in {\displaystyle \pi _{n}} are already {\displaystyle \delta }-indivisible, then set {\displaystyle \pi _{n+1}=\pi _{n}}. If not, pick one set {\displaystyle B\in \pi _{n}} that is not {\displaystyle \delta }-indivisible. Then, {\displaystyle B} can be partitioned into two disjoint measurable subsets {\displaystyle B_{1},B_{2}\in {\mathcal {B}}} satisfying {\displaystyle m(B_{1})\geq \delta } and {\displaystyle m(B_{2})\geq \delta }. In this case, set {\displaystyle \pi _{n+1}=(\pi _{n}\setminus \{B\})\cup \{B_{1},B_{2}\}}. This process must stabilize after at most {\displaystyle \lfloor m(S)/\delta \rfloor } splittings, since each splitting creates a new set of measure at least {\displaystyle \delta }.

Next, we prove boundedness of the total variations: Fix {\displaystyle \varepsilon =1}. By uniformly absolute continuity of {\displaystyle (\lambda _{n})_{n\geq 1}} there is {\displaystyle \delta >0} such that {\displaystyle m(B)<\delta } implies {\displaystyle |\lambda _{n}(B)|<1}. By the construction just given, there is a finite partition {\displaystyle \pi } of {\displaystyle S} into {\displaystyle \delta }-indivisible sets with respect to the finite measure {\displaystyle m}. For any {\displaystyle B\in \pi } and any measurable {\displaystyle A\subseteq B}, we cannot have both, {\displaystyle m(A)\geq \delta } and {\displaystyle m(B\setminus A)\geq \delta }. If {\displaystyle m(A)<\delta }, then, by uniformly absolute continuity,

{\displaystyle |\lambda _{n}(A)|<1\leq |\lambda _{n}(B)|+1}

for all {\displaystyle n\geq 1}. If, on the other hand {\displaystyle m(B\setminus A)<\delta }, then, again by uniform absolute continuity, {\displaystyle |\lambda _{n}(B\setminus A)|<1} for all {\displaystyle n\geq 1}, which implies

{\displaystyle |\lambda _{n}(A)|=|\lambda _{n}(B)-\lambda _{n}(B\setminus A)|\leq |\lambda _{n}(B)|+|\lambda _{n}(B\setminus A)|<|\lambda _{n}(B)|+1}

for all {\displaystyle n\geq 1}. In both cases, for every measurable subset {\displaystyle A\subseteq B} and every {\displaystyle n\geq 1}:

{\displaystyle |\lambda _{n}(A)|<|\lambda _{n}(B)|+1}

Thus,

{\displaystyle |\lambda _{n}|(B)\leq 4\sup _{A\subseteq B}|\lambda _{n}(A)|\leq 4|\lambda _{n}(B)|+4}

Since {\displaystyle (\lambda _{n}(B))_{n\geq 1}} converges for every {\displaystyle B\in \pi } and {\displaystyle \pi } is finite, we have

{\displaystyle C=\max _{B\in \pi }\sup _{n\geq 1}|\lambda _{n}(B)|<\infty }

and therefore

{\displaystyle \lVert \lambda _{n}\rVert _{TV}=\sum _{B\in \pi }|\lambda _{n}|(B)\leq \sum _{B\in \pi }(4|\lambda _{n}(B)|+4)\leq (4C+4)|\pi |<\infty .}
