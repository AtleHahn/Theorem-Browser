Statement

For a real or complex Banach space X, the identity operator is compact if and only if X is finite-dimensional. An operator is compact when it maps the unit ball into a set with compact closure.

Level
Within undergraduate level
Level justification

Real analysis supplies complete metric spaces, closedness, compactness and uniform convergence; linear algebra supplies linear maps. A Banach space is complete for its norm metric, and the operator bound or compactness condition is explicitly given. These statements use that single extension without dual spaces or weak topologies.

Proof 1: Apply the compact-unit-ball criterion to the identity

Use the compact-unit-ball characterization:

If {\displaystyle X} is a normed vector space, then {\displaystyle X} is finite dimensional if and only if the closed unit ball in {\displaystyle X} is compact.

In particular, the identity operator on a Banach space {\displaystyle X} is compact if and only if {\displaystyle X} is finite-dimensional.

Level
Within undergraduate level
Level justification

For the identity, the image of the unit ball is the same ball, so compactness of the operator is exactly the supplied compact-unit-ball criterion. Undergraduate linear algebra, metric compactness and the norm-induced distance suffice. Learning this definition of a compact operator is a single direct extension; no spectral theory or proof of the compact-unit-ball theorem is required.
