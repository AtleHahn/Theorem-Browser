Statement

Work in constructive set theory with pairing, extensionality and separation for the formulas used below, and with the distinct finite ordinals 0=\varnothing, 1=\{0\} and 2=\{0,1\}. Assume full separation and the axiom of choice: every set of inhabited sets has a choice function selecting an element from each member. Then every proposition P satisfies P\lor\neg P.

Beyond undergraduate level
Level justification

The statement concerns implication between axiom schemes in constructive set theory, beyond finite elementary logic or calculus.

Proof 1: Choose from two proposition-dependent subsets

One considers two subsets of any doubleton with two distinguishable members. As {\displaystyle 0\neq 1}, a convenient choice is again {\displaystyle \{0,1\}}. So, using Separation, let

{\displaystyle U=\{x\in \{0,1\}\mid (x=0)\vee P\}}

and

{\displaystyle V=\{x\in \{0,1\}\mid (x=1)\lor P\}.}

Both {\displaystyle U} and {\displaystyle V} are inhabited, as witnessed by {\displaystyle 0\in U} and {\displaystyle 1\in V}. If the proposition {\displaystyle P} can be proven, then both of these sets equal {\displaystyle \{0,1\}}. In particular, {\displaystyle P\,\to \,U=V} by extensionality. In turn, for any mathematical function {\displaystyle g} that can take both of these sets as an argument, one finds {\displaystyle P\,\to \,g(U)=g(V)}, the contrapositive of which is {\displaystyle g(U)\neq g(V)\,\to \,\neg P}.

The rest of the proof concerns the pair {\displaystyle X:=\{U,V\}}, a set of inhabited sets. (Indeed, {\displaystyle X} is itself inhabited and even validates {\displaystyle X\leq ^{*}2}, meaning that 2 surjects onto X (it is finitely indexed). However, note that when excluded middle is not assumed, {\displaystyle X} need not be provably finite, in the bijection sense.)

A choice function {\displaystyle f} on {\displaystyle X} by definition has to map into the general union, which here is {\displaystyle \{0,1\}}, and fulfill

{\displaystyle f(U)\in U\,\land \,f(V)\in V.}

Using the definition of the two subsets and the function's established codomain, this reduces to

{\displaystyle {\big (}f(U)=0\lor P{\big )}\land {\big (}f(V)=1\lor P{\big )}.}

Using the law of distributivity, this in turn implies {\displaystyle P\lor {\big (}f(U)\neq f(V){\big )}}. By the previous comment on functions, the existence of a choice function on this set thus implies the disjunction {\displaystyle P\lor \neg P}. Since the axiom of choice supplies such a choice function on X, this proves P\lor\neg P for every proposition P.
