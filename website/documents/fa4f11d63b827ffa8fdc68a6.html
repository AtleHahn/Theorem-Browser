Statement

Write \mathbb N=\{0,1,2,\ldots\}. Let k,\ell\ge2 be integers with k^p\ne\ell^q for all positive integers p,q. For r\ge2, define V_r(0)=1 and, for x>0, let V_r(x) be the largest power of r dividing x. A subset of \mathbb N is definable in (\mathbb N,+,V_r) if a first-order formula in equality, addition and V_r describes membership. A set S is ultimately periodic if there are integers N\ge0,d\ge1 such that, for all x\ge N, x\in S if and only if x+d\in S. Let S\subseteq\mathbb N. Then S is definable in both (\mathbb N,+,V_k) and (\mathbb N,+,V_\ell) if and only if it is definable in Presburger arithmetic, the first-order arithmetic of nonnegative integers with addition.

Level justification

The valuation functions, multiplicative independence and ultimate periodicity are explicitly defined. The additional first-order definability notion means describing membership by a finite quantified formula using only the listed integer operations and equality. From undergraduate quantified mathematical statements this syntactic restriction and simple examples form a small extension within about 30 minutes; no model-theory or automata classification is needed to understand the claim.

Proof 1: Compose the two ultimate-periodicity characterizations

Use the logical form of Cobham’s theorem: for the two multiplicatively independent bases, simultaneous definability in (\mathbb N,+,V_k) and (\mathbb N,+,V_\ell) is equivalent to ultimate periodicity.

We can push the analogy with logic further by noting that S is first-order definable in Presburger arithmetic if and only if it is ultimately periodic. So, a set S is definable in the logics {\displaystyle \langle N,+,V_{k}\rangle } and {\displaystyle \langle N,+,V_{\ell }\rangle } if and only if it is definable in Presburger arithmetic.
