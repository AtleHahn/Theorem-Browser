Statement

Every continuous real-valued function on a Euclidean circle takes the same value at some pair of diametrically opposite points.

Proof 1: Half-turn of the antipodal difference

Take f to be any continuous real-valued function on a circle. Draw a line through the center of the circle, intersecting it at two opposite points A and B. Define d to be f(A)-f(B). If d=0, the desired pair is already found. Otherwise, if the line is rotated 180 degrees, the value -d will be obtained instead. Due to the intermediate value theorem there must be some intermediate rotation angle for which d=0, and as a consequence f(A)=f(B) at this angle.

Within undergraduate level
Level justification

The antipodal difference varies continuously as the diameter rotates through a half-turn, changing from d to -d. The intermediate value theorem supplies a zero. Ordinary single-variable continuity and elementary circle geometry suffice.
