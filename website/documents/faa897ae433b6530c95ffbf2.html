Statement

Let f:\mathbb R^d\to\mathbb R be continuously differentiable, with an attained global minimum f^*=f(x^*). For \mu>0, the \mu-PL condition means \frac12\|\nabla f(x)\|^2\geq\mu(f(x)-f^*) for all x. Assume that f satisfies this PL condition. Let f=\mathbb E_i f_i, with continuously differentiable f_i having L-Lipschitz gradients for L>0, and assume the gradient sampling is unbiased: \mathbb E_i\nabla f_i(x)=\nabla f(x). Let the displayed second moments be finite. Given the current iterate x_k, sample a fresh index i_k and put x_{k+1}=x_k-\eta_k\nabla f_{i_k}(x_k) with \eta_k>0. Expectations in the one-step bound are conditional on x_k. Then \mathbb E[f(x_{k+1})-f^*\mid x_k]\leq(1-2\eta_k\mu)(f(x_k)-f^*)+\frac{L\eta_k^2}{2}\mathbb E_i\|\nabla f_i(x_k)\|^2.

Proof 1: Source argument

Local upper-bound lemma

If f:\mathbb R^d\to\mathbb R is continuously differentiable and its gradient is L-Lipschitz, then f(y)\leq f(x)+\langle\nabla f(x),y-x\rangle+\frac L2\|y-x\|^2 for all x,y\in\mathbb R^d.

Set {\textstyle g(t)=f(x+t(y-x))} for {\textstyle t\in [0,1]} and use the {\textstyle L} -Lipschitz continuity to show that {\textstyle f(y)-f(x)=g(1)-g(0)=\int _{0}^{1}g'(t)=\langle \int _{0}^{1}\nabla f(x+t(y-x))dt,y-x\rangle \leq \langle \nabla f(x),y-x\rangle +{\frac {L}{2}}\|y-x\|^{2}}.

Conditional expectation

Because all {\textstyle \nabla f_{i}} are {\textstyle L} -Lipschitz, so is {\textstyle \nabla f}. We thus have

{\displaystyle f(x_{k+1})\leq f(x_{k})-\eta _{k}\langle \nabla f(x_{k}),\nabla f_{i_{k}}(x_{k})\rangle +{\frac {L\eta _{k}^{2}}{2}}\|\nabla f_{i_{k}}(x_{k})\|^{2}}

Now, take the expectation over {\textstyle i_{k}}, and use the fact that {\textstyle f} is {\textstyle \mu } -PL. This gives the stated one-step bound.
