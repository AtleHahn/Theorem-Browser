Statement

Let K\subseteq\mathbb R^n be compact with m(K)>0, and let an open U\supseteq K satisfy m(U)\le(1+\epsilon)m(K) for 0<\epsilon<1. Put R=\operatorname{dist}(K,U^c)>0. For any unit vector a and 0<\delta<R, m(K\cap(K+\delta a))\ge(1-\epsilon)m(K)>0.

Level
Beyond undergraduate level
Level justification

The statement is a quantitative measure-theoretic overlap bound.

Proof 1: Inclusion–exclusion inside an open enlargement

Because K is compact, the distance R=\operatorname{dist}(K,U^c) is strictly positive. Let \delta\in(0,R) be arbitrary, and consider the set K+\delta a. If this subset is not contained in U, then we would have

\operatorname{dist}(K,U^c)\leq\|\delta a\|=\delta<R,

which is a contradiction. Therefore, K\cup(K+\delta a)\subset U. This means that

m(U)\geq m(K\cup(K+\delta a)) =m(K)+m(K+\delta a)-m(K\cap(K+\delta a)).

By translation invariance of the Lebesgue measure, we note that m(K+\delta a)=m(K), and so

m(K\cap(K+\delta a))\geq2m(K)-m(U)\geq(1-\epsilon)m(K).

Since \epsilon<1, we see that the measure on the left side is strictly positive.

Level
Beyond undergraduate level
Level justification

The compact-distance argument and inclusion-exclusion are elementary, but the result is about Lebesgue measure of arbitrary compact sets, not just ordinary regions. Consistently with the measure-theory boundary, retain beyond undergraduate provisionally.
