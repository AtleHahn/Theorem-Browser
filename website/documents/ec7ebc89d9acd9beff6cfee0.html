Statement

Let D be a lattice, so each pair x,y\in D has a meet x\wedge y (greatest lower bound) and join x\vee y (least upper bound). Let \Theta be a partially ordered parameter set and f:D\times\Theta\to\mathbb R. Suppose that for every \theta\in\Theta the function is supermodular in x:

f(x\vee y,\theta)+f(x\wedge y,\theta)\geq f(x,\theta)+f(y,\theta)\quad(x,y\in D),

and that it has increasing differences: whenever x\leq x' and \theta\leq\theta',

f(x',\theta')-f(x,\theta')\geq f(x',\theta)-f(x,\theta).

Define

A(\theta)=\{x\in D:f(x,\theta)\geq f(y,\theta)\text{ for every }y\in D\}.

If \theta\leq\theta' and both maximizer sets are nonempty, then A(\theta) is below A(\theta') in the strong set order: for all x\in A(\theta) and y\in A(\theta'),

x\wedge y\in A(\theta),\qquad x\vee y\in A(\theta').

Consequently, where the maximizer sets have greatest and least elements, both of those selections are nondecreasing in the parameter.
