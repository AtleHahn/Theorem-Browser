Statement

Let a>b>0 be integers. If their Euclidean algorithm takes N\ge1 remainder divisions, including the final division with zero remainder, then a\ge F_{N+2} and b\ge F_{N+1}, where F_1=F_2=1 and F_{j+2}=F_{j+1}+F_j.

Proof 1: Induct on the number of divisions

This can be shown by induction. If N = 1, b divides a with no remainder; the smallest natural numbers for which this is true is b = 1 and a = 2, which are F2 and F3, respectively. Now assume that the result holds for all values of N up to M − 1. The first step of the M-step algorithm is a = q0b + r0, and the Euclidean algorithm requires M − 1 steps for the pair b > r0. By induction hypothesis, one has b ≥ FM+1 and r0 ≥ FM. Therefore, a = q0b + r0 ≥ b + r0 ≥ FM+1 + FM = FM+2, which is the desired inequality.
