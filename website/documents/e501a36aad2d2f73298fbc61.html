Statement

Write \mathbb N=\{0,1,2,\ldots\}. For a set X, write [X]^n for its collection of n-element subsets. For every integer n\geq1 and integer k\geq0, there is an integer m\geq0 such that the following holds. Put I_m=\{0,1,\ldots,m-1\} (empty if m=0). For every function f:[I_m]^n\to\mathbb N satisfying

f(s)<\min(s)\qquad\text{whenever }s\in[I_m]^n\text{ and }0\notin s,

there exists H\subseteq I_m with exactly k elements such that

s,t\in[H]^n,\quad\min(s)=\min(t)\quad\Longrightarrow\quad f(s)=f(t).

Here \min(s) is the least element of the nonempty finite set s. The restriction n\geq1 specifies the domain on which this minimum notation is defined; there is no bound imposed on f(s) when 0\in s.

Level
High school only
Level justification

All objects are finite sets of integers and functions on their fixed-size subsets. The explicitly defined regressive and equal-minimum conditions require elementary finite reasoning, not logic or Ramsey-theoretic proof methods.
