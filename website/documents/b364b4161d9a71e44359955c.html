Statement

A set E\subseteq\mathbb R is exactly the set of points where some continuous function f:\mathbb R\to\mathbb R has no finite derivative if and only if

E=G\cup N,

where G is a G_\delta set and N is a G_{\delta\sigma} set of Lebesgue measure zero. A G_\delta set is a countable intersection of open sets; a G_{\delta\sigma} set is a countable union of G_\delta sets. Measure zero means that for every positive epsilon the set has a countable interval cover whose total length is less than epsilon. Having a finite derivative at x means that \lim_{h\to0}(f(x+h)-f(x))/h exists as a real number.

Proof 1: Oscillatory constructions and Dini derivatives (external)

A link to the proof can be found here (BSMF 74 (1946), pp. 147–178: Part I Theorems 1–3 pp. 149–176; Part II Theorem 4 pp. 176–177.).

In Part II use the set M' of points with no finite derivative; M'' uses a different convention concerning infinite derivatives. For sufficiency the source constructs functions on disjoint open, G_\delta, and null G_{\delta\sigma} parts. At a point of one part the other two functions have finite derivatives, so addition preserves failure of a finite derivative. Thus the construction covers the convention in this statement.

Level justification

The proof combines density-one interpolation of measurable sets, controlled differentiable and Lipschitz series, and almost-everywhere classification of four Dini derivatives with Borel-set bookkeeping. In particular, the density construction uses regularity of Lebesgue measure to build nested closed sets with prescribed density behavior. This cumulative measure-theoretic and descriptive real-analysis preparation exceeds introductory real analysis and the additional reading allowance.
