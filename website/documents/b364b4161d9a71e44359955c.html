Statement

A set E\subseteq\mathbb R is exactly the set of points where some continuous function f:\mathbb R\to\mathbb R has no finite derivative if and only if

E=G\cup N,

where G is a G_\delta set and N is a G_{\delta\sigma} set of Lebesgue measure zero. A G_\delta set is a countable intersection of open sets; a G_{\delta\sigma} set is a countable union of G_\delta sets. Measure zero means that for every positive epsilon the set has a countable interval cover whose total length is less than epsilon. Having a finite derivative at x means that \lim_{h\to0}(f(x+h)-f(x))/h exists as a real number.
