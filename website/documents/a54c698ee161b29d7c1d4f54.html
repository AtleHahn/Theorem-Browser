Statement

Let n\ge1 and X=(x_{ij}) be an n\times n matrix of independent complex polynomial variables. Put D=(\partial/\partial x_{ij}) and E=XD^t as operators on \mathbb C[x_{ij}]. For an n\times n operator matrix A, define \det_{\rm col}(A)=\sum_{\sigma\in S_n}\operatorname{sgn}(\sigma)A_{\sigma(1),1}\cdots A_{\sigma(n),n} in the displayed column order. Then \det_{\rm col}(E+\operatorname{diag}(n-1,\ldots,0))=\det(X)\det(D). The rightmost factor differentiates first.

Proof 1: Take the square case of Capelli–Cauchy–Binet — outline

Apply the following Capelli–Cauchy–Binet identity with m=n: \det_{\rm col}(E+\operatorname{diag}(n-1,\ldots,0))=\sum_{I\subseteq\{1,\ldots,m\},\ |I|=n}\det(X_I)\det((D_I)^t), where X=(x_{ia}), D=(\partial/\partial x_{ia}) and X_I,D_I select columns in increasing order.

For m=n the Capelli–Cauchy–Binet sum returns the square Capelli identity.

Level
Within undergraduate level
Level justification

The operators are ordinary multiplication and partial differentiation on polynomials, and the ordered determinant is explicitly defined. In the supplied finite-sum theorem, taking m=n leaves exactly one column subset. Calculus and linear algebra plus ordered operator composition suffice; no representation-theoretic proof is invoked.

Proof 2: Specialize the Caracciolo–Sportiello–Sokal identity — outline

Use the following commuting-entry case of the Caracciolo–Sportiello–Sokal theorem. If an n\times n matrix M has mutually commuting entries and [M_{ij},Y_{kl}]=-\delta_{jk}Q_{il}, then \det_{\rm col}(MY+Q\operatorname{diag}(n-1,\ldots,0))=\det(M)\det_{\rm col}(Y).

The original Capelli identity is the particular case M=X, Y=D^t, Q=I.

Level justification

Multiplication operators commute, and the product rule gives [x_ij,partial_(l,k)]=-delta_il delta_jk, so Q=I satisfies the supplied theorem. Substitution then proves the identity using multivariable calculus and linear algebra with ordered composition.
