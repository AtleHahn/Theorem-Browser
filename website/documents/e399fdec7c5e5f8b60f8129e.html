Statement

Let G=(V,E) be a finite directed graph with at least one edge, connected after directions are ignored, in which each vertex has equal indegree and outdegree d(v). Edges are individually distinguished, including parallel edges if present. Count Eulerian circuits as cyclic sequences of directed edges traversing each edge exactly once, identifying cyclic rotations. Equivalently, choose a fixed edge and count traversals beginning with that edge. For any vertex w, let t_w(G) be the number of spanning trees directed toward w: each vertex other than w has one outgoing tree edge, w has none, and following tree edges from any vertex reaches w. Then

\operatorname{ec}(G)=t_w(G)\prod_{v\in V}(d(v)-1)!.

Moreover t_v(G)=t_w(G) for all vertices v,w. For a one-vertex graph, the empty spanning tree is counted once; 0!=1.

Level
High school only
Level justification

All graph objects and the circuit equivalence relation are explicitly defined using elementary finite counting.
