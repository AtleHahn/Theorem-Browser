Statement

Let G be an abelian group with a translation-invariant linear order. For 0\ne g\in G let |g|=\max(g,-g). Call g,h\ne0 Archimedean equivalent if there are positive integers N,M such that N|g|>|h| and M|h|>|g|.

Let \Omega be the set of these equivalence classes, ordered by decreasing magnitude: [g]<[h] means that m|h|<|g| for every positive integer m. Define the Hahn group

\mathcal H(\Omega)=\{a:\Omega\to\mathbb R:\{\omega:a(\omega)\ne0\}\text{ is well ordered in }\Omega\}.

A subset is well ordered if each of its nonempty subsets has a least element. Addition is pointwise. Order this group lexicographically: for a\ne b, compare their values at the least \omega for which a(\omega)\ne b(\omega).

There exists an injective homomorphism \iota:G\to\mathcal H(\Omega) that preserves the order: g<h if and only if \iota(g)<\iota(h).
