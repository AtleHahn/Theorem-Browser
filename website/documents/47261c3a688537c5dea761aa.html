Statement

Let n,m\ge1 be integers and \Phi:M_n(\mathbb C)\to M_m(\mathbb C) complex-linear. Write E_{kl} for the matrix units, * for conjugate transpose, and C_\Phi=[\Phi(E_{kl})]_{k,l=1}^n. A map is r-positive if applying it entrywise to an r\times r block matrix preserves positive semidefiniteness, and completely positive if it is r-positive for every integer r\ge1. Call \Phi completely copositive if \Phi\circ T is completely positive, where T(A)=A^T. Then \Phi is completely copositive if and only if \Phi(A)=\sum_{i=1}^{nm}V_iA^TV_i^* for some V_i\in\mathbb C^{m\times n}.

Proof 1: Apply the Kraus theorem after transposing twice — outline

The Kraus form of Choi's theorem states that a map \Psi:M_n(\mathbb C)\to M_m(\mathbb C) is completely positive if and only if

\Psi(A)=\sum_{i=1}^{nm}V_iAV_i^*

for matrices V_i\in\mathbb C^{m\times n}.

It follows immediately from Choi's theorem that \Phi is completely copositive if and only if it is of the form

\Phi(A)=\sum_{i=1}^{nm}V_iA^TV_i^*.

Here complete copositivity means complete positivity of \Phi\circ T, and T^2 is the identity.

Level justification
