Statement

A real function has the intermediate value property if every value between its values at two real points is attained between those points. There exist functions g,h:\mathbb R\to\mathbb R having the intermediate value property such that g+h does not have it.

Level

Level justification

A bright US college student should be able to understand this statement after approximately 30 minutes of focused background research; this assesses understanding the claim, not its proof.

Proof 1: Consequence of the decomposition into two Darboux functions

A Darboux function is a real function with the intermediate value property. It turns out that any real-valued function ƒ on the real line can be written as the sum of two Darboux functions. This implies in particular that the class of Darboux functions is not closed under addition. The decomposition theorem is used here without proof.

Level
Within undergraduate level
Level justification

Apply the supplied decomposition to a real step function lacking the intermediate value property. Understanding this property for arbitrary real functions is elementary real analysis; the proof of the decomposition theorem is not invoked.
