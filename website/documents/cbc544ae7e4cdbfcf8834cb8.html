Statement

For every infinite computably enumerable C\subseteq\mathbb N there is a total computable strictly increasing sequence c_0<c_1<\cdots whose values lie in C.

Level
Within undergraduate level
Level justification

Computably enumerable means an algorithm lists the members, while decidable means an algorithm always answers yes or no. These simple procedure notions, together with integer polynomials and increasing sequences, suffice without formal machine indexing.

Proof 1: Select successively larger enumerated elements — outline

The source prescribes enumerating an infinite ascending list of elements of C. At each step the enumeration can be searched for an element larger than the previously chosen one; infinitude guarantees such an element.

Level justification

Run an enumeration until an element larger than the previous output appears; infinitude guarantees termination at each step. Undergraduate discrete mathematics suffices with enumerable meaning algorithmically listable, a small explicit computability extension.
