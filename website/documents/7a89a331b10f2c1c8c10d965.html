Statement

Let C be a set of words of length n\ge1 over an alphabet of q\ge2 symbols. Suppose any two distinct words differ in at least d positions, where 1\le d\le n. Then |C|\le q^{n-d+1}. Equivalently the maximal size A_q(n,d) of such a code satisfies A_q(n,d)\le q^{n-d+1}. The number of differing coordinates is called Hamming distance.

Level
High school only
Level justification

A code is explicitly a finite set of words, and distance counts unequal coordinates.

Proof 1: Delete fewer coordinates than the minimum distance

First observe that the number of {\displaystyle q}-ary words of length {\displaystyle n} is {\displaystyle q^{n}}, since each letter in such a word may take one of {\displaystyle q} different values, independently of the remaining letters.

Now let {\displaystyle C} be an arbitrary {\displaystyle q}-ary block code of minimum distance at least {\displaystyle d}. Clearly, all codewords {\displaystyle c\in C} are distinct. If we puncture the code by deleting the first {\displaystyle d-1} letters of each codeword, then all resulting codewords must still be pairwise different, since all of the original codewords in {\displaystyle C} have Hamming distance at least {\displaystyle d} from each other. Thus the size of the altered code is the same as the original code.

The newly obtained codewords each have length

{\displaystyle n-(d-1)=n-d+1,}

and thus, there can be at most {\displaystyle q^{n-d+1}} of them. Since {\displaystyle C} was arbitrary, this bound must hold for the largest possible code with these parameters, thus:

{\displaystyle |C|\leq A_{q}(n,d)\leq q^{n-d+1}.}

Level justification

Delete d-1 positions without merging distinct words and count all remaining words by the product rule. Elementary finite counting suffices.
