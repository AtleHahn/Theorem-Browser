Statement

Let f(n,x_1,\ldots,x_k) be an integer-coefficient polynomial, with integer k\ge0. The set S=\{n\in\mathbb Z:\exists x_1,\ldots,x_k\in\mathbb Z,\ f(n,x_1,\ldots,x_k)=0\} is computably enumerable: an algorithm can list exactly its members, allowing repetitions and arbitrarily long delays.

Level
Within undergraduate level
Level justification

Undergraduate sets, linear algebra, real analysis and basic topology supply the objects. The additional order, set-system, seminorm or covering definitions are explicit direct extensions of familiar operations; no specialist theory is needed to interpret the full quantified assertion.

Proof 1: Enumerate tuples and test the polynomial

Consider a Diophantine equation f(n, x1, ..., xk) = 0. Now we make an algorithm that tries all possible values for n, x1, ..., xk (in, say, some simple order consistent with the increasing order of the sum of their absolute values), and prints n every time f(n, x1, ..., xk) = 0. This algorithm will run forever and will list exactly the n for which f(n, x1, ..., xk) = 0 has a solution in x1, ..., xk.

Level justification

Enumerate finite shells of integer tuples, evaluate the polynomial and print successful first coordinates. Elementary discrete mathematics and the explicitly defined notion of an algorithmic enumeration suffice; no undecidability or formal-machine theorem is used.
