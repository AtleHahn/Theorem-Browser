Statement

Let X_n,X be random vectors in \mathbb R^k, k\ge1. Convergence in distribution means \mathbb E g(X_n)\to\mathbb E g(X) for every bounded continuous real function g on \mathbb R^k, with the analogous definition in one dimension. If all X_n take values in [0,\infty)^k, then it suffices to test only t\in[0,\infty)^k: X_n converges in distribution to X if and only if t\cdot X_n converges in distribution to t\cdot X for all such t.

Level
Beyond undergraduate level
Level justification

The complete multivariate weak-convergence formulation has the same cumulative measure-theoretic requirements as the unrestricted device.

Proof 1: Laplace transforms on the positive orthant (external)

A link to the proof can be found here (Corollary 5.5 and proof, p. 87; Laplace-transform continuity Theorem 5.3, pp. 86–87.).

Taking each coordinate direction first shows that every coordinate of X is nonnegative almost surely: weak limits preserve a closed half-line. For t\ge0, use the bounded continuous function u\mapsto\exp(-\max(u,0)) to deduce convergence of the joint Laplace transforms. Apply the nonnegative version of Theorem 5.3. Its approximation step uses x_i\mapsto e^{-x_i} and polynomials on [0,1]^k, with tightness controlling the tails. The converse follows by composing bounded continuous test functions with each linear projection.
