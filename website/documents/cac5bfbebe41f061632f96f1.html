Statement

A normal function is a class function f:\mathrm{Ord}\to\mathrm{Ord} that is strictly increasing and satisfies f(\lambda)=\sup_{\xi<\lambda}f(\xi) at each nonzero limit ordinal \lambda. Its fixed points are unbounded in \mathrm{Ord} and closed under suprema of nonempty sets of fixed points. More precisely, starting at any \alpha and iterating \alpha_0=\alpha, \alpha_{n+1}=f(\alpha_n) gives a fixed point \beta=\sup_{n<\omega}\alpha_n\ge\alpha.

Proof 1: Iterate the function and take the ordinal supremum

The first step of the proof is to verify that f(\gamma)\geq\gamma for all ordinals \gamma and that f commutes with nonempty suprema. The first of these is a standard ordinal fact whose verification is left implicit in the source. For the second, if \sup A is 0 or a successor ordinal, then \sup A is an element of A and the equality

f(\sup A)=\sup f(A)=\sup\{f(\xi):\xi\in A\}

follows from the increasing property of f. If \sup A is a limit ordinal, the equality follows from the continuous property of f.

Given these results, inductively define a nondecreasing sequence \langle\alpha_n\rangle_{n<\omega} by setting \alpha_0=\alpha and \alpha_{n+1}=f(\alpha_n) for n\in\omega. Let \beta=\sup_{n<\omega}\alpha_n, so \beta\geq\alpha. Moreover, because f commutes with nonempty suprema,

\begin{aligned} f(\beta)&=f\left(\sup_{n<\omega}\alpha_n\right)\\ &=\sup_{n<\omega}f(\alpha_n)\\ &=\sup_{n<\omega}\alpha_{n+1}\\ &=\beta. \end{aligned}

The last equality follows from the fact that the sequence \langle\alpha_n\rangle_n is nondecreasing.

The continuity of the normal function implies that the class of fixed points is closed: the supremum of any nonempty set of fixed points is again a fixed point. Thus the fixed points form a closed and unbounded class.
