Statement

Let A_1,\ldots,A_m be events in a probability space. Let N count those that occur, and put S_k=\sum_{J\subseteq\{1,\ldots,m\},\ |J|=k}\Pr(\cap_{j\in J}A_j), with S_0=1. On \mathbb R^{m+1} define E(c_0,\ldots,c_m)=(c_1,\ldots,c_m,0) and \Delta=E-I. For every vector c=(c_0,\ldots,c_m), \sum_{n=0}^m\Pr(N=n)c_n=\sum_{k=0}^mS_k(\Delta^kc)_0.

Level
Within undergraduate level
Level justification

Only finitely many events and their intersections occur, so expectation is an explicit finite probability-weighted sum. Polynomial multiplication and shifts/differences of sequences are given by formulas. Elementary finite probability and linear algebra suffice without measure-theoretic integration.

Proof 1: Truncate the shift before taking the expected component

Use the probabilistic sequence identity \sum_{n=0}^m\Pr(N=n)c_n=\sum_{k=0}^mS_k(\Delta^kc)_0 for the infinite shift (Ec)_j=c_{j+1} and \Delta=E-I. For k\le m, its zeroth difference component uses only c_0,\ldots,c_k. Replacing this shift by the displayed finite shift matrix therefore changes none of the components used in the expectation formula, yielding the stated finite-vector identity.

Within undergraduate level
Level justification

Truncate a shift because the relevant finite powers use only the displayed coordinates. Undergraduate linear algebra and finite expectation suffice.
