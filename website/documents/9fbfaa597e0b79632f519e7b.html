Statement

Let N\ge1 and let J_{jk}\ge0 be real numbers for 1\le j,k\le N. For each j, let \mu_j be an even nonnegative Borel measure on \mathbb R, meaning \mu_j(E)=\mu_j(-E) for every Borel set E. Suppose

\int_{\mathbb R}e^{bs^2}\,d\mu_j(s)<\infty\quad\text{for every }b\in\mathbb R,

and suppose each measure has the Lee–Yang property

\int_{\mathbb R}e^{hs}\,d\mu_j(s)\ne0\quad\text{for every }h\in\mathbb C\text{ with }\Re h>0.

Define the partition function

Z(z_1,\ldots,z_N)=\int_{\mathbb R^N}\exp\!\left(\sum_{j,k=1}^N J_{jk}s_js_k+\sum_{j=1}^N z_js_j\right)\,d\mu_1(s_1)\cdots d\mu_N(s_N).

Then Z(z_1,\ldots,z_N)\ne0 whenever \Re z_j>0 for every j. In particular, every zero of the common-field function z\mapsto Z(z,\ldots,z) is purely imaginary. The condition J_{jk}\ge0 is called ferromagnetic interaction.
