Statement

Let X be a complete metrizable real or complex topological vector space, Y a normed space over the same field, and H a family of continuous linear maps X\to Y. If \sup_{h\in H}\|h(x)\|<\infty for every x\in X, then H is equicontinuous: for each zero neighborhood W in Y there is a zero neighborhood N in X such that h(N)\subseteq W for all h\in H.

Level
Beyond undergraduate level
Level justification

The domain is a general complete metrizable topological vector space, not merely a finite-dimensional vector space or calculus domain.

Proof 1: Norm-bounded orbits in the complete-metrizable theorem

We use the following complete-metrizable uniform boundedness theorem: Let H\subseteq L(X,Y) be a set of continuous linear operators from a complete metrizable topological vector space X into a Hausdorff topological vector space Y. If for every x\in X, the orbit

H(x):=\{h(x):h\in H\}

is a bounded subset of Y, then H is equicontinuous. In a normed space, this boundedness is equivalent to norm boundedness.

So in particular, if Y is also a normed space and if

\sup_{h\in H}\|h(x)\|<\infty\quad\text{for every }x\in X,

then H is equicontinuous.

Level
Beyond undergraduate level
Level justification

The specialization uses uniform boundedness for arbitrary complete metrizable topological vector spaces, including topological boundedness and equicontinuity of operator families. This general setting is not confidently a small extension; retain beyond undergraduate provisionally.
