Statement

Write R(n_1,\ldots,n_c) for the least positive integer N such that every assignment of c colors to all unordered pairs of an N-element vertex set contains, for some i, a subset of size n_i whose pairs all have color i. A one-vertex subset is monochromatic in every color. R(3,s)=\Theta(s^2/\log s) as s\to\infty, meaning it lies between positive constant multiples of this function for all sufficiently large s.

Level

Level justification

Understanding the statement involves Finite graph colorings; Asymptotic estimates; Logarithms. These prerequisites fit undergraduate coursework or a brief extension of it. Proof 1: Compare the positive limiting constants

Use the following bounds, stated without proof in the source:

\left(\frac14+o(1)\right)\frac{s^2}{\log s} \le R(3,s)\le(1+o(1))\frac{s^2}{\log s}.

This shows that the Ramsey numbers R(3,s) are of order s^2/\log s.
