Statement

Write R(n_1,\ldots,n_c) for the least positive integer N such that every assignment of c colors to all unordered pairs of an N-element vertex set contains, for some i, a subset of size n_i whose pairs all have color i. A one-vertex subset is monochromatic in every color. R(3,s)=\Theta(s^2/\log s) as s\to\infty, meaning it lies between positive constant multiples of this function for all sufficiently large s.
