Statement

Let L>0 and let \alpha:[0,L]\to\mathbb R^3 be a smooth closed unit-speed curve, so \alpha(0)=\alpha(L) and |\alpha'(t)|=1. Put \gamma(t)=\alpha'(t)\in S^2. If a unit vector v satisfies \gamma(t)\cdot v\ge0 for all t, then \alpha([0,L]) lies in the plane \{x:v\cdot x=v\cdot\alpha(0)\}.

Within undergraduate level
Level justification

Proof 1: Use vanishing of a nonnegative tangent integral

Closure gives 0=(\alpha(L)-\alpha(0))\cdot v=\int_0^L\gamma(t)\cdot v\,dt. The integrand is continuous and nonnegative.

If {\displaystyle \gamma } lies in a closed hemisphere, then {\displaystyle \gamma \cdot v\equiv 0}, so {\displaystyle \alpha } is a plane curve. In particular, v\cdot\alpha(t)=v\cdot\alpha(0).

Level
Within undergraduate level
Level justification

Integrate the tangent projection using the fundamental theorem of calculus. A continuous nonnegative integrand with zero integral vanishes everywhere, so the projected position is constant. Standard vector calculus and elementary analysis suffice.
