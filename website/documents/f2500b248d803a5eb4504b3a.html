Statement

On any measure space (S,\mathcal B,m), identify finite-measure measurable sets if their symmetric difference is null. Then d([A],[B])=m(A\triangle B) is a well-defined complete metric on the quotient.

Proof 1: Indicator embedding and an almost-everywhere subsequence

Write \mathcal B_0=\{B\in\mathcal B:m(B)<\infty\} and \bar B=[B] for the equivalence class of B. Write \bar{\mathcal B}_0 for the quotient set and d_m=d. Using indicator functions, we have

d_m(\bar B_1,\bar B_2)=m(B_1\triangle B_2) =\int|\mathbf1_{B_1}-\mathbf1_{B_2}|\,dm =\|\mathbf1_{B_1}-\mathbf1_{B_2}\|_1.

This means that the metric space (\bar{\mathcal B}_0,d_m) can be identified with a subset of the space L^1(S,\mathcal B,m) which is a Banach space. Hence, d_m is a well-defined metric. Consider a Cauchy sequence (\bar B_n)_{n\geq1}. Then,

\lim_{k,n\to\infty}d_m(\bar B_k,\bar B_n) =\lim_{k,n\to\infty}\|\mathbf1_{B_k}-\mathbf1_{B_n}\|_1=0.

By completeness of L^1, the indicators have an L^1 limit. Hence, we can choose a subsequence (\bar B_{n_k})_{k\geq1} such that (\mathbf1_{B_{n_k}})_{k\geq1} converges almost everywhere to this limit. Define g:S\to\mathbb R by

g(x)=\liminf_{k\to\infty}\mathbf1_{B_{n_k}}(x).

Then, g is measurable, agrees almost everywhere with the limit, has values in \{0,1\} and

\lim_{k\to\infty}\|\mathbf1_{B_{n_k}}-g\|_1=0.

Therefore, g=\mathbf1_{B_\infty} for some B_\infty\in\mathcal B_0 and

\lim_{k\to\infty}d_m(\bar B_{n_k},\bar B_\infty) =\lim_{k\to\infty}\|\mathbf1_{B_{n_k}}-\mathbf1_{B_\infty}\|_1=0,

that is, the Cauchy sequence (\bar B_n)_{n\geq1} contains a convergent subsequence and is convergent itself. Therefore, \bar{\mathcal B}_0 is complete. We remark that B_\infty is explicitly given by the limit inferior of the sequence (B_{n_k})_{k\geq1}:

B_\infty=\liminf_{k\to\infty}B_{n_k} =\bigcup_{k=1}^{\infty}\bigcap_{j=k}^{\infty}B_{n_j}.
