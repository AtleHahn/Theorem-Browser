Statement

For an integer base b\ge2, hereditary base-b notation expands a nonnegative integer in base b, then recursively expands all exponents the same way. Coefficients lie in \{0,\ldots,b-1\}. Let B_{b,c}(a) replace every base b in that notation by c\ge b. The Goodstein sequence starts at G_m(1)=m and, while positive, obeys G_m(n+1)=B_{n+1,n+2}(G_m(n))-1; it stops at zero. The program which enumerates G_m, stops when it reaches zero and returns its number of terms computes a total function of m, but Peano arithmetic does not prove this program total.

Proof 1: Enumerate terms and use the termination/independence theorems

The Goodstein sequence of a number can be effectively enumerated by a Turing machine; thus the function that maps n to the number of steps required for the Goodstein sequence of n to terminate is computable by a particular Turing machine. This machine merely enumerates the Goodstein sequence of n and, when the sequence reaches 0, returns the length of the sequence. By Goodstein’s termination theorem, every Goodstein sequence eventually terminates, so this function is total. But by the Kirby–Paris theorem Peano arithmetic does not prove that every Goodstein sequence terminates; therefore Peano arithmetic does not prove that this Turing machine computes a total function.
