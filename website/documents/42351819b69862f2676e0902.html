Statement

For a finite CW complex X and a continuous self-map f, define \Lambda_f=\sum_{k\ge0}(-1)^k\operatorname{tr}(f_*:H_k(X;\mathbb Q)\to H_k(X;\mathbb Q)). If f is homotopic to \mathrm{id}_X, then \Lambda_f=\chi(X).

Level justification

Proof 1: Identity homology maps and Euler characteristic

Since homotopic maps induce the same maps on homology, Lefschetz numbers are equal for two homotopic maps.

The Lefschetz number of the identity map on a finite CW complex can be easily computed by realizing that each {\displaystyle (\mathrm{id}_X)_{\ast }} can be thought of as an identity matrix, and so each trace term is simply the dimension of the appropriate homology group. Thus the Lefschetz number of the identity map is equal to the alternating sum of the Betti numbers of the space, which in turn is equal to the Euler characteristic {\displaystyle \chi (X)}. Thus we have

{\displaystyle \Lambda _{\mathrm {id} }=\chi (X).\ }

Consequently, each map homotopic to the identity map has Lefschetz number equal to the Euler characteristic of X.
