Statement

Let T be a first-order theory of arithmetic containing Robinson arithmetic \mathsf Q, with a fixed standard effective Gödel numbering \alpha. Write \overline n for the standard numeral of n and \ulcorner A\urcorner=\overline{\alpha(A)} for the numeral coding a formula A. Let \psi(x) be a formula whose only free variable is x. There exists a sentence \varphi such that

T\vdash\varphi\leftrightarrow\psi(\ulcorner\varphi\urcorner).
Level
Beyond undergraduate level
Level justification

The conclusion is an internal provability equivalence involving Gödel codes and arithmetic syntax, beyond the rubric backgrounds.

Proof 1: Represent diagonal substitution and substitute the code of its defining formula

Use the representation theorem: every total computable function F is represented by a formula R_F(x,y) such that, whenever F(m)=n,

T\vdash\forall y\,(R_F(\overline m,y)\leftrightarrow y=\overline n).

Let {\displaystyle diag_{T}:\mathbb {N} \to \mathbb {N} } be the computable function that associates the code of each formula {\displaystyle \varphi (x)} with only one free variable {\displaystyle x} in the language of {\displaystyle T} with the code of the closed formula {\displaystyle \varphi (\ulcorner \varphi \urcorner )} (i.e. the substitution of {\displaystyle \ulcorner \varphi \urcorner } into {\displaystyle \varphi } for {\displaystyle x}) and {\displaystyle 0} for other arguments. (The fact that {\displaystyle diag_{T}} is computable depends on the choice of the Gödel numbering, here the standard one.)

By the representation theorem, {\displaystyle T} represents every computable function. Thus, there is a formula {\displaystyle \delta (x,y)} representing {\displaystyle diag_{T}}, in particular, for each {\displaystyle \varphi (x)}, {\displaystyle T\vdash \delta (\ulcorner \varphi \urcorner ,y)\leftrightarrow y=\ulcorner \varphi (\ulcorner \varphi \urcorner )\urcorner }.

Let {\displaystyle \psi (x)} be an arbitrary formula with only {\displaystyle x} as free variable. We now define {\displaystyle \chi (x)} as {\displaystyle \exists y(\delta (x,y)\land \psi (y))}, and let {\displaystyle \varphi } be {\displaystyle \chi (\ulcorner \chi \urcorner )}. Then the following equivalences are provable in {\displaystyle T}:

{\displaystyle \varphi \leftrightarrow \chi (\ulcorner \chi \urcorner )\leftrightarrow \exists y(\delta (\ulcorner \chi \urcorner ,y)\land \psi (y))\leftrightarrow \exists y(y=\ulcorner \chi (\ulcorner \chi \urcorner )\urcorner \land \psi (y))\leftrightarrow \exists y(y=\ulcorner \varphi \urcorner \land \psi (y))\leftrightarrow \psi (\ulcorner \varphi \urcorner )}.
