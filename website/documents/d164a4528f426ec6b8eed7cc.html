Statement

For classical propositions P,Q, if P\to Q is true and Q is false, then P is false.

Level
High school only
Level justification

This is an elementary implication about two truth values.

Mathematical Field
Mathematical logic
Required topics
two-valued propositionsmaterial implication
Review notes
none

Proof 1: Assume the antecedent and contradict the false consequent

Let

(P\to Q)\land\neg Q.

It is given that, if P is true, then Q is true, and it is also given that Q is not true. We can then show that P must not be true by contradiction. For if P were true, then Q would have to also be true (by modus ponens). However, it is given that Q is not true, so we have a contradiction. Therefore, P is not true (assuming that we are dealing with bivalent statements that are either true or false).

Proof 2: Inspect the truth table

The validity of modus tollens can be clearly demonstrated through a truth table.

P Q P\to Q
T T T
T F F
F T T
F F T

In instances of modus tollens we assume as premises that P\to Q is true and Q is false. There is only one line of the truth table—the fourth line—which satisfies these two conditions. In this line, P is false. Therefore, in every instance in which P\to Q is true and Q is false, P must also be false.
