Repeated power-set formation gives strictly increasing infinite cardinalities, and applying Cantor's argument to any set rules out a largest set cardinality. This challenges any conception of infinity as one completed maximum size and distinguishes sets from an unrestricted totality of everything.

Statement

Let A_0 be an infinite set and recursively put A_{n+1}=\mathcal P(A_n) for n\ge0. Then |A_n|<|A_{n+1}| for every n, so there is no largest cardinality of a set.

Proof 1: Iterate the power-set comparison

Cantor’s theorem states that every map A\to\mathcal P(A) misses some subset of A and that |A|<|\mathcal P(A)|.

By iteratively taking the power set of an infinite set and applying Cantor's theorem, we obtain an endless hierarchy of infinite cardinals, each strictly larger than the one before it. For any candidate set B of largest cardinality, Cantor’s theorem gives |B|<|\mathcal P(B)|. Thus no set has largest cardinality.

Within undergraduate level
Level justification

Apply Cantor at every finite stage and once to any proposed largest set. Undergraduate sets, injections and surjections suffice; ordinal or cofinality theory is not used.
