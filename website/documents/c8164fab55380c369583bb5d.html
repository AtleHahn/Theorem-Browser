For f\in\mathbb R[x] and r\in\mathbb R, x-r divides f(x) if and only if f(r)=0.

Proof 1: Zero remainder and evaluation

The remainder theorem gives f(x)=(x-r)Q(x)+f(r). If f(r)=0, this is a factorization by x-r. Conversely, if f(x)=(x-r)Q(x), evaluation at r gives f(r)=0.
