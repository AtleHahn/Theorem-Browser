Statement

Let \zeta denote the meromorphic continuation of \sum_{n\ge1}n^{-s} from \operatorname{Re}s>1. Let a<b be real and put A(t)=\pi^{-(1/2+it)/2}\Gamma((1/2+it)/2)\zeta(1/2+it). If A(a) and A(b) have opposite signs, then \zeta(1/2+it)=0 for some a<t<b.

Beyond undergraduate level

Proof 1: Sign changes certify critical-line zeros

The function

{\displaystyle \pi ^{-{\frac {s}{2}}}\Gamma ({\tfrac {s}{2}})\zeta (s)}

has the same zeros as the zeta function in the critical strip, and is real on the critical line because of the functional equation, so one can prove the existence of zeros exactly on the critical line between two points by checking numerically that the function has opposite signs at these points.

The restriction to the critical line is continuous, so opposite signs imply a zero between the two parameter values by the intermediate value theorem.
