Statement

Let U\subset\mathbb C be a bounded simply connected domain with smooth boundary and z_0\in U. The Dirichlet solution with boundary values -\log|z-z_0| and a harmonic conjugate yield a holomorphic function f on U whose only zero is the simple zero z_0 and whose boundary modulus is 1. Boundary modulus means that |f| extends continuously to \partial U with value 1.

Level
Beyond undergraduate level
Level justification

The construction refers to a harmonic Dirichlet solution, its conjugate and a holomorphic function with prescribed boundary modulus.

Proof 1: Dirichlet data construct a holomorphic function with a single simple zero

Write

{\displaystyle f(z)=(z-z_{0})e^{g(z)},}

where {\displaystyle g=u+iv} is some (to be determined) holomorphic function with real part {\displaystyle u} and imaginary part {\displaystyle v}. It is then clear that {\displaystyle z_{0}} is the only zero of {\displaystyle f}. We require {\displaystyle |f(z)|=1} for {\displaystyle z\in \partial U}, so we need

{\displaystyle u(z)=-\log |z-z_{0}|}

on the boundary. Since {\displaystyle u} is the real part of a holomorphic function, we know that {\displaystyle u} is necessarily a harmonic function; i.e., it satisfies Laplace's equation.

The question then becomes: does a real-valued harmonic function {\displaystyle u} exist that is defined on all of {\displaystyle U} and has the given boundary condition? The positive answer is provided by the Dirichlet principle. Once the existence of {\displaystyle u} has been established, the Cauchy–Riemann equations for the holomorphic function {\displaystyle g} allow us to find {\displaystyle v} (this argument depends on the assumption that {\displaystyle U} be simply connected).

The exponential factor has no zeros, so z_0 is a simple zero and the only zero. Moreover,

|f(z)|=|z-z_0|e^{u(z)},

which extends to the boundary with value 1.

Level justification

Constructing the function requires harmonic Dirichlet solvability, harmonic conjugates on simply connected domains and holomorphic zero structure. These linked complex-analysis and boundary-value prerequisites exceed a small extension of the baseline.
