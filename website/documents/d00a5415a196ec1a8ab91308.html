Statement

Fix an admissible numbering e\mapsto\varphi_e of the partial recursive functions on \mathbb N. Equality \simeq means equality of partial functions, including their domains. For every total computable F:\mathbb N\to\mathbb N, there exists n such that \varphi_n\simeq\varphi_{F(n)}.

Level
Beyond undergraduate level
Level justification

Computability-theoretic indices and partial recursive functions are outside undergraduate calculus and linear algebra.

Proof 1: Compile the diagonal evaluator and substitute its index

The proof uses a particular total computable function {\displaystyle h}, defined as follows. Given a natural number {\displaystyle x}, the function {\displaystyle h} outputs the index of the partial computable function that performs the following computation:

Given an input {\displaystyle y}, first attempt to compute {\displaystyle \varphi _{x}(x)}. If that computation returns an output {\displaystyle e}, then compute {\displaystyle \varphi _{e}(y)} and return its value, if any. Thus, for all indices {\displaystyle x} of partial computable functions, if {\displaystyle \varphi _{x}(x)} is defined, then {\displaystyle \varphi _{h(x)}\simeq \varphi _{\varphi _{x}(x)}}. If {\displaystyle \varphi _{x}(x)} is not defined, then {\displaystyle \varphi _{h(x)}} is a function that is nowhere defined. The function {\displaystyle h} can be constructed from the partial computable function {\displaystyle g(x,y)} described above and the s-m-n theorem: for each {\displaystyle x}, the number {\displaystyle h(x)} is the index of a program that computes the function {\displaystyle y\mapsto g(x,y)}.

To complete the proof, let {\displaystyle F} be any total computable function, and construct {\displaystyle h} as above. Let {\displaystyle e} be an index of the composition {\displaystyle F\circ h}, which is a total computable function, so {\displaystyle \varphi _{e}(e)} is defined. Then {\displaystyle \varphi _{h(e)}\simeq \varphi _{\varphi _{e}(e)}} by the definition of {\displaystyle h}. But, because {\displaystyle e} is an index of {\displaystyle F\circ h}, {\displaystyle \varphi _{e}(e)=(F\circ h)(e)=F(h(e))}, and thus {\displaystyle \varphi _{h(e)}\simeq \varphi _{F(h(e))}}. Hence {\displaystyle \varphi _{n}\simeq \varphi _{F(n)}} for {\displaystyle n=h(e)}.
