Statement

For planar n-vertex graphs, a separator-hierarchy algorithm finds in polynomial time an independent set of size at least (1-O(1/\sqrt{\log n})) times the maximum, as n\to\infty. Consequently maximum independent set has a polynomial-time approximation scheme on planar graphs: for every fixed \varepsilon>0, an independent set of at least (1-\varepsilon) of optimum is computable in polynomial time. An independent set is a set of vertices containing no adjacent pair.

Proof 1: Planar maximum independent set admits a separator approximation scheme (outline)

By truncating a separator hierarchy at an appropriate level, one may find a separator of size O(n/\sqrt{\log n}) whose removal partitions the graph into subgraphs of size at most c\log n, for any fixed positive constant c. By the four-color theorem, there exists an independent set of size at least n/4, so the removed nodes form a negligible fraction of the maximum independent set, and the maximum independent sets in the remaining subgraphs can be found independently in time exponential in their size.

Unite these independent sets; there are no edges between the remaining subgraphs. Compared with an optimum, at most the number of removed vertices is lost, so the relative loss is O(1/\sqrt{\log n}). Exhaustive search on O(\log n) vertices per piece takes polynomial time overall. For each fixed \varepsilon>0, the bound suffices for all sufficiently large n; the finitely many smaller sizes can be solved exactly.
