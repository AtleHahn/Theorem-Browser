Medium

A known upper bound on the relevant busy-beaver running time would turn an unbounded universal claim with a computable predicate into a finite decision. This locates the obstruction in obtaining adequate bounds, not in the mechanical checking of individual cases, and connects finite computation with universal arithmetic truth.

Statement

For an integer n\ge1, use deterministic Turing machines with n operational states, a separate Halt state, one starting state, a two-way unbounded tape over \{0,1\}, and a transition for each operational state and scanned symbol. Each transition writes a bit, moves one cell left or right, and enters a state (possibly Halt). The machine starts on an all-zero tape. Among machines that halt, \Sigma(n) is the largest number of ones left on the tape, and S(n) the largest number of transitions, including the halting transition. Let P(k) be a computable predicate on natural numbers, and suppose an n-state machine sequentially tests P(0),P(1),\ldots, halting exactly on finding a counterexample. Given any integer B\ge S(n), one can decide whether P(k) holds for every k.

Level
Within undergraduate level
Level justification

The machine model, starting configuration and score are explicitly described through finite transition rules. Understanding computability here means whether such a finite program always returns the required value; the maxima and eventual comparisons use elementary functions and quantifiers. A small machine trace is enough to illustrate the new model, without formal arithmetic or incompleteness theory.

Proof 1: Stopping a counterexample search at the bound

Consider the assertion that P(k) holds for every natural number k. Write a computer program that sequentially tests this conjecture for increasing values. Suppose this program is simulated on an n-state Turing machine. If it finds a counterexample, it halts and indicates that. However, if the conjecture is true, then our program will never halt. (This program halts only if it finds a counterexample.)

Now, this program is simulated by an n-state Turing machine, so if we know an upper bound B\ge S(n) we can decide (in a finite amount of time) whether or not it will ever halt by simply running the machine that many steps. And if, after B steps, the machine does not halt, we know that it never will and thus that there are no counterexamples to the given conjecture. This would prove the conjecture to be true.

Level
Within undergraduate level
Level justification

The proof needs elementary algorithmic reasoning: a supplied counterexample-search machine must halt within the given bound if it ever halts. Learning computable predicate and finite simulation is a small extension of discrete mathematics; no arithmetical hierarchy or incompleteness argument is used.
