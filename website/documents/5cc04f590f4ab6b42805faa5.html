Statement

In ZF set theory, every countably infinite connected locally finite undirected graph has a ray. A ray is an infinite path with no repeated vertices.

Level
Within undergraduate level
Level justification

A graph, path and finite branching have elementary set-based definitions. Infinite sequences and countability are undergraduate concepts. Understanding the existence of a ray requires no set-theoretic machinery used by its proof.

Proof 1: Choose the least suitable neighbor in a fixed enumeration — outline

Fix an enumeration of the vertices and order them by their first enumeration indices. The construction of a ray, in a graph {\displaystyle G} that meets the conditions of the lemma, can be performed step by step, maintaining at each step a finite path that can be extended to reach infinitely many vertices (not necessarily all along the same path as each other). To begin this process, start with any single vertex {\displaystyle v_{1}}. This vertex can be thought of as a path of length zero, consisting of one vertex and no edges. By the assumptions of the lemma, each of the infinitely many vertices of {\displaystyle G} can be reached by a simple path that starts from {\displaystyle v_{1}}.

Next, as long as the current path ends at some vertex {\displaystyle v_{i}}, consider the infinitely many vertices that can be reached by simple paths that extend the current path, and group these reachable endpoints according to the possible next neighbor of v_i. There are infinitely many reachable endpoints, but v_i has only finitely many neighbors. Therefore, it follows by a form of the pigeonhole principle that at least one of these neighbors is the next step for extensions reaching infinitely many endpoints. Let {\displaystyle v_{i+1}} be the least such neighbor in this order, and extend the current path by one edge, the edge from {\displaystyle v_{i}} to {\displaystyle v_{i+1}}. This extension preserves the property that infinitely many vertices can be reached by simple paths that extend the current path.

Repeating this process for extending the path produces an infinite sequence of finite simple paths, each extending the previous path in the sequence by one more edge. The union of all of these paths is the ray whose existence was promised by the lemma.

If the graph is countable, the vertices are well-ordered and one can canonically choose the smallest suitable vertex. The recursion therefore requires no choice axiom and gives the result in ZF.
