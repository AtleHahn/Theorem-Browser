All real functions have the power-set cardinality

There are more real-valued functions than real numbers. The hierarchy of infinite sizes extends beyond the continuum and limits how mathematical objects can be parametrized by individual real quantities.

Statement

Write \aleph_0=|\mathbb N| and \mathfrak c=|\mathbb R|. Cardinal products count Cartesian products, powers count function sets, and 2^{|A|} is the size of the power set of A. Then |\mathbb R^{\mathbb R}|=\mathfrak c^{\mathfrak c}=2^{\mathfrak c}>\mathfrak c.

Level
Within undergraduate level
Level justification

Set cardinalities, functions and inner products are undergraduate concepts. Cardinal powers count function sets as explicitly stated, and transcendental means not a polynomial root. No ordinal arithmetic or algebraic-number-theory structure is required.

Proof 1: Exponent laws and Cantor theorem

Use \mathfrak c=2^{\aleph_0} and \mathfrak c\aleph_0=\mathfrak c to obtain

\mathfrak c^{\mathfrak c}=(2^{\aleph_0})^{\mathfrak c}=2^{\mathfrak c\aleph_0}=2^{\mathfrak c}.

Cantor's theorem gives 2^{\mathfrak c}>\mathfrak c.
