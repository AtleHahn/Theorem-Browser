Statement

If f:[a,b]\to\mathbb R is properly Riemann integrable on a compact interval, then |f| is properly Riemann integrable. In particular every continuous real function on [a,b] is absolutely integrable.

Level

Level justification

Proof 1: Composition with the absolute value

As a standard property of the Riemann integral, when {\displaystyle A=[a,b]} is a bounded interval, every continuous function is bounded and (Riemann) integrable, and since {\displaystyle f} continuous implies {\displaystyle |f|} continuous, every continuous function is absolutely integrable. In fact, since {\displaystyle g\circ f} is Riemann integrable on {\displaystyle [a,b]} if {\displaystyle f} is (properly) integrable and {\displaystyle g} is continuous, it follows that {\displaystyle |f|=|\cdot |\circ f} is properly Riemann integrable if {\displaystyle f} is.
