Statement

Let d,m\ge1, 1\le d_i\le d, and let B_i:\mathbb R^d\to\mathbb R^{d_i} be surjective linear maps with \bigcap_i\ker B_i=\{0\}. The set of p\in[0,\infty)^m satisfying \sum_i p_i d_i=d and \dim V\le\sum_i p_i\dim B_i(V) for every linear subspace V\subseteq\mathbb R^d is a closed convex polytope (possibly empty), namely a bounded intersection of finitely many closed linear half-spaces and a hyperplane.

Level
Within undergraduate level
Level justification

Proof 1: Finitely many dimension patterns — outline

Note that while there are infinitely many possible choices of subspace V of \mathbb R^d, there are only finitely many possible inequalities of the form

\dim(V)\leq\sum_i p_i\dim(B_i(V)),

so the subset of p\in[0,\infty)^m satisfying these inequalities and d=\sum_i p_i d_i is a closed convex polytope.

Level
Within undergraduate level
Level justification

All dimensions in each inequality are integers in bounded ranges, so only finitely many coefficient patterns occur. Each condition is a closed linear half-space; the normalization and d_i>=1 imply 0<=p_i<=d/d_i, giving boundedness. Finite-dimensional linear algebra and elementary convexity suffice; the Brascamp–Lieb integral inequality is not used.
