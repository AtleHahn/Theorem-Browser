Statement

For integers k\geq2 and n\geq1, the nth positive integer which is not a kth power is

n+\left\lfloor\sqrt[k]{n+\lfloor\sqrt[k]{n}\rfloor}\right\rfloor.

Proof 1: Evaluate the third stabilized power-count iterate

Use the Lambek–Moser limit formula: if F increasingly enumerates an infinite set of positive integers with infinite complement and F^\#(t) denotes the number of values of x for which F(x)\leq t, then the nth non-member is the limit of the sequence

n,\quad n+F^\#(n),\quad n+F^\#\bigl(n+F^\#(n)\bigr),\quad\dots,

meaning that, after a certain point, all successive values become equal to each other.

For some choices of F, the sequence will start repeating after a fixed number of steps, no matter which value of n it starts with. When this happens, the element of the sequence at the point where it starts repeating gives a direct formula for the complementary function. This happens when F(n)=n^k, the kth power of n (for an integer k\geq2): the sequence always starts repeating by its third term. Using this fact, and F^\#(t)=\lfloor\sqrt[k]{t}\rfloor, the nth positive integer that is not a kth power is given by the third (repeating) term of the limiting formula as

n+\left\lfloor\sqrt[k]{n+\lfloor\sqrt[k]{n}\rfloor}\right\rfloor.

The source states the third-term stabilization fact without proof.
