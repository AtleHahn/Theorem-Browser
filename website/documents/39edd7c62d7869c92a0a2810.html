A Vitali set has zero measure for the stated finitely additive extension, even though countably many translates cover an interval. This makes the difference between finite and countable additivity concrete and exposes a limit of extending ordinary length to all sets.

Statement

Let V\subseteq[0,1] contain exactly one representative of every coset of \mathbb Q in \mathbb R. If \mu is a nonnegative, finitely additive, translation-invariant measure on all bounded subsets of \mathbb R agreeing with interval length, then \mu(V)=0.

Level
Within undergraduate level
Level justification

The set function is explicitly only finitely additive and translation invariant or zero on finite subsets. Rational cosets and countable unions are undergraduate sets/algebra; no Lebesgue integral construction is required.

Proof 1: Finite partial-sum modification outline

Let q_1,q_2,\ldots be a repetition-free enumeration of the rational numbers in [-1,1]. The translated sets V_k=V+q_k are pairwise disjoint: if v+q_k=u+q_\ell, then v-u=q_\ell-q_k\in\mathbb Q, so the representative property gives v=u and then k=\ell. These translates are all contained in [-1,2].

By modifying this disjoint-translate argument using finite additivity, one shows that each Vitali set has Banach measure 0. This does not create any contradiction since Banach measures are not countably additive, but only finitely additive. The source gives this modification as an outline, without writing out the finite partial-sum estimate.
