Statement

For a set of Gödel truth values V\subseteq[0,1] containing 0,1, Peirce’s formula has value one for all u,v\in V if and only if V=\{0,1\}. Every Peirce value is strictly positive, so its double negation has value one, with \neg t=t\Rightarrow0. Here u\Rightarrow v=1 for u\leq v and u\Rightarrow v=v otherwise; the Peirce value is ((u\Rightarrow v)\Rightarrow u)\Rightarrow u.

Level
High school only
Level justification

The truth-value operation and Peirce expression are explicitly piecewise real formulas; validity means their value is one for every permitted pair.

Proof 1: Intermediate values and double negation

The value formula is 1 when u\leq v and u when u>v. All such values are positive. If 0<u<1 is allowed, choose v=0 to obtain the nonunit value u. With only 0,1, the formula always gives 1. For any positive t, t\Rightarrow0=0 and 0\Rightarrow0=1, proving the double-negation assertion.
