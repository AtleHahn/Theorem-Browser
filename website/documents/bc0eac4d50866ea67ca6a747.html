Under the stated model-existence assumption, Borel determinacy exceeds what Zermelo set theory can prove. It illustrates how the strength of foundational axioms constrains which natural existence claims about infinite games can be established.

Statement

Assuming the existence of a model of Zermelo set theory with the axiom of choice, Zermelo set theory does not prove Borel determinacy for games on \{0,1\}. Here Zermelo set theory is the usual set theory Z without the replacement schema; Borel determinacy says that in every alternating perfect-information game of length \omega with binary moves and a Borel payoff set in \{0,1\}^{\mathbb N}, one player has a winning strategy.

Level
Beyond undergraduate level
Level justification

The unprovability claim requires the precise scope of Zermelo set theory, replacement, models and Borel determinacy for infinite games. The combined foundational and descriptive-set-theoretic background exceeds a half-hour introduction. Proof 1: Use Friedman’s countermodel

Friedman’s theorem supplies a model of Zermelo set theory with the axiom of choice in which Borel determinacy for Cantor-space (binary-move) payoff sets fails. Thus Zermelo set theory alone cannot prove the Borel determinacy theorem.

Level
Beyond undergraduate level
Level justification

The soundness inference is short, but the full claim concerns models of a specific set-theoretic axiom system, Borel payoff sets and infinite-game determinacy. These linked set-theoretic and descriptive-set-theoretic concepts require substantial background beyond the ordinary undergraduate baseline.
