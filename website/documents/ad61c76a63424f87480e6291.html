Statement

Let G=(V,E) be a finite undirected graph, allowing repeated edges and loops. Its vertices form V, and each edge has two ends attached to vertices. Write d(v) for the number of attached ends, counting a loop twice. If a specified vertex v_0 has odd degree, then the number of odd-degree vertices different from v_0 is odd.

Level
High school only

Proof 1: The other odd-degree vertices occur an odd number of times

The handshaking lemma makes the total number of odd-degree vertices even. Removing the one specified odd-degree vertex from the count leaves an odd number.

Level

Level justification

The total count of odd-degree vertices is even. Remove the designated one to obtain an odd count. Only finite parity arithmetic is involved.
