Statement

Satisfiability for first-order formulas with prenex prefix \forall\exists\forall\exists^6 is undecidable.

Level

Proof 1: Apply the fixed-prefix halting encoding

Use the stated fixed-prefix reduction: a decision algorithm for satisfiability of formulas with prefix \forall\exists\forall\exists^6 would decide the Turing-machine halting problem. Undecidability of halting therefore rules out this satisfiability algorithm.

Level
Beyond undergraduate level
Level justification

Retain Beyond undergraduate provisionally. Following the argument requires first-order satisfiability and formal reductions, and the named fixed-prefix dependency has a source mismatch: the checked Turing passage establishes a provability result, whereas the companion invokes satisfiability with the same prefix. The exact dependency and its prerequisites should be settled before considering any lower classification.

Undecidability of the halting problem
Kind:

Theorem

Treatment:

Cited without proof

Statement used:

There is no algorithm that decides for every Turing machine and input whether the computation eventually halts.

Application in proof:

Contradict the existence of a halting decider obtained from the hypothesized satisfiability algorithm.

Application level:

Undergraduate level
