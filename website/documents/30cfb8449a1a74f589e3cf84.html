Statement

Let a<b be real. Write H_0^1(a,b) for the real Sobolev space of square-integrable functions with square-integrable weak derivative and zero endpoint traces. Fix a partition a=x_0<x_1<\cdots<x_n=b with integer n\ge1. Let V_h consist of the real continuous functions on [a,b] that are affine on each [x_i,x_{i+1}] and vanish at a,b. Then V_h is a vector subspace of H_0^1(a,b) of dimension n-1.

Level
Beyond undergraduate level
Level justification

Although the dimension count is finite-dimensional, subspace membership is stated in a Sobolev space.

Proof 1: Count the interior nodal values — outline

Use the continuous piecewise-affine functions on the partition with zero endpoint values as V_h. This gives a subspace of H_0^1(a,b) whose dimension is the number of partition nodes that are not endpoints, namely n-1.

Level
Beyond undergraduate level
Level justification

Counting nodal values is finite linear algebra, but the full conclusion includes membership in H0^1 via a weak derivative and zero traces. Sobolev functions, weak derivatives and trace interpretation require graduate analysis.
