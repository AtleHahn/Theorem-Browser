Statement

Let X be a real or complex topological vector space possessing a nonempty proper convex open subset U. Then its continuous dual X^* contains a nonzero functional.

Proof 1: A proper open convex set forces a nonzero continuous functional

Geometric Hahn–Banach implies that there is a closed hyperplane separating U from any point outside U. Explicitly, there is a continuous linear functional f and a real s such that \operatorname{Re}f(u)<s\le\operatorname{Re}f(x) for all u\in U, where x\notin U; for real scalars the real part is unnecessary. In particular, there must exist a nonzero functional on X — that is, the continuous dual space X^* is non-trivial.
