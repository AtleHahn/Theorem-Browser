Statement

All graphs are finite, simple and undirected; containing a graph means containing an isomorphic subgraph, not necessarily induced. K_r(t) is the complete r-partite graph with t vertices per part: edges join precisely vertices in different parts. For fixed integers r\geq2,t\geq1, there is C=C(r,t)>0 such that every K_r(t)-free graph on n vertices has at most Cn^{r-t^{1-r}} copies of K_r, counted as vertex sets. In particular this count is o(n^r) as n\to\infty.

Proof 1: Count clique hyperedges with the hypergraph bound — outline

We use the hypergraph extension of the Kővári–Sós–Turán bound: defining K_{t,\dots,t}^{(r)} to be the complete r-partite r-uniform hypergraph with t vertices in each part, an n-vertex r-uniform hypergraph containing no copy of it has at most Cn^{r-t^{1-r}} hyperedges, for a constant C=C(r,t).

Now, for a given graph H=K_r(t) with r>1,t\geq1, and some graph G with n vertices that does not contain a subgraph isomorphic to H, we define the r-uniform hypergraph F with the same vertices as G and a hyperedge between r vertices in F if they form a clique in G. Note that if F contains a copy of K_{t,\dots,t}^{(r)}, then the original graph G contains a copy of H, as every pair of vertices in distinct parts must have an edge. Thus, F contains no copies of K_{t,\dots,t}^{(r)}, and so it has at most Cn^{r-t^{1-r}}=o(n^r) hyperedges, indicating that there are at most Cn^{r-t^{1-r}}=o(n^r) copies of K_r in G.
