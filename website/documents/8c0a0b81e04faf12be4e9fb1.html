Statement

All graphs here are finite, simple and undirected. A clique is a set of pairwise adjacent vertices. A perfect elimination ordering v_1,\ldots,v_n is an ordering in which C_i=\{v_i\}\cup\{v_j:j>i,\ v_iv_j\in E\} is a clique for every i. Given such an ordering on a nonempty graph, process v_n,\ldots,v_1, assigning each vertex the smallest positive-integer color not already used on a colored neighbor. The result is a proper coloring using the minimum possible number of colors, equal to the largest clique size.

Level
High school only
Level justification

The finite ordering and greedy color rule are explicitly specified; clique size is a finite count.

Proof 1: Optimal coloring from a reversed perfect elimination ordering — outline

Apply the source greedy-coloring recipe in the reverse of the perfect elimination ordering: each new vertex receives the first color not used by an already colored neighbor. In this order its previously colored neighbors are precisely its later neighbors in the given elimination ordering, which together with the vertex form a clique. The source states that this reverse-order greedy coloring is optimal.

Level
High school only
Level justification

Track the already colored neighbors in the reverse order: they form a clique with the new vertex. Comparing distinct clique colors to the greedy color count uses school finite counting.
