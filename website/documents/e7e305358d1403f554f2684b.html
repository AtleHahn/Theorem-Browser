Statement

Let n\ge1. Write \|x\|_\infty=\max_i|x_i| and \|x\|_2=(\sum_i x_i^2)^{1/2}. For a full-rank lattice L\subset\mathbb R^n of covolume d>0, there is a nonzero x\in L with \|x\|_\infty\le d^{1/n} and \|x\|_2\le\sqrt n\,d^{1/n}.

Level justification

Proof 1: Apply Minkowski to the empty shortest-vector cube

Use Minkowski's theorem: a symmetric convex set of volume greater than 2^nd contains a nonzero point of L.

Let l=\min\{\|x\|_\infty:x\in L\setminus\{0\}\}, which exists by lattice discreteness, and set C=\{y:\|y\|_\infty<l\}. Then \operatorname{vol}(C)=(2l)^n. If (2l)^n>2^nd, then C contains a nonzero lattice point, which is a contradiction. Thus l\leq d^{1/n}. In particular, by the standard comparison between the \ell_2 and \ell_\infty norms, a minimizing vector satisfies \|x\|_2\leq\sqrt n\,d^{1/n}.

Within undergraduate level
Level justification

Choose a shortest sup-norm lattice vector, apply the explicit volume theorem to an empty open cube and compare finite-dimensional norms. Undergraduate linear algebra and elementary lattice discreteness suffice; no general measurable-set proof is used.
