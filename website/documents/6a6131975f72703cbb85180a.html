Statement

Fix an admissible numbering \varphi_e of partial computable functions. Let P be a class of total computable functions \mathbb N\to\mathbb N. Suppose a partial computable D returns 1 or 0 according as \varphi_e\in P or not whenever \varphi_e is total; no requirement is made on other indices. For each total computable f there exists n such that every total computable g agreeing with f on 0,\ldots,n satisfies g\in P\iff f\in P.

Proof 1: Force local agreement by a self-referential search

Enumeration

A total function {\displaystyle h:\mathbb {N} \to \mathbb {N} } is said to be ultimately zero if it always takes the value zero except for a finite number of points, i.e., there exists {\displaystyle N} such that {\displaystyle h(n)=0} for all {\displaystyle n\geq N}. Note that such a function is always computable (it can be computed by simply checking if the input is in a certain predefined list, and otherwise returning zero).

We fix {\displaystyle U} a computable enumeration of all total functions which are ultimately zero, that is, {\displaystyle U} is such that:

  • For all {\displaystyle k}, the function {\displaystyle \varphi _{U(k)}} is ultimately zero;
  • For all total function {\displaystyle h} which is ultimately zero, there exists {\displaystyle k} such that {\displaystyle \varphi _{U(k)}=h};
  • The function {\displaystyle U} is itself total computable.

We can build {\displaystyle U} by standard techniques (e.g., for increasing {\displaystyle N}, enumerate ultimately zero functions which are bounded by {\displaystyle N} and zero on inputs larger than {\displaystyle N}).

Write h_k=\varphi_{U(k)} to distinguish each function from its index.

Approximation lemma

Let {\displaystyle P} be as in the statement: a set of total computable functions such that there is an algorithm which, given an index {\displaystyle e} and a promise that {\displaystyle \varphi _{e}} is total, decides whether {\displaystyle \varphi _{e}\in P}.

We first prove a lemma: For all total computable function {\displaystyle f}, and for all integer {\displaystyle N}, there exists an ultimately zero function {\displaystyle h} such that {\displaystyle h} agrees with {\displaystyle f} until {\displaystyle N}, and {\displaystyle f\in P\iff h\in P}.

To prove this lemma, fix a total computable function {\displaystyle f} and an integer {\displaystyle N}, and let {\displaystyle B} be the boolean {\displaystyle f\in P}. By Kleene's recursion theorem, build a program {\displaystyle p} which takes input {\displaystyle x} and takes these steps:

  • If {\displaystyle x\leq N} then return {\displaystyle f(x)};
  • Otherwise, run {\displaystyle x} computation steps of the algorithm D that decides {\displaystyle P} on {\displaystyle p}, and if this returns {\displaystyle B}, then return zero;
  • Otherwise, return {\displaystyle f(x)}.

Clearly, {\displaystyle p} always terminates, i.e., {\displaystyle \varphi _{p}} is total. Therefore, the promise to D run on {\displaystyle p} is fulfilled.

Suppose for contradiction that one of {\displaystyle f} and {\displaystyle \varphi _{p}} belongs to {\displaystyle P} and the other does not, i.e., {\displaystyle (\varphi _{p}\in P)\neq B}. Then we see that {\displaystyle p} computes {\displaystyle f}, since D does not return {\displaystyle B} on {\displaystyle p} no matter the amount of steps. Thus, we have {\displaystyle f=\varphi _{p}}, contradicting the fact that one of {\displaystyle f} and {\displaystyle \varphi _{p}} belongs to {\displaystyle P} and the other does not. This argument proves that {\displaystyle f\in P\iff \varphi _{p}\in P}. Then, the second step makes {\displaystyle p} return zero for sufficiently large {\displaystyle x}, thus {\displaystyle \varphi _{p}} is ultimately zero; and by construction (due to the first step), {\displaystyle \varphi _{p}} agrees with {\displaystyle f} until {\displaystyle N}. Therefore, we can take {\displaystyle h=\varphi _{p}} and the lemma is proved.

Finite agreement

With the approximation lemma, we can now prove finite agreement. Again, fix {\displaystyle P} as in the theorem statement, let {\displaystyle f} be a total computable function and let {\displaystyle B} be the boolean "{\displaystyle f\in P}". By Kleene's recursion theorem, build the program {\displaystyle p} which takes input {\displaystyle x} and runs these steps:

  • Run {\displaystyle x} computation steps of the algorithm D that decides {\displaystyle P} on {\displaystyle p}.
  • If this returns {\displaystyle B} in a certain number of steps {\displaystyle n} (which is at most {\displaystyle x}), then search in parallel, in a fixed dovetailing order independent of x, for {\displaystyle k} such that {\displaystyle h_k} agrees with {\displaystyle f} until {\displaystyle n} and {\displaystyle (h_k\in P)\neq B}. As soon as such a {\displaystyle k} is found, return h_k(x).
  • Otherwise (if D did not return {\displaystyle B} on {\displaystyle p} in {\displaystyle x} steps), return {\displaystyle f(x)}.

We first prove that D returns {\displaystyle B} on {\displaystyle p}. Suppose by contradiction that this is not the case (D returns {\displaystyle \lnot B}, or D does not terminate). Then {\displaystyle p} actually computes {\displaystyle f}. In particular, {\displaystyle \varphi _{p}} is total, so the promise to D when run on {\displaystyle p} is fulfilled, and D returns the boolean {\displaystyle \varphi _{p}\in P}, which is {\displaystyle f\in P}, i.e., {\displaystyle B}, contradicting the assumption.

Let {\displaystyle n} be the number of steps that D takes to return {\displaystyle B} on {\displaystyle p}. We claim that {\displaystyle n} satisfies the conclusion of the theorem: for all total computable function {\displaystyle g} which agrees with {\displaystyle f} until {\displaystyle n}, it holds that {\displaystyle f\in P\iff g\in P}. Assume for contradiction that there exists {\displaystyle g} total computable which agrees with {\displaystyle f} until {\displaystyle n} and such that {\displaystyle (g\in P)\neq B}.

Applying the lemma again, there exists {\displaystyle k} such that {\displaystyle h_k} agrees with {\displaystyle g} until {\displaystyle n} and {\displaystyle g\in P\iff h_k\in P}. Since both {\displaystyle h_k} and {\displaystyle f} agree with {\displaystyle g} until {\displaystyle n}, {\displaystyle h_k} also agrees with {\displaystyle f} until {\displaystyle n}, and since {\displaystyle (g\in P)\neq B} and {\displaystyle g\in P\iff h_k\in P}, we have {\displaystyle (h_k\in P)\neq B}. Therefore, {\displaystyle h_k} satisfies the conditions of the parallel search step in the program {\displaystyle p}, namely: {\displaystyle h_k} agrees with {\displaystyle f} until {\displaystyle n} and {\displaystyle (h_k\in P)\neq B}. This proves that the search in the second step always terminates. We fix {\displaystyle k} to be the value that it finds.

We observe that {\displaystyle \varphi _{p}=h_k}. Indeed, either the second step of {\displaystyle p} returns h_k(x), or the third step returns {\displaystyle f(x)}, but the latter case only happens for {\displaystyle x\leq n}, and we know that {\displaystyle h_k} agrees with {\displaystyle f} until {\displaystyle n}.

In particular, {\displaystyle \varphi _{p}=h_k} is total. This makes the promise to D run on {\displaystyle p} fulfilled, therefore D returns {\displaystyle \varphi _{p}\in P} on {\displaystyle p}.

We have found a contradiction: on the one hand, the boolean {\displaystyle \varphi _{p}\in P} is the return value of D on {\displaystyle p}, which is {\displaystyle B}, and on the other hand, we have {\displaystyle \varphi _{p}=h_k}, and we know that {\displaystyle (h_k\in P)\neq B}.
