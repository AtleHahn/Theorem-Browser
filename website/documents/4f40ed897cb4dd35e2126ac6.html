Statement

Let \Sigma be a finite alphabet, \Sigma^* its finite words, and L\subseteq\Sigma^*. Write x\sim_L y if for every word z, xz\in L if and only if yz\in L. A language is regular if accepted by a deterministic finite automaton (DFA). Then L is regular if and only if \sim_L has finitely many equivalence classes. In that case their number is the minimum number of states of a DFA accepting L, and every minimal such DFA has a unique isomorphism to the canonical DFA with states [x], initial state [\epsilon], transition [x]\xrightarrow{a}[xa], and accepting states [x] with x\in L. Here \epsilon is the empty word, and DFA isomorphisms preserve initial and accepting states and labeled transitions.

Level
Within undergraduate level
Level justification

Equivalence relations and finite words are undergraduate discrete concepts. A deterministic finite automaton adds a finite labeled transition graph with starting/accepting states; the statement gives the canonical construction and isomorphism requirements explicitly. No computability hierarchy is involved.

Proof 1: Canonical quotient automaton and minimality (outline)

If L is regular, construct a minimal DFA to accept it. Clearly, if x,y end up in the same state after running through the DFA, then x\sim_L y, thus the number of equivalence classes of \sim_L is at most the number of DFA states, which must be finite.

Conversely, if \sim_L has a finite number of equivalence classes, then the canonical automaton is a DFA acceptor: let each equivalence class [x] correspond to a state, with transitions [x]\xrightarrow{a}[xa] for each a\in\Sigma, starting state [\epsilon], and accepting states [x] where x\in L. Thus the language is regular. The equality between the number of classes and the minimum number of states follows from this construction and the preceding bound.

Given a minimal DFA acceptor A, we construct an isomorphism to the canonical one.

Construct the following equivalence relation: x\sim_A y if and only if x,y end up on the same state when running through A.

Since A is an acceptor, if x\sim_A y then x\sim_L y. Thus each \sim_L equivalence class is a union of one or more equivalence classes of \sim_A. Further, since A is minimal, the number of states of A is equal to the number of equivalence classes of \sim_L, by the equality just proved. All states of a minimal DFA are reachable, so this is also the number of \sim_A classes. Thus \sim_A=\sim_L.

Now this gives us a bijection between states of A and the states of the canonical acceptor. It is clear that this bijection also preserves the transition rules, the starting state and the accepting states, thus it is an isomorphism of DFA. The isomorphism is unique, since for both DFA, any state is reachable from the starting state for some word x.
