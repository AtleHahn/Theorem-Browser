Statement

Let n\ge1 and let Q,L\in\mathbb R^{n\times n} be symmetric matrices. The following are equivalent:

  1. For every nonzero x\in\mathbb R^n, if x^{\mathsf T}Lx=0, then x^{\mathsf T}Qx<0.
  2. There exists \mu\in\mathbb R such that Q-\mu L is negative definite, that is, x^{\mathsf T}(Q-\mu L)x<0 for every nonzero x\in\mathbb R^n.

Here x^{\mathsf T} denotes transpose. No definiteness assumption on L is imposed.

Proof 1: Quadratic minimization on a regular level set (external)

A link to the proof can be found here (Theorem2.2, printed p.4, proof on p.9; Theorem2.1 and the regular case of Theorem3.2).

Set A=-Q and C=L. If C=0, take \mu=0. Otherwise choose a nonzero level k=x_0^{\mathsf T}Cx_0. On the unit null cone compactness supplies a positive margin \varepsilon; if this cone is empty, any positive \varepsilon works. Apply the source to A-\varepsilon I/2 on x^{\mathsf T}Cx=k. At every feasible point Cx\ne0, so only the regular part of Theorem 3.2 is used. Its conclusion makes A+\mu C positive definite, which is exactly the required negative definiteness of Q-\mu L. The singular part of Theorem 3.2, which invokes Theorem 2.3, is unnecessary; this avoids circularity.
