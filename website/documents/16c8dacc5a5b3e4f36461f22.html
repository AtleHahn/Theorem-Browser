Statement

\mathsf{BPP}\subseteq\Sigma_2^P\cap\Pi_2^P. Here BPP consists of languages decided in randomized polynomial time with bounded two-sided error, \Sigma_2^P consists of languages described by a polynomial-time predicate preceded by polynomially bounded existential then universal string quantifiers, and \Pi_2^P is its complement class.

Proof 1: Random translates and an existential-universal predicate — outline

Without loss of generality, a randomized polynomial-time machine M deciding a language L\in\mathsf{BPP} with error ≤ 2−|x| can be chosen. (All BPP problems can be amplified to reduce the error probability exponentially.) The basic idea of the proof is to define a Σ2 sentence that is equivalent to stating that x is in the language, L, defined by M by using a set of transforms of the random variable inputs.

Let n=|x| and let m=m(n)\ge1 be its polynomially bounded random-bit length. All strict inequalities below are for sufficiently large n.

Since the output of M depends on random input, as well as the input x, it is useful to define which random strings produce acceptance as A(x) = {r | M(x,r) accepts}. The key to the proof is to note that when x ∈ L, A(x) is very large and when x ∉ L, A(x) is very small. By using bitwise parity, ⊕, a set of transforms can be defined as A(x) ⊕ t={r ⊕ t | r ∈ A(x)}. For x\in L, the covering argument below shows that the union of a small finite number of these transforms will contain the entire space of random input strings. Using this fact, a Σ2 sentence and a Π2 sentence can be generated that is true if and only if x ∈ L (as explained in the conclusion).

Covering the random space.

The general idea of the covering argument is to prove that if A(x) covers a large part of the random space {\displaystyle R=\{1,0\}^{m}} then there exists a small set of translations that will cover the entire random space. In more mathematical language:

If {\displaystyle {\frac {|A(x)|}{|R|}}\geq 1-{\frac {1}{2^{|x|}}}}, then {\displaystyle \exists t_{1},t_{2},\ldots ,t_{m}}, where {\displaystyle t_{i}\in \{1,0\}^{m}} such that {\displaystyle \bigcup _{i}A(x)\oplus t_{i}=R.}

Proof. Independently and uniformly at random pick t1, t2, ..., tm. Let {\displaystyle S=\bigcup _{i}A(x)\oplus t_{i}} (the union of all transforms of A(x)).

So, for all r in R,

{\displaystyle \Pr[r\notin S]=\Pr[r\notin A(x)\oplus t_{1}]\cdot \Pr[r\notin A(x)\oplus t_{2}]\cdots \Pr[r\notin A(x)\oplus t_{m}]\leq {\frac {1}{2^{|x|\cdot m}}}.}

Enumerate R as r_1,\ldots,r_{2^m}. The probability that there will exist at least one element in R not in S is

{\displaystyle \Pr {\Bigl [}\bigvee _{i}(r_{i}\notin S){\Bigr ]}\leq \sum _{i}{\frac {1}{2^{|x|\cdot m}}}={\frac {2^{m}}{2^{|x|\cdot m}}}<1.}

Therefore

{\displaystyle \Pr[S=R]\geq 1-{\frac {2^{m}}{2^{|x|\cdot m}}}>0.}

Thus there is a selection for each {\displaystyle t_{1},t_{2},\ldots ,t_{m}} such that

{\displaystyle \bigcup _{i}A(x)\oplus t_{i}=R.}

Noncoverage for nonmembers.

For x\in L, the covering argument shows that A(x) can cover every possible point in the space using a small set of translations. Complementary to this, for x ∉ L only a small fraction of the space is covered by {\displaystyle S=\bigcup _{i}A(x)\oplus t_{i}}. We have:

{\displaystyle {\frac {|S|}{|R|}}\leq m\cdot {\frac {|A(x)|}{|R|}}\leq m\cdot 2^{-|x|}<1}

because {\displaystyle m} is polynomial in {\displaystyle |x|}.

Conclusion.

The two estimates show that language membership of a language in BPP can be expressed as a Σ2 expression, as follows.

{\displaystyle x\in L\iff \exists t_{1},t_{2},\dots ,t_{m}\,\forall r\in R\bigvee _{1\leq i\leq m}(M(x,r\oplus t_{i}){\text{ accepts}}).}

That is, x is in language L if and only if there exist {\displaystyle m} binary vectors, where for all random bit vectors r, TM M accepts at least one random vector ⊕ ti.

The above expression is in Σ2 in that it is first existentially then universally quantified. The quantified strings have polynomial total length and the final predicate is computable in polynomial time. The finitely many exceptional input lengths can be handled separately, since polynomial-hierarchy classes permit finite changes. Therefore BPP ⊆ Σ2. Because BPP is closed under complement, this proves BPP ⊆ Σ2 ∩ Π2.
