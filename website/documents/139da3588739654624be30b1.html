Statement

Let \tau be a finite relational first-order vocabulary, and use effectively coded sentences and finite nonempty \tau-structures. Assume \tau contains a binary relation symbol. The set of sentences true in every finite nonempty \tau-structure is not recursively enumerable.

Proof 1: Negation turns finite validity into the complementary satisfiability problem

The set of finitely satisfiable sentences is recursively enumerable: enumerate all pairs (\mathcal A,\phi) where \mathcal A is finite and \mathcal A\models\phi, and output the sentence components.

Assume that the set of all finitely valid sentences is recursively enumerable. Since \neg\phi is finitely valid if and only if \phi is not finitely satisfiable, we conclude that the set of sentences which are not finitely satisfiable is recursively enumerable. If both a set A and its complement are recursively enumerable, then A is recursive. It follows that the set of finitely satisfiable sentences is recursive, which contradicts Trakhtenbrot's theorem that finite satisfiability is undecidable for the stated vocabulary.

Level justification
