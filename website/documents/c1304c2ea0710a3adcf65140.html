Statement

For a continuous activation \sigma:\mathbb R\to\mathbb R, a one-hidden-layer network means g(x)=C\sigma(Ax+b), applying \sigma to each coordinate, where the hidden width k\ge1 is arbitrary and A\in\mathbb R^{k\times n}, b\in\mathbb R^k, C\in\mathbb R^{m\times k} for m output coordinates (with m=1 for scalar output). Assume these networks uniformly approximate every continuous map on every compact Euclidean set. Then for every fixed positive integer L of hidden layers, networks using \sigma at each hidden layer, arbitrary finite widths, affine preactivations and a linear output also have this approximation property.

Level
Within undergraduate level
Level justification

Understanding the statement involves continuous maps on compact Euclidean sets; uniform approximation; matrix composition and finite network depth. These prerequisites fit undergraduate coursework or a brief extension of it. A bright US college student should be able to understand this statement after approximately 30 minutes of focused background research; this assesses understanding the claim, not its proof.

Proof 1: Identity approximation between layers

A continuous map f on a compact Euclidean set can also be approximated by a network of greater depth by using the one-hidden-layer approximation for the first layer and approximating the identity function with later layers.
