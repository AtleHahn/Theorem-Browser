Statement

A subset of \mathbb N is \Sigma_m^0, for m\ge1, if it is definable in first-order arithmetic by a formula with m alternating blocks of unbounded quantifiers, beginning existentially, followed by a formula with only bounded quantifiers. Vacuous blocks are allowed. For an oracle set A\subseteq\mathbb N, let A' be the set of indices of oracle Turing machines that halt on input 0 with oracle A, and define A^{(0)}=A and A^{(n+1)}=(A^{(n)})'.

For every integer n\ge0 and B\subseteq\mathbb N,

B\in\Sigma_{n+1}^0 \quad\Longleftrightarrow\quad B\text{ is computably enumerable relative to }\varnothing^{(n)}.

Here relative computable enumerability means that an oracle Turing machine with that oracle halts on input x exactly when x\in B.

For every integer n>0, the set \varnothing^{(n)} is \Sigma_n^0-complete: it belongs to \Sigma_n^0, and every B\in\Sigma_n^0 is many-one reducible to it. Thus there is a total computable function g:\mathbb N\to\mathbb N with

x\in B\quad\Longleftrightarrow\quad g(x)\in\varnothing^{(n)}.
