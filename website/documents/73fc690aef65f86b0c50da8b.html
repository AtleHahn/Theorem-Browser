Statement

For integers q\ge1 and a with \gcd(a,q)=1, put \vartheta(x;q,a)=\sum_{p\le x,\ p\equiv a\pmod q}\log p, where p ranges over primes and \log is natural logarithm. Write \varphi(q) for the number of residue classes modulo q coprime to q, and set E(x;q,a)=\vartheta(x;q,a)-x/\varphi(q). For each real A>0 there are constants C_A>0 and x_A\ge2 such that for all real x\ge x_A and 1\le Q\le x,

\sum_{1\le q\le Q}\ \sum_{\substack{a\bmod q\\(a,q)=1}}|E(x;q,a)|^2\le C_A\left(Qx\log x+\frac{x^2}{(\log x)^A}\right).
