Statement

For integers q\ge1 and a with \gcd(a,q)=1, put \vartheta(x;q,a)=\sum_{p\le x,\ p\equiv a\pmod q}\log p, where p ranges over primes and \log is natural logarithm. Write \varphi(q) for the number of residue classes modulo q coprime to q, and set E(x;q,a)=\vartheta(x;q,a)-x/\varphi(q). For each real A>0 there are constants C_A>0 and x_A\ge2 such that for all real x\ge x_A and 1\le Q\le x,

\sum_{1\le q\le Q}\ \sum_{\substack{a\bmod q\\(a,q)=1}}|E(x;q,a)|^2\le C_A\left(Qx\log x+\frac{x^2}{(\log x)^A}\right).

Proof 1: Character sums and a prime-power correction (proof sketch) (external)

A link to the proof can be found here (§1.1, pp. 1–3; Gallagher argument on pp. 2–3.). The linked exposition is a proof sketch with the indicated dependencies.

Let D(q,a)=psi(x;q,a)-theta(x;q,a)>=0. The total weight of higher prime powers is O(sqrt(x)) by Chebyshev's bound (the powers >=3 contribute O(x^(1/3) log(x)^2)). For each q, sum_a D(q,a)^2 <= (sum_a D(q,a))^2=O(x). Summing q<=Q gives O(Qx). Apply |u-v|^2<=2|u|^2+2|v|^2 and Vaughan's Theorem 1; Qx log(2x/Q)<=O(Qx log x) for 1<=Q<=x. This proves the stated bound with adjusted constants, uniformly over the full Q range.
