Statement

Let I be a nonempty directed partially ordered set and (A_i,f_{ij}) an inverse system of nonempty finite sets: for i\leq j, f_{ij}:A_j\to A_i, f_{ii}=\operatorname{id} and f_{ij}f_{jk}=f_{ik}. Then the inverse limit, the set of tuples (a_i) with f_{ij}(a_j)=a_i for all i\leq j, is nonempty.

Level
Within undergraduate level
Level justification

Undergraduate sets, products, maps and orders suffice. The inverse system and limit are explicitly defined by compatibility equations on tuples; directedness is a short order condition. No category theory is needed for this formulation.

Proof 1: Apply compactness to finite compatibility conditions — outline

Work in the usual classical setting with choice. The result can be proved with Tychonoff's theorem, viewing the finite sets as compact discrete spaces, and then using the finite intersection property characterization of compactness.
