Statement

Let G be a group and A\trianglelefteq G a normal subgroup, let H=G/A, and let K=A^H be the group of all functions H\to A under pointwise multiplication. With the action (h\cdot f)(u)=f(h^{-1}u), form A\wr H=K\rtimes H, with multiplication (f,h)(g,k)=(f(h\cdot g),hk). There is an injective homomorphism \theta:G\to A\wr H satisfying \theta(A)=\theta(G)\cap K, where K is identified with K\times\{1\}.

Level
Within undergraduate level
Level justification

Quotients and normal subgroups are undergraduate group theory. The function group, action and semidirect multiplication are explicitly defined, adding a limited related construction.

Proof 1: Coset-representative construction

This proof comes from Dixon–Mortimer.

Define \psi:G\to H to be the quotient homomorphism, whose kernel is A. Choose a set T=\{t_u:u\in H\} of (right) coset representatives of A in G, where \psi(t_u)=u. Then for all x in G, t_u^{-1}xt_{\psi(x)^{-1}u}\in\ker\psi=A. For each x in G, we define a function f_x:H\to A such that f_x(u)=t_u^{-1}xt_{\psi(x)^{-1}u}. Then the embedding \theta is given by \theta(x)=(f_x,\psi(x))\in A\wr H.

We now prove that this is a homomorphism. If x and y are in G, then \theta(x)\theta(y)=(f_x(\psi(x)\cdot f_y),\psi(xy)). Now (\psi(x)\cdot f_y)(u)=f_y(\psi(x)^{-1}u), so for all u in H,

\begin{aligned} f_x(u)(\psi(x)\cdot f_y)(u) &=t_u^{-1}xt_{\psi(x)^{-1}u}t_{\psi(x)^{-1}u}^{-1}yt_{\psi(y)^{-1}\psi(x)^{-1}u}\\ &=t_u^{-1}xyt_{\psi(xy)^{-1}u}, \end{aligned}

so f_x(\psi(x)\cdot f_y)=f_{xy}. Hence \theta is a homomorphism as required.

The homomorphism is injective. If \theta(x)=\theta(y), then both f_x(u)=f_y(u) (for all u) and \psi(x)=\psi(y). Then t_u^{-1}xt_{\psi(x)^{-1}u}=t_u^{-1}yt_{\psi(y)^{-1}u}, but we can cancel t_u^{-1} and t_{\psi(x)^{-1}u}=t_{\psi(y)^{-1}u} from both sides, so x=y, hence \theta is injective. Finally, \theta(x)\in K precisely when \psi(x)=1, in other words when x\in A (as A=\ker\psi).
