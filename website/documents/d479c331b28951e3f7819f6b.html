Statement

Given a finite integer matrix A, one can decide in finite time whether every finite colouring of the positive integers admits a solution x of Ax=0 all of whose coordinates are positive integers of the same colour.

Proof 1: Finite search for a columns partition — outline

Use Rado’s columns theorem: an integer matrix A has a positive integer solution to Ax=0 in one colour under every finite colouring if and only if its columns can be partitioned into nonempty blocks C_1,\ldots,C_t such that the first block sums to zero and each later block sum is a rational linear combination of columns in earlier blocks.

Given a system of linear equations it is a priori unclear how to check computationally that it is regular. Fortunately, Rado's theorem provides a criterion which is testable in finite time. Instead of considering colourings (of infinitely many natural numbers), it must be checked that the given matrix satisfies the columns condition. Since the matrix consists only of finitely many columns, this property can be verified in finite time.
