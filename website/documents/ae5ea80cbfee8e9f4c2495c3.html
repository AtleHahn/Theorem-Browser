Statement

Let d\ge1 be an integer and let [0,1]^d denote the real d-tuples with all coordinates in [0,1]. Write \|z\|_\infty=\max_{1\le i\le d}|z_i|. Suppose f:[0,1]^d\to[0,1]^d is Lipschitz with constant 0\le L<1 in this norm. Run PFix with residual tolerance \varepsilon=(1-L)\delta, where \delta>0. It returns a point within \delta of the unique fixed point, using O(\log^d(1/((1-L)\delta))) exact value queries as \delta\downarrow0 for fixed d,L.

Level
Within undergraduate level
Level justification

The cube, contraction and residual are undergraduate metric/calculus notions. PFix is used through an explicit input/output query guarantee, a limited algorithm-cost interpretation rather than its construction.

Proof 1: Substitute the contraction-adjusted tolerance into PFix

PFix has the external residual guarantee O(\log^d(1/\varepsilon)) queries. Execute it with \varepsilon=(1-L)\delta. The contraction residual-to-distance estimate makes its output a \delta-absolute fixed point. The same substitution in the residual query bound gives O(\log^d(1/((1-L)\delta))).

Level justification

Substitute the contraction-adjusted tolerance into the supplied residual and query guarantees. Undergraduate metric-space contractions and elementary algorithmic asymptotic bounds suffice; no construction of PFix is required.
