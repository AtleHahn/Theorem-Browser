Statement

For z>0 define \Gamma(z)=\int_0^\infty e^{-x}x^{z-1}\,dx. For every integer n\geq0, \Gamma(n+1)=n!, with 0!=1.

Proof 1: The gamma function extends the factorial — proof

The gamma function is an example of a special function, defined as an improper integral for {\displaystyle z>0}. For z>1, integration by parts illustrates it to be an extension of the factorial function:

{\displaystyle {\begin{aligned}\Gamma (z)&=\int _{0}^{\infty }e^{-x}x^{z-1}dx\\[6pt]&=-\int _{0}^{\infty }x^{z-1}\,d\left(e^{-x}\right)\\[6pt]&=-{\Biggl [}e^{-x}x^{z-1}{\Biggl ]}_{0}^{\infty }+\int _{0}^{\infty }e^{-x}d\left(x^{z-1}\right)\\[6pt]&=0+\int _{0}^{\infty }\left(z-1\right)x^{z-2}e^{-x}dx\\[6pt]&=(z-1)\Gamma (z-1).\end{aligned}}}

Since

{\displaystyle \Gamma (1)=\int _{0}^{\infty }e^{-x}\,dx=1,}

for integers n\ge0, applying this formula repeatedly at z=n+1,n,\ldots,2 (with the base value handling n=0) gives the factorial: {\displaystyle \Gamma (n+1)=n!}

Level
Within undergraduate level
Level justification

Integrate the defining improper integral by parts, use vanishing exponential boundary terms and iterate from Gamma(1)=1. This is undergraduate calculus.
