Statement

Let X be a normal topological space, meaning that any two disjoint closed subsets have disjoint open neighborhoods. Let A\subseteq X be closed and f:A\to\mathbb R continuous. Then there is a continuous function F:X\to\mathbb R with F|_A=f.

If f is bounded, F can be chosen to satisfy

\sup_{x\in X}|F(x)|=\sup_{a\in A}|f(a)|,

where the supremum of the absolute values on an empty domain is taken as zero. No boundedness assumption on f is required for the extension assertion.
