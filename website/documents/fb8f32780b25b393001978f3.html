Statement

Let X be a CW complex and n\ge1 an integer. Inclusion X^n\hookrightarrow X induces a bijection on path components, isomorphisms \pi_i(X^n,a)\to\pi_i(X,a) for every base vertex a\in X^0 and 1\le i<n, and a surjection for i=n.

Proof 1: Homotopy groups of a CW skeleton — outline

Use the relative-cell connectivity result: if a CW pair (Z,C) has no cells outside C in dimensions at most n, then \pi_i(Z,C)=0 for i\le n, with the usual low-dimensional pointed-set interpretation.

We have in particular that {\displaystyle (X,X^{n})\,} is n-connected, so it follows from the long exact sequence of homotopy groups for the pair {\displaystyle (X,X^{n})\,} that we have isomorphisms {\displaystyle \pi _{i}(X^{n})\,}→{\displaystyle \pi _{i}(X)\,} for all {\displaystyle i<n\,} and a surjection {\displaystyle \pi _{n}(X^{n})\,}→{\displaystyle \pi _{n}(X)\,}.
