Statement

Let X_1,X_2,\ldots be independent identically distributed real random variables with distribution function F(x)=\tfrac12+\pi^{-1}\arctan(x/\pi), and let M_n=\max_{1\le j\le n}X_j. For each real u>-1, \Pr(M_n/n-1\le u)\to\exp(-1/(1+u)) as n\to\infty.

Level
Within undergraduate level
Level justification

The distribution function is explicitly given, so understanding the statement needs only independence, maxima of finite samples and cumulative probability. These elementary probability definitions connect directly to products and the displayed ordinary limit; no general measure-theoretic probability is needed for comprehension.

Proof 1: A Fréchet limit from the explicit Cauchy distribution function — outline

A little bit of calculus shows that the right tail's cumulative distribution {\displaystyle \ 1-F(x)\ } is asymptotic to {\displaystyle \ {\frac {1}{\ x\ }}\ ,} or

{\displaystyle \ln F(x)\sim {\frac {-1~}{\ x\ }}\quad {\mathsf {~as~}}\quad x\rightarrow \infty \ ,}

so we have

{\displaystyle \ln \left(\ F(x)^{n}\ \right)=n\ \ln F(x)\sim {\frac {-n~~}{x}}~.}

Thus we have

{\displaystyle F(x)^{n}\approx \exp \left({\frac {-n~~}{x}}\right)}

and letting {\displaystyle \ u\equiv {\frac {x}{\ n\ }}-1\ } (and skipping some explanation)

{\displaystyle \lim _{n\to \infty }{\Bigl (}\ F{\bigl (}\ n\ (u+1)\ {\bigr )}^{n}\ {\Bigr )}=\exp \left({\tfrac {-1~}{\ 1+u\ }}\right)\ }

for any fixed u>-1.

Independence gives \Pr(M_n\le x)=F(x)^n.
