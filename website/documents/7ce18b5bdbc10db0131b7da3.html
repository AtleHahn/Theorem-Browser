Restricting attention to uniquely solvable instances does not simply remove the essential difficulty of NP search: an efficient solver with this promise would yield randomized algorithms for all NP problems. The result links uniqueness, randomness, and the practical distinction between recognizing a solution and finding whether one exists.

Statement

Suppose there is a deterministic polynomial-time algorithm for Boolean formulas which rejects every unsatisfiable formula and accepts every formula with exactly one satisfying assignment; its output on formulas with more than one satisfying assignment is unrestricted. Then

\mathrm{NP}=\mathrm{RP}.

Here \mathrm{NP} consists of decision problems whose yes instances have polynomial-size certificates checkable in deterministic polynomial time. The class \mathrm{RP} consists of decision problems having randomized polynomial-time algorithms that never accept no instances and accept each yes instance with probability at least 1/2.

Proof 1: Pairwise-independent affine isolation (external)

A link to the proof can be found here (Sections2.1–2.2.1, pp.1–2).

Try every hash length m=2,\ldots,n+2, correcting the printed range. Encode each affine parity test with gates and impose both directions of every gate equivalence; each assignment of the original variables then has exactly one extension to the auxiliary variables. Thus isolation means exactly one satisfying assignment of the entire formula. For a nonempty solution set, one length succeeds with probability at least 1/8. Repeat the full list eight times with independent maps and accept if any call to the assumed algorithm accepts: the failure probability is at most (7/8)^8<1/2. Unsatisfiable inputs remain unsatisfiable on every trial, so outputs on multiple-solution formulas cannot create a false positive. Finally, polynomial verifier encodings give \mathrm{NP}\subseteq\mathrm{RP}, while an accepting random-bit string is an NP certificate for any RP computation.

Finite binary linear algebra proves pairwise independence, and a union bound gives an isolation probability bounded below by a constant for one hash length. Trying all lengths and repeating gives one-sided randomized decision. Boolean gate constraints encode verification and hash computations with polynomial size; these are undergraduate discrete mathematics and probability.
