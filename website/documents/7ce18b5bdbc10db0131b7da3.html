Statement

Suppose there is a deterministic polynomial-time algorithm for Boolean formulas which rejects every unsatisfiable formula and accepts every formula with exactly one satisfying assignment; its output on formulas with more than one satisfying assignment is unrestricted. Then

\mathrm{NP}=\mathrm{RP}.

Here \mathrm{NP} consists of decision problems whose yes instances have polynomial-size certificates checkable in deterministic polynomial time. The class \mathrm{RP} consists of decision problems having randomized polynomial-time algorithms that never accept no instances and accept each yes instance with probability at least 1/2.
