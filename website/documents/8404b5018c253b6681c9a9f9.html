Statement

Under classical semantics, for any sentences P,Q, every model of P\land\neg P satisfies Q; equivalently P\land\neg P\models Q. Semantic consequence here means truth in every model of the premises.

Level
Within undergraduate level
Level justification

Classical truth conditions and universal quantification over models suffice. Semantic consequence is explicitly defined, and no formal syntax coding or model construction is needed for the contradictory-premise assertion.

Proof 1: Vacuous consequence from absence of models

A sentence {\displaystyle P} is a semantic consequence of a set of sentences {\displaystyle \Gamma } if and only if every model of {\displaystyle \Gamma } is a model of {\displaystyle P}. However, there is no model of the contradictory set {\displaystyle (P\wedge \lnot P)}. A fortiori, there is no model of {\displaystyle (P\wedge \lnot P)} that is not a model of {\displaystyle Q}. Thus, vacuously, every model of {\displaystyle (P\wedge \lnot P)} is a model of {\displaystyle Q}. Thus {\displaystyle Q} is a semantic consequence of {\displaystyle (P\wedge \lnot P)}.
