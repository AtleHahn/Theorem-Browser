Statement

Let Q\in\mathbb R^{n\times n} be symmetric and B\in\mathbb R^{m\times n}. Then x^TQx<0 for every nonzero x\in\ker B if and only if there is \mu\in\mathbb R such that Q-\mu B^TB\prec0, where M\prec0 means x^TMx<0 for every nonzero real vector x.

Proof 1: Substitute the Gram matrix in Finsler’s lemma — outline

The source specifies the positive-semidefinite case by the substitution L=B^TB in Finsler’s lemma. The imported lemma says that negativity of x^TQx on nonzero vectors satisfying x^TLx=0 is equivalent to Q-\mu L\prec0 for some real \mu. With the supplied substitution the constraint is x^TB^TBx=0, i.e. Bx=0, giving the two displayed forms.
