Statement

Let f:X\to Y be constant with value y, and let L,R\subseteq X be nonempty disjoint sets. Then f(L\setminus R)=\{y\}\supsetneq f(L)\setminus f(R)=\varnothing.

Level
High school only
Level justification

Constant functions and differences of nonempty disjoint sets use elementary membership.

Proof 1: Compare singleton images with the empty set

Let f:X\to Y be any constant function with image f(X)=\{y\} and suppose that L,R\subseteq X are non-empty disjoint subsets. This implies that L\setminus R=L is not empty and so its image under f is equal to \{y\}.

The containment f(L\setminus R)\supsetneq f(L)\setminus f(R) is strict:

\{y\}=f(L\setminus R)\ne f(L)\setminus f(R) =\{y\}\setminus\{y\}=\varnothing.

In words: functions might not distribute over set subtraction \setminus.

Level
High school only
Level justification

The nonempty difference L minus R is L and maps to the singleton, while the two singleton images have empty difference. This is elementary set membership.
