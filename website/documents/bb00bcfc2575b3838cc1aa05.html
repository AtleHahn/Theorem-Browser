Statement

Let C\subset\mathbb R^d be a nonempty closed bounded convex set, and let E be its extreme-point set. For every c\in C there are nonnegative weights w(e) on E, only finitely many nonzero, with \sum_e w(e)=1 and c=\sum_e w(e)e. The probability measure \mu=\sum_e w(e)\delta_e then satisfies f(c)=\int_C f\,d\mu for every real affine function f on C. Here \delta_e is unit point mass, so this integral is the finite sum \sum_e w(e)f(e).

Proof 1: Turn a Minkowski convex combination into atomic weights — outline

The classical result of Hermann Minkowski says that in Euclidean space, a bounded, closed convex set C is the convex hull of its extreme point set E, so that any c in C is a (finite) convex combination of points e of E. Here E may be a finite or an infinite set. In vector terms, by assigning non-negative weights w(e) to the e in E, only finitely many nonzero, we can represent any c in C as

{\displaystyle c=\sum _{e\in E}w(e)e\ }

with

{\displaystyle \sum _{e\in E}w(e)=1.\ }

In any case the w(e) give the probability measure \mu=\sum_{e\in E}w(e)\delta_e supported on a finite subset of E. For any affine function f on C, its value at the point c is

{\displaystyle f(c)=\int_C f\,d\mu=\sum_{e\in E}w(e)f(e).}
