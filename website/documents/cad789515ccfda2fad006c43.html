Statement

If x,y are incomparable in a partial order R on X, then S=R\cup\{(q,p):qRx\text{ and }yRp\} is a partial order strictly containing R.

Level
Within undergraduate level
Level justification

Sets, binary relations and partial-order axioms are undergraduate foundations. The new relation is explicitly defined from the old relation and an incomparable pair, requiring no further order theory.

Proof 1: One-pair closure construction (outline)

Suppose that a given partial order R does not compare x and y. Then the order is extended by first adding the pair (x,y) to the relation, which may result in a non-transitive relation, and then restoring transitivity by adding all pairs (q,p) such that qRx and yRp. This produces a relation that is still reflexive, antisymmetric and transitive and that strictly contains the original one. By reflexivity, the added pairs already include (x,y), so this is exactly the relation S in the statement. The source leaves the relation checks implicit.
