Statement

For a real continuous function f on [0,1] with \int_0^1 f=0, let Tf=u be the unique twice continuously differentiable function with u''+f=0, u'(0)=u'(1)=0 and \int_0^1u=0. Then

\int_0^1 u(x)^2\,dx\le\pi^{-2}\int_0^1 f(x)u(x)\,dx=\pi^{-2}\int_0^1u'(x)^2\,dx.

Proof 1: Eigenvalue bound and integration by parts — outline

Use the standard operator realization as an explicit external prerequisite: the mean-zero Neumann inverse T extends to a compact positive self-adjoint operator on the mean-zero subspace of L2([0,1]). The spectral theorem for compact self-adjoint operators therefore applies to the eigenvalues computed below.

Given a continuous function f on [0, 1] of average value zero, let Tf denote the function u on [0, 1] which is of average value zero, and with u′′ + f = 0 and u′(0) = u′(1) = 0. From basic analysis of ordinary differential equations with constant coefficients, the eigenvalues of T are (kπ)−2 for nonzero integers k, the largest of which is then π−2. Because T is a bounded and self-adjoint operator, it follows that

{\displaystyle \int _{0}^{1}Tf(x)^{2}\,\mathrm {d} x\leq \pi ^{-2}\int _{0}^{1}f(x)Tf(x)\,\mathrm {d} x={\frac {1}{\pi ^{2}}}\int _{0}^{1}(Tf)'(x)^{2}\,\mathrm {d} x}

The equality is due to integration by parts.
