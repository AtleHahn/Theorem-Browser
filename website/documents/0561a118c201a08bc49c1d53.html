Statement

For a finite partially ordered set, the minimum number of antichains partitioning it equals the maximum size of a chain. A chain is a set of mutually comparable elements, and an antichain consists of mutually incomparable elements.

Proof 1: Comparability graph and its complement

The comparability graph of a partially ordered set joins two distinct elements exactly when they are comparable. A graph is perfect when, in every induced subgraph, the size of a largest clique equals the minimum number of colors in a proper coloring.

Mirsky's theorem characterizing the height of a partially ordered set in terms of partitions into antichains can be formulated as the perfection of the comparability graph of the partially ordered set, and Dilworth's theorem characterizing the width of a partially ordered set in terms of partitions into chains can be formulated as the perfection of the complements of these graphs. Thus, the perfect graph theorem—the complement of a perfect graph is perfect—can be used to prove Mirsky's theorem from Dilworth's theorem. Here Dilworth's theorem is used as a prerequisite: the maximum size of an antichain equals the minimum number of chains in a partition.
