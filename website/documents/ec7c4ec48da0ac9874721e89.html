Statement

Let G be a finite directed graph and A,B\subseteq V(G). A directed AB-path starts in A, ends in B and has no internal vertex in A\cup B; a zero-edge path in A\cap B is allowed. An AB-separator is a vertex set meeting every directed AB-path. There exist a family \mathcal P of pairwise vertex-disjoint AB-paths and an AB-separator Q such that every path in \mathcal P meets Q in exactly one vertex and every vertex of Q lies on a path in \mathcal P.

Level
High school only
Level justification

All directed path and separator conditions, including zero-edge paths, are locally defined on a finite graph.

Proof 1: Count intersections of optimal disjoint paths with a minimum separator

Use the directed set-to-set Menger theorem: the minimum size of a vertex set meeting all directed AB-paths equals the maximum number of pairwise vertex-disjoint AB-paths. Choose a maximum family \mathcal P and a minimum separator Q, with common size k. Every one of the k disjoint paths contains at least one vertex of Q, and these vertices are distinct. Since Q has exactly k vertices, every path contains exactly one and no vertex of Q remains outside the paths. This also covers k=0.

Level
High school only
Level justification

Choose equally sized optimal path and separator sets using the stated theorem and count one distinct separator vertex per disjoint path. Finite counting suffices.
