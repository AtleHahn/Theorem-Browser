For every positive integer n, there is an n-vertex graph with O(n^{3/2}) edges containing every n-vertex planar graph as a not-necessarily-induced subgraph.

Proof 1: Sparse universal graphs for planar graphs (outline)

Use the source’s strengthened separator theorem: for each size m, a graph-independent separator size c(m)=O(\sqrt m) can be chosen, with parity arranged so the two remaining sides each have (m-c(m))/2 vertices. This gives a fixed recursive hierarchy of vertex slots for every n-vertex planar graph. Join every pair of slots that occurs in a common ancestor-separator bag. Equivalently, each separator slot is joined to all slots below its hierarchy node, and each separator is a clique. Every planar graph embeds by assigning its separators and its equal-sized recursive parts to these fixed slots. At a node of size m, the new edges number O(m\sqrt m). The two child sizes are at most m/2, so summing this work down the hierarchy is a geometric series with ratio at most 2(1/2)^{3/2}<1. Thus the total is O(n^{3/2}), on exactly the original n slots.
