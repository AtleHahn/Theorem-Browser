Statement

Let G be a finite directed graph with n\ge2 labeled vertices, source s, and read-only adjacency input. Put R_k=\{v:\text{there is a directed path from }s\text{ to }v\text{ of length at most }k\}. For 0\le k\le n-1, there is a nondeterministic O(\log n)-space procedure with a successful branch precisely when w\in R_k.

Level
Within undergraduate level
Level justification

The graph, path-length bound and read-only input are explicit. A successful nondeterministic branch means one sequence of permitted guesses succeeds, while space counts the binary bits stored apart from the input. These concrete definitions, O(log n) as a constant multiple of binary label length, and elementary graph paths are a small extension of undergraduate mathematical reasoning within about 30 minutes; no general machine-class theory is needed.

Proof 1: Bounded-path verification in nondeterministic logarithmic space — outline

To check that w\in R_k, nondeterministically look for a path from s to w of length at most k. If this check fails, abort the current branch.

function verify_reachable(G, s, w, k)
    // Verifies that w ∈ Rk. If this is not the case, aborts
    // the current computation branch, rejecting the input.
    if s = w then
        return
    c ← s
    repeat k times
        // Aborts if there is no edge from c, otherwise
        // non-deterministically branches
        guess an edge c → d in G
        c ← d
        if c = w then
            return
    // We did not guess a path.
    reject

The procedure stores only the current vertex, the guessed next vertex, and a step counter, together with its fixed input parameters. Vertex labels and the counter require O(\log n) bits; the graph input is read-only.
