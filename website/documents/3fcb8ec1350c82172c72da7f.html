Statement

Given four circles forming a packing of the tetrahedron graph K_4 (four positive-radius circles with disjoint interiors, each tangent to the other three), there is a second set of four mutually tangent circles, indexed by the four triangular faces, such that each face circle is orthogonal to the three original circles incident with that face. Orthogonality means that the circles meet at right angles.

Level
High school only
Level justification

The statement describes a finite configuration of circles and right angles using elementary solid/plane geometry.

Proof 1: Specialize primal–dual packing to the tetrahedron — outline

Apply the primal–dual circle-packing theorem to the tetrahedron graph. Its four vertices give the first four circles and its four triangular faces give four dual circles; the dual graph is again K_4. Every face is incident with three vertices, so the corresponding three circle intersections are orthogonal. The uniqueness of the tetrahedral packing up to Möbius transformations and reflection allows the primal configuration to be the given four circles; these transformations preserve tangency and intersection angles.
