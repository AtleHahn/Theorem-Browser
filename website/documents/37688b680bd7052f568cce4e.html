Statement

There exists a real number x\in(0,1) normal in every integer base b\ge2: for each finite block of m base-b digits, its limiting frequency in the base-b expansion of x is b^{-m}.

Proof 1: A probability-one set is nonempty

Use the probabilistic theorem explicitly stated by the source: a real number chosen uniformly from (0,1) is normal almost surely. Thus the set of normal numbers in (0,1) has probability one. It cannot be empty, since the empty set has probability zero. Hence a normal number exists.
