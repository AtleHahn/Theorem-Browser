Statement

Assume Zorn’s lemma. If every chain in a poset P has an upper bound and a\in P, there is a maximal b\in P with a\leq b.

Level
Within undergraduate level
Level justification

Orders, maximal elements and chains are elementary set/order concepts. Zorn is a stated hypothesis in the existence assertion, so understanding its conclusion requires only the upper-bound condition, not additional set theory.

Proof 1: Restrict to the upper cone

Stated dependency

Zorn’s lemma: a partially ordered set in which every chain (including the empty chain) has an upper bound has a maximal element. A chain is a totally ordered subset; an element m is maximal if m\leq y implies m=y.

Argument

Indeed, let {\displaystyle Q=\{x\in P\mid x\geq a\}} with the partial ordering from {\displaystyle P}. The empty chain in Q has upper bound a. Then, for a nonempty chain in {\displaystyle Q}, an upper bound in {\displaystyle P} is in {\displaystyle Q} and so {\displaystyle Q} satisfies the hypothesis of Zorn's lemma and a maximal element in {\displaystyle Q} is a maximal element in {\displaystyle P} as well.

Level
Within undergraduate level
Level justification

Restrict to the upper cone, verify its chain upper bounds and apply the explicitly stated Zorn lemma. Undergraduate sets and partial orders suffice.
