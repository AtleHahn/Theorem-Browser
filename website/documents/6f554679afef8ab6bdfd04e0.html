Statement

Graphs below are finite, undirected and simple. A clique is a set of pairwise adjacent vertices; an independent set has no edges within it. The complete r-partite graph joins all vertices in different parts and none in the same part. Write T(n,r) for this graph on n vertices with r part sizes differing by at most 1 (empty parts allowed). Let H be a fixed graph of chromatic number q\ge3 (the smallest number of colors in a proper vertex coloring), and let 2\le a<q be an integer. Then T(n,q-1) is H-free and its number of a-cliques is (\binom{q-1}{a}/(q-1)^a+o(1))n^a as n\to\infty. Thus this is a constructive lower bound for the maximum number of a-cliques in an H-free graph.

Proof 1: Color the parts and choose one vertex from each — outline

One can see that the Turán graph T(n,\chi(H)-1) cannot contain any copies of H, so the Turán graph establishes the lower bound.

Since the Turán graph contains r parts with size around n/r, the number of K_as in T(n,r) is around

\binom ra\left(\frac nr\right)^a.

Taking r=\chi(H)-1=q-1, the Turán graph T(n,\chi(H)-1) attains the desired number of copies of K_a.
