Statement

Let X\subseteq\mathbb R^n consist of N\geq1 points, let 0<\varepsilon<1, and let k be a nonnegative integer with k\geq15\ln(N)/\varepsilon^2. There is a linear map f:\mathbb R^n\to\mathbb R^k such that (1+\varepsilon)^{-1}\|u-v\|\leq\|f(u)-f(v)\|\leq(1+\varepsilon)\|u-v\| for all u,v\in X.

Proof 1: Tolerance rescaling from the squared-distance theorem (outline)

Use the source-stated squared-distance Johnson–Lindenstrauss theorem: for 0<\eta<1 and integer k>8\ln N/\eta^2, a linear map preserves all squared pairwise distances within factors 1\pm\eta. If N=1, any linear map satisfies the conclusion. If N>1, put \eta=3\varepsilon/4. Since 128/9<15, the assumed k is strictly greater than 8\ln N/\eta^2. Apply that theorem and take square roots. The inequalities (1+\varepsilon)^{-1}<\sqrt{1-3\varepsilon/4} and \sqrt{1+3\varepsilon/4}<\sqrt{1+\varepsilon}<1+\varepsilon, valid for 0<\varepsilon<1, give the conclusion.
