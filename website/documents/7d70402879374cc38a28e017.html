Statement

Let 1<p<\infty.

For every sequence (a_n)_{n\ge1} of nonnegative real numbers,

\sum_{n=1}^{\infty}\left(\frac{a_1+\cdots+a_n}{n}\right)^p \le \left(\frac{p}{p-1}\right)^p\sum_{n=1}^{\infty}a_n^p.

If the right side is finite, equality holds if and only if every a_n is zero.

For every nonnegative measurable function f:(0,\infty)\to[0,\infty),

\int_0^\infty\left(\frac1x\int_0^x f(t)\,dt\right)^p\,dx \le\left(\frac{p}{p-1}\right)^p\int_0^\infty f(x)^p\,dx.

The integrals are Lebesgue integrals. If the right side is finite, equality holds if and only if f=0 almost everywhere. Both inequalities allow infinite nonnegative sums or integrals.

Level
Beyond undergraduate level
Level justification

The discrete form is elementary to state, but the complete measurable-function formulation uses Lebesgue integration and almost-everywhere equality. Their cumulative burden is not confidently a small extension of the assumed introductory analysis background.
