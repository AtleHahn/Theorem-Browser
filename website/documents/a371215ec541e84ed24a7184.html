Statement

In Quine’s New Foundations set theory, let S be a set and \mathcal P_1(S)=\{\{s\}:s\in S\} its family of singleton subsets. No function f:\mathcal P_1(S)\to\mathcal P(S) is surjective. Consequently |\mathcal P_1(S)|<|\mathcal P(S)|, where this means there is an injection but no bijection.

Level
Beyond undergraduate level
Level justification

The assertion is made within New Foundations rather than ordinary set theory; its stratified comprehension and singleton-cardinality distinctions require specialized foundational preparation. Under the statement-understanding criterion, a bright US college student would need more than approximately 30 minutes of focused background research to understand the full claim.

Proof 1: Use the stratified singleton diagonal subset

The modified diagonal argument begins by noticing that

D=\{s\in S:s\notin f(\{s\})\}

is a set in NF, by stratified comprehension.

The proof follows by the fact that if f were indeed a map onto \mathcal P(S), there would be an r in S such that f(\{r\}) coincides with the modified diagonal set above. This would show that if r is not in f(\{r\}), then r is in f(\{r\}) and vice versa, a contradiction. Inclusion of \mathcal P_1(S) in \mathcal P(S) supplies the injection for the strict cardinal inequality.

Level justification
