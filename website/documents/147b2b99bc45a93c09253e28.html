Statement

Let q be an odd prime power, K=\operatorname{GF}(q), and let \chi(0)=0, \chi(a)=1 for nonzero squares and \chi(a)=-1 for nonsquares. Define the real matrix Q by Q_{ab}=\chi(a-b) for a,b\in K. Suppose q\equiv3\pmod4. Let j be the all-ones column of length q, C=\begin{bmatrix}0&j^T\\-j&Q\end{bmatrix} and H=I_{q+1}+C. Then H has entries \pm1, HH^T=(q+1)I_{q+1}, and H+H^T=2I_{q+1}; it is a skew Hadamard matrix.

Proof 1: Add the identity to a skew conference matrix

Use the Paley conference-matrix properties: C is skew-symmetric and CC^T=qI. Since C has zero diagonal and entries \pm1 off the diagonal,

H=I+C=I+\begin{bmatrix}0&j^T\\-j&Q\end{bmatrix}

has entries \pm1. Since C is skew-symmetric with CC^T=qI, it follows that

HH^T=(I+C)(I-C)=(q+1)I.

The matrix H is a skew Hadamard matrix, which means it satisfies H+H^T=2I.
