Statement

For every positive integer n, the number d(n) of positive divisors is odd if and only if n is a square.

Level
High school only
Level justification

The claim concerns elementary integer divisibility and parity.

Proof 1: Pair complementary divisors

Pair every divisor d with the divisor n/d. If n is not a square, each pair consists of two distinct divisors, so the count is even. If n is a square, only d=\sqrt n is paired with itself; all others occur in pairs, so the count is odd.

Level
High school only
Level justification

Pair each divisor with its complementary factor; exactly a square has one unpaired square-root divisor. School divisibility and parity suffice.
