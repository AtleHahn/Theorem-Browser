Statement

The power set \mathcal P(\mathbb N) has cardinality strictly larger than \mathbb N, so it is uncountable.

Level

Level justification

Proof 1: The set of non-selfish natural numbers

Let {\displaystyle \mathbb {N} =\{1,2,3,\ldots \}}, the set of natural numbers.

Suppose that {\displaystyle \mathbb {N} } is equinumerous with its power set {\displaystyle {\mathcal {P}}(\mathbb {N} )}. Let us see a sample of what {\displaystyle {\mathcal {P}}(\mathbb {N} )} looks like:

{\displaystyle {\mathcal {P}}(\mathbb {N} )=\{\varnothing ,\{1,2\},\{1,2,3\},\{4\},\{1,5\},\{3,4,6\},\{2,4,6,\dots \},\dots \}.}

Indeed, {\displaystyle {\mathcal {P}}(\mathbb {N} )} contains infinite subsets of {\displaystyle \mathbb {N} }, e.g. the set of all positive even numbers {\displaystyle \{2,4,6,\ldots \}=\{2k:k\in \mathbb {N} \}}, along with the empty set {\displaystyle \varnothing }.

Now that we have an idea of what the elements of {\displaystyle {\mathcal {P}}(\mathbb {N} )} are, let us attempt to pair off each element of {\displaystyle \mathbb {N} } with each element of {\displaystyle {\mathcal {P}}(\mathbb {N} )} to show that these infinite sets are equinumerous. In other words, we will attempt to pair off each element of {\displaystyle \mathbb {N} } with an element from the infinite set {\displaystyle {\mathcal {P}}(\mathbb {N} )}, so that no element from either infinite set remains unpaired. Such an attempt to pair elements would look like this:

{\displaystyle \mathbb {N} {\begin{Bmatrix}1&\longleftrightarrow &\{4,5\}\\2&\longleftrightarrow &\{1,2,3\}\\3&\longleftrightarrow &\{4,5,6\}\\4&\longleftrightarrow &\{1,3,5\}\\\vdots &\vdots &\vdots \end{Bmatrix}}{\mathcal {P}}(\mathbb {N} ).}

Given such a pairing, some natural numbers are paired with subsets that contain the very same number. For instance, in our example the number 2 is paired with the subset {1, 2, 3}, which contains 2 as a member. Let us call such numbers selfish. Other natural numbers are paired with subsets that do not contain them. For instance, in our example the number 1 is paired with the subset {4, 5}, which does not contain the number 1. Call these numbers non-selfish. Likewise, 3 and 4 are non-selfish.

Using this idea, let us build a special set of natural numbers. This set will provide the contradiction we seek. Let {\displaystyle B} be the set of all non-selfish natural numbers. By definition, the power set {\displaystyle {\mathcal {P}}(\mathbb {N} )} contains all sets of natural numbers, and so it contains this set {\displaystyle B} as an element. If the mapping is bijective, {\displaystyle B} must be paired off with some natural number, say {\displaystyle b}. However, this causes a problem. If {\displaystyle b} is in {\displaystyle B}, then {\displaystyle b} is selfish because it is in the corresponding set, which contradicts the definition of {\displaystyle B}. If {\displaystyle b} is not in {\displaystyle B}, then it is non-selfish and it should instead be a member of {\displaystyle B}. Therefore, no such element {\displaystyle b} which maps to {\displaystyle B} can exist.

Since there is no natural number which can be paired with {\displaystyle B}, we have contradicted our original supposition, that there is a bijection between {\displaystyle \mathbb {N} } and {\displaystyle {\mathcal {P}}(\mathbb {N} )}.

Note that the set {\displaystyle B} may be empty. This would mean that every natural number {\displaystyle x} maps to a subset of natural numbers that contains {\displaystyle x}. Then, every number maps to a nonempty set and no number maps to the empty set. But the empty set is a member of {\displaystyle {\mathcal {P}}(\mathbb {N} )}, so the mapping still does not cover {\displaystyle {\mathcal {P}}(\mathbb {N} )}.

Through this proof by contradiction we have proven that the cardinality of {\displaystyle \mathbb {N} } and {\displaystyle {\mathcal {P}}(\mathbb {N} )} cannot be equal. We also know that the cardinality of {\displaystyle {\mathcal {P}}(\mathbb {N} )} cannot be less than the cardinality of {\displaystyle \mathbb {N} } because {\displaystyle {\mathcal {P}}(\mathbb {N} )} contains all singletons, by definition, and these singletons form a "copy" of {\displaystyle \mathbb {N} } inside of {\displaystyle {\mathcal {P}}(\mathbb {N} )}. Therefore, only one possibility remains, and that is that the cardinality of {\displaystyle {\mathcal {P}}(\mathbb {N} )} is strictly greater than the cardinality of {\displaystyle \mathbb {N} }.
