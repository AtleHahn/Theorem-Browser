Statement

Let X be a real or complex normed space and f:M\to\mathbb K a bounded linear functional on a vector subspace. There is a bounded linear extension F:X\to\mathbb K with \|F\|=\|f\|, where the norms are the unit-ball suprema.

Level
Within undergraduate level
Level justification

Linear algebra supplies subspaces and linear functionals; analysis supplies norm bounds and countability. Sublinear, convex or seminorm conditions are explicitly given inequalities, and the functional norm is a unit-ball supremum. These direct extensions suffice without locally convex or dual-topology theory.

Proof 1: Norm-preserving Hahn–Banach extension

A linear functional {\displaystyle f} on a normed space is continuous if and only if it is bounded, which means that its dual norm

{\displaystyle \|f\|=\sup\{|f(m)|:\|m\|\leq 1,m\in \operatorname {domain} f\}}

is finite, in which case {\displaystyle |f(m)|\leq \|f\|\|m\|} holds for every point {\displaystyle m} in its domain. Moreover, if {\displaystyle c\geq 0} is such that {\displaystyle |f(m)|\leq c\|m\|} for all {\displaystyle m} in the functional's domain, then necessarily {\displaystyle \|f\|\leq c.} The map {\displaystyle F} being an extension of {\displaystyle f} means that {\displaystyle \operatorname {domain} f\subseteq \operatorname {domain} F} and {\displaystyle F(m)=f(m)} for every {\displaystyle m\in \operatorname {domain} f.} Consequently,

{\displaystyle \{|f(m)|:\|m\|\leq 1,m\in \operatorname {domain} f\}=\{|F(m)|:\|m\|\leq 1,m\in \operatorname {domain} f\}\subseteq \{|F(x)\,|:\|x\|\leq 1,x\in \operatorname {domain} F\}}

and so the supremum of the set on the left hand side, which is {\displaystyle \|f\|,} does not exceed the supremum of the right hand side, which is {\displaystyle \|F\|.} In other words, {\displaystyle \|f\|\leq \|F\|.}

If {\displaystyle F} is a linear extension of a linear functional {\displaystyle f} then their dual norms always satisfy {\displaystyle \|f\|\leq \|F\|} so that equality {\displaystyle \|f\|=\|F\|} is equivalent to {\displaystyle \|F\|\leq \|f\|,} which holds if and only if {\displaystyle |F(x)|\leq \|f\|\|x\|} for every point {\displaystyle x} in the extension's domain. This can be restated in terms of the function {\displaystyle \|f\|\,\|\cdot \|:X\to \mathbb {R} } defined by {\displaystyle x\mapsto \|f\|\,\|x\|,} which is always a seminorm:

A linear extension of a bounded linear functional {\displaystyle f} is norm-preserving if and only if the extension is dominated by the seminorm {\displaystyle \|f\|\,\|\cdot \|.}

Applying the Hahn–Banach theorem to {\displaystyle f} with this seminorm {\displaystyle \|f\|\,\|\cdot \|} thus produces a dominated linear extension whose norm is (necessarily) equal to that of {\displaystyle f,} which proves the theorem:

Applying Hahn–Banach

Let {\displaystyle f} be a continuous linear functional defined on a vector subspace {\displaystyle M} of a normed space {\displaystyle X.} Then the function {\displaystyle p:X\to \mathbb {R} } defined by {\displaystyle p(x)=\|f\|\,\|x\|} is a seminorm on {\displaystyle X} that dominates {\displaystyle f,} meaning that {\displaystyle |f(m)|\leq p(m)} holds for every {\displaystyle m\in M.} By the Hahn–Banach theorem, there exists a linear functional {\displaystyle F} on {\displaystyle X} that extends {\displaystyle f} (which guarantees {\displaystyle \|f\|\leq \|F\|}) and that is also dominated by {\displaystyle p,} meaning that {\displaystyle |F(x)|\leq p(x)} for every {\displaystyle x\in X.} The fact that {\displaystyle \|f\|} is a real number such that {\displaystyle |F(x)|\leq \|f\|\|x\|} for every {\displaystyle x\in X,} guarantees {\displaystyle \|F\|\leq \|f\|.} Since {\displaystyle \|F\|=\|f\|} is finite, the linear functional {\displaystyle F} is bounded and thus continuous.
