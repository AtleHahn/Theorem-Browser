Statement

Let X be a class and R a binary relation on X. Write P_x=\{y\in X:yRx\}. Suppose:

  • R is set-like: every P_x is a set.
  • R is well-founded: every nonempty subset S of X has an element x\in S with P_x\cap S=\varnothing.
  • R is extensional: P_x\ne P_y whenever x\ne y.

Then there is a unique transitive class C and a unique isomorphism F:(X,R)\to(C,\in). Transitive means that z\in y\in C implies z\in C; an isomorphism here is a bijective class map satisfying yRx\iff F(y)\in F(x). The collapse satisfies

F(x)=\{F(y):yRx\}\qquad(x\in X).

The classes X and C may be proper classes.
