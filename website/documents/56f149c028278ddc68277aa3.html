Statement

For a measure space (\Omega,\mathcal F,\mu), L^1(\mu) is the space of integrable scalar functions modulo equality almost everywhere, with norm \|f\|_1=\int|f|\,d\mu, and L^\infty(\mu) uses the essential-supremum norm. For an operator defined on L^1, the condition on its L^\infty norm means that it maps L^1\cap L^\infty into L^\infty with the stated bound on that intersection. For every \varepsilon>0, there exist a measure space (\Omega,\mathcal F,\mu), a linear operator T:L^1(\mu)\to L^1(\mu), and f\in L^1(\mu) such that

\|Tg\|_1\le\|g\|_1\quad(g\in L^1),\qquad \|Tg\|_\infty\le(1+\varepsilon)\|g\|_\infty\quad(g\in L^1\cap L^\infty),

but the averages n^{-1}\sum_{j=0}^{n-1}T^jf fail to converge to a finite limit on a set of positive measure.

Proof 1: Positive contraction and change of measure (external)

A supporting source can be found here (Section 3.6, An example with divergence, pp.151–153). The deduction below supplies the argument for the stored statement.

Use the positive L1 contraction T on a finite interval and nonnegative f with divergent ergodic averages constructed in Krengel Section3.6. The following change-of-measure argument is supplied here: set a=1+epsilon and h=sum_{j>=0} a^(-j) T^j 1. Positivity and contraction imply 1<=h<infinity almost everywhere and integral h<=mu(Omega)/(1-1/a). Moreover Th=a(h-1)<=a h by L1 convergence. Put dnu=h dmu and Sg=T(hg)/h. Multiplication by h is an isometry from L1(nu) to L1(mu), so S is an L1 contraction. For bounded g, positivity gives |Sg|<=||g||infinity Th/h<=a||g||infinity. Finally S^j(f/h)=T^j f/h, so its Cesaro averages diverge on the same positive-measure set, since mu and nu are equivalent and h is positive finite. This supplies all claimed properties; rename S as the operator in the statement.
