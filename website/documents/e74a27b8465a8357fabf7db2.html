Statement

A positive integer N is a congruum if N=y^2-x^2=z^2-y^2 for integers x,y,z. Given a positive integer N, its being a congruum can be decided by checking finitely many positive integer parameter pairs m>n dividing N in the parameterization N=k^2\,4mn(m^2-n^2); for each pair it suffices to test whether the quotient by 4mn(m^2-n^2) is the square of a positive integer.

Level
High school only
Level justification

The finite search is stated entirely with integer divisors, squares and an explicit polynomial formula.

Proof 1: Restricting the parameters to divisors — outline

For the congruum problem, the parameterized solution reduces this testing problem to checking a finite set of parameter values, as the two parameters m and n must both divide the given number.

The parameterized solution used here states that all positive congrua arise as 4mn(m^2-n^2) or as positive integer square multiples of these numbers, with positive integers m>n.
