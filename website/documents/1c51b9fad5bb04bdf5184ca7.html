Statement

Let T:\Omega\to\Omega^\prime be a function, let (\Omega^\prime,\mathcal A^\prime) be a measurable space, and define \sigma(T)=\{T^{-1}(B):B\in\mathcal A^\prime\}. For every A\in\sigma(T) there is an \mathcal A^\prime-measurable function g:\Omega^\prime\to[0,1] such that \mathbf1_A=g\circ T.

Level
Within undergraduate level
Level justification

Sigma-algebras are families closed under complements and countable unions; measurability is a preimage condition. These linked definitions extend undergraduate sets/functions, and no measure or integral is involved.

Proof 1: Select a measurable preimage representative

Now, assume that {\displaystyle f=\mathbf {1} _{A}} is an indicator of some set {\displaystyle A\in \sigma (T)}. If we identify {\displaystyle A'\in {\mathcal {A}}'} such that {\displaystyle A=T^{-1}(A')}, then the function {\displaystyle g=\mathbf {1} _{A'}} suits the requirement, and since {\displaystyle A\in \sigma (T)}, such a set {\displaystyle A'\in {\mathcal {A}}'} always exists.
