Statement

For a positive nonsquare integer n, an integer pair (x,y) solves x^2-ny^2=1 if and only if x+y\sqrt n is a unit of norm one in \mathbb Z[\sqrt n]. The norm is \operatorname N(x+y\sqrt n)=(x+y\sqrt n)(x-y\sqrt n).

Level
Within undergraduate level
Level justification

Introductory ring theory supplies units, and Z[sqrt(n)] consists of the displayed quadratic expressions. The norm is explicitly multiplication by the conjugate. No general field norm, field extension or algebraic-number-theory structure is needed for this equivalence.

Proof 1: Conjugate inverse and norm factorization

The displayed norm factorization equals x^2-ny^2. If this is one, x-y\sqrt n is an inverse in the same ring. Conversely a norm-one unit has x^2-ny^2=1 by that same norm formula.
