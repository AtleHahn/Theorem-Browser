Statement

Assuming the axiom of choice, every nonempty partially ordered set in which every chain has a least upper bound has a maximal element.

Level
Within undergraduate level
Level justification

Undergraduate sets, functions, orders and infinite sequences suffice. Choice, well-ordering or maximal-chain principles are explicit set-selection/order assertions where invoked, not a demand to learn their independence proofs. The displayed quantifiers and constructions can be understood through familiar subsets and functions.

Proof 1: Choose a strict successor and use Bourbaki–Witt

Assume for contradiction that the nonempty chain-complete poset X has no maximal element. Let g be a choice function on {\displaystyle P(X)-\{\varnothing \},} where P(X) is the power set of X. Define a function {\displaystyle f:X\to X} by

{\displaystyle f(x)=g(\{y\ :\ y>x\}).}

This is allowed as, by assumption, the set is non-empty. Then f(x) > x, so f is an inflationary function with no fixed point, contradicting the Bourbaki–Witt theorem: every inflationary self-map of a nonempty chain-complete poset has a fixed point.

Level
Within undergraduate level
Level justification

Choice selects one strict successor for each point under the no-maximal-element assumption. The resulting map is inflationary and fixed-point-free, contradicting the supplied Bourbaki–Witt statement. Chains, least upper bounds and these map properties are a small related extension of undergraduate order/set theory.
