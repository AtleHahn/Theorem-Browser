The tape space used by halting Busy Beaver machines eventually exceeds every computable bound. No algorithm can provide a universal effective ceiling on this finite resource demand.

Review status

Main-run extraction and separate source/standalone review; not formal verification

Statement

For an integer n\ge1, use deterministic Turing machines with n operational states, a separate Halt state, one starting state, a two-way unbounded tape over \{0,1\}, and a transition for each operational state and scanned symbol. Each transition writes a bit, moves one cell left or right, and enters a state (possibly Halt). The machine starts on an all-zero tape. Among machines that halt, \Sigma(n) is the largest number of ones left on the tape, and S(n) the largest number of transitions, including the halting transition. Define \operatorname{space}(n) as the largest number of tape cells read before halting, excluding a cell reached only by the final move; define \operatorname{num}(n) as the largest unary block output by a halting machine (with no other ones). For every total computable f:\mathbb N\to\mathbb N, \operatorname{space}(n)>f(n) eventually, so space is not computable.

Level
Within undergraduate level
Level justification

The machine model, starting configuration and score are explicitly described through finite transition rules. Understanding computability here means whether such a finite program always returns the required value; the maxima and eventual comparisons use elementary functions and quantifiers. A small machine trace is enough to illustrate the new model, without formal arithmetic or incompleteness theory.

Proof 1: Every written cell has been visited

Every cell in which a machine writes a one must have been read by that machine. Thus \Sigma(n)\le\operatorname{space}(n). By Radó’s score-growth theorem, \Sigma eventually exceeds every total computable function; the same is consequently true of space, which cannot itself be computable.

Level
Within undergraduate level
Level justification

Counting written cells proves Sigma<=space, and the imported domination statement then applies. The final contradiction substitutes a hypothetically computable space function into that statement. Only elementary computability beyond finite counting is required.
