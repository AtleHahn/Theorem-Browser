Statement

For every set X and map f:X\to\{0,1\}^X, the function G:X\to\{0,1\} defined by G(x)=1-f(x)(x) does not belong to the image of f. In particular f is not surjective.

Proof 1: Negate each function at its own parameter

Let f:X\to\{0,1\}^X, and define G(x)=1-f(x)(x). Then G is not in the range of f: its value at each x is the opposite of the value f(x)(x).

Level
Within undergraduate level
Level justification

The only extra notation beyond elementary functions is that f(x) is itself a binary-valued function on X. Evaluating it at x and changing its bit defines a function different from each f(x). Arbitrary sets, function spaces and surjectivity are standard introductory undergraduate set-and-function concepts; no cardinal arithmetic or advanced logic is required.
