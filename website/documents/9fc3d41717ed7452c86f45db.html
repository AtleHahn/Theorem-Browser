Statement

Let X be a compact complex manifold and p,q\ge0 integers. Use the convention that forms with any negative bidegree component are zero. Write Z^{p,q}=\{\alpha\in\Omega^{p,q}(X):\partial\alpha=\bar\partial\alpha=0\} and H_{BC}^{p,q}(X)=Z^{p,q}/\operatorname{im}(\partial\bar\partial:\Omega^{p-1,q-1}\to\Omega^{p,q}). De Rham cohomology means d-closed complex forms modulo d-exact forms. There is a well-defined linear map H_{BC}^{p,q}(X)\to H_{dR}^{p+q}(X,\mathbb C) sending the class of \alpha to its de Rham class.

These require substantial specialist preparation beyond a brief introduction from undergraduate mathematics. Proof 1: Send the same closed form to its de Rham class — outline

Since a differential form which is both \partial and \bar\partial-closed is d-closed, there is a natural map H_{BC}^{p,q}(X)\to H_{dR}^{p+q}(X,\mathbb C) from Bott–Chern cohomology groups to de Rham cohomology groups.

Level
Beyond undergraduate level
Level justification

The quotient-map argument uses differential forms of bidegree on complex manifolds, Dolbeault differentials and de Rham cohomology. These are several linked graduate-geometric constructions. Well-definedness also uses partial bar-partial beta=d(bar-partial beta), so the quotient relations become exact forms.
