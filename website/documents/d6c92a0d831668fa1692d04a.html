Statement

Assume the axiom of choice. Let P be a set and \mathcal F\subseteq\mathcal P(P) a nonempty family closed under taking subsets and under unions of chains ordered by inclusion. Then \mathcal F has an inclusion-maximal member.

Level
Within undergraduate level
Level justification

Partial orders, chains, antichains and countability are undergraduate set/order concepts. A chain means pairwise comparable and an antichain pairwise incomparable; selection principles, where assumed, are explicit hypotheses. These short definitions suffice for the quantified existence or partition claim.

Proof 1: The minimal tower of one-element extensions — outline

Write F=\mathcal F.

By the axiom of choice, we have a function {\displaystyle f:{\mathfrak {P}}(P)-\{\emptyset \}\to P} such that {\displaystyle f(S)\in S} for the power set {\displaystyle {\mathfrak {P}}(P)} of {\displaystyle P}.

For each {\displaystyle C\in F}, let {\displaystyle C^{*}} be the set of all {\displaystyle x\in P-C} such that {\displaystyle C\cup \{x\}} is in {\displaystyle F}. If {\displaystyle C^{*}=\emptyset }, then let {\displaystyle {\widetilde {C}}=C}. Otherwise, let

{\displaystyle {\widetilde {C}}=C\cup \{f(C^{*})\}.}

Note {\displaystyle C} is a maximal element if and only if {\displaystyle {\widetilde {C}}=C}. Thus, we are done if we can find a {\displaystyle C} such that {\displaystyle {\widetilde {C}}=C}.

Take C_0=\varnothing\in F, which is possible by nonemptiness and closure under subsets. We call a subset {\displaystyle T\subseteq F} a tower (over {\displaystyle C_{0}}) if

  1. {\displaystyle C_{0}} is in {\displaystyle T}.
  2. The union of each totally ordered subset {\displaystyle T'\subseteq T} is in {\displaystyle T}, where "totally ordered" is with respect to set inclusion.
  3. For each {\displaystyle C} in {\displaystyle T}, {\displaystyle {\widetilde {C}}} is in {\displaystyle T}.

There exists at least one tower; indeed, {\displaystyle F} itself is a tower. Let {\displaystyle T_{0}} be the intersection of all towers, which is again a tower.

Now, we shall show {\displaystyle T_{0}} is totally ordered. We say a set {\displaystyle C} is comparable in {\displaystyle T_{0}} if for each {\displaystyle A} in {\displaystyle T_{0}}, either {\displaystyle A\subseteq C} or {\displaystyle C\subseteq A}. Let {\displaystyle \Gamma } be the set of all sets in {\displaystyle T_{0}} that are comparable in {\displaystyle T_{0}}. We claim {\displaystyle \Gamma } is a tower. The conditions 1. and 2. are straightforward to check. For 3., let {\displaystyle C} in {\displaystyle \Gamma } be given and then let {\displaystyle U} be the set of all {\displaystyle A} in {\displaystyle T_{0}} such that either {\displaystyle A\subseteq C} or {\displaystyle {\widetilde {C}}\subseteq A}.

We claim {\displaystyle U} is a tower. The conditions 1. and 2. are again straightforward to check. For 3., let {\displaystyle A} be in {\displaystyle U}. If {\displaystyle A\subseteq C}, then since {\displaystyle C} is comparable in {\displaystyle T_{0}}, either {\displaystyle {\widetilde {A}}\subseteq C} or {\displaystyle C\subseteq {\widetilde {A}}}. In the first case, {\displaystyle {\widetilde {A}}} is in {\displaystyle U}. In the second case, we have {\displaystyle A\subseteq C\subseteq {\widetilde {A}}}, which implies either {\displaystyle A=C} or {\displaystyle C={\widetilde {A}}}. (This is the moment we needed to collapse a set to an element by the axiom of choice to define {\displaystyle {\widetilde {A}}}.) Either way, we have {\displaystyle {\widetilde {A}}} is in {\displaystyle U}. Similarly, if \widetilde C\subseteq A, we see {\displaystyle {\widetilde {A}}} is in {\displaystyle U}. Hence, {\displaystyle U} is a tower. Now, since {\displaystyle U\subseteq T_{0}} and {\displaystyle T_{0}} is the intersection of all towers, {\displaystyle U=T_{0}}, which implies {\displaystyle {\widetilde {C}}} is comparable in {\displaystyle T_{0}}; i.e., is in {\displaystyle \Gamma }. This completes the proof of the claim that {\displaystyle \Gamma } is a tower.

Finally, since {\displaystyle \Gamma } is a tower contained in {\displaystyle T_{0}}, we have {\displaystyle T_{0}=\Gamma }, which means {\displaystyle T_{0}} is totally ordered.

Let {\displaystyle C} be the union of {\displaystyle T_{0}}. By 2., {\displaystyle C} is in {\displaystyle T_{0}} and then by 3., {\displaystyle {\widetilde {C}}} is in {\displaystyle T_{0}}. Since {\displaystyle C} is the union of {\displaystyle T_{0}}, {\displaystyle {\widetilde {C}}\subseteq C} and thus {\displaystyle {\widetilde {C}}=C}. {\displaystyle \square }

Proof 2: The inflationary extension map and Bourbaki–Witt — outline

Choose s(C)=C when no one-element extension in \mathcal F exists, and otherwise adjoin one selected admissible element. In the inclusion poset \mathcal F, every chain has its union as a least upper bound. The map s is inflationary. Bourbaki–Witt gives a fixed point, which is maximal because downward closure makes any strict extension contain an admissible one-element extension.
