Statement

Work over a ground model V of ZFC with the generalized continuum hypothesis (GCH), meaning 2^\kappa=\kappa^+ for every infinite cardinal \kappa. Let F be a class function definable over V with parameters, assigning a cardinal F(\kappa) to each infinite regular cardinal \kappa of V, and suppose, as computed in V,

\kappa<\lambda\ \Longrightarrow\ F(\kappa)\le F(\lambda),\qquad \operatorname{cf}(F(\kappa))>\kappa.

Cardinals are identified with initial ordinals, \kappa^+ is the least larger cardinal, 2^\kappa is the cardinality of the power set of a set of size \kappa, and \operatorname{cf}(\alpha) is the least cardinality of an unbounded subset of the ordinal \alpha. An infinite cardinal is regular when its cofinality equals itself and singular otherwise. The following is a forcing assertion: a class forcing notion over V can be chosen whose generic extensions V[H] satisfy the stated properties. A forcing notion is an ordered class of conditions, ordered by strengthening; a generic filter meets every dense subclass definable over the ground model, and V[H] is the extension obtained by evaluating ground-model names using that filter. Cardinals and cofinalities being preserved means the ground model and extension assign the same cardinals and ordinal cofinalities. This model-relative formulation does not assert that an arbitrary external class function can be inserted into a model unaware of that class. The class forcing realizing 2^\kappa=F(\kappa) on all infinite regular cardinals can be chosen so that, for every singular cardinal \lambda, its generic extension also satisfies

2^\lambda=\min\{\theta:\theta\text{ is a cardinal},\ \theta\ge\sup_{\kappa<\lambda,\ \kappa\text{ infinite regular}}F(\kappa),\ \operatorname{cf}(\theta)>\lambda\}.

The cardinals, supremum and cofinalities on the right may be evaluated in the ground model, because the extension preserves cardinals and cofinalities. This is a property of the chosen Easton extension, not a restriction asserting that all models with the same regular-cardinal powers have these singular-cardinal values.
