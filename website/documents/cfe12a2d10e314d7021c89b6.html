Statement

Graphs below are finite, undirected and simple. A clique is a set of pairwise adjacent vertices; an independent set has no edges within it. For integers n\ge1,r\ge1, an n-vertex graph without a (r+1)-clique has at most (1-1/r)n^2/2 edges.

Level
High school only
Level justification

The assertion uses a finite clique prohibition and a quadratic bound on an integer edge count.

Proof 1: Move weights onto a clique — outline

Consider a {\displaystyle K_{r+1}} free graph with vertices labelled {\displaystyle 1,2,\ldots ,n}, and maximize the function

{\displaystyle f(x_{1},x_{2},\ldots ,x_{n})=\sum _{\{i,j\}\in E}x_{i}x_{j}}

over all nonnegative {\displaystyle x_{1},x_{2},\ldots ,x_{n}} with sum {\displaystyle 1}. Each unordered edge is counted once. This function is known as the Lagrangian of the graph and its edges.

The idea behind the proof is that if {\displaystyle x_{i},x_{j}} are both nonzero while {\displaystyle i,j} are not adjacent in the graph, the function

{\displaystyle f(x_{1},\ldots ,x_{i}-t,\ldots ,x_{j}+t,\ldots ,x_{n})}

is linear in {\displaystyle t}. Hence, one can either replace {\displaystyle (x_{i},x_{j})} with either {\displaystyle (x_{i}+x_{j},0)} or {\displaystyle (0,x_{i}+x_{j})} without decreasing the value of the function. Hence, there is a point with at most {\displaystyle r} nonzero variables where the function is maximized.

Now, the Cauchy–Schwarz inequality gives that the maximal value is at most {\displaystyle {\frac {1}{2}}\left(1-{\frac {1}{r}}\right)}. Plugging in {\displaystyle x_{i}={\frac {1}{n}}} for all {\displaystyle i} gives that the maximal value is at least {\displaystyle {\frac {|E|}{n^{2}}}}, giving the desired bound.

Proof 2: Random orderings in the complement — outline

Local independent-set lemma

The proof shows that every graph with degrees {\displaystyle d_{1},d_{2},\ldots ,d_{n}} has an independent set of size at least

{\displaystyle S={\frac {1}{d_{1}+1}}+{\frac {1}{d_{2}+1}}+\cdots +{\frac {1}{d_{n}+1}}.}

The proof attempts to find such an independent set as follows:

  • Consider a random permutation of the vertices of the graph
  • Select every vertex that is adjacent to none of the vertices before it.

A vertex of degree {\displaystyle d} is included in this with probability {\displaystyle {\frac {1}{d+1}}}, so this process gives an average of {\displaystyle S} vertices in the chosen set.

Apply it to the complement

Applying this fact to the complement graph and bounding the size of the chosen set using the Cauchy–Schwarz inequality proves Turán's theorem. The complementary-graph Cauchy–Schwarz calculation is left implicit in the source.
