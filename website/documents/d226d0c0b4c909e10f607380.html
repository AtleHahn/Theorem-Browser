Statement

In hyperboloid coordinates define L_2=\partial_b^2+\partial_x^2, R_2=b\partial_b+x\partial_x, L_3=L_2+\partial_y^2, R_3=R_2+y\partial_y, and \Delta_n=-L_n-R_n^2-(n-1)R_n. For a smooth radial function f on hyperbolic two-space, write r=\sqrt{b^2+x^2}=\sinh t with t\ge0, set (Sf)(t)=f(2t), and extend a function by (Eh)(b,x,y)=h(b,x). Then M_0=ES satisfies \Delta_3M_0f=4M_0\Delta_2f.

Proof 1: Flensted–Jensen radial descent relation — source argument

If f(b,x) is a function on \mathbb H^2, Ef is defined by

Ef(b,x,y)=f(b,x).

Thus, from the given coordinate operators,

\Delta_3Ef=E(\Delta_2-R_2)f.

If f is radial (SO(2)-invariant), then, regarding f as a function of r or t, the radial formula \Delta_2f=-\partial_t^2f-\coth t\,\partial_tf gives

(-\Delta_2+R_2)f =\partial_t^2f+\coth t\,\partial_tf+r\partial_rf =\partial_t^2f+(\coth t+\tanh t)\partial_tf.

On the other hand,

\partial_t^2+(\coth t+\tanh t)\partial_t =\partial_t^2+2\coth(2t)\partial_t.

Thus, setting Sf(t)=f(2t),

(\Delta_2-R_2)Sf=4S\Delta_2f,

leading to the fundamental descent relation of Flensted–Jensen for M_0=ES:

\Delta_3M_0f=4M_0\Delta_2f.

The radial expressions at t=0 are understood by their smooth extensions.
