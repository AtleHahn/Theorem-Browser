Statement

In ZFC, if an ordinal \alpha has \operatorname{cf}(\alpha)=\omega, then 2^{\aleph_0}\ne\aleph_\alpha. In particular it is neither \aleph_\omega nor \aleph_{\omega_1+\omega}.

Proof 1: Apply König’s cofinality restriction — outline

Kőnig's theorem, using the concept of cofinality, shows that 2^{\aleph_0} cannot equal \aleph_\alpha for \alpha with cofinality \omega. For example, 2^{\aleph_0}\ne\aleph_\omega. Per Kőnig's theorem, it is not consistent to assume 2^{\aleph_0} is \aleph_\omega or \aleph_{\omega_1+\omega} or any cardinal with cofinality \omega.

The cofinality restriction used here is \operatorname{cf}(2^{\aleph_0})>\aleph_0; for a limit ordinal \alpha, \operatorname{cf}(\aleph_\alpha)=\operatorname{cf}(\alpha). Both displayed indices have cofinality \omega.
