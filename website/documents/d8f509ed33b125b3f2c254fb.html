Statement

Let Z_1,Z_2,\ldots be independent uniform symbols from a finite alphabet of q\ge2 symbols. With probability one, the resulting infinite string contains every finite nonempty word over the alphabet as a consecutive substring.

Proof 1: Use almost-everywhere normality of base-q expansions — outline

Identify the alphabet symbols with the base-q digits 0,\ldots,q-1. The infinite random digit string corresponds to a uniform number in [0,1]. Almost every such number is normal in base q: each finite digit word has its prescribed positive limiting frequency. A normal expansion contains every finite digit word, since each has positive limiting frequency. Therefore, with probability one, the random sequence contains all finite words.
