Statement

Fix \alpha\in(1/2,1). Every n-vertex planar graph has a partition A\sqcup S\sqcup B with no A–B edges, |A|,|B|\le\alpha n, and |S|=O_\alpha(\sqrt n).

Proof 1: Repeated splitting and regrouping (outline)

Use the source’s procedure of repeatedly applying a constant-ratio planar separator to the larger pieces, then regrouping. Stop when every remaining component has at most (2\alpha-1)n vertices. Only a number of recursion levels depending on \alpha is needed, so the union of separators has O_\alpha(\sqrt n) vertices. Accumulate components into A until its size first reaches (1-\alpha)n; the last component has size at most (2\alpha-1)n, so |A|\le\alpha n. The remaining components form B with |B|\le\alpha n. If the total remaining size never reaches (1-\alpha)n, place it all in one side. Distinct components have no edges between them.
