Statement

Let d\ge1 be an integer, N a Poisson point process on \mathbb R^d with intensity measure \Lambda, and f:\mathbb R^d\to\mathbb R measurable. Let s\ge0 and assume \int\min(|f|,1)\,d\Lambda<\infty,\qquad\int|e^{-sf}-1|\,d\Lambda<\infty. The sum S=\sum_{x\in N}f(x) is almost surely absolutely convergent, and its Laplace functional satisfies \mathcal L_N(sf):=\mathbb E[e^{-sS}]=\exp\!\left(-\int_{\mathbb R^d}(1-e^{-sf(x)})\,\Lambda(dx)\right).

Level
Beyond undergraduate level
Level justification

The statement concerns Poisson random measures and measure-theoretic convergence.

Proof 1: Set the exponential parameter to minus s

Use the stated Poisson exponential formula: if \int\min(|f|,1)\,d\Lambda<\infty, then S=\sum_{x\in N}f(x) is almost surely absolutely convergent, and \mathbb E[e^{\theta S}]=\exp\!\left(\int(e^{\theta f(x)}-1)\,\Lambda(dx)\right) whenever the displayed integral converges. Set \theta=-s. Under the assumed convergence, rewrite e^{-sf}-1=-(1-e^{-sf}) to obtain the Laplace formula.

Level justification

Insert minus s into the supplied exponential formula. The full assertion nevertheless requires spatial Poisson point processes, random infinite sums and integrability against an intensity measure, which are graduate probability.
