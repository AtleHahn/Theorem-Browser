Statement

For z=re^{i\theta} with r>0 and real \theta, |e^{1/z}|=\exp(\cos\theta/r). Along a fixed angle, if \cos\theta>0 the modulus tends to infinity as r\downarrow0, and if \cos\theta<0 then e^{1/z}\to0.

Level justification

Proof 1: Polar factorization and modulus

Using a change of variable to polar coordinates {\displaystyle z=re^{i\theta }} the function f(z) = e1/z becomes:

{\displaystyle f(z)=e^{{\frac {1}{r}}e^{-i\theta }}=e^{{\frac {1}{r}}\cos(\theta )}e^{-{\frac {1}{r}}i\sin(\theta )}.}

Taking the absolute value of both sides:

{\displaystyle \left|f(z)\right|=\left|e^{{\frac {1}{r}}\cos \theta }\right|\left|e^{-{\frac {1}{r}}i\sin(\theta )}\right|=e^{{\frac {1}{r}}\cos \theta }.}

Thus, for values of θ such that cos θ > 0, we have |f(z)|\to\infty as {\displaystyle r\to 0}, and for {\displaystyle \cos \theta <0}, {\displaystyle f(z)\to 0} as {\displaystyle r\to 0}.
