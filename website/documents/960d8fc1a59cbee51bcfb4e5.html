Statement

For an odd prime p and integer a not divisible by p, write (a/p)=1 if a is a nonzero square modulo p, and (a/p)=-1 otherwise. Let I contain one representative from each pair \{u,-u\} of nonzero residues modulo p. Let t=\#\{j\in I:aj\in-I\}. Then (a/p)=(-1)^t.

Level
High school only
Level justification

An explicitly described finite half-system uses elementary congruences.

Proof 1: Gauss's lemma for an arbitrary half-system — outline

Use the same product argument as for the usual half-system: multiplication by a, followed by changing signs into I, permutes I. The product therefore gives a^{(p-1)/2}\prod_{j\in I}j\equiv(-1)^t\prod_{j\in I}j\pmod p. Cancel the nonzero product and use Euler’s criterion. The source specifies that the proof is the same as the preceding product proof.

Level justification

Multiply the chosen residue representatives, record the signs needed to return to the half-system, cancel a nonzero product and invoke Euler criterion. This is finite permutations and elementary modular arithmetic.
