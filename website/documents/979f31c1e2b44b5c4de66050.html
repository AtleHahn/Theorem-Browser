Statement

For a positive integer n, let A be a symmetric n\times n matrix with integer entries such that x^TAx>0 for every nonzero x\in\mathbb R^n. Write Q(x)=x^TAx. Say that Q represents an integer m if Q(x)=m for some x\in\mathbb Z^n. If Q represents every member of S=\{1,2,3,5,6,7,10,14,15\}, then it represents every positive integer. This test set is sharp: for each s\in S, there exists a positive-definite quadratic form with an integer symmetric matrix (with dimension allowed to depend on s) that represents every positive integer except s.

Level
Within undergraduate level
Level justification

Linear algebra supplies symmetric matrices and positive definiteness. Representing an integer means solving the explicitly given quadratic equation in integer coordinates. The finite test and its universal conclusion require no further theory of quadratic forms; the statement is undergraduate, although proving it is much harder.
