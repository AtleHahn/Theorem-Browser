Statement

Let r\ge0 be an integer and \kappa an infinite cardinal. Define E_0(\kappa)=\kappa and E_{j+1}(\kappa)=2^{E_j(\kappa)}, where 2^\lambda is power-set cardinality; write \lambda^+ for the least cardinal greater than \lambda. If |S|=E_r(\kappa)^+, then for every map c:[S]^{r+1}\to\kappa there exists H\subseteq S of cardinality \kappa^+ such that c is constant on [H]^{r+1}. Here [S]^m denotes the set of m-element subsets. The bound is sharp: on a set of cardinality E_r(\kappa) there is such a coloring with no homogeneous subset of cardinality \kappa^+.

Beyond undergraduate level
Level justification

Iterated cardinal exponentiation and successor arithmetic exceed a short extension of undergraduate sets, despite the concrete coloring language.
