Statement

A relation R on a set X is reflexive if xRx for every x\in X, symmetric if xRy implies yRx, and transitive if xRy and yRz imply xRz. An equivalence relation has all three properties. Let R be a symmetric and transitive relation on a set X. Then R is reflexive if and only if it is total in the sense that for every a\in X there is a b\in X with aRb.

Proof 1: Totality and reflexivity for a symmetric transitive relation

If the relation is total, given a choose b with aRb. Symmetry gives bRa, and transitivity gives aRa. Conversely, if it is reflexive, given a choose b=a; then aRb.
