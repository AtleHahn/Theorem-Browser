Medium

Boolean satisfiability captures every problem whose proposed solutions can be verified in polynomial time. This makes the distinction between finding and checking solutions mathematically precise; NP-completeness alone does not establish that efficient solution methods are impossible.

Statement

The Boolean satisfiability problem SAT is NP-complete under deterministic polynomial-time many-one reductions. SAT takes a finite Boolean formula, built from Boolean variables and Boolean operations, and asks whether some assignment of truth values makes it true.

Precisely, SAT belongs to NP, and for every language L\subseteq\{0,1\}^* in NP there is a function r computable by a deterministic Turing machine in time polynomial in the input length, producing Boolean formulas, such that for every finite binary string x,

x\in L\quad\Longleftrightarrow\quad r(x)\text{ is satisfiable}.

Here a language is a set of finite strings, and NP consists of languages decided by nondeterministic Turing machines in polynomial time: all computation branches halt within a polynomial bound, and a string is accepted exactly when at least one branch accepts. A Turing machine has finitely many control states and tape symbols, reads and writes one tape cell and moves its head at each step; nondeterminism allows a choice among permitted transitions. Input length is the number of symbols in the encoding.

Level
Beyond undergraduate level
Level justification

The logical formula component is elementary, but nondeterministic machine semantics, quantified running-time bounds and reductions between arbitrary languages form several interdependent additions to the standard undergraduate baseline. Their cumulative burden is conservatively beyond the short reading allowance.
