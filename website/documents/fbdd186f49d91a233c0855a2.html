Statement

Let \mathbb F_q be a finite field with q elements. Let C\subseteq\mathbb F_q^n be a nonzero linear code of dimension 1\le k\le n. Let d be its minimum Hamming distance, equivalently the least number of nonzero coordinates of a nonzero codeword. Then d\le n-k+1.

Level
Within undergraduate level
Level justification

Linear algebra over a field supplies subspaces and dimension. The code is just a subspace, and minimum Hamming distance is explicitly the minimum number of nonzero coordinates. A finite field adds no extension-field arithmetic here.

Proof 1: Count words in a finite-dimensional code

If {\displaystyle C} is a linear code with block length {\displaystyle n}, dimension {\displaystyle k} and minimum distance {\displaystyle d} over the finite field with {\displaystyle q} elements, then the number of codewords is {\displaystyle q^{k}} and the external Singleton cardinality bound (at most q^{n-d+1} words) implies:

{\displaystyle q^{k}\leq q^{n-d+1},}

so that

{\displaystyle k\leq n-d+1,}

which is usually written as

{\displaystyle d\leq n-k+1.}

Proof 2: Rank of a parity-check matrix — outline

Let H be a parity-check matrix, so C=\ker H and \operatorname{rank}H=n-k. Use the standard parity-check characterization: the minimum distance is the least number of linearly dependent columns of H. Any n-k+1 columns are dependent by the rank bound, so d\le n-k+1.

Proof 3: Weight of a systematic generator row — outline

After a coordinate permutation choose a generator matrix in standard form G=(I_k\mid A). Each row is a nonzero codeword with one nonzero coordinate in the identity block and at most n-k further nonzero coordinates. Its weight is at most n-k+1, so the minimum nonzero codeword weight d is at most n-k+1.
