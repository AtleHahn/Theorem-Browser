Statement

A generalized arithmetic progression (GAP) of dimension d is a set \{x_0+\sum_{j=1}^d n_jx_j:0\le n_j<L_j\} with positive integer lengths L_j; it is proper when these parameter tuples give distinct values. For sets, A+B=\{a+b:a\in A,b\in B\}. If a finite integer set A is contained in a finite proper GAP P of dimension d, and |P|\le C|A| with C\ge1, then |A+A|\le C2^d|A|.

Level
High school only
Level justification

The progression and properness are explicit finite integer parameterizations; sumsets and the desired count bound use elementary arithmetic.

Proof 1: Double the progression ranges and use containment — outline

The source bounds the sum of the progression by |P+P|\le2^d|P|. Indeed each coordinate range at most doubles when two parameter tuples are added. Since A+A\subseteq P+P, |A+A|\le|P+P|\le2^d|P|\le C2^d|A|.

Level justification

Count the enlarged coordinate ranges and use containment of sumsets. The progression is explicitly parametrized, so school finite products and inequalities suffice.
