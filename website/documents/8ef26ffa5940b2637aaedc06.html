Statement

Let X\in\mathbb R^{n\times K} be deterministic with full column rank, and let y=X\beta+\varepsilon, where \beta\in\mathbb R^K is unknown and deterministic, E\varepsilon=0 and \operatorname{Cov}(\varepsilon)=\sigma^2 I_n with 0\le\sigma^2<\infty. Put B=(X^TX)^{-1}X^T and \widehat\beta=By. For deterministic C=B+D, the estimator Cy is unbiased for all \beta if and only if DX=0, equivalently CX=I_K.

Level
Within undergraduate level
Level justification

Expectations, covariance entries and unbiasedness add related finite-vector average definitions to undergraduate linear algebra and integration. There is no asymptotic statistical theory.

Proof 1: Compute the expectation for every parameter vector

Let \tilde\beta=Cy be the linear estimator with C=(X^TX)^{-1}X^T+D. We calculate:

{\displaystyle {\begin{aligned}\operatorname {E} \left[{\tilde {\beta }}\right]&=\operatorname {E} [Cy]\\&=\operatorname {E} \left[\left((X^{\operatorname {T} }X)^{-1}X^{\operatorname {T} }+D\right)(X\beta +\varepsilon )\right]\\&=\left((X^{\operatorname {T} }X)^{-1}X^{\operatorname {T} }+D\right)X\beta +\left((X^{\operatorname {T} }X)^{-1}X^{\operatorname {T} }+D\right)\operatorname {E} [\varepsilon ]\\&=\left((X^{\operatorname {T} }X)^{-1}X^{\operatorname {T} }+D\right)X\beta &&\operatorname {E} [\varepsilon ]=0\\&=(X^{\operatorname {T} }X)^{-1}X^{\operatorname {T} }X\beta +DX\beta \\&=(I_{K}+DX)\beta .\\\end{aligned}}}

Therefore, since unbiasedness is required for every parameter vector {\displaystyle \beta }, {\displaystyle {\tilde {\beta }}} is unbiased if and only if {\displaystyle DX=0}.

Level justification

The full statement includes covariance as the matrix of centered second moments, even though it is unused in this proof. These finite-vector expectation definitions are a limited extension of undergraduate integration and linear algebra. Linearity gives E(Cy)=(I+DX)beta, which equals beta for every beta precisely when DX=0.
