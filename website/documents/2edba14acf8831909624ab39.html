Statement

A propositional proof system is a deterministic algorithm P(\phi,x) running in time polynomial in |\phi|+|x| such that a formula \phi is a tautology exactly when some x is accepted. It is polynomially bounded if a single polynomial p bounds the shortest accepted proof of every tautology by p(|\phi|). A polynomially bounded propositional proof system exists if and only if \mathrm{NP}=\mathrm{coNP}.

Proof 1: Use polynomial certificates for the coNP-complete tautology language

Because \phi is not a tautology if and only if \neg\phi is satisfiable, \mathsf{TAUT} is coNP-complete, using the standard NP-completeness of propositional satisfiability. Thus, if there exists a proof system for \mathsf{TAUT} that is polynomially bounded, then \mathrm{NP}=\mathrm{coNP}: its proofs are polynomial-length certificates, so \mathsf{TAUT}\in\mathrm{NP}, giving \mathrm{coNP}\subseteq\mathrm{NP} and equality by taking complements.

Conversely, if \mathrm{NP}=\mathrm{coNP}, then \mathsf{TAUT}, being in coNP, would also be in NP, and thus there is a polynomially bounded proof system for proving tautologies, namely its polynomial-time certificate verifier.
