Statement

Let f:\{0,1\}^2\to\{0,1\}. The operations + and multiplication mean OR and AND, respectively, and x^{\prime}=1-x is Boolean complementation. For x_1,x_2\in\{0,1\}, f(x_1,x_2)=x_1x_2f(1,1)+x_1x_2^{\prime}f(1,0)+x_1^{\prime}x_2f(0,1)+x_1^{\prime}x_2^{\prime}f(0,0).

Level
High school only
Level justification

The finite binary function and each logical operation are defined locally, so elementary finite logic suffices.

Proof 1: Iterate Shannon decomposition

Use the Shannon expansion f(x_1,x_2)=x_1f(1,x_2)+x_1^{\prime}f(0,x_2) for each argument.

{\displaystyle {\begin{aligned}f(x_{1},x_{2})&=x_{1}\cdot f(1,x_{2})+x_{1}'\cdot f(0,x_{2})\\&=x_{1}x_{2}\cdot f(1,1)+x_{1}x_{2}'\cdot f(1,0)+x_{1}'x_{2}\cdot f(0,1)+x_{1}'x_{2}'\cdot f(0,0)\end{aligned}}}
Level
High school only
Level justification

Split each cofactor by the second bit after splitting on the first. Exactly one of the four literal products is one at any input, so its truth-table value is selected. Only Boolean arithmetic is involved.
