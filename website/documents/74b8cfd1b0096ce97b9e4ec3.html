Statement

Let T preserve a probability measure \mu on (\Omega,\Sigma) and let g_n\in L^1(\mu), n\ge1, be real functions satisfying g_{n+m}(x)\le g_n(x)+g_m(T^n x) almost everywhere for every n,m\ge1. Then g_n(x)/n converges almost everywhere to a T-invariant measurable function g:\Omega\to[-\infty,\infty). If T is ergodic, g is almost everywhere constant.

Level
Beyond undergraduate level
Level justification

Probability spaces, measure-theoretic integrability and ergodicity exceed the undergraduate calculus baseline.

Proof 1: Steele’s good-block partition argument (outline)

Use a:b to denote the integers from a to b. All countably many almost-everywhere statements below are imposed on a common set of full measure stable under forward iteration, by intersecting its inverse images.

Partition inequality and reduction

Fix some {\textstyle n\geq 1}. By subadditivity, for any {\textstyle l\in 1:n-1}

{\displaystyle g_{n}\leq g_{n-l}+g_{l}\circ T^{n-l}}

We can picture this as starting with the set {\textstyle 0:n-1}, and then removing its length {\textstyle l} tail.

Repeating this construction until the set {\textstyle 0:n-1} is all gone, we have an upper bound for {\textstyle g_{n}} from each consecutive-block partition of {\textstyle 0:n-1}.

Specifically, let {\textstyle \{k_{i}:(k_{i}+l_{i}-1)\}_{i}} be a partition of {\textstyle 0:n-1}, then we have

{\displaystyle g_{n}\leq \sum _{i}g_{l_{i}}\circ T^{k_{i}}}

By subadditivity, using the partition of {\textstyle 0:n-1} into singletons.

{\displaystyle {\begin{aligned}g_{1}&\leq g_{1}\\g_{2}&\leq g_{1}+g_{1}\circ T\\g_{3}&\leq g_{1}+g_{1}\circ T+g_{1}\circ T^{2}\\&\cdots \end{aligned}}}

Now, construct the sequence

{\displaystyle {\begin{aligned}f_{1}&=g_{1}-g_{1}\\f_{2}&=g_{2}-(g_{1}+g_{1}\circ T)\\f_{3}&=g_{3}-(g_{1}+g_{1}\circ T+g_{1}\circ T^{2})\\&\cdots \end{aligned}}}

which is integrable and subadditive and satisfies {\textstyle f_{n}\leq 0} for all {\textstyle n}.

By the nonpositive case to be proved below, {\textstyle f_{n}/n} converges a.e. to a {\textstyle T}-invariant function.

By Birkhoff's pointwise ergodic theorem, the running average

{\displaystyle {\frac {1}{n}}\sum_{j=0}^{n-1}g_1\circ T^j}

converges a.e. to a {\textstyle T}-invariant function. Therefore, their sum does as well.

Henceforth assume g_n\leq0.

Invariance of the lower limit

Let {\textstyle g:=\liminf g_{n}/n}, then it is {\textstyle T}-invariant.

By subadditivity,

{\displaystyle {\frac {g_{n+1}}{n+1}}\leq {\frac {g_{1}+g_{n}\circ T}{n+1}}}

Taking the lower limit as n\to\infty, we have

{\displaystyle g\leq g\circ T}

We can visualize {\textstyle T} as hill-climbing on the graph of {\textstyle g}. The following level-set argument shows that g=g\circ T almost everywhere.

Let {\textstyle c\in \mathbb {R} }, then

{\displaystyle \{g\geq c\}\subset \{g\circ T\geq c\}=T^{-1}(\{g\geq c\})}

and since both sides have the same measure, by squeezing, they are equal a.e..

That is, {\textstyle g(x)\geq c\iff g(Tx)\geq c}, a.e..

Now apply this for all rational {\textstyle c}.

A partition using good blocks

Fix arbitrary {\textstyle \epsilon ,M>0}, and construct the truncated function, still {\textstyle T}-invariant:

{\displaystyle g':=\max(g,-M)}

With these, it suffices to prove an a.e. upper bound

{\displaystyle \limsup g_{n}/n\leq g'+\epsilon }

since it would allow us to take the limit {\textstyle \epsilon =1/1,1/2,1/3,\dots }, then the limit {\textstyle M=1,2,3,\dots }, giving us a.e.

{\displaystyle \limsup g_{n}/n\leq \liminf g_{n}/n=:g}

And by squeezing, we have {\textstyle g_{n}/n} converging a.e. to {\textstyle g}. Define two families of sets, one shrinking to the empty set, and one growing to the full set. For each "length" {\displaystyle L=1,2,3,\dots }, define

{\displaystyle B_{L}:=\{x:g_{l}/l>g'+\epsilon ,\forall l\in 1,2,\dots ,L\}}{\displaystyle A_{L}:=B_{L}^{c}=\{x:g_{l}/l\leq g'+\epsilon ,\exists l\in 1,2,\dots ,L\}}

Since {\textstyle g'\geq \liminf g_{n}/n}, the {\textstyle B} family shrinks to the empty set.

Fix {\textstyle x\in\Omega}. Fix {\textstyle L\in \mathbb {N} }. Fix {\textstyle n>L}. The ordering of these qualifiers is vitally important, because we will be removing the qualifiers one by one in the reverse order.

To prove the a.e. upper bound, we must use the subadditivity, which means we must construct a partition of the set {\textstyle 0:n-1}. We do this inductively, using the invariance of g':

Take the smallest {\textstyle k} not already in a partition.

If {\textstyle T^{k}x\in A_{L}}, then {\textstyle g_{l}(T^{k}x)/l\leq g'(x)+\epsilon } for some {\textstyle l\in 1,2,\dots L}. Take one such {\textstyle l} – the choice does not matter.

If {\textstyle k+l-1\leq n-1}, then we cut out {\textstyle \{k,\dots ,k+l-1\}}. Call these partitions "type 1". Else, we cut out {\textstyle \{k\}}. Call these partitions "type 2".

Else, we cut out {\textstyle \{k\}}. Call these partitions "type 3".

Now convert this partition into an inequality:

{\displaystyle g_{n}(x)\leq \sum _{i}g_{l_{i}}(T^{k_{i}}x)}

where {\textstyle k_{i}} are the heads of the partitions, and {\textstyle l_{i}} are the lengths.

Since all {\textstyle g_{n}\leq 0}, we can remove the other kinds of partitions:

{\displaystyle g_{n}(x)\leq \sum _{i:{\text{type 1}}}g_{l_{i}}(T^{k_{i}}x)}

By construction, each {\textstyle g_{l_{i}}(T^{k_{i}}x)\leq l_{i}(g'(x)+\epsilon )}, thus

{\displaystyle {\frac {1}{n}}g_{n}(x)\leq g'(x){\frac {1}{n}}\sum _{i:{\text{type 1}}}l_{i}+\epsilon }

Now it would be tempting to continue with {\textstyle g'(x){\frac {1}{n}}\sum _{i:{\text{type 1}}}l_{i}\leq g'(x)}, but unfortunately {\textstyle g'\leq 0}, so the direction is the exact opposite. We must lower bound the sum {\textstyle \sum _{i:{\text{type 1}}}l_{i}}.

The number of type 3 elements is at most

{\displaystyle \sum _{k\in 0:n-1}1_{B_{L}}(T^{k}x)}

If a number {\textstyle k} is of type 2, then it must be inside the last {\textstyle L-1} elements of {\textstyle 0:n-1}. Thus the number of type 2 elements is at most {\textstyle L-1}. Together, we have the lower bound:

{\displaystyle {\frac {1}{n}}\sum _{i:{\text{type 1}}}l_{i}\geq 1-{\frac {L-1}{n}}-{\frac {1}{n}}\sum _{k\in 0:n-1}1_{B_{L}}(T^{k}x)}

Removing the cutoffs

Remove the {\textstyle n>L} qualifier by taking the {\textstyle n\to \infty } limit.

By Birkhoff's pointwise ergodic theorem, there exists an a.e. pointwise limit

{\displaystyle {\frac {1}{n}}\sum _{k\in 0:n-1}1_{B_{L}}(T^{k}x)\to {\bar {1}}_{B_{L}}(x)}

satisfying

{\displaystyle \int {\bar {1}}_{B_{L}}=\mu (B_{L});\quad {\bar {1}}_{B_{L}}(x)\in [0,1]}

At the limit, we find that for a.e. {\textstyle x\in\Omega,L\in \mathbb {N} },

{\displaystyle \limsup _{n}{\frac {g_{n}(x)}{n}}\leq g'(x)(1-{\bar {1}}_{B_{L}}(x))+\epsilon }

Remove the {\textstyle L\in \mathbb {N} } qualifier by taking the {\textstyle L\to \infty } limit.

Since we have

{\displaystyle \int {\bar {1}}_{B_{L}}=\mu (B_{L})\to 0}

and {\displaystyle {\bar {1}}_{B_{L}}\geq {\bar {1}}_{B_{L+1}}\geq \cdots } as {\displaystyle 1_{B_{L}}\geq 1_{B_{L+1}}\geq \cdots }, we can apply the same argument used for proving Markov's inequality, to obtain

{\displaystyle \limsup _{n}{\frac {g_{n}(x)}{n}}\leq g'(x)+\epsilon }

for a.e. {\textstyle x\in\Omega}.

In detail, the argument is as follows: since {\displaystyle {\bar {1}}_{B_{L}}\geq {\bar {1}}_{B_{L+1}}\geq \cdots \geq 0}, and {\displaystyle \int {\bar {1}}_{B_{L}}\to 0}, we know that for any small {\displaystyle \delta ,\delta '>0}, all large enough {\displaystyle L} satisfies {\displaystyle {\bar {1}}_{B_{L}}(x)<\delta } everywhere except on a set of measure {\displaystyle < \delta '}. Thus,

{\displaystyle \limsup _{n}{\frac {g_{n}(x)}{n}}\leq g'(x)(1-\delta )+\epsilon }

with probability {\displaystyle \geq 1-\delta '}. Now take both {\displaystyle \delta ,\delta '\to 0}.

Taking the indicated countable limits in \epsilon and M proves convergence. The initial reduction and Birkhoff limit exclude a positive infinite limit. Finally, an invariant measurable function on an ergodic probability space is almost everywhere constant.
