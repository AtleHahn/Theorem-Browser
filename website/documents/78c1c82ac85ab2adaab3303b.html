Statement

Let K=\mathbb R. An algebraic subset of K^m is the common zero set of polynomial equations with coefficients in K. The algebraic set Y=\{(x,y)\in K^2:xy-1=0\} projects onto K\setminus\{0\} under (x,y)\mapsto x, and that projection is not algebraic.

Level
High school only
Level justification

Algebraic sets are explicitly polynomial zero sets, and the projection simply keeps the first coordinate.

Proof 1: Project the equation xy equals one

As a simple example consider the hyperbola in R2 defined by the equation

{\displaystyle xy-1=0.\,}

This is a perfectly good algebraic set, but projecting it down by sending (x, y) in R2 to x in R produces the set of points satisfying x ≠ 0. This is a semialgebraic set, but it is not an algebraic set as the algebraic sets in R are R itself, the empty set and the finite sets.

Level
High school only
Level justification

Solve xy=1 for nonzero x and use the finite-root property to exclude a polynomial zero-set description of the punctured line. Algebraic set is explicitly defined; school polynomial algebra suffices.
