Statement

Let f:\mathbb R^2\to\mathbb R be Lebesgue measurable. If either

\int_{\mathbb R}\left(\int_{\mathbb R}|f(x,y)|\,dx\right)dy<\infty\quad\text{or}\quad\int_{\mathbb R}\left(\int_{\mathbb R}|f(x,y)|\,dy\right)dx<\infty,

then f is Lebesgue integrable on \mathbb R^2, meaning \int_{\mathbb R^2}|f|<\infty. All integrals are Lebesgue integrals; undefined sections, if any, are assigned arbitrary values on the exceptional null set.
