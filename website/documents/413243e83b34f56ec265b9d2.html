Likely alternative prerequisite level: High school only; lowest recorded proof level: Undergraduate level. Color the edge {i,j}, i<j, of a sufficiently large finite complete graph by the given color of j-i. The finite multicolor Ramsey induction gives a monochromatic triangle i<j<k. Then x=j-i,y=k-j,z=k-i are positive, all one color, and x+y=z. The needed finite Ramsey bound follows by repeated pigeonhole selection and induction, without rational column spans or Rado's theorem.

Statement

Every finite colouring of the positive integers has positive integers x,y,z of one colour with x+y=z.

Level
High school only
Level justification

Only colours assigned to positive integers and the equation x+y=z must be understood.

Review notes
none

Proof 1: Use the three-column matrix — outline

Use Rado’s columns theorem: an integer matrix A has a positive integer solution to Ax=0 in one colour under every finite colouring if its columns can be partitioned into nonempty blocks C_1,\ldots,C_t such that the first block sums to zero and each later block sum is a rational linear combination of columns in earlier blocks. Apply the theorem to the source matrix (1\ 1\ {-1}). The resulting monochromatic positive solution is precisely x+y-z=0.

Level justification

Check the columns condition for the single-row matrix using rational linear combinations and apply the explicitly supplied theorem. Undergraduate elementary linear algebra suffices; the deep proof of Rado is not used.
