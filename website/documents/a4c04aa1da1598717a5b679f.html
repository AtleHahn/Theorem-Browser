Statement

Let n,r be positive integers with n\geq2r, and let \mathcal A be a family of distinct r-element subsets of an n-element set U. If every two members of \mathcal A intersect, then

|\mathcal A|\leq\binom{n-1}{r-1}.

If n>2r, equality holds exactly when there is an element x\in U such that \mathcal A consists of all r-element subsets containing x. If n=2r, the maximum families are exactly those obtained by choosing one set from each complementary pair \{S,U\setminus S\} of r-element subsets. The binomial coefficient \binom{n-1}{r-1} counts the (r-1)-element subsets of an (n-1)-element set.

Level
High school only
Level justification

Finite subsets, shared elements and elementary counting suffice for the complete bound and equality descriptions.

Proof 1: Kneser eigenvalues and the extremal indicator projection (external)

A link to the proof can be found here (§3, Propositions4–5 and Theorem1 proof, pp.4–6).

When n=2r, two r-sets are disjoint exactly when they are complements, so maximizers choose one from each complementary pair. This also supplies the (n-1)-point bound used in the uniqueness proof when n=2r+1. The case r=1 is immediate. In the last sandwich of inequalities, both comparison signs are non-strict. For the spectral input, span the functions x_S(T)=\mathbf1_{S\subseteq T} with |S|\le i: inclusion-exclusion gives eigenvalue (-1)^i\binom{n-r-i}{r-i} on successive orthogonal layers, so only elementary symmetric-matrix theory is needed.
