Statement

Let g:\mathbb R\to\mathbb R be smooth with g'\!>0 and g(\theta+2\pi)=g(\theta)+2\pi, so f(e^{i\theta})=e^{ig(\theta)} is an orientation-preserving circle diffeomorphism. Let \psi:[0,1]\to[0,1] be smooth, zero near 0 and one near 1. Then F(0)=0 and

F(re^{i\theta})=r\exp\!\left(i\psi(r)g(\theta)+i(1-\psi(r))\theta\right)

define a smooth diffeomorphism of the closed disk extending f.

Level
Within undergraduate level

Proof 1: Interpolate the angular lift with a radial cutoff — outline

For the orientation-preserving case, a diffeomorphism f of the unit circle can be extended to a diffeomorphism F of the unit disk by the Alexander extension:

{\displaystyle \displaystyle {F(re^{i\theta })=r\exp[i\psi (r)g(\theta )+i(1-\psi (r))\theta ],}}

where ψ is a smooth function with values in [0,1], equal to 0 near 0 and 1 near 1, and f(eiθ) = eig(θ), with g(θ + 2π) = g(θ) + 2π.

Set F(0)=0. The source supplies this construction; the periodicity, positive angular derivative and smooth-inverse checks are implicit.

Within undergraduate level
Level justification

Use the explicit polar formula, positive angular derivative and identity near the origin to obtain a smooth inverse. Undergraduate multivariable calculus and the inverse function theorem suffice; no abstract manifold extension theorem is used.
