Statement

Let n_1,\ldots,n_k>1 be pairwise coprime and 0\le a_i<n_i. Set x_1=a_1. For j=2,\ldots,k, choose the first number of the progression x_{j-1}+t\prod_{i<j}n_i (t=0,1,\ldots) congruent to a_j modulo n_j, and call it x_j. Each search terminates, and x_k is the unique solution of all congruences in [0,\prod_i n_i).

Level

Level justification

The algorithm is explicitly defined by integer additions and remainder tests.

Proof 1: Filter successive solution progressions — outline

For this method, we suppose, without loss of generality, that {\displaystyle 0\leq a_{i}<n_{i}} (if it were not the case, it would suffice to replace each {\displaystyle a_{i}} by the remainder of its division by {\displaystyle n_{i}}). This implies that the solution belongs to the arithmetic progression

{\displaystyle a_{1},a_{1}+n_{1},a_{1}+2n_{1},\ldots }

By testing the values of these numbers modulo {\displaystyle n_{2},} one eventually finds a solution {\displaystyle x_{2}} of the two first congruences. Then the solution belongs to the arithmetic progression

{\displaystyle x_{2},x_{2}+n_{1}n_{2},x_{2}+2n_{1}n_{2},\ldots }

Testing the values of these numbers modulo {\displaystyle n_{3},} and continuing until every modulus has been tested eventually yields the solution. Here the integer Chinese remainder theorem supplies, at each stage, a unique solution class modulo the product of the moduli tested.

Level
High school only
Level justification

Each CRT solution class for the previous moduli is an arithmetic progression; the next coprime modulus selects exactly one residue of its parameter. Induction gives termination and the least representative.
