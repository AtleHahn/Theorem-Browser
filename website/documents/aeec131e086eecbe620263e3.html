Statement

For an integer m>0, the equation w^2+2x^2+5y^2+5z^2=m has a solution (w,x,y,z)\in\mathbb Z^4 if and only if m\ne15.

Level
High school only
Level justification

All variables are integers; the statement asks which positive integers are values of one explicitly given quadratic polynomial. No matrix theory or proof prerequisites are needed.

Review notes

  • This explicit counterexample witnesses the necessity of the upper endpoint in the fifteen theorem. It has useful conceptual content, but is a special case of its sharpness assertion.

Proof 1: Ternary representation and residue cases (external)

A supporting source can be found here (Theorem 1(f), Section 3.6, Lemmas 18–20, pp.10–12). The deduction below supplies the argument for the stored statement.

Use the named ternary representation theorem: x^2+2y^2+5z^2 represents every positive integer except E={25^j(25k+10),25^j(25k+15):j,k>=0}. Its modern proof is Blackwell et al., Theorem 1(f), §3.6. The following quaternary reduction is supplied here: if m is outside E take the fourth variable zero. If m is in E and 25 divides m, take fourth variable 1: m-5>0 and is 20 mod25, outside E. If m=25k+10, take fourth variable 1: m-5 is 5 mod25, outside E. If m=25k+15 with k>=1, take fourth variable 2: m-20>0 and is 20 mod25, outside E. Only m=15 remains. Modulo 5, w^2+2x^2=0 forces both w and x divisible by 5; their size bounds at m=15 force w=x=0. Then y^2+z^2=3 is impossible. Thus 15 is exactly the exception.

Level justification

The residue-case completion is elementary, but its ternary representation theorem constructs auxiliary primes using Dirichlet's theorem and quadratic reciprocity. The supporting proof of Dirichlet's theorem develops character sums, Euler products, analytic continuation and nonvanishing of L-functions.
