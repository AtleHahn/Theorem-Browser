Statement

Let n,t be integers with 1\le t\le n, and let 0<p<1/(t+1). Suppose \mathcal F is a family of subsets of [n]=\{1,\ldots,n\} such that |A\cap B|\ge t for all A,B\in\mathcal F. Define

\mu_p(\mathcal F)=\sum_{A\in\mathcal F}p^{|A|}(1-p)^{n-|A|}.

Then \mu_p(\mathcal F)\le p^t, with equality if and only if there is a fixed t-element set T\subseteq[n] such that \mathcal F=\{A\subseteq[n]:T\subseteq A\}. In particular, for an intersecting family (t=1) and 0<p<1/2, its measure is at most p, with equality exactly for all sets containing a fixed element.

High school only
Level justification

The fully defined finite-set and weighted-sum statement requires only elementary counting and arithmetic; no proof method or measure theory prerequisite.
