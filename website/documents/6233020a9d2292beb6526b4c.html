Statement

Zermelo–Fraenkel set theory without the axiom of choice (ZF) proves the following assertion: for every separable Hilbert space H_1, every Hilbert space H_2, every subset U\subseteq H_1, every real L\geq0, and every L-Lipschitz map f:U\to H_2, there exists an extension F:H_1\to H_2 with the same bound. Separable means that a countable subset is dense in the norm topology.

A Hilbert space is a real or complex inner-product space complete for its induced norm. For L\geq0, a map f:U\to H_2 on a subset U\subseteq H_1 is L-Lipschitz if \|f(u)-f(v)\|\leq L\|u-v\| for all u,v\in U. An extension with the same bound is a map F:H_1\to H_2 with F|_U=f and \|F(x)-F(y)\|\leq L\|x-y\| for all x,y\in H_1.
