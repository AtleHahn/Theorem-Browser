Statement

In Zermelo–Fraenkel set theory without choice (ZF), the Boolean prime ideal theorem implies the following assertion: for any Hilbert spaces H_1,H_2, subset U\subseteq H_1, real L\geq0, and L-Lipschitz map f:U\to H_2, an extension F:H_1\to H_2 with the same bound exists.

A Hilbert space is a real or complex inner-product space complete for its induced norm. For L\geq0, a map f:U\to H_2 on a subset U\subseteq H_1 is L-Lipschitz if \|f(u)-f(v)\|\leq L\|u-v\| for all u,v\in U. An extension with the same bound is a map F:H_1\to H_2 with F|_U=f and \|F(x)-F(y)\|\leq L\|x-y\| for all x,y\in H_1.

The Boolean prime ideal theorem here says that every nontrivial Boolean algebra has a proper prime ideal. A Boolean algebra is a bounded distributive lattice with meet \wedge, join \vee, least element 0, greatest element 1, and complements; nontrivial means 0\ne1. An ideal I contains 0, is downward closed and closed under finite joins, is proper if 1\notin I, and is prime if a\wedge b\in I implies a\in I or b\in I.
