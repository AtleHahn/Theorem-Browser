A program can output its own index without receiving that index as input. This makes computational self-reference an exact construction rather than a verbal paradox, while not by itself attributing understanding or self-awareness to the program.

Statement

Fix an admissible numbering e\mapsto\varphi_e of the partial recursive functions on \mathbb N. Equality \simeq means equality of partial functions, including their domains. There exists an index p such that \varphi_p(y)=p for every y\in\mathbb N.

Level
Beyond undergraduate level
Level justification

Computability-theoretic indices and partial recursive functions are outside undergraduate calculus and linear algebra.

Proof 1: Use the function that returns its first argument

Apply the second recursion theorem to the total computable function Q(x,y)=x. The resulting index satisfies \varphi_p(y)=Q(p,y)=p for all y.

Level
Beyond undergraduate level
Level justification

The specialization Q(x,y)=x is simple, but the full theorem is about admissible numberings of partial recursive functions and extensional fixed points. Retain beyond undergraduate provisionally because that recursion-theoretic framework is not a confidently small extension of ordinary algorithms.
