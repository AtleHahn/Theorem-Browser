Statement

Let R be a commutative unital ring and M a finitely generated R-module. Let J(R) be the intersection of all maximal ideals of R. If J(R)M=M, then M=0.

Level
Beyond undergraduate level
Level justification

The Jacobson radical and finite generation are abstract ring/module notions.

Proof 1: Use the determinant annihilator and invertibility

Use the determinant form of Nakayama's lemma: for a finitely generated module M, if IM=M, there exists r\equiv1\pmod I such that rM=0. Apply this with I=J(R). Then 1-r is in the Jacobson radical, so r is invertible. Here one uses the standard radical property that 1-j is a unit for every j\in J(R). Since rM=0, it follows that M=0.

Proof 2: Remove a generator using a radical coefficient

Suppose, for the sake of contradiction, that M\ne0 and that x_1,\ldots,x_n generate M, with n\geq1 being the smallest number with this property. Since x_n\in J(R)M, there are a_i\in J(R) with

x_n=a_1x_1+\cdots+a_nx_n,

or

(1-a_n)x_n=a_1x_1+\cdots+a_{n-1}x_{n-1}.

Here the set of generators \{x_1,\ldots,x_{n-1}\} is regarded as empty and the sum equal to 0 if n=1. Because a_n\in J(R), 1-a_n is a unit: if not, 1-a_n is in some maximal ideal \mathfrak m, but then a_n\in\mathfrak m as \mathfrak m\supset J(R), so 1=(1-a_n)+a_n\in\mathfrak m, a contradiction. Thus

x_n=(1-a_n)^{-1}(a_1x_1+\cdots+a_{n-1}x_{n-1}).

Therefore, x_1,\ldots,x_{n-1} generate M. This contradicts the minimality of n, and so M=0.
