Statement

For a finite numerical set A, write A+A=\{a+b:a,b\in A\} and A\cdot A=\{ab:a,b\in A\}. There exist c>0 and n_0\geq2 such that, for every integer n\geq n_0, the set A=\{1,\ldots,n\} satisfies |A\cdot A|\geq c n^2/\log n.

Level
High school only
Level justification

The statement uses only finite counts and a real logarithmic function.

Proof 1: Apply the product-growth bound to an integer interval

The set A=\{1,\ldots,n\} has a small sumset, of cardinality 2n-1. This example is an instance of the few-sums-many-products result of Elekes and Ruzsa: a set with a small sumset, such as an arithmetic progression, has product-set cardinality \Omega(|A|^2/\log|A|). Applying that stated bound to this progression gives the conclusion.
