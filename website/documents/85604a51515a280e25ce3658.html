Statement

For every recursively enumerable set T of first-order formulas in an effectively encoded language, there is a decidable set of axioms T^* with the same deductive closure. Decidable here concerns membership in the axiom set, not decidability of all consequences.

Proof 1: Craig’s recursive axiomatization theorem (outline)

If T is empty, take T^*=\varnothing. Otherwise, take an enumeration that continues indefinitely, repeating axioms if necessary.

Let {\displaystyle A_{1},A_{2},\dots } be an enumeration of the axioms of a recursively enumerable set {\displaystyle T} of first-order formulas. Construct another set {\displaystyle T^{*}} consisting of

{\displaystyle \underbrace {A_{i}\land \dots \land A_{i}} _{i}}

for each positive integer {\displaystyle i}. That is,

{\displaystyle T^{*}=\{A_{1},A_{2}\land A_{2},A_{3}\land A_{3}\land A_{3},\ldots \}}

The deductive closures of {\displaystyle T^{*}} and {\displaystyle T} are thus equivalent; the proof will show that {\displaystyle T^{*}} is a recursive/decidable set.

Given any formula {\displaystyle X}, let its length be {\displaystyle |X|}. Then to decide {\displaystyle X\in T^{*}}, it suffices to first run the enumeration algorithm until all {\displaystyle A_{1},A_{2},\dots ,A_{|X|}} are output, then check if {\displaystyle X} is equal to one of

{\displaystyle A_{1},A_{2}\land A_{2},\dots ,\underbrace {A_{|X|}\land \dots \land A_{|X|}} _{|X|}.}

Only these indices need to be checked, since a conjunction of i formula copies has length at least i.
