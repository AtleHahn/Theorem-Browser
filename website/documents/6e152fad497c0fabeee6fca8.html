Statement

A rooted tree is a finite connected graph without cycles with a specified vertex called its root. A vertex w is a descendant of v when the path from the root to w contains v; it is a child when it is adjacent to v and is a descendant. An inf-embedding is an injective vertex map preserving descendants such that, for any two distinct children w_1,w_2 of v, the path joining their images contains the image of v. The root need not map to the root. For each nonnegative integer n there is a positive integer m such that every sequence T_1,\ldots,T_m of rooted trees with exactly i+n vertices in T_i has an inf-embedding T_i\to T_j for some i<j. Also, for each finite ordered label set X there is a finite bound on the length of any sequence of X-labeled rooted trees in which T_i has at most i vertices and no earlier tree inf-embeds into a later tree while mapping each label to a greater or equal label. Thus the longest such labeled sequence, the corresponding TREE value, is finite.
