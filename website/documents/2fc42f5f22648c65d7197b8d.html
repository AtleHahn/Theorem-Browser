Statement

A sequent \Gamma\vdash\Delta means that if all formulas in the finite list \Gamma are true, at least one in the finite list \Delta is true. An empty left list is true and an empty right disjunction is false. If \Gamma and \Delta contain only propositional variables, then \Gamma\vdash\Delta is true under every truth assignment if and only if a variable occurs in both lists.

Level
High school only
Level justification

The statement defines the sequent directly as an implication about two finite lists of truth values, including empty-list conventions. A common variable and validity under every assignment are elementary finite conditions. No first-order syntax, formal derivation system or college logic course is required to understand the equivalence.

Proof 1: Compare the atomic conjunction and disjunction — outline

The items to the left of the turnstile are understood to be connected by conjunction, and those to the right by disjunction. Therefore, when both consist only of atomic symbols, the sequent is accepted axiomatically (and always true) if and only if at least one of the symbols on the right also appears on the left.

Level
High school only
Level justification

If a variable appears on both sides, truth of every left variable makes that right variable true. If the lists are disjoint, assign every left variable true and every right variable false, giving a counterexample. The same assignment argument handles either empty list with the stated conventions. This is elementary finite truth-value reasoning, not first-order model theory.
