Statement

Let n>0 be an integer and let X\subset\mathbb R^{n+1} be the image of an injective continuous map S^n\to\mathbb R^{n+1}, where S^n is the unit n-sphere. Then \mathbb R^{n+1}\setminus X has exactly two connected components, each path connected.

Level
Within undergraduate level
Level justification

Basic topology supplies continuous injections, connected components, path connectedness and homeomorphisms. The sphere or Jordan curve is explicitly a familiar Euclidean subset or continuous circle image; the full assertion needs no homology or manifold machinery used by its proof.

Proof 1: Read the component count from reduced homology

Let Y=\mathbb R^{n+1}\setminus X. Use the source-stated homology calculation in the case k=n>0: \widetilde H_0(Y;\mathbb Z)\cong\mathbb Z. Zeroth reduced integral homology has rank one less than the number of path components, so Y has exactly two path components. The complement is open in Euclidean space; its connected components are path connected. Consequently there are also exactly two connected components.

Level
Beyond undergraduate level
Level justification

The actual proof reads the component count from reduced singular homology of an embedded sphere complement. Homology and its separation calculation are substantial algebraic-topology prerequisites.
