Statement

Let A\in\mathbb C^{n\times n}, n\ge1, be normal (AA^*=A^*A), and use the Euclidean vector norm and its induced matrix 2-norm. For \lambda^a\in\mathbb C and 0\ne\boldsymbol v^a\in\mathbb C^n, set \boldsymbol r=A\boldsymbol v^a-\lambda^a\boldsymbol v^a. Some eigenvalue \lambda of A satisfies |\lambda-\lambda^a|\le\|\boldsymbol r\|_2/\|\boldsymbol v^a\|_2.

Proof 1: Residual bound for normal matrices proof

The Bauer–Fike residual bound says that for a diagonalization A=V\Lambda V^{-1} and \boldsymbol r=A\boldsymbol v^a-\lambda^a\boldsymbol v^a with \boldsymbol v^a\ne0, some eigenvalue \lambda obeys |\lambda-\lambda^a|\le\kappa_2(V)\|\boldsymbol r\|_2/\|\boldsymbol v^a\|_2, where \kappa_2(V)=\|V\|_2\|V^{-1}\|_2.

If A is normal, choose the eigenvector matrix V to be a unitary matrix, therefore:

{\displaystyle \|V\|_{2}=\left\|V^{-1}\right\|_{2}=1,}

so that κ2(V) = 1. The residual formulation then becomes:

{\displaystyle \exists \lambda \in \Lambda (A):\quad \left|\lambda -\lambda ^{a}\right|\leq {\frac {\|{\boldsymbol {r}}\|_{2}}{\left\|{\boldsymbol {v}}^{a}\right\|_{2}}}}
