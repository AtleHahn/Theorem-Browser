Statement

Let f:\{0,1\}^n\to\{0,1\}, where n\ge1 is an integer. The operations + and multiplication mean OR and AND, respectively, and x^{\prime}=1-x is Boolean complementation. A multiplexer with selector x and binary inputs u,v returns u when x=1 and v when x=0. Every such f can be realized by a finite hierarchy of multiplexers, with the input variables as selectors and binary constants at terminal inputs.

Level
High school only
Level justification

The inputs are finitely many bits, all Boolean operations are specified, and a multiplexer is explicitly defined as a two-way selector. A hierarchy repeats those finite choices until a constant output is reached. Understanding the claim that every truth table admits such a hierarchy requires elementary finite functions and case distinctions, not circuit-complexity theory.

Proof 1: Iterate Shannon decomposition — outline

Use the Shannon expansion

f(x_1,x_2,\ldots,x_n)=x_1f(1,x_2,\ldots,x_n)+x_1'f(0,x_2,\ldots,x_n).

The expansion is interpreted as an if-then-else, with the variable x_1 being the condition and the cofactors being the branches (f(1,x_2,\ldots,x_n) when x_1 is true and respectively f(0,x_2,\ldots,x_n) when x_1 is false).

Any Boolean function can be implemented directly in a switching circuit using a hierarchy of basic multiplexers by repeated application of this theorem.

Level
High school only
Level justification

Split on one input bit using the stated Shannon identity, then split each remaining cofactor on the next bit until only constants remain. This finite decision-tree construction uses only elementary Boolean rules and induction.
