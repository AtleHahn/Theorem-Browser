Statement

For a variety X/\mathbb F_q, write N_m=|X(\mathbb F_{q^m})| and Z(X,T)=\exp(\sum_{m\geq1}N_m T^m/m) as a formal power series. For \alpha,\beta\in\mathbb C, if E/\mathbb F_q is an elliptic curve with N_m=1-\alpha^m-\beta^m+q^m for every m\geq1, then Z(E,T)=(1-\alpha T)(1-\beta T)/[(1-T)(1-qT)].

Beyond undergraduate level
Level justification

The curve and its point-count generating function require finite-field algebraic geometry.

Proof 1: Sum the four point-count terms outline

Insert the supplied count 1-\alpha^m-\beta^m+q^m in the exponential defining Z. The source gives the resulting quotient of four linear factors; the routine summation uses -\log(1-u)=\sum_{m\geq1}u^m/m.
