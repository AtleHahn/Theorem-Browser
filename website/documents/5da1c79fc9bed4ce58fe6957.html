Statement

Subdivide [−1,1] into finitely many consecutive edges and label its vertices by nonzero integers L(v), with L(−1)=−L(1). Suppose no edge has labels a,−a. Call an edge alternating when its labels have opposite signs and different absolute values. Then the number of alternating edges is odd.

Level
High school only
Level justification

The finite subdivision, sign changes and parity assertion use only elementary one-dimensional geometry and counting.

Proof 1: Count sign changes along the interval

Here {\displaystyle n=1}. In this case, {\displaystyle B_{n}} is the interval {\displaystyle [-1,1]} and its boundary is the set {\displaystyle \{-1,1\}}. The labeling L is boundary-odd, so {\displaystyle L(-1)=-L(+1)}. Without loss of generality, reversing all signs if necessary, assume that L(-1)<0 and L(+1)>0. Start at −1 and go right. At some edge e, the labeling must change from negative to positive. Since L has no complementary edges, e must have a negative label and a positive label with a different size (e.g. −1 and +2); this means that e is a alternating edge. Moreover, if at any point the labeling changes again from positive to negative, then this change makes a second alternating edge, and by the same reasoning as before there must be a third alternating edge later. Hence, the number of alternating edges is odd.

Level justification

Count successive sign changes along a finite ordered list whose endpoint signs differ. The forbidden complementary edges make every sign change alternating. Elementary parity suffices.
