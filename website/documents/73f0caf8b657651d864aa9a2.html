Statement

Let G be finite and \rho:G\to\mathrm{GL}_n(\mathbb C) an irreducible representation, with character \chi=\operatorname{tr}\rho. If the conjugacy class of g\in G has size q^d, for a prime q and integer d\ge0, then q^d\chi(g)/n is an algebraic integer.

Beyond undergraduate level
Level justification

The result uses representation theory and algebraic integrality.

Proof 1: Integral central class sum and Schur’s lemma

Identify integer-valued class functions with the center of the integral group ring by their coefficients, with group-ring convolution as multiplication. The set of integer-valued class functions on {\displaystyle G}, {\displaystyle Z(\mathbb {Z} [G])}, is a commutative ring, finitely generated as a module over {\displaystyle \mathbb {Z} }. All of its elements are thus integral over {\displaystyle \mathbb {Z} }, in particular the mapping {\displaystyle u} which takes the value 1 on the conjugacy class of {\displaystyle g} and 0 elsewhere.

The mapping {\displaystyle A\colon Z(\mathbb {Z} [G])\rightarrow \operatorname {End} (\mathbb {C} ^{n})} which sends a class function {\displaystyle f} to

{\displaystyle \sum _{s\in G}f(s)\rho (s)}

is a ring homomorphism. Because {\displaystyle \rho (s)^{-1}A(u)\rho (s)=A(u)} for all {\displaystyle s}, Schur's lemma implies that {\displaystyle A(u)} is a homothety {\displaystyle \lambda I_{n}}. Its trace {\displaystyle n\lambda } is equal to

{\displaystyle \sum _{s\in G}u(s)\chi (s)=q^{d}\chi (g).}

Because the homothety {\displaystyle \lambda I_{n}} is the homomorphic image of an integral element, this proves that the complex number {\displaystyle \lambda =q^{d}\chi (g)/n} is an algebraic integer.

Level justification

Use the integral group-ring center as a finite module, extend the representation, apply Schur lemma and transfer integrality to the scalar. Group rings, finite-module integrality and irreducible character theory together exceed a small undergraduate extension.
