Statement

For a\in\{0,1\}^{\mathbb N_{>0}}, set v(a)=\sum_{k\ge1}a_k2^{-k} and F(a)=v(a)+1 if a is eventually all ones, F(a)=v(a) otherwise. Then F is injective into \mathbb R.

Proof 1: Separating ambiguous binary expansions gives an injection — outline

For a binary sequence a=(a_k)_{k\ge1} set v(a)=\sum_{k=1}^{\infty}a_k2^{-k}. Map a to v(a)+1 if it is eventually all ones, and otherwise to v(a). The only binary-expansion ambiguity is between a terminating expansion and one ending in repeating ones; the added one separates these two expansions. This gives an injection from all binary sequences into the real numbers.

Level
Within undergraduate level
Level justification

Use the only possible binary-expansion ambiguity and separate its two types by a unit shift. Undergraduate real series and elementary set mappings suffice.
