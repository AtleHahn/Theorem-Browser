Statement

Consider binary decisions with a fixed true alternative. For each voter i\ge1, let X_i equal 1 when the voter chooses that alternative and 0 otherwise; probabilities are conditional on this fixed true state. Suppose the X_i are independent and put p_i=\Pr(X_i=1). For odd n, majority is correct when \sum_{i=1}^n X_i>n/2; for even n, a tie is decided by an independent fair coin.

If

\frac1n\sum_{i=1}^n p_i\longrightarrow p>\frac12,

then the probability that majority chooses the true alternative tends to 1 as n\to\infty. Individual p_i need not be equal or exceed 1/2. The assertion applies separately conditional on each possible true state; it does not assert monotonicity in the jury size.

High school only
Level justification

The statement concerns averages and limits of elementary binary probabilities, with independence explicitly specified. These require elementary reasoning rather than graduate probability.
