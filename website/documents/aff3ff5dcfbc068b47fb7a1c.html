Statement

Let M be a faithful finitely generated module over a commutative ring A. There is a submodule N_0\subseteq M maximal among submodules N for which M/N is faithful. Consequently, every nonzero submodule L\subseteq M/N_0 has nonfaithful quotient (M/N_0)/L.

Proof 1: Use finite generators to apply Zorn’s lemma — outline

Consider the set {\displaystyle S} of submodules {\displaystyle N\subset M} such that {\displaystyle M/N} is faithful. Choose a set of generators {\displaystyle \{x_{1},\dots ,x_{n}\}} of {\displaystyle M} and then note that {\displaystyle M/N} is faithful if and only if for each {\displaystyle a\in A}, the inclusion {\displaystyle \{ax_{1},\dots ,ax_{n}\}\subset N} implies {\displaystyle a=0}. Thus, it is clear that Zorn's lemma applies to the set {\displaystyle S}, and so the set has a maximal element, {\displaystyle N_{0}}. By maximality and the correspondence between submodules of M/N_0 and submodules of M containing N_0, each nonzero submodule L\subseteq M/N_0 has nonfaithful quotient (M/N_0)/L.

The source leaves the chain-union check for Zorn’s lemma implicit.
