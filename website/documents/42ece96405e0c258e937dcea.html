Statement

A proper vertex coloring assigns distinct colors to the two ends of every edge. Graphs here are finite and simple, with no loops or repeated edges. Suppose a family \mathcal C of configurations (connected subgraphs with their vertices’ degrees in the ambient graph specified) has the following properties. Every vertex-minimal non-four-colorable planar graph contains a configuration in \mathcal C. Whenever a planar graph G contains such a configuration, it can be reduced to a planar graph H with fewer vertices so that a four-coloring of H yields a four-coloring of G. Then every planar graph is four-colorable.

Level
High school only
Level justification

The configuration and reduction properties are supplied for finite planar graphs and colorings.

Proof 1: Minimal counterexample and a reducible configuration

If the four-color conjecture were false, there would be a planar graph G with the smallest possible number of vertices that requires more than four colors. By the assumed unavoidability, it contains a configuration from \mathcal C.

If a graph contains a reducible configuration, the graph can be reduced to a smaller graph. This smaller graph has the condition that if it can be colored with four colors, this also applies to the original graph. This implies that if the original graph cannot be colored with four colors the smaller graph cannot either and so the original graph is not minimal. Thus a minimal counterexample cannot exist.

Level
High school only
Level justification

Choose a counterexample of least vertex count and apply the explicit reduction and coloring extension assumptions to contradict minimality. Elementary finite graph reasoning and integer well-ordering suffice.
