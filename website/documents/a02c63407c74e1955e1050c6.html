Statement

All graphs here are finite, simple and undirected. A clique is a set of pairwise adjacent vertices. A cycle is induced if no edge joins two of its nonconsecutive vertices; a graph is chordal if every induced cycle has length three. A perfect elimination ordering v_1,\ldots,v_n is an ordering in which C_i=\{v_i\}\cup\{v_j:j>i,\ v_iv_j\in E\} is a clique for every i. Let n\ge1 and suppose the ordering is given. Form the n sets C_i and retain precisely those that are maximal cliques, meaning not properly contained in any clique. This lists every maximal clique of the graph; consequently there are at most n distinct maximal cliques.

Proof 1: Listing maximal cliques from a perfect elimination ordering — outline

Use the prescribed list: for every vertex, form the clique consisting of that vertex and its later neighbors, then test which of these cliques are maximal. The source gives this as the list of all maximal cliques. There are only n candidate sets, so the list has at most n distinct members.
