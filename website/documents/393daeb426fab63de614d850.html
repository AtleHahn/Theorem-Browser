Statement

Let (C_n) be a computable strictly increasing sequence of finite subsets of \mathbb N with union C. Suppose a total computable nondecreasing function f:\mathbb N\to\mathbb N tends to infinity and, for all sufficiently large k, f(k)<\min(C_{2k+2}\setminus C_{2k}). Then C is computable.

Level
Within undergraduate level
Level justification

Computable here means that a finite algorithm returns the indicated integer or finite set. The constructions involve ordinary sequences, recursion and natural-number sets, familiar from undergraduate proof and algorithm practice; no program-index semantics or formal provability is needed.

Proof 1: Use the bound as a finite-segment stabilization modulus — outline

Here f(k) is a function that is computable, non-decreasing, and satisfies \lim_k f(k)=\infty. If

f(k)<\min(C_{2k+2}\setminus C_{2k})

for all large enough k, then C is decidable.

The source leaves the finite-segment search implicit. Fix a stage beyond which the inequality holds. For an input i, search beyond that stage for k with f(k)\geq i. Since f is nondecreasing, no subsequent pair of stages can add an element at most i. Membership of i therefore agrees with its membership in the computable finite set C_{2k}.
