Statement

Fix an admissible numbering \varphi_e of partial computable functions \mathbb N\rightharpoonup\mathbb N. Let P be a class of total computable functions \mathbb N\to\mathbb N with a partial computable procedure D that halts and decides membership on every index of a total function. For every total computable f and N\in\mathbb N, there is an ultimately zero total function h with h(x)=f(x) for x\le N and (h\in P\iff f\in P).

Level
Beyond undergraduate level
Level justification

The approximation assertion concerns a promise algorithm on total-function indices and preservation of its Boolean value.

Proof 1: Delay the zero tail until the promise decision

An ultimately zero function is zero at all sufficiently large inputs.

Let {\displaystyle P} be as in the statement: a set of total computable functions such that there is an algorithm which, given an index {\displaystyle e} and a promise that {\displaystyle \varphi _{e}} is total, decides whether {\displaystyle \varphi _{e}\in P}.

We first prove a lemma: For all total computable function {\displaystyle f}, and for all integer {\displaystyle N}, there exists an ultimately zero function {\displaystyle h} such that {\displaystyle h} agrees with {\displaystyle f} until {\displaystyle N}, and {\displaystyle f\in P\iff h\in P}.

To prove this lemma, fix a total computable function {\displaystyle f} and an integer {\displaystyle N}, and let {\displaystyle B} be the boolean {\displaystyle f\in P}. By Kleene's recursion theorem, build a program {\displaystyle p} which takes input {\displaystyle x} and takes these steps:

  • If {\displaystyle x\leq N} then return {\displaystyle f(x)};
  • Otherwise, run {\displaystyle x} computation steps of the algorithm D that decides {\displaystyle P} on {\displaystyle p}, and if this returns {\displaystyle B}, then return zero;
  • Otherwise, return {\displaystyle f(x)}.

Clearly, {\displaystyle p} always terminates, i.e., {\displaystyle \varphi _{p}} is total. Therefore, the promise to D run on {\displaystyle p} is fulfilled.

Suppose for contradiction that one of {\displaystyle f} and {\displaystyle \varphi _{p}} belongs to {\displaystyle P} and the other does not, i.e., {\displaystyle (\varphi _{p}\in P)\neq B}. Then we see that {\displaystyle p} computes {\displaystyle f}, since D does not return {\displaystyle B} on {\displaystyle p} no matter the amount of steps. Thus, we have {\displaystyle f=\varphi _{p}}, contradicting the fact that one of {\displaystyle f} and {\displaystyle \varphi _{p}} belongs to {\displaystyle P} and the other does not. This argument proves that {\displaystyle f\in P\iff \varphi _{p}\in P}. Then, the second step makes {\displaystyle p} return zero for sufficiently large {\displaystyle x}, thus {\displaystyle \varphi _{p}} is ultimately zero; and by construction (due to the first step), {\displaystyle \varphi _{p}} agrees with {\displaystyle f} until {\displaystyle N}. Therefore, we can take {\displaystyle h=\varphi _{p}} and the lemma is proved.
