If a positive integer N is not the square of an integer, then \sqrt N is irrational.

Proof 1: Contrapose and square a reduced fraction — outline

To prove that if a positive integer N is a nonsquare number, its square root is irrational, we can equivalently prove its contrapositive, that if a positive integer N has a square root that is rational, then N is a square number. This can be shown by setting \sqrt N equal to the rational expression a/b with a and b being positive integers with no common prime factor, and squaring to obtain N=a^2/b^2 and noting that since N is a positive integer, b=1, so that N=a^2, a square number.

Proof 2: Monic polynomial and the integer-root theorem

The integer root theorem is the case of the rational root theorem when p(x) is a monic polynomial with integer coefficients: for such a polynomial, every rational root is an integer. Applying this to p(x)=x^2-N shows that the square root of a natural number that is not a perfect square is irrational, since an integer square root would make N a perfect square.
