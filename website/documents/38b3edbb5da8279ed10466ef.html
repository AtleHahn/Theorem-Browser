Statement

Define L_0=\varnothing, L_{\alpha+1}=\operatorname{Def}(L_\alpha), and L_\lambda=\bigcup_{\alpha<\lambda}L_\alpha for limit ordinals \lambda, where \operatorname{Def}(S) consists of subsets of S first-order definable in (S,\in) using parameters from S. Let \alpha be an ordinal and X\subseteq L_\alpha a transitive set, meaning x\in X implies x\subseteq X. Suppose (X,\in) is an elementary substructure of (L_\alpha,\in): every first-order formula with parameters from X has the same truth value in the two structures. Then X=L_\beta for some ordinal \beta\le\alpha.
