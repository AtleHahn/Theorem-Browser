Statement

Let X be a Polish space, that is, a topological space whose topology is induced by a complete separable metric. Let (P_t)_{t\geq0} be Markov probability kernels on the Borel sets of X: for each x\in X, P_t(x,\cdot) is a probability measure, and for each Borel set B, x\mapsto P_t(x,B) is Borel measurable. Assume

P_0(x,B)=\mathbf1_B(x),\qquad P_{s+t}(x,B)=\int_X P_t(y,B)\,P_s(x,dy)\quad(s,t\geq0).

Use the Feller convention appropriate to a general Polish space: for every bounded continuous real function f on X and every t\geq0, the function

P_tf(x)=\int_X f(y)\,P_t(x,dy)

is continuous (and bounded).

Suppose there is x_0\in X for which \{P_t(x_0,\cdot):t>0\} is uniformly tight: for every \varepsilon>0, some compact K\subseteq X satisfies P_t(x_0,K)\geq1-\varepsilon for all t>0.

Then there is a Borel probability measure \mu on X such that

\int_X P_t(x,B)\,\mu(dx)=\mu(B)

for every Borel set B and every t>0. Here the Borel sets form the sigma-algebra generated by the open subsets of X.
