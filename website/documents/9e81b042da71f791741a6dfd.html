Statement

Graphs here are finite, simple and undirected. A cubic graph has degree three at every vertex; a bridge is an edge whose deletion increases the number of connected components. A perfect matching is a set of edges meeting each vertex exactly once. If M is a perfect matching of a cubic graph G, then the spanning subgraph with edge set E(G)\setminus M is a disjoint union of cycles.

Level
High school only
Level justification

The finite graph notions can be defined locally and the counting is elementary.

Proof 1: Remove one incident edge at every vertex

Each vertex loses exactly one incident edge when the perfect matching is removed, leaving degree two. Thus the complement is a 2-factor, that is, a spanning union of cycles.

Level justification

Removing the matching leaves exactly two incident edges at each vertex. Apply the elementary finite degree-two graph characterization.
