Statement

Let n\ge2, let G\subset\mathbb C^n be open, and let K\subset G be compact. If G\setminus K is connected, every holomorphic function f on G\setminus K has a unique holomorphic extension to G.

Proof 1: Ehrenpreis cutoff and compactly supported Dolbeault solution

Ehrenpreis' proof is based on the existence of smooth bump functions, unique continuation of holomorphic functions, and the Poincaré lemma — the last in the form that for any smooth and compactly supported differential (0,1)-form ω on Cn with \overline\partialω = 0, there exists a smooth and compactly supported function η on Cn with \overline\partialη = ω. The crucial assumption n ≥ 2 is required for the validity of this Poincaré lemma; if n = 1 then it is generally impossible for η to be compactly supported.

Write \overline\partial for the antiholomorphic differential. If K is empty there is nothing to prove. The ansatz for F is φ f − v for smooth functions φ and v on G; such an expression is meaningful provided that φ is identically equal to zero on a neighborhood of K, where f is undefined. Furthermore, given any holomorphic function on G which is equal to f on some open set, unique continuation (based on connectedness of G \ K) shows that it is equal to f on all of G \ K.

The holomorphicity of this function is identical to the condition \overline\partialv = f \overline\partialφ. For such a smooth function φ, the differential (0,1)-form f \overline\partialφ is \overline\partial-closed. Choosing φ to be a smooth function which is identically equal to zero on a neighborhood of K and identically equal to one on the complement of some compact subset L of G, extending this (0,1)-form by zero to \mathbb C^n makes it smooth with compact support, so that the Poincaré lemma identifies an appropriate v of compact support. This defines F as a holomorphic function on G; it only remains to show (following the above comments) that it coincides with f on some open set.

On the set Cn \ L, v is holomorphic since φ is identically constant. Since it is zero near infinity, unique continuation shows that it is identically zero on the unbounded component of \mathbb C^n\setminus L.

Any connected component of Cn \ L must intersect G \ L in a nonempty open set. To see the nonemptiness, connect an arbitrary point p of Cn \ L to some point of L via a line. The intersection of the line with Cn \ L may have many connected components, but the component containing p gives a continuous path from p into G \ L.

Thus v is identically zero on some nonempty open subset of G\setminus L. Thus, on this open subset, F equals f and the existence part of Hartog's theorem is proved. Uniqueness is automatic from unique continuation, based on connectedness of G.
