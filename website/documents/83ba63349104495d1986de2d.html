Statement

Let d\ge1 be an integer. Let 1\le p,r,q<\infty satisfy 1/q=1/p+1/r-1. For real measurable f\in L^p(\mathbb R^d) and h\in L^r(\mathbb R^d), the integral-kernel bound below specializes to

\|h*f\|_q\le\|h\|_r\|f\|_p,\qquad (h*f)(x)=\int_{\mathbb R^d}h(x-y)f(y)\,dy.

Proof 1: Convolution-kernel substitution

Use the following integral-kernel inequality as an explicit external dependency: if on measure spaces X,Y, a measurable real kernel K:X\times Y\to\mathbb R obeys \int_Y|K(x,y)|^rdy\le C^r for every x and \int_X|K(x,y)|^rdx\le C^r for every y, then

\int_X\left|\int_YK(x,y)f(y)\,dy\right|^qdx\le C^q\left(\int_Y|f(y)|^pdy\right)^{q/p}.

Here 1/q=1/p+1/r-1.

If {\displaystyle X=Y=\mathbb {R} ^{d}} and {\displaystyle K(x,y)=h(x-y)}, then the inequality becomes Young's convolution inequality. Here the common kernel bound is C=\|h\|_r, using translation invariance of Lebesgue measure.
