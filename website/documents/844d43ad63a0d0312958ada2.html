Statement

Let a sequent proof system have a rewriting relation on its finite proof trees. Suppose every rewrite preserves the endsequent, every tree containing a Cut application admits a rewrite, and every sequence of rewrites terminates. Then every provable sequent has a cut-free proof tree.

Level
Within undergraduate level
Level justification

Proof trees and sequent endconclusions add a limited formal-syntax interpretation to finite trees. Rewrite termination and preservation are explicit assumptions, not cut-elimination machinery.

Proof 1: Rewrite to a terminal tree

Start with a proof tree and apply rewrites as long as possible. Termination makes this process stop. Its last tree contains no Cut application, since any such tree would admit another rewrite. Each step preserves the endsequent, so the last tree is a cut-free proof of the original sequent.
