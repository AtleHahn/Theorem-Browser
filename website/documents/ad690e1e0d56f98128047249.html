Statement

Let \Omega\subset\mathbb R^n be a domain with smooth boundary. A smooth function on \overline\Omega means a smooth function on its interior whose derivatives of every order extend continuously to the closure. Every such function has a smooth extension to all of \mathbb R^n.

Level
Within undergraduate level
Level justification

Multivariable calculus supplies smooth functions, smooth inverses and regular planar curves. Smooth boundary is locally a smooth graph, and the closure-smoothness convention is supplied. These Euclidean notions need no abstract manifold or bundle construction.

Proof 1: Boundary jets and Borel’s lemma — outline

A smooth function on a half space Rn,+ of points where xn ≥ 0 is a smooth function f on the interior x_n>0 for which the derivatives ∂α f extend to continuous functions on the half space. On the boundary xn = 0, f restricts to smooth function. By Borel's lemma, f can be extended to a smooth function on the whole of Rn. Since Borel's lemma is local in nature, the same argument shows that if {\displaystyle \Omega } is a (bounded or unbounded) domain in Rn with smooth boundary, then any smooth function on the closure of {\displaystyle \Omega } can be extended to a smooth function on Rn.

Beyond undergraduate level
Level justification

Match all boundary derivatives using a parameter-dependent Borel lemma and localize in smooth boundary charts. Smooth jets, boundary localization and smooth gluing form a cumulative advanced-analysis prerequisite chain.

Proof 2: Half-space extension and partition of unity — outline

Use the Seeley half-space extension theorem as an external dependency: smooth functions up to the boundary of a Euclidean half-space admit a continuous linear extension to the whole Euclidean space. Denote the one-dimensional half-line extension operator by E.

Define the extension for a half space in Rn by applying the operator E to the last variable xn. Similarly, using a smooth partition of unity and a local change of variables, the result for a half space implies the existence of an analogous extending map

{\displaystyle \displaystyle {C^{\infty }({\overline {\Omega }})\rightarrow C^{\infty }(\mathbf {R} ^{n})}}

for any domain {\displaystyle \Omega } in Rn with smooth boundary.

Level
Beyond undergraduate level
Level justification

Use a continuous smooth extension operator in the normal coordinate, then glue in boundary charts with a partition of unity. Function-space operators, boundary charts and smooth partitions constitute substantial additional background.
