Statement

For real variables x_1,\ldots,x_k, the Laplace operator \sum_{j=1}^k\partial^2/\partial x_j^2 is elliptic. For k\ge2, the wave operator -\partial^2/\partial x_1^2+\sum_{j=2}^k\partial^2/\partial x_j^2 is not elliptic. The principal symbol is obtained by retaining highest-order terms and replacing \partial/\partial x_j by a real variable y_j; ellipticity means it is nonzero for every nonzero y.

Proof 1: Source argument

The Laplace operator in k variables has symbol {\displaystyle y_{1}^{2}+\cdots +y_{k}^{2}}, and so is elliptic as this is nonzero whenever any of the {\displaystyle y_{i}}'s are nonzero. The wave operator has symbol {\displaystyle -y_{1}^{2}+\cdots +y_{k}^{2}}, which is not elliptic if {\displaystyle k\geq 2}, as the symbol vanishes for some non-zero values of the ys.
