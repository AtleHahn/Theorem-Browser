Statement

The set of transcendental elements of \mathbb R (those satisfying no nonzero polynomial with integer coefficients) has cardinality \mathfrak c=|\mathbb R|.

Level
Within undergraduate level
Level justification

Set cardinalities, functions and inner products are undergraduate concepts. Cardinal powers count function sets as explicitly stated, and transcendental means not a polynomial root. No ordinal arithmetic or algebraic-number-theory structure is required.

Proof 1: Remove the countable algebraic part — outline

The algebraic elements of \mathbb R form a countably infinite set. They and the transcendental elements partition \mathbb R, which has cardinality \mathfrak c. Removing a countable subset from an uncountable set of cardinality \mathfrak c leaves cardinality \mathfrak c. Thus the transcendental elements have this cardinality.

Level
Within undergraduate level
Level justification

Subtract the countable algebraic subset from the uncountable real set and use the supplied cardinality rule. Undergraduate countability and infinite cardinal arithmetic suffice.
