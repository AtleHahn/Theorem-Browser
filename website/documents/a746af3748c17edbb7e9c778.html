Statement

Let a be a normal element of a C*-algebra A, using unitization for spectra when necessary. Then a=a^* iff \sigma(a)\subseteq\mathbb R, and a=a^*=a^2 iff \sigma(a)\subseteq\{0,1\}. If A is unital, a is unitary iff \sigma(a)\subseteq\{z:|z|=1\}.

Proof 1: Coordinate-function identities

The continuous functional calculus \Phi_a for the normal element a is an isometric *-homomorphism with \Phi_a(\operatorname{Id})=a, where \operatorname{Id}(z)=z on \sigma(a). Thus a is self-adjoint, unitary, or a projection if and only if \operatorname{Id}\in C(\sigma(a)) has the corresponding property. In the nonunital case the calculus is taken in the unitization.

Exactly when \operatorname{Id} is self-adjoint,

z=\operatorname{Id}(z)=\overline{\operatorname{Id}(z)}=\bar z

holds for all z\in\sigma(a), i.e. \sigma(a) is real. Exactly when \operatorname{Id} is unitary,

1=\operatorname{Id}(z)\overline{\operatorname{Id}(z)}=z\bar z=|z|^2

holds for all z\in\sigma(a), therefore \sigma(a)\subseteq\{\lambda\in\mathbb C:|\lambda|=1\}. Finally, \operatorname{Id} is a projection if and only if

(\operatorname{Id}(z))^2=\operatorname{Id}(z)=\overline{\operatorname{Id}(z)},

that is, z^2=z=\bar z for all z\in\sigma(a), i.e. \sigma(a)\subseteq\{0,1\}.
