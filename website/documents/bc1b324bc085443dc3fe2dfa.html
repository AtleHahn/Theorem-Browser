Statement

Let T be a finite triangulation of the closed unit disk whose boundary triangulation is invariant under v↦−v. Label vertices by nonzero integers, with L(−v)=−L(v) on the boundary. Suppose no edge has labels a,−a. A triangle is alternating when its three labels have different absolute values and signs alternating in order of absolute value. Then the number of alternating triangles is odd.

Level
High school only
Level justification

The finite disk triangulation, antipodal boundary pairing and alternating label condition are explicitly defined using plane triangles, signs and integer order.

Proof 1: Count increasing and decreasing edges modulo two — outline

Consider {\displaystyle n=2}. In this case {\displaystyle B_{n}} is a disc and its boundary is a circle. The labeling L is boundary-odd, so in particular {\displaystyle L(-v)=-L(v)} for any boundary vertex v on the boundary. Split the boundary circle at v and -v into two semi-circles and treat each semi-circle as an interval. Since the endpoint signs are opposite, sign changes occur an odd number of times. No edge is complementary, so every sign-changing edge is alternating. Thus this interval must have an alternating simplex, e.g. an edge with labels (+1,−2). Moreover, the number of such edges on both intervals is odd. Antipodal symmetry exchanges the two semicircles and negates both endpoint labels. Consequently, on the boundary we have an odd number of edges where the label of smaller absolute value is positive and the label of larger absolute value negative, and an odd number of edges where the label of smaller absolute value is negative and the label of larger absolute value positive. We call the former decreasing, the latter increasing.

There are two kinds of triangles.

  • If a triangle is not alternating, it must have an even number of increasing edges and an even number of decreasing edges.
  • If a triangle is alternating, it must have one increasing edge and one decreasing edge.

Count incidences of increasing edges with triangles modulo two. Interior edges are counted twice and boundary edges once. Thus the odd boundary count equals the number of alternating triangles modulo two, proving that this number is odd.

Level justification

Pair antipodal boundary edges, check the finitely many triangle sign patterns and count edge-triangle incidences modulo two. The triangulation is a finite planar arrangement and elementary parity suffices.
