Statement

In ZF, assume that every infinite set A admits a bijection with A\times A. Then the axiom of choice holds.

Level
Within undergraduate level
Level justification

Sets, bijections and Cartesian products are undergraduate foundations. Choice is the existence of a selection function for every family of nonempty sets, a single set-theoretic principle; no forcing/model construction is needed to understand this conditional implication.

Proof 1: Use a large ordinal and least preimages

It is known that the well-ordering theorem is equivalent to the axiom of choice; thus it is enough to show that the hypothesis implies that for every set B there exists a well-order.

Since the collection of all ordinals such that there exists a surjective function from B to the ordinal is a set, there exists an infinite ordinal \beta such that there is no surjective function from B to \beta. We assume without loss of generality that the sets B and \beta are disjoint. By the initial assumption,

|B\cup\beta|=|(B\cup\beta)\times(B\cup\beta)|,

thus there exists a bijection

f:B\cup\beta\longrightarrow(B\cup\beta)\times(B\cup\beta).

For every x\in B, it is impossible that \beta\times\{x\}\subseteq f[B], because otherwise we could define a surjective function from B to \beta: send b to the first coordinate of f(b) when f(b)\in\beta\times\{x\}, and send the other elements to 0\in\beta. Therefore, there exists at least one ordinal \gamma\in\beta such that f(\gamma)\in\beta\times\{x\}, so the set

S_x=\{\gamma\in\beta:f(\gamma)\in\beta\times\{x\}\}

is not empty.

We can define a new function: g(x)=\min S_x. This function is well defined since S_x is a nonempty set of ordinals, and so has a minimum. For every x,y\in B, x\ne y, the sets S_x and S_y are disjoint. Therefore, we can define a well-order on B: for every x,y\in B we define

x\le y\quad\Longleftrightarrow\quad g(x)\le g(y),

since g is injective and its image g[B] is a set of ordinals and therefore well-ordered.

Level
Beyond undergraduate level
Level justification

The least-fiber argument is explicit, but its ZF setting requires ordinal bounds on surjective images and choice-free well-ordering equivalences. The combined foundational prerequisite burden is not confidently a small extension.
