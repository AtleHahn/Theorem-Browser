Statement

Let X be data from a statistical model with parameter \theta, let T(X) be sufficient for \theta, and let \delta(X) be a real estimator integrable under each model distribution. For a convex loss L:\mathbb R\to\mathbb R for which L(\delta(X)) is integrable, the conditional estimator \delta_1(X)=\mathbb E_\theta[\delta(X)\mid T(X)] is independent of the unknown parameter and satisfies \mathbb E_\theta L(\delta_1(X))\le\mathbb E_\theta L(\delta(X)).

Level
Beyond undergraduate level
Level justification

Statistical sufficiency and conditional estimators in an arbitrary probability model require general probability and mathematical statistics.

Proof 1: Condition on a sufficient statistic

If L is a convex function and {\displaystyle {\mathfrak {G}}} a sub-sigma-algebra, then, from the conditional version of Jensen's inequality, we get

{\displaystyle L(\operatorname {E} [\delta (X)\mid {\mathfrak {G}}])\leq \operatorname {E} [L(\delta (X))\mid {\mathfrak {G}}]\quad \Longrightarrow \quad \operatorname {E} [L(\operatorname {E} [\delta (X)\mid {\mathfrak {G}}])]\leq \operatorname {E} [L(\delta (X))].}

So if δ(X) is some estimator of an unobserved parameter θ given a vector of observables X; and if T(X) is a sufficient statistic for θ; then an improved estimator, in the sense of having a no greater expected loss L, can be obtained by calculating

{\displaystyle \delta _{1}(X)=\operatorname {E} _{\theta }[\delta (X)\mid T(X)],}

where \mathfrak G=\sigma(T(X)); this is the conditional expected value of δ given the observed sufficient statistic. Further, because T is a sufficient statistic, {\displaystyle \delta _{1}(X)} does not depend on θ, hence, becomes a statistic.
