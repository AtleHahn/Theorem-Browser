Statement

Let f:[0,1]\to[0,1] be continuous. For 0<\delta<1, exact value queries suffice to find a point within \delta of some fixed point using O(\log(1/\delta)) queries as \delta\downarrow0. If f is L-Lipschitz with L>1, a point with |f(x)-x|\le\varepsilon can be found using O(\log((L+1)/\varepsilon)) queries as \varepsilon\downarrow0. A query supplies the exact value f(x) at a chosen point.

Level
Within undergraduate level
Level justification

Understanding the statement involves Continuous real interval self-maps; Approximation distance and residual; Exact evaluation queries; Logarithmic query bounds; Lipschitz inequality. These prerequisites fit undergraduate coursework or a brief extension of it. A bright US college student should be able to understand this statement after approximately 30 minutes of focused background research; this assesses understanding the claim, not its proof.

Proof 1: Bisect an interval containing a fixed point — outline

Start with [0,1]. At each step evaluate f at the midpoint x of the current interval. If f(x)>x, keep the right half; otherwise keep the left half, including the midpoint. The current interval always contains a fixed point. Its length halves on every query, so after O(\log(1/\delta)) queries any point in the retained interval is within \delta of a fixed point. For the Lipschitz residual conclusion, use \delta=\varepsilon/(L+1). The local Lipschitz error calculation is

|f(x)-x|\le |f(x)-f(x_0)|+|x_0-x|\le(L+1)|x-x_0|,

where x_0 is the fixed point in the retained interval. Substituting this \delta in the query count gives the stated residual bound.
