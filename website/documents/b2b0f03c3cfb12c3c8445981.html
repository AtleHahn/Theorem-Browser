Statement

Let DLO be the first-order theory in the language with one binary relation <, on nonempty domains, whose axioms say that < is a strict dense linear order without endpoints. DLO has exactly one countable model up to isomorphism, represented by (\mathbb Q,<).

Level
Within undergraduate level
Level justification

In this particular language, a model is a set with a relation satisfying the stated order axioms. The companion spells out density, endpoint absence and order isomorphism. Countability and uniqueness up to an order-preserving bijection fit undergraduate sets and relations with a brief introduction to the word model; no general model-theoretic machinery is needed.

Proof 1: Cantor’s isomorphism theorem supplies the unique type

A strict linear order is an irreflexive transitive relation < such that distinct elements are comparable. It is dense if x<y implies x<z<y for some z, and has no endpoints if every element has both a smaller and a larger element. An order isomorphism is a bijection preserving and reflecting <.

Cantor proved that any countable dense linear order with no endpoints is isomorphic to the rational numbers. The rational order is itself such a countable model. Hence every countable model belongs to that one isomorphism type.

Level
Within undergraduate level
Level justification

The theory is explicitly just the listed dense-order properties. Apply the supplied order-isomorphism theorem and note that Q is one example. Categoricity here only renames uniqueness up to an order-preserving bijection; no general model-theoretic machinery is used.
