Embed a countable linear order by successive finite extensions

Statement

A strict linear order is an irreflexive transitive relation < such that distinct elements are comparable. It is dense if x<y implies x<z<y for some z, and has no endpoints if every element has both a smaller and a larger element. An order isomorphism is a bijection preserving and reflecting <. Every finite or countable linear order L has an order-preserving injection into every nonempty dense linear order M without endpoints; in particular it embeds into \mathbb Q.

Level
Within undergraduate level
Level justification

Partial orders, chains, antichains and countability are undergraduate set/order concepts. A chain means pairwise comparable and an antichain pairwise incomparable; selection principles, where assumed, are explicit hypotheses. These short definitions suffice for the quantified existence or partition claim.

Proof 1: Successive finite-gap insertions — outline

Use the “going forth” half of the back-and-forth method. Enumerate L, and start with empty order-isomorphic finite subsets A\subseteq L and B\subseteq M. Repeatedly increase the sizes of A and B by adding a new element from L, the first missing element in its enumeration, and matching it with an order-equivalent element of M, using the density and lack of endpoints of the order.

This finds an equivalence between the first ordering and a subset of the second ordering. When L is finite the procedure terminates.
