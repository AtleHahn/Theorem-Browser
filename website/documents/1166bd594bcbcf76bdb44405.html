Statement

Let S be a finite set and let f,g:S\to S be involutions, meaning f(f(s))=s and g(g(s))=s for every s\in S. If f has an odd number of fixed points, then g also has an odd number of fixed points and in particular has at least one.

Level
High school only
Level justification

Involution is explicitly a map that undoes itself, and fixed-point counts concern finite sets and parity.

Proof 1: Transfer parity through the common finite set

Use the stated involution parity theorem: the number of fixed points of any involution of a finite set has the same parity as the size of that set. The fixed-point count of f is odd, so |S| is odd. The fixed-point count of g has the same parity and is therefore odd and nonzero.

Level
High school only
Level justification

Use the given parity identity twice for the same finite set. Elementary finite sets and odd-even counting suffice.
