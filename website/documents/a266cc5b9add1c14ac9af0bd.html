Statement

Fix n\geq1, positive raw entitlements t_1,\ldots,t_n, and a real-valued function r(t,a) for t>0 and integers a\geq0, nonincreasing in a. Starting from a_i=0, assign each successive seat to any agent maximizing r(t_i,a_i), then increase that agent’s count by one. Let M(\mathbf t,h) contain all allocations obtainable after h steps, including every possible tie choice; M(\mathbf t,0) contains the zero vector. If \mathbf a\in M(\mathbf t,h) and S\subseteq\{1,\ldots,n\} is nonempty, put h_S=\sum_{i\in S}a_i. Using the same raw entitlements t_i for i\in S and the same function r, the restricted vector (a_i)_{i\in S} is an obtainable allocation after h_S steps on that subset.

Level
High school only
Level justification

All allocation rules, score comparisons and tie choices are explicitly defined on finite runs.

Proof 1: Keep the subsequence of awards to the chosen agents

Choose a run producing \mathbf a and delete from its sequence every award to an agent outside S. Before each retained award, each agent in S has exactly the same count as it had at that award in the original run: deleted awards affected only other agents. Its score is therefore unchanged. An agent maximizing the score among all agents at that time also maximizes it among those in S. The retained award is thus a valid next step in the restricted run, using the inherited choice if scores tie. There are h_S retained awards, and their resulting counts are exactly (a_i)_{i\in S}.

Level
High school only
Level justification

Delete awards outside the subset and observe that the remaining scores and maximizing choices are unchanged. Finite sequences, counts and maxima suffice.
