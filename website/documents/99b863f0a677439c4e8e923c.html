Statement

Let m:U\to[0,1] have some value strictly between 0 and 1. Define product intersection by (m\cap_t n)(x)=m(x)n(x). Then m\cap_t m\ne m, so product intersection is not an idempotent operation on all fuzzy sets.

Level
High school only
Level justification

Membership functions and product intersection are explicitly functions into [0,1] with pointwise multiplication.

Proof 1: Square a partial membership grade — outline

The source uses arithmetic multiplication as its nonidempotent example. Self-intersection gives membership m(x)^2. At a partial member, 0<m(x)<1 implies m(x)^2<m(x), so the resulting membership function differs.
