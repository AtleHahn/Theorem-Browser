Statement

A partial order is a reflexive, antisymmetric, transitive relation \le. Distinct elements are comparable when one is below the other. A chain has every pair comparable; an antichain has no distinct comparable pair. A partition consists of disjoint subsets whose union is the whole set. Let P be a finite partially ordered set and h its largest chain size. Then the minimum number of antichains in a partition of P is h. For the empty order both quantities are zero.

Level
High school only
Level justification

Every order and partition notion is explicitly defined on a finite set, including the empty case.

Proof 1: Partition by longest-chain ranks

In such a partition, every two elements of the longest chain must go into two different antichains, so the number of antichains is always greater than or equal to the height; another formulation of Mirsky's theorem is that there always exists a partition for which the number of antichains equals the height.

To prove the existence of a partition into a small number of antichains for an arbitrary finite partially ordered set, consider for every element x the chains that have x as their largest element, and let N(x) denote the size of the largest of these x-maximal chains. Then each set N^{-1}(i), consisting of elements that have equal values of N, is an antichain, and these antichains partition the partial order into a number of antichains equal to the size of the largest chain. For the empty order both quantities are zero.

Proof 2: Apply Dilworth and the perfect graph complement theorem

We use Dilworth's theorem, stating that for a finite partially ordered set the maximum size of an antichain equals the minimum number of chains in a partition of the set into chains.

An undirected graph is perfect if, in every induced subgraph, the chromatic number equals the size of the largest clique. The comparability graph joins two distinct elements exactly when they are comparable. In the comparability graph of a partially ordered set, a clique represents a chain and a coloring represents a partition into antichains, and induced subgraphs of comparability graphs are themselves comparability graphs, so Mirsky's theorem states that comparability graphs are perfect. Analogously, Dilworth's theorem states that every complement graph of a comparability graph is perfect. The perfect graph theorem of Lovász states that the complements of perfect graphs are always perfect, and can be used to deduce Mirsky's theorem from Dilworth's theorem.
