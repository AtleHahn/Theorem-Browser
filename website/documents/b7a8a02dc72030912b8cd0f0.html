Every nonempty periodic semigroup has an idempotent

Statement

Let S be a semigroup, a set with an associative operation xy. Call S periodic if for every x\in S the set \{x^m:m\ge1\} is finite. If S is nonempty and periodic, it contains an idempotent, an element e with e^2=e.

Level
Within undergraduate level
Level justification

The semigroup is explicitly just an associative operation, and periodicity and idempotence are supplied as elementary power conditions. Introductory algebra suffices without additional structure.

Proof 1: Pass to a finite monogenic subsemigroup

Choose an element x of the nonempty semigroup. Its generated subsemigroup is finite. Use the external theorem that every finite nonempty monogenic semigroup contains an idempotent. That idempotent belongs to S.

Level
Within undergraduate level
Level justification

Choose one element, restrict to its finite set of positive powers and apply the supplied finite-semigroup theorem. Undergraduate introductory abstract algebra suffices with semigroups as the small extension obtained by retaining only associativity.
