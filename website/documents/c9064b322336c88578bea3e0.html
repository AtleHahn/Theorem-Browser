Statement

Let S be a compact Riemann surface and f:S\to\mathbb P^1(\mathbb C) a nonconstant holomorphic map whose branch values lie in a set of three distinct points \{a,b,c\}. There is a Möbius transformation M of the Riemann sphere such that M\circ f is ramified only over \{0,1,\infty\}.

Level
Beyond undergraduate level
Level justification

The statement concerns ramification and biholomorphic coordinate changes on the Riemann sphere.

Proof 1: Möbius change of target — outline

The map f is ramified only over three points, which after a Möbius transformation may be taken to be \{0,1,\infty\}.

Level
Beyond undergraduate level
Level justification

The Möbius normalization itself is elementary complex algebra, but understanding the full proof requires holomorphic maps on compact Riemann surfaces, ramification and branch values, and their behavior under a target biholomorphism. These linked complex-geometric concepts exceed the short undergraduate extension; replacing S by a plane domain would change the given setting.

Theorem

Treatment:

Implicitly assumed

Statement used:

Any ordered triple of distinct points of the extended complex plane can be mapped to 0,1,infinity by a Möbius transformation.

Application in proof:

Choose M carrying the three allowed branch values to the normalized triple.

Application level:

Undergraduate level

Level justification:

The transformation is a fractional linear function; for finite a,b,c one may use (z-a)(b-c)/((z-c)(b-a)), with the usual limits at infinity. This is a small complex-algebra extension.

Postcomposition by a biholomorphism transports branch values
Kind:

Theorem

Treatment:

Implicitly assumed

Statement used:

If f is a holomorphic map of Riemann surfaces and M a biholomorphism of its target, M composed with f has the same ramification points and branch values transported by M.

Application in proof:

Conclude that the normalized map is ramified only over 0,1,infinity.

Application level:

Beyond undergraduate level

Level justification:

The application requires local complex charts, ramification multiplicities and the Riemann-surface setting.
