Statement

Let n\geq1 and f:\{0,1\}^n\to\{0,1\}. Write x'=1-x for complementation, juxtaposition for Boolean AND and + for Boolean OR. Then

f(x_1,x_2,\ldots,x_n)=x_1f(1,x_2,\ldots,x_n)+x_1'f(0,x_2,\ldots,x_n).
Level
High school only
Level justification

All function domains and logical operations are finite and explicitly specified.

Mathematical Field
Mathematical logic
Required topics
Finite binary functionsBoolean AND, OR and complement
Review notes
none

Proof 1: Select the cofactor matching the input — outline

The terms f(1,x_2,\ldots,x_n) and f(0,x_2,\ldots,x_n) are the positive and negative Shannon cofactors, respectively, of f with respect to x_1: they are f with the argument x_1 set equal to 1 and to 0 respectively.

The expansion is interpreted as an if-then-else, with the variable x_1 being the condition and the cofactors being the branches (f(1,x_2,\ldots,x_n) when x_1 is true and respectively f(0,x_2,\ldots,x_n) when x_1 is false).

Level
High school only
Level justification

Check x1=1 and x1=0. In each case the Boolean operations select precisely the corresponding value of f. The explicit two-case rules require only elementary logic.
