Statement

Let G,H be quasi-isometric finitely presented groups. Then the word problem for G is decidable if and only if that for H is decidable: an algorithm decides whether a finite generator word represents the identity. For a finite presentation P=\langle X\mid R\rangle, define \operatorname{Area}_P(w) for a freely reduced word representing the identity as the least number of conjugates of elements of R^{\pm1} whose product is w in the free group on X. Its Dehn function is \delta_P(n)=\max\{\operatorname{Area}_P(w):w=1,\ |w|\le n\}. An isoperimetric function is a nondecreasing upper bound for these areas in terms of word length. For nondecreasing functions f,g:\mathbb N\to[0,\infty), write f\preceq g if there is an integer C\ge1 such that f(n)\le Cg(Cn+C)+Cn+C for all n\ge0, and f\approx g if both dominations hold. A recursive isoperimetric upper bound means a nondecreasing integer-valued bound computable by an algorithm.

Proof 1: Transfer a recursive isoperimetric upper bound — outline

  • If G and H are quasi-isometric finitely presented groups and some finite presentation of G has an isoperimetric function f(n) then for any finite presentation of H there is an isoperimetric function equivalent to f(n). In particular, this fact holds for G = H, where the same group is given by two different finite presentations.
  • For a finitely presented group G given by a fixed finite presentation the following conditions are equivalent:
    • G has a recursive Dehn function with respect to the chosen presentation.
    • There exists a recursive isoperimetric function f(n) for the chosen presentation.
    • The group G has solvable word problem.

In particular, this implies that solvability of the word problem is a quasi-isometry invariant for finitely presented groups.
