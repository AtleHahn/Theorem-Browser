Statement

A partial order is a reflexive, antisymmetric, transitive relation \le. Distinct elements are comparable when one is below the other. A chain has every pair comparable; an antichain has no distinct comparable pair. A partition consists of disjoint subsets whose union is the whole set. The comparability graph of a partial order has its elements as vertices and edges between distinct comparable elements. A clique is a set of pairwise adjacent vertices; a proper coloring assigns different colors at adjacent vertices. A graph is perfect if every induced subgraph has minimum color count equal to maximum clique size. An induced subgraph retains all edges between its selected vertices. The complementary graph has exactly the edges absent between distinct vertices. Every finite comparability graph is perfect.

Proof 1: Level coloring of each induced suborder — outline

A partial order is a reflexive, antisymmetric, transitive relation \le. Distinct elements are comparable when one is below the other. A chain has every pair comparable; an antichain has no distinct comparable pair. A partition consists of disjoint subsets whose union is the whole set.

For any element x, consider the chains that have x as their largest element, and let N(x) denote the size of the largest of these x-maximal chains. Then each set N^{-1}(i), consisting of elements that have equal values of N, is an antichain, and these antichains partition the partial order into a number of antichains equal to the size of the largest chain.

A comparability graph is an undirected graph formed from a partial order by creating a vertex per element of the order, and an edge connecting any two comparable elements. Thus, a clique in a comparability graph corresponds to a chain, and an independent set in a comparability graph corresponds to an antichain. Any induced subgraph of a comparability graph is itself a comparability graph, formed from the restriction of the partial order to a subset of its elements.

An undirected graph is perfect if, in every induced subgraph, the chromatic number equals the size of the largest clique. Every comparability graph is perfect: this is essentially just Mirsky's theorem, the level-partition result proved above, restated in graph-theoretic terms.

Level justification
