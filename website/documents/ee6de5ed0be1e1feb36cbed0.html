Statement

A language S\subseteq\{0,1\}^* is sparse if the number of its words of length at most n is bounded by a polynomial in n. If a sparse language is NP-hard under polynomial-time many-one reductions, then \mathrm P=\mathrm{NP}.

Proof 1: Use the one-query case of the bounded-query theorem — outline

Use the stated bounded-query theorem: if SAT is decidable in polynomial time with a constant number of queries to a sparse oracle language, then \mathrm P=\mathrm{NP}. If S is NP-hard by polynomial-time many-one reductions, a reduction maps each SAT instance x to a word r(x) with x\in\mathrm{SAT} exactly when r(x)\in S. Computing r(x) and making this one oracle query decides SAT in polynomial time. One query is a constant number, so the imported theorem gives the conclusion.
