Statement

Give the set \mathcal C of partial computable functions \mathbb N\rightharpoonup\mathbb N the topology generated by [q]=\{f\in\mathcal C:q\subseteq f\} for finite partial functions q. If P\subseteq\mathcal C has a computably enumerable index set, then P is open.

Level
Beyond undergraduate level
Level justification

The statement concerns semidecision and open sets in a space of partial functions.

none

Proof 1: Express the class as a union of finite-extension opens

Rice–Shapiro gives a finite subfunction in P for each f\in P, and upward closure puts all its partial computable extensions in P. Thus P is a union of the basic open sets determined by its finite members.

Level
Beyond undergraduate level
Level justification

Apply Rice-Shapiro to an extensional computably enumerable index class and interpret finite subfunctions as basic neighborhoods. Combining the specialized computability framework with this function-space topology is not confidently a small extension, so retain beyond undergraduate.
