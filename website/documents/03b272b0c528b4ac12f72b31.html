Statement

Let G be a finite graph with configurations declaring each edge open or closed. For vertices u,v,w,z, let A be the event of an open u–v path and B that of an open w–z path. Define A\square B using disjoint sets of edge coordinates that force the two events under arbitrary changes to other coordinates. Then A\square B is precisely the event that there are such two open paths sharing no edge.

Level
High school only
Level justification

Disjoint certificates are explicitly finite edge-coordinate sets with a forcing property; arbitrary changes quantify over finite configurations, not probability measures.

Proof 1: Interpreting edge certificates — outline

An open path certifies its connection using its own edge set, so two edge-disjoint open paths give disjoint certificates. Conversely, if I certifies a connection, close all edges outside I. The connection must still hold, hence there is an open path using only edges of I. Applying this to two disjoint certificates gives edge-disjoint paths in the original configuration.

Level
High school only
Level justification

A path supplies its own edge certificate; closing all other edges extracts a path from any certificate. School finite graph and set reasoning suffice.
