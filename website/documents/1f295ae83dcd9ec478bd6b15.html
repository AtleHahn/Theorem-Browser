Statement

Let n,m\ge1 be integers and x_{ia} (1\le i\le n, 1\le a\le m) commuting complex polynomial variables. On \mathbb C[x_{ia}] put E_{ij}=\sum_{a=1}^m x_{ia}\partial/\partial x_{ja}. Write [P,Q]=PQ-QP for the operator commutator and \delta_{ij} for the Kronecker delta. For an n\times n operator matrix A, define \det_{\rm col}(A)=\sum_{\sigma\in S_n}\operatorname{sgn}(\sigma)A_{\sigma(1),1}\cdots A_{\sigma(n),n} in the displayed column order. If m<n, then \det_{\rm col}(E+\operatorname{diag}(n-1,n-2,\ldots,0))=0.

Proof 1: The minor sum has no index sets

Let n,m\ge1 be integers and x_{ia} (1\le i\le n, 1\le a\le m) commuting complex polynomial variables. On \mathbb C[x_{ia}] put E_{ij}=\sum_{a=1}^m x_{ia}\partial/\partial x_{ja}. Write [P,Q]=PQ-QP for the operator commutator and \delta_{ij} for the Kronecker delta.

For an n\times n operator matrix A, define \det_{\rm col}(A)=\sum_{\sigma\in S_n}\operatorname{sgn}(\sigma)A_{\sigma(1),1}\cdots A_{\sigma(n),n} in the displayed column order.

Use the Capelli–Cauchy–Binet identity \det_{\rm col}(E+\operatorname{diag}(n-1,\ldots,0))=\sum_{I\subseteq\{1,\ldots,m\},\ |I|=n}\det(X_I)\det((D_I)^t), where X=(x_{ia}), D=(\partial/\partial x_{ia}) and X_I,D_I select columns in increasing order.

In particular (similar to the commutative case): if m < n, then {\displaystyle \det(E+(n-i)\delta _{ij})=0}.

Level
Within undergraduate level
Level justification

Use the explicitly displayed Capelli identity and observe that no n-element column subset exists when m<n. Undergraduate determinants and polynomial partial derivatives suffice; operator multiplication order is defined, so no Lie representation theory is required.
