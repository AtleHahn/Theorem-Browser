Statement

There exist computably enumerable sets A,B\subseteq\mathbb N that are incomparable under Turing reducibility:

A\not\leq_T B\qquad\text{and}\qquad B\not\leq_T A.

A set is computably enumerable if a Turing machine without an oracle can enumerate its elements. The relation A\leq_T B means that a Turing machine supplied with an oracle answering membership questions about B decides membership in A, halting with the correct answer on every input.

Level
Beyond undergraduate level
Level justification

The cumulative distinction between enumeration and decision, formal computation and relative oracle computation is not assumed in the undergraduate mathematics baseline; the complete reduction-theoretic assertion cannot confidently fit the short allowance.
