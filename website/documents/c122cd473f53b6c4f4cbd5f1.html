Statement

Graphs are finite undirected graphs considered up to isomorphism. A minor is obtained by a sequence of vertex deletions, edge deletions and edge contractions. Let p be a graph invariant such that \{G:p(G)\le k\} is minor-closed for each integer k. For each fixed k there exists a decision algorithm for p(G)\le k with polynomial exponent independent of k; its constant can depend on k. No uniform construction of all these algorithms is asserted.

Within undergraduate level
Level justification

The graph-minor operations are explicitly defined. A polynomial-time decision algorithm means a finite procedure with a polynomial bound in graph size; the fixed-family/fixed-parameter quantifiers are stated. This adds a small computational definition without complexity-class reductions.

Proof 1: Apply the same finite tests at each fixed parameter

We use the Robertson–Seymour finite forbidden-minor theorem and the algorithm that, for each fixed graph H, tests whether a graph has H as a minor in cubic time, with a constant factor depending on H. For every minor-closed family \mathcal F, the resulting method is to check whether the given graph contains H as a minor for each forbidden minor H in the obstruction set of \mathcal F.

For graph invariants with the property that, for each k, the graphs with invariant at most k are minor-closed, the same method applies. For any fixed k there is a polynomial time algorithm for testing whether the invariant is at most k, in which the exponent in the running time of the algorithm does not depend on k.

However, this method does not directly provide a single fixed-parameter-tractable algorithm for computing the parameter value for a given graph with unknown k, because of the difficulty of determining the set of forbidden minors.

Level
Within undergraduate level
Level justification

For each fixed parameter, choose its finite obstructions and sum the cubic fixed-minor testing times. Undergraduate algorithms suffice, including the distinction between a family of existing algorithms and a uniform construction.
