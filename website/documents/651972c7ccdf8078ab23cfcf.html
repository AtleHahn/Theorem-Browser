Statement

Let a finite disk triangulation have every vertex labelled in \{1,-1,2,-2\}. An interior edge is incident to two triangles and a boundary edge to one. If the number of boundary edges with endpoint labels 1,-2 is odd, then some triangle contains an edge whose endpoint labels are opposite numbers.

Level
High school only
Level justification

The finite mesh incidences and signed label test are explicit; oddness is elementary integer parity.

Proof 1: Pair boundary gates along the supplied walks — outline

Call an edge labelled (+1,-2) a gate. Select a boundary gate and go through it. There are three cases:

  • You are now in a (+1,-2,+2) triangle. It contains the complementary edge (-2,+2).
  • You are now in a (+1,-2,-1) triangle. It contains the complementary edge (+1,-1).
  • You are in a triangle with another (+1,-2) edge. Go through it and continue.

In the last case the third label is +1 or -2, so there is exactly one other gate. Such triangles pair their two gates. A path starting at the boundary cannot enter a cycle of paired gates, since every gate of that cycle is already paired along the cycle.

The last case can take you outside the disk. However, since the number of boundary gates is odd, if the walks so far have all left the disk, there must be a new, unvisited gate on the boundary. Go through it and continue.

The triangulation is finite, so some walk must end inside the disk, either in a (+1,-2,+2) or in a (+1,-2,-1) triangle. In either case there is a complementary edge.

Level
High school only
Level justification

Follow paired triangle gates; all boundary-to-boundary paths consume two gates, so an odd leftover path ends at a complementary edge. Finite combinatorial paths and parity suffice, with no topological degree theorem required.
