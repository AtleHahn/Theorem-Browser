Statement

Let L be a first-order language and \Sigma a set of L-sentences, with the usual nonempty-domain semantics. Then \Sigma has a model if and only if every finite subset of \Sigma has a model.

Proof 1: Use completeness and finiteness of formal proofs

One can prove the compactness theorem using Gödel's completeness theorem, which establishes that a set of sentences is satisfiable if and only if no contradiction can be proven from it. Since proofs are always finite and therefore involve only finitely many of the given sentences, the compactness theorem follows. Conversely, a model of the entire set is a model of each finite subset.

Level justification

The finite-premise observation is simple, but applying completeness requires first-order structures, semantic satisfiability, formal derivations and syntactic consistency. Retain beyond undergraduate provisionally for this cumulative logical background.

Proof 2: Build an ultraproduct over the finite subsets — outline

Fix a first-order language L, and let \Sigma be a collection of L-sentences such that every finite subcollection i\subseteq\Sigma has a model \mathcal M_i. Choose these models using the axiom of choice. Let I be the collection of finite subsets of \Sigma, and let \prod_{i\in I}\mathcal M_i be the direct product of the structures. For each i\in I, let A_i=\{j\in I:j\supseteq i\}. The family of all of these sets A_i generates a proper filter, so there is an ultrafilter U containing all sets of the form A_i.

Now for any sentence \varphi in \Sigma:

  • The set A_{\{\varphi\}} is in U.
  • Whenever j\in A_{\{\varphi\}}, then \varphi\in j, hence \varphi holds in \mathcal M_j.
  • The set of all j with the property that \varphi holds in \mathcal M_j is a superset of A_{\{\varphi\}}, hence also in U.

Łoś's theorem now implies that \varphi holds in the ultraproduct \prod_{i\in I}\mathcal M_i/U. So this ultraproduct satisfies all formulas in \Sigma. The reverse implication follows because a model of \Sigma is a model of each finite subset.
