Statement

A complex square matrix A is normal, meaning A^*A=AA^*, if and only if A=UDU^* for a unitary matrix U and a diagonal matrix D.

Level

Level justification

A bright US college student should be able to understand this statement after approximately 30 minutes of focused background research; this assesses understanding the claim, not its proof.

Proof 1: Schur reduction and the diagonal converse

One can show that A is normal if and only if it is unitarily diagonalizable using the Schur decomposition. That is, any matrix can be written as A = UTU*, where U is unitary and T is upper triangular. If A is normal, then one sees that TT* = T*T. Therefore, T must be diagonal since a normal upper triangular matrix is diagonal.

The converse is immediate: if A=UDU^* with U unitary and D diagonal, then A^*A=UD^*DU^*=UDD^*U^*=AA^*.
