Statement

Let G=(V,E) be a finite directed graph with distinct vertices s,t, capacities c_{uv}\ge0 and a flow 0\le f_{uv}\le c_{uv} whose total inflow equals total outflow at every vertex except s,t. Define its value by the net outflow |f|=\sum_{(s,v)\in E}f_{sv}-\sum_{(v,s)\in E}f_{vs}. A cut is a partition (S,V\setminus S) with s\in S,t\notin S, of capacity c(S,V\setminus S)=\sum_{u\in S,v\notin S,(u,v)\in E}c_{uv}. The residual graph has an arc u\to v whenever an original edge u\to v has f_{uv}<c_{uv}, and an arc v\to u whenever that original edge has f_{uv}>0. If t is not reachable from s in the residual graph, let S be the set of reachable vertices. Then |f|=c(S,V\setminus S); consequently f has maximum value and this cut has minimum capacity.

High school only
Level justification

Proof 1: Saturate the forward cut and empty the backward cut

In the residual graph G_f, define A=S to be the set of vertices reachable from s, and A^c=V-A. By hypothesis t\notin A.

Claim. value( f ) = c(A, Ac), where the capacity of an s-t cut is defined by

{\displaystyle c(S,T)=\sum \nolimits _{(u,v)\in E\cap(S\times T)}c_{uv}}.

Now, we know, {\displaystyle value(f)=f_{out}(A)-f_{in}(A)} for any set A containing s and not t. Therefore, for value( f ) = c(A, Ac) we need:

  • All outgoing edges from the cut must be fully saturated.
  • All incoming edges to the cut must have zero flow.

To prove the above claim we consider two cases:

  • In G, there exists an outgoing edge {\displaystyle (x,y),x\in A,y\in A^{c}} such that it is not saturated, i.e.,  f (x, y) < cxy. This implies, that there exists a forward edge from x to y in Gf, therefore there exists a path from s to y in Gf, which is a contradiction. Hence, any outgoing edge (x, y) is fully saturated.

  • In G, there exists an incoming edge {\displaystyle (y,x),x\in A,y\in A^{c}} such that it carries some non-zero flow, i.e.,  f (y, x) > 0. This implies, that there exists a backward edge from x to y in Gf, therefore there exists a path from s to y in Gf, which is again a contradiction. Hence, any incoming edge (y, x) must have zero flow.

The identity \operatorname{value}(f)=f_{\rm out}(A)-f_{\rm in}(A) follows by summing flow conservation over A\setminus\{s\}: internal edge contributions cancel. Both of the above statements prove that the capacity of the cut obtained in the above described manner is equal to the flow obtained in the network.

Since any flow in the network is always less than or equal to the capacity of every cut possible in a network, this equality proves that f is a maximum flow and that (A,A^c) is a minimum cut.
