Statement

Let A be a set, X\subseteq A, and F a family of operations on A, each with positive finite arity. Let X_+ be the smallest set containing X and closed under these operations. Suppose generation is free: no element of X is an operation value on X_+, distinct operations have disjoint images there, and each operation is injective on tuples from X_+. Let B be a nonempty set, assign to each f\in F of arity n an operation d(f):B^n\to B, and let h:X\to B. There is a unique \widehat h:X_+\to B extending h and satisfying \widehat h(f(x_1,\ldots,x_n))=d(f)(\widehat h(x_1),\ldots,\widehat h(x_n)).

Level
Within undergraduate level
Level justification

Sets, finite-arity operations and recursive generation are familiar discrete/algebraic notions. The freeness and extension identities are explicitly given, so no abstract category or universal-algebra machinery is needed to understand the uniqueness claim.

Proof 1: Compatible stagewise evaluation and uniqueness induction

Put X_{-1}=\varnothing, X_0=X, and

X_{i+1}=X_i\cup\{f(x_1,\ldots,x_n):f\in F,\ (x_1,\ldots,x_n)\in X_i^n\}.

Then X_+=\bigcup_{i\ge0}X_i. Write g=d(f) for the operation on B corresponding to f.

We must define a sequence of functions h_i:X_i\to B inductively, satisfying the extension and homomorphism identities in the statement restricted to X_i. For this, we define h_0=h, and given h_i then h_{i+1} shall have the following graph:

\begin{aligned} \operatorname{graph}(h_{i+1})={}& \{(f(x_1,\ldots,x_n),d(f)(h_i(x_1),\ldots,h_i(x_n))):\\ &\hspace{35mm}(x_1,\ldots,x_n)\in X_i^n\setminus X_{i-1}^n,\ f\in F\}\\ &{}\cup\operatorname{graph}(h_i). \end{aligned}

First we must be certain the graph actually has functionality. Since X_+ is freely generated, we have f(x_1,\ldots,x_n)\in X_{i+1}\setminus X_i when (x_1,\ldots,x_n)\in X_i^n\setminus X_{i-1}^n, so we only have to determine functionality for the first set in the union. Knowing that the operations d(f) are functions, two pairs (x,y) and (x,z) in this set can occur only if

x=f(x_1,\ldots,x_m)=f'(y_1,\ldots,y_n)

for some (x_1,\ldots,x_m)\in X_i^m\setminus X_{i-1}^m, (y_1,\ldots,y_n)\in X_i^n\setminus X_{i-1}^n and f,f'\in F.

Since f(X_+^m) and f'(X_+^n) are disjoint when f\ne f', this equality implies f=f' and m=n. Since each operation is injective on tuples from X_+, we must have x_j=y_j for 1\le j\le n. Then

y=z=g(h_i(x_1),\ldots,h_i(x_n)),\qquad g=d(f),

displaying functionality.

We use the partial-function lemma: if (f_i)_{i\ge0} is a sequence of partial functions from A to B such that f_i\subseteq f_{i+1} for all i, then the union of their graphs is the graph of a partial function. Thus \widehat h=\bigcup_{i\ge0}h_i is a partial function. Since

\operatorname{dom}(\widehat h)=\bigcup_{i\ge0}\operatorname{dom}(h_i) =\bigcup_{i\ge0}X_i=X_+,

\widehat h is total on X_+.

Furthermore, it is clear from the definition of h_i that \widehat h satisfies the two identities in the statement. To prove uniqueness, if h' is any other function satisfying these identities, it is enough to use a simple induction showing that \widehat h and h' agree on X_i for every i\ge0. This proves the unique homomorphic extension theorem.
