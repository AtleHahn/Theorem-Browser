Statement

Let R be a set-like well-founded relation on a class X: for each x, the predecessors \{y:yRx\} form a set, and every nonempty subset of X has an R-minimal element. There exists a class map F with F(x)=\{F(y):yRx\}. Its image is a transitive class, and yRx implies F(y)\in F(x). A class C is transitive if every element of any member of C is itself in C.

Level
Beyond undergraduate level
Level justification

Recursion on proper classes with set-like well-founded relations requires substantial axiomatic set-theory preparation. Proof 1: Apply well-founded recursion

A mapping F such that F(x) = {F(y) : y R x} for all x in X can be defined for any well-founded set-like relation R on X by well-founded recursion. It provides a homomorphism of R onto a transitive class.

Here homomorphism means that yRx implies F(y)\in F(x). The source leaves verification of this property and transitivity implicit.

Level
Beyond undergraduate level
Level justification

Apply recursion on a general set-like class relation and interpret its transitive class image. Proper classes, set-like recursion and Replacement are not confidently a small extension of elementary set relations.
