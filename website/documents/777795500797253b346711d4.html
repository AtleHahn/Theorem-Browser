Statement

Let R be a Euclidean domain with a function f assigning nonnegative integer sizes to nonzero elements. In a repeated division procedure a=qb+r, suppose each step either has r=0 and stops, or has f(r)<f(b). Then the procedure terminates in finitely many steps.

Level
Within undergraduate level
Level justification

Introductory ring theory supplies polynomial division, gcds, units, irreducibility and characteristic. A fraction field uses ordinary fractions over a domain; content is the gcd of coefficients. These closely related definitions suffice without advanced commutative algebra.

Proof 1: Descend through nonnegative integer sizes

The basic principle is that each nonterminal step of the algorithm reduces f inexorably; hence, if f can be reduced only a finite number of times, the algorithm must stop in a finite number of steps. This principle relies on the well-ordering property of the non-negative integers, which asserts that every non-empty set of non-negative integers has a smallest member.

Within undergraduate level
Level justification

Each nonterminal division reduces the assigned nonnegative integer size. The Euclidean-domain setting requires introductory ring theory, while the termination argument is ordinary integer descent.
