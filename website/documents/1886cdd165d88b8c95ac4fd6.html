Statement

Let \theta be a smooth one-form on a smooth (2p+1)-dimensional manifold, where p\geq0, and suppose \theta\wedge(d\theta)^p is nowhere zero. Then each point has local coordinates (x_1,\ldots,x_{p+1},y_1,\ldots,y_p) with \theta=\sum_{j=1}^p x_j\,dy_j+dx_{p+1}.

Proof 1: Specialize the nonvanishing branch to contact dimension — outline

Use the nonvanishing branch of the one-form Darboux normal-form theorem: suppose \theta is a differential 1-form on an n-dimensional manifold, such that d\theta has constant exterior rank p, meaning (d\theta)^p\ne0 and (d\theta)^{p+1}=0. If \theta\wedge(d\theta)^p\ne0 everywhere, then there is a local system of coordinates (x_1,\ldots,x_{n-p},y_1,\ldots,y_p) in which

\theta=x_1\,dy_1+\cdots+x_p\,dy_p+dx_{p+1}.

A particular case is recovered when n=2p+1; if \theta\wedge(d\theta)^p\ne0 everywhere, then \theta is a contact form.
