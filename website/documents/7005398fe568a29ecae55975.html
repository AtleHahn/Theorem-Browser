Statement

Let E have n\ge0 elements. If \mathcal S is a family of subsets of E such that no member strictly contains another, then |\mathcal S|\le\binom n{\lfloor n/2\rfloor}. This maximum is attained by the family of all \lfloor n/2\rfloor-element subsets. Equivalently, this binomial coefficient is the width of the inclusion order on the subsets of E, where width is the largest size of such an antichain.

Level
High school only
Level justification

An antichain is explicitly a family of finite subsets none strictly containing another; the bound is finite counting.

Proof 1: Compare the LYM weights with the middle level

Let {\displaystyle s_{k}} denote the number of {\displaystyle k}-sets in {\displaystyle \mathcal S}. For all {\displaystyle 0\leq k\leq n},

{\displaystyle {n \choose \lfloor {n/2}\rfloor }\geq {n \choose k}}

and, thus,

{\displaystyle {s_{k} \over {n \choose \lfloor {n/2}\rfloor }}\leq {s_{k} \over {n \choose k}}.}

Since {\displaystyle \mathcal S} is an antichain, one can sum over the above inequality from {\displaystyle k=0} to {\displaystyle n} and then apply the Lubell–Yamamoto–Meshalkin inequality to obtain

{\displaystyle \sum _{k=0}^{n}{s_{k} \over {n \choose \lfloor {n/2}\rfloor }}\leq \sum _{k=0}^{n}{s_{k} \over {n \choose k}}\leq 1,}

and multiplying both sides by the binomial coefficient in the denominator of the left hand side gives

{\displaystyle |\mathcal S|=\sum _{k=0}^{n}s_{k}\leq {n \choose \lfloor {n/2}\rfloor }.}

The family of k-element subsets of an n-element set is an antichain. No set in this family can strictly contain any of the others, because a strictly containing set has to be bigger than the set it contains, and in this family all sets have equal size. The value of k that makes this example have as many sets as possible is n/2 if n is even, or either of the nearest integers to n/2 if n is odd. For this choice, the number of sets in the family is \binom n{\lfloor n/2\rfloor}.
