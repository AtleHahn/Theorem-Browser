Statement

Let G be a finite group and \theta:G\to\mathbb C a class function. Put \langle\theta,\theta\rangle=|G|^{-1}\sum_{g\in G}|\theta(g)|^2. Then \theta is an irreducible complex character if and only if its restriction to every elementary subgroup is a virtual character, \theta(1)>0, and \langle\theta,\theta\rangle=1. Here a virtual character is an integer combination of irreducible characters, and elementary means a direct product of a cyclic group and a prime-power-order group.

Proof 1: Combine virtual-character and norm criteria

Brauer's characterization of characters asserts that a complex-valued class function of G is a virtual character if and only if its restriction to each Brauer elementary subgroup of G is a virtual character. This result, together with the fact that a virtual character \theta is an irreducible character if and only if \theta(1)>0 and \langle\theta,\theta\rangle=1 (where \langle\, ,\,\rangle is the usual inner product on the ring of complex-valued class functions), gives the stated criterion.

Level justification

The proof combines a local virtual-character criterion with the norm-one characterization of irreducibles. Class functions, irreducible and virtual characters and restrictions to elementary subgroups require substantial representation-theoretic background.
