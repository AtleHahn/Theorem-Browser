Statement

Let a finite group G permute an n-element set X. Let colors Y have nonnegative integer weights, with finitely many colors f_w of each weight w, and write f(t)=\sum_{w\ge0}f_wt^w. Colorings \phi:X\to Y have weight \sum_xw(\phi(x)). Let c_j(g) count the j-cycles of g on X and Z_G(t_1,\ldots,t_n)=|G|^{-1}\sum_g\prod_{j=1}^nt_j^{c_j(g)}. Then the generating function F(t) for coloring orbits by weight is Z_G(f(t),f(t^2),\ldots,f(t^n)). The same substitution applies to nonnegative integer-vector weights in finitely many variables: replace each color variable x_i by x_i^j in the jth slot.

Level
Within undergraduate level
Level justification

Finite group actions, cycles and orbit counting are introductory algebra/combinatorics. The weighted generating functions and cycle-index substitution are explicitly defined by coefficient counts, a direct formal-series extension.

Proof 1: Weighted Pólya enumeration — proof

The weighted version of the theorem uses a refined form of Burnside's lemma for weighted enumeration. It is equivalent to apply Burnside's lemma separately to orbits of different weight.

The sets of colorings of a fixed weight are finite, since the weights are nonnegative and there are finitely many colors of each weight.

For clearer notation, let {\displaystyle x_{1},x_{2},\ldots } be the variables of the generating function f of {\displaystyle Y}. Given a vector of weights {\displaystyle \omega }, let {\displaystyle x^{\omega }} denote the corresponding monomial term of f. Applying Burnside's lemma to orbits of weight {\displaystyle \omega }, the number of orbits of this weight is

{\displaystyle {\frac {1}{|G|}}\sum _{g\in G}\left|(Y^{X})_{\omega ,g}\right|}

where {\displaystyle (Y^{X})_{\omega ,g}} is the set of colorings of weight {\displaystyle \omega } that are also fixed by g. If we then sum over all possible weights, we obtain

{\displaystyle F(x_{1},x_{2},\ldots )={\frac {1}{|G|}}\sum _{g\in G,\omega }x^{\omega }\left|(Y^{X})_{\omega ,g}\right|.}

Meanwhile a group element g with cycle structure {\displaystyle c_{1}(g),c_{2}(g),\ldots ,c_{n}(g)} will contribute the term

{\displaystyle t_{1}^{c_{1}(g)}t_{2}^{c_{2}(g)}\cdots t_{n}^{c_{n}(g)}}

to the cycle index of G. The element g fixes an element {\displaystyle \phi \in Y^{X}} if and only if the function φ is constant on every cycle q of g. For every such cycle q, the generating function by weight of |q| identical colors from the set enumerated by f is

{\displaystyle f\left(x_{1}^{|q|},x_{2}^{|q|},x_{3}^{|q|},\ldots \right).}

It follows that the generating function by weight of the points fixed by g is the product of the above term over all cycles of g, i.e.

{\displaystyle {\begin{aligned}\sum _{\omega }x^{\omega }\left|(Y^{X})_{\omega ,g}\right|&=\prod _{q{\text{ cycle of }}g}f\left(x_{1}^{|q|},x_{2}^{|q|},x_{3}^{|q|},\ldots \right)\\&=f(x_{1},x_{2},\ldots )^{c_{1}(g)}f\left(x_{1}^{2},x_{2}^{2},\ldots \right)^{c_{2}(g)}\cdots f\left(x_{1}^{n},x_{2}^{n},\ldots \right)^{c_{n}(g)}\end{aligned}}}

Substituting this in the sum over all g yields the substituted cycle index as claimed.
