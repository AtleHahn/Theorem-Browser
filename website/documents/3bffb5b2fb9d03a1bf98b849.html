Statement

Let \Omega be an oval in a finite projective plane of order n: each line and each pencil has n+1 elements, |\Omega|=n+1, and no three points of \Omega are collinear. A tangent meets \Omega in exactly one point; a secant meets it in two. Each oval point has one tangent. If n is even, all tangents are exactly the lines through a single point N, called the nucleus.

Level
High school only
Level justification

The oval, tangents, secants and finite-plane incidence sizes are explicitly finite combinatorial conditions.

Proof 1: Count tangents using parity and a line partition

Let s be a secant, s ∩ Ω = {P0, P1} and s= {P0, P1,...,Pn}. Because |Ω| = n + 1 is odd, through any Pi, i = 2,...,n, there passes at least one tangent ti. The total number of tangents is n + 1. Hence, through any point Pi for i = 2,...,n there is exactly one tangent. If N is the point of intersection of two tangents, no secant can pass through N. Each line joining N to an oval point must therefore be a tangent, giving n+1 distinct such lines. Because n + 1, the number of tangents, is also the number of lines through any point, any line through N is a tangent.

Level
High school only
Level justification

Partition the oval by lines through a point, use odd parity to force tangents and exhaust the total tangent count. The finite incidence and oval properties are supplied, so school finite counting and parity suffice.
