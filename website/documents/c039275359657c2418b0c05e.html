Statement

An ultrafilter \mathcal U is a proper filter such that for each subset A of its index set exactly one of A and its complement belongs to \mathcal U. The ultrapower \mathbb R^{\mathbb N_{>0}}/\mathcal U identifies sequences agreeing on a set in \mathcal U, and [s]<[t] means \{i:s_i<t_i\}\in\mathcal U. Real numbers are represented by constant sequences. Assume \mathcal U contains every cofinite set. Put \omega_i=i, \psi_i=2i, and \chi_i=i except \chi_7=8. Then for every real number r, r<[\omega]=[\chi]<[\psi].

Level
Within undergraduate level
Level justification

Sequence equivalence and order are explicitly tested by ultrafilter membership. A proper filter is an upward and finite-intersection-closed family excluding the empty set; together with the supplied cofinite assumption this is a short extension of undergraduate sets, sequences and quotients. No transfer theorem or general nonstandard analysis is required.

Proof 1: Cofinite comparison sets

For every real number r, the indices i for which \omega_i=i>r form a cofinite set, which belongs to \mathcal U. Thus the sequence \omega defines an equivalence class representing a hyperreal number that is greater than any real number.

As an example of the carrying over of relations into the ultraproduct, consider the sequence \psi defined by \psi_i=2i. Because \psi_i>\omega_i=i for all positive integers i, it follows that the equivalence class of \psi_i=2i is greater than the equivalence class of \omega_i=i, so that it can be interpreted as an infinite number which is greater than the one originally constructed. However, let \chi_i=i for i not equal to 7, but \chi_7=8. The set of indices on which \omega and \chi agree is a member of \mathcal U (because they agree on the cofinite set \mathbb N_{>0}\setminus\{7\}), so \omega and \chi belong to the same equivalence class.
