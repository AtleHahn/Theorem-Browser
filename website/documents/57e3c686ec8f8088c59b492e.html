Statement

For an integer n\ge1, use deterministic Turing machines with n operational states, a separate Halt state, one starting state, a two-way unbounded tape over \{0,1\}, and a transition for each operational state and scanned symbol. Each transition writes a bit, moves one cell left or right, and enters a state (possibly Halt). The machine starts on an all-zero tape. Among machines that halt, \Sigma(n) is the largest number of ones left on the tape, and S(n) the largest number of transitions, including the halting transition. Let T be an arithmetically sound computably axiomatized theory extending Peano arithmetic, with its ordinary arithmetic formalization of machines and proofs. There exists n_T such that, for every n\ge n_T and every integer k, T does not prove S(n)=k.

Proof 1: Proof search and second incompleteness — outline

Given the theory T, a Turing machine with n_T states can be designed to enumerate every possible proof in T. If the theory is inconsistent, then all false statements are provable, and the Turing machine can be given the condition to halt if, and only if, it finds a proof of, for example, 0=1. If T proved a value of S(n_T), the finite running-time bound, together with verification of the machine’s finite nonhalting computation up to that bound, would prove that it never halts. This proves the consistency of T, contrary to Gödel’s second incompleteness theorem. For larger n, the same proof-search machine may be regarded as an n-state machine by adding unused states, giving the same contradiction.
