Statement

A doubly stochastic n\times n real matrix has nonnegative entries and every row and column sums to 1. A permutation matrix has entries 0,1 with exactly one 1 in each row and column. For every integer n\ge1 and doubly stochastic X=(x_{ij}), there is a permutation matrix P=(p_{ij}) such that p_{ij}=1 implies x_{ij}>0.

Level
High school only
Level justification

Both matrix types are explicitly finite arrays with specified entries and row/column counts. Selecting positive positions requires finite counting and sums, not vector-space theory.

Proof 1: Hall matching from row and column sums

Construct a bipartite graph in which the rows of X are listed in one part and the columns in the other, and in which row i is connected to column j iff xij ≠ 0. Let {\displaystyle A} be any set of rows, and define {\displaystyle A'} as the set of columns joined to rows in A in the graph. We want to express the sizes {\displaystyle |A|} and {\displaystyle |A'|} of the two sets in terms of the xij.

For every i in A, the sum over j in A' of xij is 1, since all columns j for which xij ≠ 0 are included in A', and X is doubly stochastic; hence {\displaystyle |A|} is the sum over all i ∈ A, j ∈ A' of xij.

Meanwhile {\displaystyle |A'|} is the sum over all i (whether or not in A) and all j in A' of xij ; and this is ≥ the corresponding sum in which the i are limited to rows in A. Hence {\displaystyle |A'|\geq |A|}.

It follows that the conditions of Hall's marriage theorem are satisfied, and that we can therefore find a set of edges in the graph which join each row in X to exactly one (distinct) column. These edges define a permutation matrix whose non-zero cells correspond to non-zero cells in X.

Level justification

Treat the matrix as a nonnegative array, compare row and column sums, and apply the supplied finite matching criterion to select one positive entry per row and column. No vector-space or spectral concepts are needed.
