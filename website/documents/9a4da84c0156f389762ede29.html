Statement

Let X_1,\ldots,X_n be independent variables taking values 0,1, with \Pr(X_i=1)=p_i, n\ge1. Put X=\sum_iX_i and \mu=\sum_ip_i. For \delta>0,

\Pr(X\ge(1+\delta)\mu)\le\left(\frac{e^\delta}{(1+\delta)^{1+\delta}}\right)^\mu.

For 0<\delta<1,

\Pr(X\le(1-\delta)\mu)\le\left(\frac{e^{-\delta}}{(1-\delta)^{1-\delta}}\right)^\mu.

Proof 1: Bernoulli moments and logarithmic parameter choices — outline

Let X_1,\ldots,X_n be independent Bernoulli random variables, whose sum is X, each having probability p_i of being equal to 1. For a Bernoulli variable:

\operatorname E[e^{tX_i}] =(1-p_i)e^0+p_ie^t =1+p_i(e^t-1)\leq e^{p_i(e^t-1)}.

The exponential Markov bound and independence give

\Pr(X\geq a)\leq\inf_{t>0}e^{-ta}\prod_{i=1}^n\operatorname E[e^{tX_i}].

So, using this with a=(1+\delta)\mu for any \delta>0 and where \mu=\operatorname E[X]=\sum_{i=1}^n p_i,

\begin{aligned} \Pr(X\geq(1+\delta)\mu) &\leq\inf_{t>0}\exp(-t(1+\delta)\mu)\prod_{i=1}^n\operatorname E[\exp(tX_i)]\\ &\leq\inf_{t>0}\exp\left(-t(1+\delta)\mu+\sum_{i=1}^n p_i(e^t-1)\right)\\ &=\inf_{t>0}\exp\left(-t(1+\delta)\mu+(e^t-1)\mu\right). \end{aligned}

If we simply set t=\log(1+\delta) so that t>0 for \delta>0, we can substitute and find

\exp\left(-t(1+\delta)\mu+(e^t-1)\mu\right) =\frac{\exp((1+\delta-1)\mu)}{(1+\delta)^{(1+\delta)\mu}} =\left[\frac{e^\delta}{(1+\delta)^{1+\delta}}\right]^\mu.

This proves the upper-tail result.

A similar proof strategy, using the negative-parameter exponential Markov bound

\Pr(X\leq a)\leq\inf_{t<0}e^{-ta}\prod_{i=1}^n\operatorname E[e^{tX_i}],

can be used to show that for 0<\delta<1,

\Pr(X\leq(1-\delta)\mu)\leq \left(\frac{e^{-\delta}}{(1-\delta)^{1-\delta}}\right)^\mu.
