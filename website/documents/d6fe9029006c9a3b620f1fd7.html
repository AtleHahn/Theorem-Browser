Statement

Let n\ge4 be even. The set of all unordered pairs from an n-element vertex set can be partitioned into n-1 classes, each class consisting of n/2 disjoint pairs covering every vertex once. Equivalently, the complete graph K_n has an edge coloring with n-1 colors in which each color class is a perfect matching.

Level
High school only
Level justification

A complete graph is explicitly the set of unordered pairs, and a perfect matching partitions the vertices into pairs; the conclusion is finite combinatorics.

Proof 1: Specialize to two-element hyperedges

Baranyai theorem (dependency)

If integers 2\le r<k satisfy r\mid k, all r-element subsets of a k-element set can be partitioned into classes, each of which partitions the vertex set into r-element subsets.

Pair specialization

In the special case {\displaystyle r=2}, we have a complete graph {\displaystyle K_{n}} on {\displaystyle n} vertices, and we wish to color the edges with {\displaystyle {\binom {n}{2}}{\frac {2}{n}}=n-1} colors so that the edges of each color form a perfect matching. Baranyai's theorem says that we can do this whenever {\displaystyle n} is even.

Level
High school only
Level justification

Use the supplied partition theorem with r=2 and k=n. Its hypotheses hold because n is even and at least four. Each class contains n/2 disjoint pairs, and dividing the total n(n-1)/2 pairs by n/2 gives n-1 classes. The proof needs only finite sets, divisibility and counting, not a proof of Baranyai’s theorem.
