Statement

On \mathbb R/\mathbb Z with normalized Lebesgue measure, rotation T(x)=x+p/q is not ergodic when p,q are coprime integers and q\ge1. Here ergodic means that every measurable set invariant modulo null sets has measure zero or one.

Level
Within undergraduate level
Level justification

The circle quotient is basic topology; Lebesgue measurable sets, null-set equality and the supplied ergodicity definition add a limited related measure interpretation. No ergodic limit theorem is required.

Proof 1: Form the finite orbit of a short interval

Write \theta=p/q in lowest terms, so T(x)=x+\theta. Then T is periodic, with period q, and thus cannot be ergodic: for any interval I of length a, 0 < a < 1/q, its orbit under T (that is, the union of I, T(I), ..., Tq−1(I), which contains the image of I under any number of applications of T) is a T-invariant mod 0 set that is a union of q intervals of length a, hence it has measure qa strictly between 0 and 1.

Level
Within undergraduate level
Level justification

The interval witness is elementary, but the complete ergodicity definition also quantifies over all measurable sets invariant modulo null sets. These linked measure definitions extend undergraduate topology; the finite union of q disjoint short intervals then has invariant measure qa strictly between zero and one.
