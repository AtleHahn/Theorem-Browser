Statement

For positive integers L,D,n, a configuration with benefits consists of points a+\sum_{j=1}^D i_js_j with positive integer strides s_j: the interior has all 0\le i_j<L, and its kth face has i_1=\cdots=i_k=L and the remaining indices in \{0,\ldots,L-1\}, for 1\le k\le D. Each interior/face must be individually monochromatic; different faces may have different colors. Write M(L,D,n) for the least interval size forcing such a configuration in every n-coloring, when it exists. If M=M(L,D,n) and Q=M(L,1,n^M) are finite, then M(L,D+1,n)\le MQ.

Level
High school only
Level justification

The configuration, faces and forcing thresholds are explicitly finite integer-indexed coloring definitions.

Proof 1: Block patterns add one dimension

In this proof M(L,D,n) denotes the threshold in the statement, and the unparenthesized M is its fixed value M(L,D,n).

First, if you have an n-coloring of the interval 1...I, you can define a block coloring of k-size blocks. Just consider each sequence of k colors in each k block to define a unique color. Call this k-blocking an n-coloring. k-blocking an n coloring of length l produces an nk coloring of length l/k.

So given a n-coloring of an interval I of size {\displaystyle M\cdot \operatorname {M} (L,1,n^{M})} you can M-block it into an nM coloring of length {\displaystyle \operatorname {M} (L,1,n^{M})}. But that means, by the definition of M, that you can find a 1-dimensional arithmetic sequence (with benefits) of length L in the block coloring, which is a sequence of blocks equally spaced, whose first L blocks are all the same block-color, i.e. you have a bunch of blocks of length M in the original sequence, which are equally spaced, which have exactly the same sequence of colors inside.

The additional endpoint block may have a different pattern.

Now, by the definition of M, you can find a D-dimensional arithmetic sequence with benefits in any one of the first L matching blocks, and since all of these L blocks have the same sequence of colors, the same D-dimensional AP with benefits appears in all of the blocks, just by translating it from block to block. This is the definition of a D + 1 dimensional arithmetic progression, so you have a homogeneous D + 1 dimensional AP. The new stride parameter sD + 1 is defined to be the distance between the blocks.

But you need benefits. The boundaries you get now are all old boundaries, plus their translations into identically colored blocks, because iD+1 is always less than L. The extra endpoint block supplies the final corner. The only boundary which is not like this is the 0-dimensional point when {\displaystyle i_{1}=i_{2}=\cdots =i_{D+1}=L}. This is a single point, and is automatically homogeneous.
