Statement

Let E\subseteq\mathbb R. For a continuous 2\pi-periodic function f:\mathbb R\to\mathbb C, put \widehat f(n)=(2\pi)^{-1}\int_0^{2\pi}f(t)e^{-int}\,dt and S_Nf(x)=\sum_{|n|\le N}\widehat f(n)e^{inx}. There exists such an f for which S_Nf(x) fails to converge at every x\in E if and only if E has Lebesgue measure zero. Divergence at additional points is allowed.

Level
Within undergraduate level
Level justification

Complex differentiability and the explicitly defined Fourier sums extend calculus directly. For the Fourier assertions, null sets can be understood through arbitrarily small interval covers, and residual sets through countable intersections of dense open sets. These limited additions to real analysis and topology suffice without general measure integration.

Proof 1: Combine Katznelson’s construction theorem with Carleson — outline

Katznelson (1966) showed that for any set of measure zero there is a continuous periodic function whose Fourier series diverges at all points of the set (and possibly elsewhere). When combined with Carleson's theorem this shows that there is a continuous periodic function whose Fourier series diverges at all points of a given set of reals if and only if the set has measure zero.

Here Carleson's theorem says that the Fourier series of an L^2 periodic function converges almost everywhere. A continuous periodic function is square-integrable on a period, so any set on which its Fourier series diverges everywhere has measure zero.
