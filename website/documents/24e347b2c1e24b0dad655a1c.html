Assume the axiom of choice and Zorn’s lemma. An arbitrary product X=\prod_i X_i of compact topological spaces is compact in the product topology; the factors need not be Hausdorff.

Proof 1: Maximal finite-intersection family

Stated dependency

Zorn’s lemma: a partially ordered set in which every chain (including the empty chain) has an upper bound has a maximal element. A chain is a totally ordered subset; an element m is maximal if m\leq y implies m=y.

Argument

If the product is empty, it is compact. Assume it is nonempty.

Let {\displaystyle X_{i}} be a family of compact spaces, not necessarily Hausdorff. We shall show that a family {\displaystyle F} of closed subsets of {\displaystyle X:=\prod _{i}X_{i}} with the finite intersection property has nonempty intersection. Let {\displaystyle P} be the collection of all the families of subsets of {\displaystyle X} with the finite intersection property (not necessarily closed subsets). We let {\displaystyle P} be ordered by set inclusion. If {\displaystyle C\subset P} is a chain, then clearly the union of {\displaystyle C} has the finite intersection property; so, the union is in {\displaystyle P}. Thus, by Zorn's lemma, there is a maximal element {\displaystyle M} in {\displaystyle P} containing {\displaystyle F}. We shall show that the intersection of all the closed sets in {\displaystyle M} has nonempty intersection; a fortiori, {\displaystyle F} has nonempty intersection.

For each finite subset {\displaystyle M'\subset M}, since {\displaystyle \cap M'} is nonempty, {\displaystyle \bigcap_{A\in M'}p_i(A)} is nonempty for the projection {\displaystyle p_{i}:X\to X_{i}.} Thus, for each {\displaystyle i}, the set

{\displaystyle N_{i}:=\left\{{\overline {p_{i}(A)}}\mid A\in M\right\}}

has nonempty intersection since it has the finite intersection property and {\displaystyle X_{i}} is compact. We note

  1. If {\displaystyle M'\subset M} is a finite subset, {\displaystyle \cap M'} is in {\displaystyle M}.
  2. For an open set {\displaystyle U_{i}} intersecting {\displaystyle \cap N_{i}}, we have {\displaystyle p_{i}^{-1}(U_{i})} is in {\displaystyle M}.

Indeed, (1) holds since {\displaystyle M=M\cup \{\cap M'\}} by maximality, as the set on the right has the finite intersection property. Similarly, for a finite subset {\displaystyle M'\subset M}, since {\displaystyle A=\cap M'} is in {\displaystyle M}, {\displaystyle U_{i}\cap p_{i}(A)\neq \emptyset } or {\displaystyle p_{i}^{-1}(U_{i})\cap A\neq \emptyset }. Thus, the set {\displaystyle M\cup \{p_{i}^{-1}(U_{i})\}} has the finite intersection property and (2) follows by the maximality of {\displaystyle M}.

Now, by the axiom of choice, we can find an element {\displaystyle m} in {\displaystyle \prod _{i}(\cap N_{i})}. We claim this {\displaystyle m} is in each closed set {\displaystyle A} in {\displaystyle M}. Since {\displaystyle A} is closed, it is enough to show {\displaystyle m} is in the closure of {\displaystyle A}; i.e., each basic neighborhood of {\displaystyle m} intersects {\displaystyle A}. A basic neighborhood of {\displaystyle m} has the form {\displaystyle \cap _{j=1}^{r}p_{i_{j}}^{-1}(U_{i_{j}})}. But by the property (2) above, we have {\displaystyle \left\{A,p_{i_{j}}^{-1}(U_{i_{j}})\mid j=1,\dots ,r\right\}\subset M}, which gives the claim by the finite intersection property. {\displaystyle \square }

Proof 2: Maximal partial cluster point using nets

This proof, due to P. Chernoff, is based on the following characterization of compactness in terms of nets:

  • A space is compact if and only if each net on it has a cluster point.

If the product is empty, it is compact. A cluster point of a net is a point each of whose neighborhoods meets every tail of the net.

Given a family of compact spaces {\displaystyle X_{a}} indexed by a set {\displaystyle A}, to show

{\displaystyle \prod _{a\in A}X_{a}}

is compact, we can therefore show each net {\displaystyle \langle x_{\alpha }\mid \alpha \in I\rangle } on it has a cluster point.

We shall identify the product {\displaystyle \prod _{a\in A}X_{a}} as the set of all maps {\displaystyle f:A\to \cup _{a\in A}X_{a}} such that {\displaystyle f(a)\in X_{a}}; in fact, this is the usual definition of a set-theoretic product. Then finding a required cluster point amounts to constructing such a map with the required property. For that, consider the set

{\displaystyle E:=\{f:B\to Y\mid B\subset A,f(b)\in X_{b},\,f\,{\text{ a cluster point of }}\,{x_{\alpha}}|_{B}\}}

where {\displaystyle Y=\cup _{a\in A}X_{a}}. We give this set the ordering by restriction; i.e., {\displaystyle f\leq g} if and only if {\displaystyle f} is the restriction of {\displaystyle g}.

The empty function belongs to E and bounds the empty chain. We now claim the hypothesis of Zorn's lemma is satisfied. For that, let {\displaystyle f_{i}:B_{i}\to Y} be a chain in the above {\displaystyle E} and define {\displaystyle f:B\to Y} by {\displaystyle B=\cup _{i}B_{i}} and {\displaystyle f|_{B_{i}}=f_{i}}. To show {\displaystyle f} is a cluster point of {\displaystyle {x_{\alpha}}|_{B}}, let {\displaystyle U} be a basic neighborhood of {\displaystyle f} in {\displaystyle \prod _{a\in B}X_{a}.} By definition, it can be written as {\displaystyle U=\prod _{c\in C}U_{c}\times \prod _{b\in B-C}X_{b}} for some finite subset {\displaystyle C\subset B} and open subsets {\displaystyle U_{c}\subset X_{c}}. Now, since {\displaystyle C} is finite, {\displaystyle C\subset B_{i}} for large enough {\displaystyle i}. And since {\displaystyle f|_{B_{i}}} is a cluster point of the net {\displaystyle x_{\alpha }|_{B_{i}}}, for each {\displaystyle \alpha \in I}, we can find a {\displaystyle \beta \geq \alpha } such that {\displaystyle x_{\beta }|_{B_{i}}\in \prod _{c\in C}U_{c}\times \prod _{b\in B_{i}-C}X_{b}} and thus {\displaystyle x_{\beta }|_{B}\in U} as required.

Hence, by Zorn's lemma, we can find a maximal element {\displaystyle f:B\to Y} in {\displaystyle E}. We shall show {\displaystyle B=A}. Suppose otherwise; then there is an element {\displaystyle a\in A-B}. Now, {\displaystyle f|_{B}} is a cluster point of {\displaystyle \langle x_{\alpha }|_{B}\mid \alpha \in I\rangle } and so we can find a subnet {\displaystyle x':J\to I{\overset {x}{\to }}\prod X_{a}} of the net {\displaystyle x} such that {\displaystyle x'_{\alpha }|_{B}} converges to {\displaystyle f|_{B}}. Since {\displaystyle X_{a}} is compact, {\displaystyle x'_{\alpha }|_{\{a\}}} has a cluster point, and so similarly we can find a subnet {\displaystyle x''} of {\displaystyle x'} that converges on {\displaystyle \{a\}}, to some point of {\displaystyle X_{a}}. Thus, we can extend {\displaystyle f} to {\displaystyle g} that is a limit of {\displaystyle x''|_{B\cup \{a\}}}, a contradiction to the maximality of {\displaystyle f}. {\displaystyle \square }
