Statement

Suppose each independent run of an algorithm returns a specified correct answer with probability p>1/2. Let 0<\delta<1 and choose an integer

n\ge\frac{2p\log(1/\delta)}{(p-1/2)^2}.

Return the answer appearing in more than half of these n runs, when there is such an answer. The probability that the correct answer occurs in a strict majority, and hence is returned, is at least 1-\delta.

Level
High school only
Level justification

The statement is a finite counting/probability guarantee with an explicit numerical threshold.

Proof 1: Apply the lower-tail estimate to correct-run indicators

Run the algorithm n times, with the integer n chosen as in the statement, and output a guess that is output by more than n/2 runs of the algorithm. (There cannot be more than one such guess.) Assuming that these algorithm runs are independent, the probability that more than n/2 of the guesses are correct is equal to the probability that the sum X of independent Bernoulli random variables X_k that are 1 with probability p is more than n/2. This can be shown to be at least 1-\delta via the multiplicative Chernoff bound, with \mu=np:

\Pr\left[X>\frac n2\right]\ge1-e^{-n(p-1/2)^2/(2p)}\ge1-\delta.

The bound used here is \Pr(X\le(1-\alpha)\mu)\le e^{-\alpha^2\mu/2} for 0<\alpha<1, with \alpha=1-1/(2p). Its non-strict lower-tail event includes ties among the possible failures.

Level justification

Encode successful runs by independent Bernoulli indicators, substitute the explicit tail parameter and solve the exponential bound. Undergraduate elementary probability suffices; no proof of concentration theory is required.
