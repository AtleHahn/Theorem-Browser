Statement

For a positive integer n, define T_n:[0,1]\to[0,1] by T_n(x)=\{nx\} for x<1 and T_n(1)=1, where braces denote fractional part. Then T_m\circ T_n=T_{mn} for positive integers m,n.

Level
High school only
Level justification

Fractional-part functions and linear-graph computations use high-school algebra.

Proof 1: Remove the integer part before the second multiplication

The proof of this lemma is not difficult, but we need to be slightly careful with the endpoint x = 1. For this point the lemma is clearly true, since

{\displaystyle T_{m}(T_{n}(1))=T_{m}(1)=1=T_{mn}(1).}

So let us assume that 0 ≤ x < 1. In this case,

{\displaystyle T_{n}(x)=\{nx\}<1,}

so Tm(Tn(x)) is given by

{\displaystyle T_{m}(T_{n}(x))=\{m\{nx\}\}.}

Therefore, what we really need to show is that

{\displaystyle \{m\{nx\}\}=\{mnx\}.}

To do this we observe that {nx} = nx − k, where k is the integer part of nx; then

{\displaystyle \{m\{nx\}\}=\{mnx-mk\}=\{mnx\},}

since mk is an integer.

Level
High school only
Level justification

Separate the specially defined endpoint and remove an integer multiple from the fractional part for x below one. This is elementary arithmetic and function composition.
