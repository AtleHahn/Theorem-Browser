Statement

For a finite set of variables, join two variables by an edge exactly when they must be stored at the same time. A proper coloring of this interference graph with k colors gives a fixed assignment to k registers in which every simultaneously needed set of variables occupies distinct registers.

Level
High school only
Level justification

The finite objects and coloring constraints are defined locally; only elementary counting and algebra are needed.

Proof 1: Register assignment from an interference-graph coloring

Use the source interference graph and assign each variable to the register corresponding to its vertex color. Any two variables needed simultaneously are adjacent and therefore receive different registers.

Level
High school only
Level justification

Use each vertex color as its register number; simultaneously needed pairs are adjacent and hence differently colored. Elementary finite graph definitions suffice.
