Statement

Let H be a real or complex Hilbert space, with inner product \langle x,y\rangle linear in x. Write [y,x]=\langle x,y\rangle, so brackets are linear in their second argument. For every continuous linear functional \varphi:H\to\mathbb F there is a unique f_\varphi\in H such that \varphi(x)=[f_\varphi,x] for all x. Moreover \|f_\varphi\|=\|\varphi\|, where the functional norm is \sup_{\|x\|\le1}|\varphi(x)|. Here \mathbb F is the real or complex scalar field of H.

Level
Within undergraduate level
Level justification

Linear algebra supplies inner products, kernels, orthogonality and scalar-valued linear maps. Hilbert completeness and the functional norm as a unit-ball supremum are direct analysis extensions. A Riesz vector is explicitly a vector representing the functional by inner product, so no dual topology or spectral theory is needed.

Proof 1: Orthogonal kernel decomposition and the representing-vector formula

Use the source’s bra–ket notation \langle y\mid x\rangle=[y,x]=\langle x,y\rangle, linear in x.

Let {\displaystyle \mathbb {F} } denote the underlying scalar field of {\displaystyle H.}

Proof of norm formula:

Fix {\displaystyle y\in H.} Define {\displaystyle \Lambda :H\to \mathbb {F} } by {\displaystyle \Lambda (z):=\langle \,y\,|\,z\,\rangle ,} which is a linear functional on {\displaystyle H} since {\displaystyle z} is in the linear argument. By the Cauchy–Schwarz inequality,

{\displaystyle |\Lambda (z)|=|\langle \,y\,|\,z\,\rangle |\leq \|y\|\|z\|}

which shows that {\displaystyle \Lambda } is bounded (equivalently, continuous) and that {\displaystyle \|\Lambda \|\leq \|y\|.} It remains to show that {\displaystyle \|y\|\leq \|\Lambda \|.} By using {\displaystyle y} in place of {\displaystyle z,} it follows that

{\displaystyle \|y\|^{2}=\langle \,y\,|\,y\,\rangle =\Lambda (y)=|\Lambda (y)|\leq \|\Lambda \|\|y\|}

(the equality {\displaystyle \Lambda (y)=|\Lambda (y)|} holds because {\displaystyle \Lambda (y)=\|y\|^{2}\geq 0} is real and non-negative). Thus that {\displaystyle \|\Lambda \|=\|y\|.} {\displaystyle \blacksquare }

The proof above did not use the fact that {\displaystyle H} is complete, which shows that the formula for the norm {\displaystyle \|\langle \,y\,|\,\cdot \,\rangle \|_{H^{*}}=\|y\|_{H}} holds more generally for all inner product spaces.

Proof that a Riesz representation of {\displaystyle \varphi } is unique:

Suppose {\displaystyle f,g\in H} are such that {\displaystyle \varphi (z)=\langle \,f\,|\,z\,\rangle } and {\displaystyle \varphi (z)=\langle \,g\,|\,z\,\rangle } for all {\displaystyle z\in H.} Then

{\displaystyle \langle \,f-g\,|\,z\,\rangle =\langle \,f\,|\,z\,\rangle -\langle \,g\,|\,z\,\rangle =\varphi (z)-\varphi (z)=0\quad {\text{ for all }}z\in H}

which shows that {\displaystyle \Lambda :=\langle \,f-g\,|\,\cdot \,\rangle } is the constant {\displaystyle 0} linear functional. Consequently {\displaystyle 0=\|\langle \,f-g\,|\,\cdot \,\rangle \|=\|f-g\|,} which implies that {\displaystyle f-g=0.} {\displaystyle \blacksquare }

Proof that a vector {\displaystyle f_{\varphi }} representing {\displaystyle \varphi } exists:

Let {\displaystyle K:=\ker \varphi :=\{m\in H:\varphi (m)=0\}.} If {\displaystyle K=H} (or equivalently, if {\displaystyle \varphi =0}) then taking {\displaystyle f_{\varphi }:=0} completes the proof so assume that {\displaystyle K\neq H} and {\displaystyle \varphi \neq 0.} The continuity of {\displaystyle \varphi } implies that {\displaystyle K} is a closed subspace of {\displaystyle H} (because {\displaystyle K=\varphi ^{-1}(\{0\})} and {\displaystyle \{0\}} is a closed subset of {\displaystyle \mathbb {F} }). Let

{\displaystyle K^{\bot }:=\{v\in H~:~\langle \,v\,|\,k\,\rangle =0~{\text{ for all }}k\in K\}}

denote the orthogonal complement of {\displaystyle K} in {\displaystyle H.} Because {\displaystyle K} is closed and {\displaystyle H} is a Hilbert space, {\displaystyle H} can be written as the direct sum {\displaystyle H=K\oplus K^{\bot }} (by the Hilbert projection theorem). Because {\displaystyle K\neq H,} there exists some non-zero {\displaystyle p\in K^{\bot }.} For any {\displaystyle h\in H,}

{\displaystyle \varphi [(\varphi h)p-(\varphi p)h]~=~\varphi [(\varphi h)p]-\varphi [(\varphi p)h]~=~(\varphi h)\varphi p-(\varphi p)\varphi h=0,}

which shows that {\displaystyle (\varphi h)p-(\varphi p)h~\in ~\ker \varphi =K,} where now {\displaystyle p\in K^{\bot }} implies

{\displaystyle 0=\langle \,p\,|\,(\varphi h)p-(\varphi p)h\,\rangle ~=~\langle \,p\,|\,(\varphi h)p\,\rangle -\langle \,p\,|\,(\varphi p)h\,\rangle ~=~(\varphi h)\langle \,p\,|\,p\,\rangle -(\varphi p)\langle \,p\,|\,h\,\rangle .}

Solving for {\displaystyle \varphi h} shows that

{\displaystyle \varphi h={\frac {(\varphi p)\langle \,p\,|\,h\,\rangle }{\|p\|^{2}}}=\left\langle \,{\frac {\overline {\varphi p}}{\|p\|^{2}}}p\,{\Bigg |}\,h\,\right\rangle \quad {\text{ for every }}h\in H,}

which proves that the vector {\displaystyle f_{\varphi }:={\frac {\overline {\varphi p}}{\|p\|^{2}}}p} satisfies {\displaystyle \varphi h=\langle \,f_{\varphi }\,|\,h\,\rangle {\text{ for every }}h\in H.}

Applying the norm formula that was proved above with {\displaystyle y:=f_{\varphi }} shows that {\displaystyle \|\varphi \|_{H^{*}}=\left\|\left\langle \,f_{\varphi }\,|\,\cdot \,\right\rangle \right\|_{H^{*}}=\left\|f_{\varphi }\right\|_{H}.} Also, the vector {\displaystyle u:={\frac {p}{\|p\|}}} has norm {\displaystyle \|u\|=1} and satisfies {\displaystyle f_{\varphi }:={\overline {\varphi (u)}}u.} {\displaystyle \blacksquare }
