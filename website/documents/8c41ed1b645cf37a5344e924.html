Statement

Write S^j=\{x\in\mathbb R^{j+1}:\|x\|_2=1\} and call a map odd if g(-x)=-g(x). For each integer n\ge1, the following three assertions are equivalent:

  1. Every continuous f:S^n\to\mathbb R^n has f(x)=f(-x) for some x.
  2. Every continuous odd g:S^n\to\mathbb R^n has a zero.
  3. There is no continuous odd map S^n\to S^{n-1}.

Proof 1: Odd differences, inclusion and radial projection

Here is a proof that assertion 1, the Borsuk–Ulam theorem, is equivalent to assertion 2:

(1\Longrightarrow2) If the theorem is correct, then it is specifically correct for odd functions, and for an odd function, g(-x)=g(x) iff g(x)=0. Hence every odd continuous function has a zero.

(1\Longleftarrow2) For every continuous function f:S^n\to\mathbb R^n, the following function is continuous and odd: g(x)=f(x)-f(-x). If every odd continuous function has a zero, then g has a zero, and therefore, f(x)=f(-x).

To prove that assertions 2 and 3 are equivalent, we use the following continuous odd maps:

  • the obvious inclusion i:S^{n-1}\to\mathbb R^n\setminus\{0\},
  • and the radial projection map p:\mathbb R^n\setminus\{0\}\to S^{n-1} given by x\mapsto x/\|x\|_2.

The proof now writes itself.

(2\Longrightarrow3) We prove the contrapositive. If there exists a continuous odd function f:S^n\to S^{n-1}, then i\circ f is a continuous odd function S^n\to\mathbb R^n\setminus\{0\}.

(2\Longleftarrow3) Again we prove the contrapositive. If there exists a continuous odd function f:S^n\to\mathbb R^n\setminus\{0\}, then p\circ f is a continuous odd function S^n\to S^{n-1}.
