Statement

For every three integers k,r,m\geq1 there is an integer N\geq1 with the following property. Let \mathrm{FIN}_k(N) be all functions f:\{1,\ldots,N\}\to\{0,1,\ldots,k\} attaining the value k. For any coloring c:\mathrm{FIN}_k(N)\to\{1,\ldots,r\} there are f_1,\ldots,f_m\in\mathrm{FIN}_k(N) with

\max\operatorname{supp}(f_i)<\min\operatorname{supp}(f_{i+1})\qquad(1\leq i<m)

such that all pointwise sums

F_1\circ f_{i_1}+\cdots+F_s\circ f_{i_s}

have the same color, for every 1\leq s\leq m, 1\leq i_1<\cdots<i_s\leq m, and all nondecreasing surjections F_j:\mathbb N_0\to\mathbb N_0 satisfying \max_jF_j(k)=k.

Here \mathbb N_0=\{0,1,2,\ldots\} and \operatorname{supp}(f)=\{a:f(a)\ne0\}. Nondecreasing means order-preserving, and surjective means taking every nonnegative integer value. Such maps send zero to zero and satisfy F_j(k)\leq k. The disjoint supports and the maximum condition ensure that every displayed sum is in the colored set \mathrm{FIN}_k(N).
