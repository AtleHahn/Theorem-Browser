Statement

Relational algebra and domain-independent relational calculus have exactly the same expressive power: a query on relational databases is expressible in relational algebra if and only if it is expressible by a domain-independent relational-calculus query. Equivalence means that the two expressions return the same relation for every database instance.

Here a relational database stores relations as sets of tuples, with named attributes (columns). Relational algebra forms queries by composing operations on relations, including union, difference, Cartesian product, projection onto specified attributes, selection of tuples satisfying a condition, and renaming attributes. Relational calculus describes the returned tuples by logical formulas with variables and quantifiers, in first-order logic. A calculus query is domain-independent when changing the ambient domain of values beyond those occurring in the database does not change its result. The theorem uses set semantics and ordinary two-valued logic; SQL multisets and SQL nulls are not part of this statement.

Level justification

Finite relations and the listed operations are elementary set constructions. First-order queries and invariance under enlarging the data domain are modest linked definitions for an undergraduate with basic logic; understanding the statement does not require database implementation theory or the proof.
