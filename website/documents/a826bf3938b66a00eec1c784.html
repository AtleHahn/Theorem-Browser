Statement

Let M,N be smooth manifolds without boundary, and let f:M\to N be a smooth surjective map. Suppose f is a submersion, so that df_p:T_pM\to T_{f(p)}N is surjective for every p\in M, and is proper, so that f^{-1}(K) is compact for every compact set K\subseteq N.

Then f is a locally trivial smooth fibration: for every y\in N, there are an open neighborhood U of y and a diffeomorphism

\Phi:f^{-1}(U)\longrightarrow U\times f^{-1}(y)

such that \operatorname{pr}_1\circ\Phi=f|_{f^{-1}(U)}, where \operatorname{pr}_1 is projection onto U.
