Statement

For a finite simple graph G on an even number n of labeled vertices, deciding whether a perfect matching exists reduces to formal zero testing of a polynomial determinant. A perfect matching meets each vertex in exactly one selected edge.

Level
Within undergraduate level
Level justification

Understanding the statement involves Finite graphs; Perfect matchings; Polynomial determinants; Identity testing. These prerequisites fit undergraduate coursework or a brief extension of it. A bright US college student should be able to understand this statement after approximately 30 minutes of focused background research; this assesses understanding the claim, not its proof.

Proof 1: Construct the Tutte matrix and test its determinant

Give each edge \{i,j\} with i<j a distinct indeterminate x_{ij}.

Create a Tutte matrix A in the following way:

{\displaystyle A={\begin{bmatrix}a_{11}&a_{12}&\cdots &a_{1{\mathit {n}}}\\a_{21}&a_{22}&\cdots &a_{2{\mathit {n}}}\\\vdots &\vdots &\ddots &\vdots \\a_{{\mathit {n}}1}&a_{{\mathit {n}}2}&\ldots &a_{\mathit {nn}}\end{bmatrix}}}

where

{\displaystyle a_{ij}={\begin{cases}x_{ij}\;\;{\mbox{if}}\;(i,j)\in E{\mbox{ and }}i<j\\-x_{ji}\;\;{\mbox{if}}\;(i,j)\in E{\mbox{ and }}i>j\\0\;\;\;\;{\mbox{otherwise}}.\end{cases}}}

Use Tutte’s theorem that the symbolic determinant is nonzero if and only if a perfect matching exists. The Tutte matrix determinant (in the variables xij, ⁠{\displaystyle i<j}⁠ ) is then defined as the determinant of this skew-symmetric matrix which is non-zero (as polynomial) if and only if a perfect matching exists. One can then use polynomial identity testing to find whether G contains a perfect matching.

Build the explicit skew polynomial matrix and invoke the stated determinant criterion. Undergraduate determinants, polynomial identities and finite graphs suffice; no proof of the matching theorem or identity-testing algorithm is needed.
