Statement

Let a_n\ge0 and b_n>0 for integers n\ge1. If a_n/b_n\to c with 0<c<\infty, then \sum_{n=1}^\infty a_n converges if and only if \sum_{n=1}^\infty b_n converges.

Level
Within undergraduate level
Level justification

Understanding the statement involves nonnegative infinite series; sequence limits; convergence. These prerequisites fit undergraduate coursework or a brief extension of it. A bright US college student should be able to understand this statement after approximately 30 minutes of focused background research; this assesses understanding the claim, not its proof.

Proof 1: Limit comparison test — comparison argument

Because {\displaystyle \lim _{n\to \infty }{\frac {a_{n}}{b_{n}}}=c} we know that for every {\displaystyle \varepsilon >0} there is a positive integer {\displaystyle n_{0}} such that for all {\displaystyle n\geq n_{0}} we have that {\displaystyle \left|{\frac {a_{n}}{b_{n}}}-c\right|<\varepsilon }, or equivalently

{\displaystyle -\varepsilon <{\frac {a_{n}}{b_{n}}}-c<\varepsilon }{\displaystyle c-\varepsilon <{\frac {a_{n}}{b_{n}}}<c+\varepsilon }{\displaystyle (c-\varepsilon )b_{n}<a_{n}<(c+\varepsilon )b_{n}}

As {\displaystyle c>0} we can choose {\displaystyle \varepsilon } to be sufficiently small such that {\displaystyle c-\varepsilon } is positive. So {\displaystyle b_{n}<{\frac {1}{c-\varepsilon }}a_{n}} and by the direct comparison test, if {\displaystyle \sum _{n}a_{n}} converges then so does {\displaystyle \sum _{n}b_{n}}.

Similarly {\displaystyle a_{n}<(c+\varepsilon )b_{n}}, so if {\displaystyle \sum _{n}a_{n}} diverges, again by the direct comparison test, so does {\displaystyle \sum _{n}b_{n}}.

That is, both series converge or both series diverge.

Finite initial segments do not affect convergence.
