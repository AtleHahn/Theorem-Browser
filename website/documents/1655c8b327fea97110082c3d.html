Statement

Consider integer radix \beta\ge2, integer precision p\ge1 and allowed integer exponents e_{\min}\le e\le e_{\max}. Include zero and numbers \pm s\beta^{e-p+1} for integers 0<s\le\beta^p-1, allowing subnormal significands at the minimum exponent. If represented finite numbers x,y satisfy y/2\le x\le2y, then x-y is representable; consequently correctly rounded subtraction is exact.

Level
High school only
Level justification

The allowed floating-point numbers and subnormal convention are explicitly integer-significand and radix-power formulas. Correct rounding of a representable result needs no numerical-analysis theory.

Proof 1: Bound the aligned integer significand

Let {\displaystyle \beta } be the radix of the floating-point system and {\displaystyle p} the precision.

Consider several easy cases first:

  • If {\displaystyle x} is zero then {\displaystyle x-y=-y}, and if {\displaystyle y} is zero then {\displaystyle x-y=x}, so the result is trivial because floating-point negation is always exact.

  • If {\displaystyle x=y} the result is zero and thus exact.

  • If {\displaystyle x\leq y}, we can write {\displaystyle x-y=-(y-x)} with {\displaystyle x/2\leq y\leq 2x}, so the result follows from the theorem restricted to {\displaystyle x\geq y}.

For the rest of the proof, assume {\displaystyle 0<y<x\leq 2y} without loss of generality.

Write {\displaystyle x,y>0} in terms of their positive integral significands {\displaystyle s_{x},s_{y}\leq \beta ^{p}-1} and minimal exponents {\displaystyle e_{x},e_{y}}:

{\displaystyle {\begin{aligned}x&=s_{x}\cdot \beta ^{e_{x}-p+1}\\y&=s_{y}\cdot \beta ^{e_{y}-p+1}\end{aligned}}}

Note that {\displaystyle x} and {\displaystyle y} may be subnormal—we do not assume {\displaystyle s_{x},s_{y}\geq \beta ^{p-1}}.

The subtraction gives:

{\displaystyle {\begin{aligned}x-y&=s_{x}\cdot \beta ^{e_{x}-p+1}-s_{y}\cdot \beta ^{e_{y}-p+1}\\&=s_{x}\beta ^{e_{x}-e_{y}}\cdot \beta ^{e_{y}-p+1}-s_{y}\cdot \beta ^{e_{y}-p+1}\\&=(s_{x}\beta ^{e_{x}-e_{y}}-s_{y})\cdot \beta ^{e_{y}-p+1}.\end{aligned}}}

Let {\displaystyle s'=s_{x}\beta ^{e_{x}-e_{y}}-s_{y}}. Since {\displaystyle 0<y<x} we have:

  • {\displaystyle e_{y}\leq e_{x}}, so {\displaystyle e_{x}-e_{y}\geq 0}, from which we can conclude {\displaystyle \beta ^{e_{x}-e_{y}}} is an integer and therefore so is {\displaystyle s'=s_{x}\beta ^{e_{x}-e_{y}}-s_{y}}; and
  • {\displaystyle x-y>0}, so {\displaystyle s'>0}.

Further, since {\displaystyle x\leq 2y}, we have {\displaystyle x-y\leq y}, so that

{\displaystyle s'\cdot \beta ^{e_{y}-p+1}=x-y\leq y=s_{y}\cdot \beta ^{e_{y}-p+1}}

which implies that

{\displaystyle 0<s'\leq s_{y}\leq \beta ^{p}-1.}

Hence

{\displaystyle x-y=s'\cdot \beta ^{e_{y}-p+1},\quad {\text{for}}\quad 0<s'\leq \beta ^{p}-1,}

so {\displaystyle x-y} is a floating-point number. ∎
