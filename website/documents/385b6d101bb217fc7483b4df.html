Statement

Let d\ge2 be an integer. A density matrix is a positive semidefinite Hermitian d\times d matrix of trace one. For its eigenvalues \lambda_i, define S(\rho)=-\sum_i\lambda_i\log\lambda_i, using natural logarithms and 0\log0=0. Put T(\rho,\sigma)=\tfrac12\operatorname{Tr}\sqrt{(\rho-\sigma)^*(\rho-\sigma)}. For fixed d, the function S is continuous in trace distance: if T(\rho_j,\rho)\to0, then S(\rho_j)\to S(\rho).

Proof 1: Use the small-distance Fannes bound — outline

Use Fannes’ estimate |S(\rho)-S(\sigma)|\le2T\log d-2T\log(2T),\qquad T\le\frac1{2e}, to obtain continuity of the entropy.
