Statement

Let T>0, let A:\mathbb R\to\mathbb R^{n\times n} satisfy A(t+T)=A(t), and let \phi:\mathbb R\to GL_n(\mathbb C) be a differentiable fundamental matrix for x'=A(t)x: thus \phi'(t)=A(t)\phi(t) and \phi(t) is invertible for every t. Put M=\phi(0)^{-1}\phi(T), the monodromy matrix. Then, for every real t,

\phi(t+T)=\phi(t)M.

For every complex matrix B satisfying e^{TB}=M, there is an invertible T-periodic matrix function P with

\phi(t)=P(t)e^{tB}.

If \phi is real-valued, there exists a real matrix R with

e^{2TR}=M^2=\phi(0)^{-1}\phi(2T),

and for each such R there is a real invertible 2T-periodic matrix function Q such that \phi(t)=Q(t)e^{tR} for all real t. Here GL_n(\mathbb C) denotes invertible complex n\times n matrices and e^C=\sum_{k=0}^{\infty}C^k/k! is the matrix exponential.

Level justification

Linear systems and matrix exponentials connect directly to undergraduate differential equations and linear algebra. Fundamental matrix is explicitly defined as an invertible solution matrix, a small extension of those familiar concepts.
