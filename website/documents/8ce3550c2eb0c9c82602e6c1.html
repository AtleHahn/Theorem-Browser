Statement

Let \mathbf A be a graph of groups on a connected graph A with vertex set V and oriented edge set E. Edge reversal e\mapsto\bar e is a fixed-point-free involution, o(e) and t(e)=o(\bar e) are the endpoints, and E^+ chooses one orientation of each geometric edge. Each vertex has a group A_v, each edge has a group A_e=A_{\bar e}, and there are injective boundary maps \alpha_e:A_e\to A_{o(e)}, \omega_e=\alpha_{\bar e}:A_e\to A_{t(e)}. Choose a spanning tree T. Write F(S) for the free group on a set S and \langle\!\langle R\rangle\!\rangle for the normal subgroup generated by relators R. Define G=\pi_1(\mathbf A,T) as the quotient of (\ast_{v\in V}A_v)\ast F(E) by \bar e\alpha_e(c)e=\omega_e(c), e\bar e=1 for all e\in E,c\in A_e, and e=1 for edges of T. For every v\in V, the canonical homomorphism A_v\to G is injective.

Proof 1: Source presentation calculation

Use the normal-forms theorem for a graph of groups. For an expression a_0e_1a_1\cdots e_na_n following a closed edge path, with each a_i in the corresponding vertex group, the theorem states in particular that when n=0 and this expression equals 1 in G, the element a_0 is 1 in its vertex group.

The normal-forms theorem therefore immediately implies that the canonical homomorphisms A_v\to\pi_1(\mathbf A,T) are injective, so the vertex groups can be regarded as subgroups of G.
