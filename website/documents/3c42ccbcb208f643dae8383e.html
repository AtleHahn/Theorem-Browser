Statement

An isotopy between loops consists of bijections α,β,γ satisfying α(x)·β(y)=γ(xy), where · is the target multiplication. If Q is Moufang, every loop isotope Q′ of Q is Moufang.

Level
Within undergraduate level
Level justification

Introductory algebra supplies binary operations, identity, inverses and generated substructures. A loop removes associativity while retaining unique division; the Moufang identities are explicit equations. Isotopy/translation, where used, is defined by specified bijections. These direct variations of group axioms suffice for understanding the full claim.

Proof 1: Compose isotopies and apply the universal characterization

Moufang loops are universal among inverse-property loops; that is, a loop Q is a Moufang loop if and only if every loop isotope of Q has the inverse property. Here the inverse property means that each element x has a two-sided inverse satisfying x^{-1}(xy)=y=(yx)x^{-1} for all y. It follows that every loop isotope of a Moufang loop is a Moufang loop.
