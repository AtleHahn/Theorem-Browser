Statement

If some propositional proof system is polynomially bounded—every tautology has a proof of length bounded by a polynomial in the formula length—then \mathrm{NP}=\mathrm{coNP}. Here a proof system has a polynomial-time verifier accepting a formula with some proof exactly when the formula is a tautology.

Level
Within undergraduate level
Level justification

The proof system is defined as a polynomial-time verifier. NP as polynomial certificates, coNP as complements and completeness as polynomial instance translation add closely related operational definitions, sufficient for this application.

Proof 1: Use polynomial-size proofs as certificates — outline

The set of propositional tautologies, \mathrm{TAUT}, is a coNP-complete set. A propositional proof system is a certificate-verifier for membership in \mathrm{TAUT}. Existence of a polynomially bounded propositional proof system means that there is a verifier with polynomial-size certificates, i.e., \mathrm{TAUT} is in NP. By coNP-completeness and the standard closure consequence that a coNP-complete language in NP implies \mathrm{NP}=\mathrm{coNP}, the result follows.

The completeness and closure consequence are used without proof, as in the source.
