Finite-set homogeneity of a countable dense order

Statement

A strict linear order is an irreflexive transitive relation < such that distinct elements are comparable. It is dense if x<y implies x<z<y for some z, and has no endpoints if every element has both a smaller and a larger element. An order isomorphism is a bijection preserving and reflecting <. Let L be a nonempty countable dense linear order without endpoints and k\ge0 an integer. For any two k-element subsets A,B\subseteq L, there is an order automorphism h:L\to L with h(A)=B.

Level
Within undergraduate level
Level justification

Partial orders, chains, antichains and countability are undergraduate set/order concepts. A chain means pairwise comparable and an antichain pairwise incomparable; selection principles, where assumed, are explicit hypotheses. These short definitions suffice for the quantified existence or partition claim.

Proof 1: Start back-and-forth with a prescribed finite matching — outline

Local back-and-forth recipe

The back-and-forth construction builds up an isomorphism between any two given orders, using a greedy algorithm, in an ordering given by a countable enumeration of the two orderings. In more detail, the proof maintains two order-isomorphic finite subsets {\displaystyle A} and {\displaystyle B} of the two given orders, initially the prescribed finite subsets A,B matched by their unique increasing bijection. It repeatedly increases the sizes of {\displaystyle A} and {\displaystyle B} by adding a new element from one order, the first missing element in its enumeration, and matching it with an order-equivalent element of the other order, proven to exist using the density and lack of endpoints of the order. The two orderings switch roles at each step: the proof finds the first missing element of the first order, adds it to {\displaystyle A}, matches it with an element of the second order, and adds it to {\displaystyle B}; then it finds the first missing element of the second order, adds it to {\displaystyle B}, matches it with an element of the first order, and adds it to {\displaystyle A}, etc. Every element of each ordering is eventually matched with an order-equivalent element of the other ordering, so the two orderings are isomorphic.

Level
Within undergraduate level
Level justification

Start with the increasing finite matching and alternately include the first missing element of each enumeration. Density and absence of endpoints permit each finite-gap insertion; the union is a total order-preserving bijection. Countable constructions and elementary order theory are a small extension of undergraduate sets and induction.
