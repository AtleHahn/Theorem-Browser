Proof 1: Count subsets and compare powers of two

For finite sets, Cantor's theorem can be seen to be true by simple enumeration of the number of subsets. Counting the empty set as a subset, a set with {\displaystyle n} elements has a total of {\displaystyle 2^{n}} subsets, and the theorem holds because {\displaystyle 2^{n}>n} for all non-negative integers.
