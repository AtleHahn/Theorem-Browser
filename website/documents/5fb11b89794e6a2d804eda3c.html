Statement

The function f(x)=e^{ix} on [0,2\pi] is differentiable but has no c\in(0,2\pi) with f(2\pi)-f(0)=2\pi f'(c).

Proof 1: Compare the zero chord with the nonzero exponential derivative

The real-valued mean value theorem is false if a differentiable function is complex-valued instead of real-valued. For example, if f(x)=e^{xi} for all real x, then

f(2\pi)-f(0)=0=0(2\pi-0)

while f'(x)\ne0 for any real x.

Level
Within undergraduate level
Level justification

The endpoint difference is zero while the real-parameter derivative i exp(ix) is always nonzero. This is ordinary calculus applied componentwise to sine and cosine.
