Statement

In this result all game trees are finite. Games here are impartial two-player games of perfect information under normal play: the player with no move loses, and there are no infinite plays. A position is represented by its set of options. In the disjunctive sum G+H, a move changes exactly one component. A \mathcal P-position has a winning strategy for the previous player (the second player to move from it), and a \mathcal N-position for the next player. Write G\approx G' when G+H and G'+H have the same outcome for every such impartial game H. Here *m is a single heap of m objects, with options *0,\ldots,*(m-1); *0 has no options. Suppose a nonnegative-integer function g on finite impartial game positions satisfies g(*m)=m, g(X)=0 exactly for \mathcal P-positions, and g(X+Y)=g(X)\oplus g(Y), where \oplus denotes bitwise exclusive-or. Then for every finite G,H, G+H and *g(G)+H have the same outcome.

Level
High school only
Level justification

Finite game trees, options, disjunctive sum, outcome classes, Nim heaps and xor are all specified. The universal test-game quantifier ranges over these finite combinatorial objects; the statement assumes the three value laws rather than constructing a general game theory.

Proof 1: Compare the two nim-sums

Put m=g(G). The assumed laws give g(G+H)=m\oplus g(H)=g(*m+H). Equal Grundy values give the same outcome because precisely value zero corresponds to a \mathcal P-position. Thus these sums have the same outcome for every finite test game H.

Level justification

Use the three explicitly assumed laws to give the two finite sums equal integer values and hence the same zero-or-nonzero outcome. Elementary finite games and binary integers suffice.
