Statement

For positive integers n, let c_n>0 satisfy n e^{-c_n^2/2}/(\sqrt{2\pi}\,c_n)=1. Then c_n\sim\sqrt{2\log n} and \log c_n\sim\tfrac12\log\log n as n\to\infty.

Proof 1: Leading growth of the normal extreme-value centering — outline

The centering is defined by n e^{-c_n^2/2}/(\sqrt{2\pi}\,c_n)=1. For these values one obtains \log c_n\approx\tfrac12\log\log n, and consequently c_n\approx\sqrt{2\log n}, giving the displayed leading orders.
