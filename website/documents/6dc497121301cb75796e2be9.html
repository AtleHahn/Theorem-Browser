Statement

In first-order semantics allowing an assignment to free variables, P(x)\to P(c) is not valid and \{P(x),\neg P(c)\} is satisfiable. Substitution x:=c can therefore turn a satisfiable free-variable input set into a literal clash.

Level
Within undergraduate level
Level justification

The distinction between free assignments and universally bound tableau variables requires elementary first-order semantics, a short extension of undergraduate logic and functions; no advanced model theory is used.

Proof 1: Evaluate a two-element structure

Take domain \{1,2\}, interpret c as 1, let P(1) be false and P(2) true, and assign x=2. The implication has true antecedent and false consequent, and both formulas of the set hold. But replacing the free input variable by c gives P(c),\neg P(c). This demonstrates why free input variables must be distinguished from the globally universally bound variables introduced by the tableau rule.
