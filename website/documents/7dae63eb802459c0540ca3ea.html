Statement

Let N=k2^n+1 with positive odd k<2^n and n\ge1. Testing all integers a=2,\ldots,N-1 for a^{(N-1)/2}\equiv-1\pmod N decides primality: some test succeeds exactly when N is prime.

Proof 1: Enumerate all candidate bases

A success implies primality by Proth’s theorem. If N is prime, Euler’s criterion and the nonresidue count guarantee a successful nonzero residue. The residues 0,1 cannot succeed, and all congruence classes are represented by 0,\ldots,N-1, so the listed tests include a successful one. Thus failure of all of them proves compositeness.
