Statement

Let \mathbf a_j, a_j, \mathbf b_j, \mathbf r(x)=\sum_jx_j\mathbf a_j/a_j, and \mathbf Q(m)=\sum_jm_j\mathbf b_j be as in the explicit equations a_j=|\mathbf a_j|>0, \mathbf a_i\cdot\mathbf b_j=2\pi\delta_{ij} for a real basis \mathbf a_1,\mathbf a_2,\mathbf a_3. Suppose a function g(x)=f(\mathbf r(x)) has the expansion g(x)=\sum_{m\in\mathbb Z^3}c(m)e^{2\pi i\sum_jm_jx_j/a_j}. Then the same expansion, with the same summation convention, is f(\mathbf r)=\sum_{\mathbf Q}c(\mathbf Q)e^{i\mathbf Q\cdot\mathbf r}, where c(\mathbf Q(m))=c(m) and the sum runs over the reciprocal lattice.

Proof 1: Replace each coordinate phase and reindex — outline

We would now like to abandon the auxiliary coordinates {\displaystyle x_{1,2,3}} and to return to the original position vector {\displaystyle \mathbf {r} }. This can be achieved by means of the reciprocal lattice whose vectors {\displaystyle \mathbf {b} _{1,2,3}} are dual (up to a factor {\displaystyle 2\pi }) to the original Bravais vectors {\displaystyle \mathbf {a} _{1,2,3}},

{\displaystyle \mathbf {a} _{i}\cdot \mathbf {b_{j}} =2\pi \delta _{ij},}

with {\displaystyle \delta _{ij}} the Kronecker delta. With this, the scalar product between a reciprocal lattice vector {\displaystyle \mathbf {Q} } and an arbitrary position vector {\displaystyle \mathbf {r} } written in the Bravais lattice basis becomes

{\displaystyle \mathbf {Q} \cdot \mathbf {r} =\left(m_{1}\mathbf {b} _{1}+m_{2}\mathbf {b} _{2}+m_{3}\mathbf {b} _{3}\right)\cdot \left(x_{1}{\frac {\mathbf {a} _{1}}{a_{1}}}+x_{2}{\frac {\mathbf {a} _{2}}{a_{2}}}+x_{3}{\frac {\mathbf {a} _{3}}{a_{3}}}\right)=2\pi \left(x_{1}{\frac {m_{1}}{a_{1}}}+x_{2}{\frac {m_{2}}{a_{2}}}+x_{3}{\frac {m_{3}}{a_{3}}}\right),}

which is exactly the expression occurring in the Fourier exponents. The Fourier series for {\displaystyle f(\mathbf {r} )=g(x_{1},x_{2},x_{3})} can therefore be rewritten as a sum over all the reciprocal lattice vectors {\displaystyle \mathbf {Q} =m_{1}\mathbf {b} _{1}+m_{2}\mathbf {b} _{2}+m_{3}\mathbf {b} _{3}},

{\displaystyle f(\mathbf {r} )=\sum _{\mathbf {Q} }c(\mathbf {Q} )\,e^{i\mathbf {Q} \cdot \mathbf {r} },}

Here c(\mathbf Q(m))=c(m), and the given summation convention is retained.

Level justification

Expand the dot product using the dual-basis relations, obtaining exactly the old phase. The map from integer triples to reciprocal-lattice vectors is bijective, so the same summation convention merely acquires new labels. Undergraduate linear algebra and series notation suffice; no convergence theorem for Fourier series is asserted.
