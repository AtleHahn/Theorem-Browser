Statement

Let X be a real or complex Hausdorff locally convex topological vector space. For K\subseteq X, write \operatorname{ext}(K) for points of K that do not lie strictly between two distinct points of K, and \overline{\operatorname{co}}(A) for the smallest closed convex set containing A. Every nonempty compact convex subset K of X has an extreme point.

Level
Beyond undergraduate level
Level justification

The statements involve topological vector spaces and infinite-dimensional convexity, beyond undergraduate calculus and linear algebra.

Proof 1: Exclude an empty set of extreme points

By the compact convex Krein–Milman identity, K=\overline{\operatorname{co}}(\operatorname{ext}(K)). If there were no extreme points, the right side would be the closed convex hull of the empty set, hence empty. This contradicts K\ne\varnothing.

Level
Beyond undergraduate level
Level justification

Exclude an empty set of extreme points using the closed-hull identity. The implication is elementary but the actual setting is general locally convex topological vector spaces, beyond the agreed small-extension allowance.
