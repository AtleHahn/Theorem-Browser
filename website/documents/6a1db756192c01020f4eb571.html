Statement

Let P be a poset equipped with a choice function c:\mathcal P(P)\setminus\{\varnothing\}\to P on its nonempty subsets. Assume every chain has an upper bound. Then P has a maximal element if and only if every inflationary function f:P\to P (one satisfying x\leq f(x)) has a fixed point.

Level
Within undergraduate level
Level justification

Sets and partial orders supply chains, upper bounds and maximality. Well-order means every nonempty subset has a least member, and choice/Zorn is a stated principle. The explicit equivalences and fixed-point conditions require no ordinal arithmetic or forcing theory.

Proof 1: Choose a strict successor away from maximal elements

Indeed, if P has a maximal element, a maximal element is a fixed point. Conversely, assuming that every inflationary map has a fixed point, define the function {\displaystyle f:P\to P} by {\displaystyle f(x)=x} if {\displaystyle x} is maximal and {\displaystyle f(x)=c(x^{*})} otherwise, where {\displaystyle x^{*}=\{y\mid y>x\}} is the strict upper set of {\displaystyle x}. A fixed point of this {\displaystyle f} is exactly a maximal element. {\displaystyle \square }
