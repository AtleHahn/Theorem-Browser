Statement

Let f:X\to Y be a function and L,R arbitrary sets. For any set A, use f(A)=\{f(x):x\in A\cap X\} , f^{-1}(B)=\{x\in X:f(x)\in B\}, and F_y=f^{-1}(\{y\})=\{x\in X:f(x)=y\}. Put Q=\{y\in f(L):L\cap F_y\subseteq R\}. Then f(L\setminus R)=f(L)\setminus f(R)\quad\Longleftrightarrow\quad f(L)\cap f(R)=Q\quad\Longleftrightarrow\quad f(L)\cap f(R)\subseteq Q.

Level
High school only
Level justification

All images, preimages, fibers and the set Q are explicitly defined. The criterion requires elementary membership, subsets and complements, even for arbitrary ambient sets.

Proof 1: Cancel relative complements of the excluded fiber values

Let {\displaystyle Q:=\left\{y\in f(L):L\cap F_y\subseteq R\right\}} where because {\displaystyle Q\subseteq f(R\cap L),} {\displaystyle Q} is also equal to {\displaystyle Q=\left\{y\in f(R\cap L):L\cap F_y\subseteq R\right\}.} By the image-difference fiber identity, {\displaystyle f(L\setminus R)=f(L)\setminus Q} so that {\displaystyle f(L)\setminus f(R)=f(L\setminus R)} if and only if {\displaystyle f(L)\setminus f(R)=f(L)\setminus Q.} Since {\displaystyle f(L)\setminus f(R)=f(L)\setminus (f(L)\cap f(R)),} this happens if and only if {\displaystyle f(L)\setminus (f(L)\cap f(R))=f(L)\setminus Q.} Because {\displaystyle f(L)\cap f(R){\text{ and }}Q} are both subsets of {\displaystyle f(L),} the condition on the right hand side happens if and only if {\displaystyle f(L)\cap f(R)=Q.} Because {\displaystyle Q\subseteq f(R\cap L)\subseteq f(L)\cap f(R),} the equality {\displaystyle f(L)\cap f(R)=Q} holds if and only if {\displaystyle f(L)\cap f(R)\subseteq Q.}
