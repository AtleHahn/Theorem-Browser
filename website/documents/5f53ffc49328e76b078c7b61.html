Statement

Let \Gamma be a fixed finite set of relations on \{0,1\}, each of finite positive arity. An instance of \operatorname{CSP}(\Gamma) is a finite conjunction of constraints R(x_{i_1},\ldots,x_{i_k}), with R\in\Gamma and Boolean variables (repetitions are allowed). The problem asks whether an assignment of 0 or 1 to the variables satisfies every constraint.

An operation f:\{0,1\}^m\to\{0,1\} preserves a relation R\subseteq\{0,1\}^k if applying f coordinatewise to any m tuples in R produces another tuple in R.

If at least one of the following six operations preserves every relation in \Gamma, then \operatorname{CSP}(\Gamma) is decidable in polynomial time:

  • the unary constant operation x\mapsto0;
  • the unary constant operation x\mapsto1;
  • binary AND, (x,y)\mapsto x\wedge y;
  • binary OR, (x,y)\mapsto x\vee y;
  • ternary majority, (x,y,z)\mapsto(x\wedge y)\vee(x\wedge z)\vee(y\wedge z);
  • ternary parity, (x,y,z)\mapsto x\oplus y\oplus z, where \oplus is addition modulo 2.

If none of these six operations preserves every relation, then \operatorname{CSP}(\Gamma) is NP-complete under polynomial-time many-one reductions. Here NP is the class of decision problems whose yes instances have certificates checkable in polynomial time; NP-complete means belonging to NP and receiving such a reduction from every problem in NP. Polynomial time is measured in the input formula length, with \Gamma fixed.
