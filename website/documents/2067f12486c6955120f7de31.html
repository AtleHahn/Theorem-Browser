Statement

A partial order is a reflexive, antisymmetric and transitive relation \le. A chain has all pairs comparable; an antichain has no distinct comparable pair. For positive integers r,s, a partial order on rs+1 elements has a chain of size r+1 or an antichain of size s+1.

Level
High school only
Level justification

The partial-order axioms, chains and antichains are supplied locally. The assertion compares finite set sizes with the integer product rs, so it requires elementary order reasoning and counting.

Proof 1: Count antichain parts after applying Mirsky

If no chain has size r+1, the height is at most r. By Mirsky's theorem the set is a union of at most r antichains. If each had at most s elements there would be at most rs elements in all, a contradiction. Thus some antichain has at least s+1 elements.

Level justification

All order notions are defined and the proof applies the explicitly stated finite partition theorem followed by counting at most r times s elements. No proof of Mirsky theorem is needed.
