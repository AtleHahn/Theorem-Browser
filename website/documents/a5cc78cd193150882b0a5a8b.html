Some computable problems have no asymptotically best program: every implementation can be improved by an arbitrarily prescribed computable speedup. This separates computability from the existence of an optimal method and limits the ideal of a final, most efficient algorithm.

Statement

Fix a Blum complexity measure (\varphi,\Phi): \varphi_i is the partial function computed by program i in a fixed standard effective programming system, and \Phi_i:\mathbb N\rightharpoonup\mathbb N is its cost function. The Blum axioms require \operatorname{dom}\Phi_i=\operatorname{dom}\varphi_i and that the relation \Phi_i(x)\leq c be decidable uniformly in i,x,c, with the relation false when \Phi_i(x) is undefined.

For every total computable function f:\mathbb N^2\to\mathbb N, there exists a total computable predicate g:\mathbb N\to\{0,1\} such that, for every program i computing g, there is a program j computing g for which

f(x,\Phi_j(x))\leq\Phi_i(x)

for all but finitely many x\in\mathbb N.

Level
Beyond undergraduate level
Level justification

The complete theorem quantifies over abstract program numberings and arbitrary axiomatic complexity measures, not only familiar running times. Formal computability, uniform decidability and the nested quantifiers form a cumulative specialty burden beyond the conservative undergraduate allowance.
