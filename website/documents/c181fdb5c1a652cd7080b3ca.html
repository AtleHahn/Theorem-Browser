Statement

A finite planar graph on n vertices has a tree decomposition of width O(\sqrt n). A tree decomposition assigns a vertex bag to each node of a tree, contains each graph vertex, contains both ends of each edge in a common bag, and has connected bag occurrences for each vertex; its width is the largest bag size minus one.

Proof 1: Square-root bound for planar treewidth (outline)

Separators may be combined into a separator hierarchy of a planar graph, a recursive decomposition into smaller graphs. Use the planar separator theorem to remove at most C\sqrt m vertices from each m-vertex subgraph, leaving two sets A,B of size at most 2m/3 with no edges between them. A separator hierarchy may be represented by a binary tree in which the root node represents the given graph itself, and the two children of the root are the roots of recursively constructed separator hierarchies for the induced subgraphs formed from A and B. At terminal parts, put the remaining vertices into the terminal separator.

A separator hierarchy of this type forms the basis for a tree decomposition of the given graph, in which the set of vertices associated with each tree node is the union of the separators on the path from that node to the root of the tree. Each edge either stays in a recursive part or meets an ancestor separator, so its endpoints occur together in a bag. Once a vertex enters a separator it persists through all descendant bags, giving connected occurrences.

Since the sizes of the graphs go down by a constant factor at each level of the tree, the upper bounds on the sizes of the separators also go down by a constant factor at each level, so their sizes on these paths add in a geometric series to O(\sqrt n):

C\sqrt n\sum_{j\geq0}(2/3)^{j/2}=O(\sqrt n),

up to the constant-size terminal contribution. Thus the tree decomposition formed in this way has width O(\sqrt n).
