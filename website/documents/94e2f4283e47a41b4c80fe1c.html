Proof 1: Combine the Frey–Ribet obstruction with semistable modularity

Every exponent n>2 has a divisor p equal to 4 or an odd prime; writing n=pq, a positive solution produces (a^q)^p+(b^q)^p=(c^q)^p. The cases p=3 and p=4 are the classical Fermat cases, used here as external results.

For a remaining prime p\ge5, we start by assuming, for the sake of contradiction, that there is a positive integer solution (a,b,c) to

a^p+b^p=c^p.

Ribet's theorem, using Frey and Serre's work, shows that using the solution we can create a semistable elliptic curve E over \mathbb Q which is not modular.

Wiles proved the modularity theorem for semistable elliptic curves: all semistable elliptic curves over \mathbb Q are modular. We have our proof by contradiction, because we have shown that if Fermat's Last Theorem is incorrect, we could construct a semistable elliptic curve that cannot be modular (Ribet's theorem) and must be modular (Wiles). As it cannot be both, no such curve exists, and Fermat's Last Theorem must be correct.
