Statement

Let a\le b be real and let \delta:[a,b]\to(0,\infty) be any function. A tagged partition of [a,s] consists of finitely many endpoints and tags a=x_0\le t_1\le x_1\le\cdots\le t_n\le x_n=s; it is \delta-fine if each [x_{j-1},x_j] is contained in (t_j-\delta(t_j),t_j+\delta(t_j)). Put S=\{r\in[a,b]:\text{some }\delta\text{-fine partition of }[a,s]\text{ exists with }s\ge r\}. Then S is open relative to [a,b]. More precisely, any such partition with last tag t_n gives [a,b]\cap[a,t_n+\delta(t_n))\subseteq S.

Proof 1: Extend the final interval inside its tag neighborhood — outline

The set S is downward closed. Given a fine partition ending at x_n with last tag t_n, the last endpoint can be extended within the same open tag interval. Hence the relatively open ray [a,b]\cap[a,t_n+\delta(t_n)) lies in S and contains each point witnessed by that partition. These rays show that S is relatively open.
