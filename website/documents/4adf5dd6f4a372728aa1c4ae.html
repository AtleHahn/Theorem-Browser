Statement

A literal is a propositional variable or its negation. A negation-normal formula uses only conjunctions and disjunctions of literals. Start a finite tree at a finite set X of such formulas. At a leaf replace \Gamma\cup\{A\land B\} by \Gamma\cup\{A,B\}, or branch \Gamma\cup\{A\lor B\} into \Gamma\cup\{A\} and \Gamma\cup\{B\}. Close a leaf containing opposite literals. Every exhaustive expansion terminates. Its tree is closed exactly when X has no satisfying truth assignment; each remaining open leaf supplies one.

Proof 1: Preserve leaf truth assignments and decrease the connective count

The formulas in a set are considered to be in conjunction. The rules of expansion work on the leaves of the tableau, ignoring all internal nodes. For conjunction, the rule is based on the equivalence of a set containing a conjunction A\land B with the set containing both A and B in place of it. In particular, a leaf labeled with \Gamma\cup\{A\land B\} is replaced by one with label \Gamma\cup\{A,B\}.

For disjunction, a set \Gamma\cup\{A\lor B\} is equivalent to the disjunction of the two sets \Gamma\cup\{A\} and \Gamma\cup\{B\}. As a result, if the first set labels a leaf, two children can be appended to it, labeled with the latter two sets.

Finally, if a set contains both a literal and its negation, this branch can be closed. The tableau represents the disjunction of the conjunctions at its leaves. The procedure modifies the tableau in such a way that the formula represented by the resulting tableau is equivalent to the original one. If all these conjunctions are proved unsatisfiable, the original set of formulas is unsatisfiable.

The breakdown process terminates after a finite number of steps, because each application of a rule eliminates a connective along each resulting branch, and there are only finitely many connectives in the initial set. Here the processed formula is removed: the total connective count in a leaf set strictly decreases. The finite initial count bounds branch depth, and branching is at most two.

Classical logic has the property that we need to investigate only (any) one tableau completely: if it closes then X is unsatisfiable, and if it is open then X is satisfiable. In the second case, the leaf node of an open branch gives an assignment to the atomic formulas and negated atomic formulas which makes X jointly satisfiable. Assign the literals at that leaf their required truth values and choose arbitrary values for unmentioned variables.
