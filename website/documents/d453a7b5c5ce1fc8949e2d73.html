Statement

The following principles are equivalent. Zorn: every poset in which each chain has an upper bound contains a maximal element. Hausdorff: every chain C_0 in a poset P is contained in an inclusion-maximal chain of P. An upper bound is an element at least as large as every element of the subset.

Level
Within undergraduate level
Level justification

Sets and partial orders supply chains, upper bounds and maximality. Well-order means every nonempty subset has a least member, and choice/Zorn is a stated principle. The explicit equivalences and fixed-point conditions require no ordinal arithmetic or forcing theory.

Proof 1: The chain poset and an upper bound of a maximal chain

First assume Zorn's lemma. Let { \displaystyle P'} be the set of all chains in P containing the given chain C_0, partially ordered by set inclusion. Since a union of a nonempty totally ordered set of chains is a chain, and C_0 is an upper bound for the empty chain, the hypothesis of Zorn's lemma (every chain has an upper bound) is satisfied for {\displaystyle P'} and thus {\displaystyle P'} contains a maximal element or a maximal chain in {\displaystyle P}.

Conversely, if the maximal principle holds, then {\displaystyle P} contains a maximal chain {\displaystyle C}. By the hypothesis of Zorn's lemma, {\displaystyle C} has an upper bound {\displaystyle x} in {\displaystyle P}. If {\displaystyle y\geq x}, then {\displaystyle {\widetilde {C}}=C\cup \{y\}} is a chain containing {\displaystyle C} and so by maximality, {\displaystyle {\widetilde {C}}=C}; i.e., {\displaystyle y\in C} and so {\displaystyle y=x}. {\displaystyle \square }

Level justification

Apply Zorn to chains containing the initial chain; conversely extend a maximal chain by any element above its upper bound. Basic set-order reasoning suffices.
