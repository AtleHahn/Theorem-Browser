Statement

For a Hermitian matrix X=\sum_j\lambda_jP_j, scalar functions act spectrally: h(X)=\sum_j h(\lambda_j)P_j. Here P_j are the orthogonal eigenprojections and \operatorname{Tr} is the matrix trace. Let n\ge1 be an integer and choose either J=\mathbb R or J=(0,\infty). Let A,B be Hermitian n\times n matrices with spectra in J, and let f:J\to\mathbb R be differentiable and convex. Then \operatorname{Tr}\bigl(f(A)-f(B)-(A-B)f'(B)\bigr)\ge0. If f is strictly convex, equality holds exactly when A=B.

Proof 1: Convex trace function and its supporting line — outline

Let C=A-B so that, for t\in(0,1),

B+tC=(1-t)B+tA,

varies from B to A.

Define

F(t)=\operatorname{Tr}[f(B+tC)].

By the trace-convexity theorem (a convex scalar function induces a convex trace function), F(t) is convex, and so for all t\in(0,1),

F(0)+t(F(1)-F(0))\geq F(t),

which is,

F(1)-F(0)\geq\frac{F(t)-F(0)}{t},

and, in fact, the right hand side is monotone nondecreasing in t.

Taking the limit t\to0^+ yields,

F(1)-F(0)\geq F'(0),

which, using the spectral trace differentiation formula F'(0)=\operatorname{Tr}(Cf'(B)), with rearrangement and substitution is Klein's inequality:

\operatorname{Tr}[f(A)-f(B)-(A-B)f'(B)]\geq0.

Note that if f is strictly convex and C\neq0, then F is strictly convex, by the strict version of the trace-convexity theorem. The final assertion follows from the strict supporting-line inequality for a differentiable strictly convex real function: F(1)>F(0)+F'(0). Conversely, A=B gives equality.
