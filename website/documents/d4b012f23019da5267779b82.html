Statement

An arithmetical theory is effectively axiomatized when its theorems can be enumerated by an algorithm. Write T\vdash A for provability, \ulcorner A\urcorner for a sentence’s natural-number code, \bar n for the numeral for n, and Q for Robinson arithmetic. Let T be a consistent effectively axiomatized extension of Q, with standard Gödel sentence G and numeralwise correct proof predicate. If T\vdash\neg G, then T is \omega-inconsistent: it proves an existential sentence while refuting each of its numeral instances. Write \operatorname{Prf}_T(n,m) for that proof predicate, \operatorname{Prov}_T(m)=\exists n\operatorname{Prf}_T(n,m), and recall that the standard Gödel sentence satisfies T\vdash G\leftrightarrow\neg\operatorname{Prov}_T(\ulcorner G\urcorner).

Proof 1: Refuting the ordinary Gödel sentence witnesses omega-inconsistency — source argument

If G were provable, then \operatorname{Prov}_T(\ulcorner G\urcorner) would be provable, by the standard proof-coding property that an actual proof yields a provable provability assertion. But G asserts the negation of \operatorname{Prov}_T(\ulcorner G\urcorner). Thus the system would be inconsistent, proving both a statement and its negation. This contradiction shows that G cannot be provable.

If the negation of G were provable, then \operatorname{Prov}_T(\ulcorner G\urcorner) would be provable (because G was constructed to be equivalent to the negation of \operatorname{Prov}_T(\ulcorner G\urcorner)). However, for each specific number n, n cannot be the Gödel number of a proof of G, because G is not provable. Thus on one hand the system proves there is a number with a certain property (that it is the Gödel number of a proof of G), but on the other hand, for every specific number n, we can prove that it does not have this property:

T\vdash\exists n\,\operatorname{Prf}_T(n,\ulcorner G\urcorner), \qquad T\vdash\neg\operatorname{Prf}_T(\bar n,\ulcorner G\urcorner) \quad\text{for each }n\in\mathbb N.

This is impossible in an \omega-consistent system. Hence the system is not \omega-consistent.
