Proof 1: Specialize the multiplicity bound to dimension one

Albanese’s theorem supplies an n-dimensional projective model with singularity multiplicities at most n!. For a curve n=1, so the bound is one. A multiplicity-one point on a curve is regular; hence this model has no singular points.
