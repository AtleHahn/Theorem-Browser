Statement

For every recursively enumerable set T of first-order formulas, with standard effective finite-string encoding, there is a polynomial-time decidable axiom set T^{\dagger} with the same deductive closure. In particular this axiom set is primitive recursive. If an enumeration machine outputs A_i after f(i) cumulative computation steps, where output times are positive integers, the construction replaces A_i by the conjunction of f(i) copies of A_i.

Proof 1: Polynomial-time axiomatization by Craig’s trick (outline)

A set of axioms is primitive recursive if there is a primitive recursive function that decides membership in the set. For a nonempty set, using an enumeration that continues indefinitely (repeating axioms if necessary), the index-padding algorithm, which replaces A_i by a conjunction of i copies and tests a formula X by waiting for the first |X| enumerated axioms, is recursive, but not necessarily primitive recursive. The main issue is that, at the part where we "run the enumeration algorithm until all {\displaystyle A_{1},A_{2},\dots ,A_{|X|}} are output", the enumeration algorithm may take a very long time to output all {\displaystyle A_{1},A_{2},\dots ,A_{|X|}}.

For primitive recursion, all loops must be bounded by a pre-computed upper bound. Consequently, we are not allowed to say "run the enumeration algorithm until...". However, we can say "run the enumeration algorithm for up to k steps", provided that we know what k should be.

Now, instead of replacing a formula {\displaystyle A_{i}} with

{\displaystyle \underbrace {A_{i}\land \dots \land A_{i}} _{i}}

one replaces it with

{\displaystyle \underbrace {A_{i}\land \dots \land A_{i}} _{f(i)}}

where {\displaystyle f} is a function that, given {\displaystyle i}, returns the number of steps the enumeration Turing machine takes in order to output {\displaystyle A_{i}}. In fact, this construction gives a decision algorithm that runs in polynomial time, which is a particularly well-behaved class of primitively recursive functions.

Here f(i) is the positive cumulative output time. Repetition preserves logical equivalence and hence the deductive closure. The source gives the time-padding construction but leaves the candidate-length simulation bound and runtime accounting unwritten.
