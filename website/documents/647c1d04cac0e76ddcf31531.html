Simpler proof assessment

Likely alternative prerequisite level: High school only; lowest recorded proof level: Undergraduate level. Finite induction on the subset size, with repeated pigeonhole selection, builds a finite ordered set on which the color of an m-subset depends only on its first m-1 elements. Apply the induction hypothesis to these stabilized colors, using a sufficiently large finite reservoir at each step. For unequal targets use their maximum and then take a subset of the needed size. Empty/vacuous small targets cause no difficulty. Only finite counting and induction are needed, without an infinite coloring or compactness passage.

Statement

For any positive integers m,c,n_1,\ldots,n_c, there exists a positive integer N such that every coloring of the m-element subsets of an N-element set with c colors has, for some i, an n_i-element subset whose m-element subsets all have color i.

Proof 1: Extend finite colorings and contradict infinite Ramsey — outline

It suffices to obtain a monochromatic subset of size T=\max_i n_i, then take the required number of vertices for its color. For the common-target argument write n=m, and let [k]^{(n)} denote the set of n-element subsets of [k]=\{1,\ldots,k\}. We deduce this finite Ramsey theorem from the infinite version by a proof by contradiction. Suppose the finite Ramsey theorem is false. Then there exist integers c, n, T such that for every integer k, there exists a c-colouring of [k](n) without a monochromatic set of size T. Let Ck denote the c-colourings of [k](n) without a monochromatic set of size T.

For any k, the restriction of a colouring in Ck+1 to [k](n) (by ignoring the colour of all sets containing k + 1) is a colouring in Ck. Define ⁠{\displaystyle C_{k}^{1}}⁠ to be the colourings in Ck which are restrictions of colourings in Ck+1. Since Ck+1 is not empty, neither is ⁠{\displaystyle C_{k}^{1}}⁠.

Similarly, the restriction of any colouring in ⁠{\displaystyle C_{k+1}^{1}}⁠ is in ⁠{\displaystyle C_{k}^{1}}⁠, allowing one to define ⁠{\displaystyle C_{k}^{2}}⁠ as the set of all such restrictions, a non-empty set. Continuing so, define ⁠{\displaystyle C_{k}^{\ell}}⁠ for all positive integers \ell,k.

Now, for any integer k,

{\displaystyle C_{k}\supseteq C_{k}^{1}\supseteq C_{k}^{2}\supseteq \cdots }

and each set is non-empty. Furthermore, Ck is finite as

{\displaystyle |C_{k}|\leq c^{\binom{k}{n}}}

Here \binom{k}{n}=0 when k<n. It follows that the intersection of all of these sets is non-empty, and let

{\displaystyle D_{k}=C_{k}\cap C_{k}^{1}\cap C_{k}^{2}\cap \cdots }

Then every colouring in Dk is the restriction of a colouring in Dk+1. Therefore, by unrestricting a colouring in Dk to a colouring in Dk+1, and continuing doing so, one constructs a colouring of {\displaystyle \mathbb {N} ^{(n)}} without any monochromatic set of size T. This contradicts the infinite Ramsey theorem.
