Proof 1: Apply the reciprocal rule to an integer power

For a negative integer n, let n=-m so that m is a positive integer. Using the reciprocal rule and the positive-integer power rule,

\frac{d}{dx}x^n =\frac{d}{dx}\left(\frac1{x^m}\right) =\frac{-\frac{d}{dx}x^m}{(x^m)^2} =-\frac{mx^{m-1}}{x^{2m}} =-mx^{-m-1} =nx^{n-1}.
