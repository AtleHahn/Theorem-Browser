Statement

Let H be a complex Banach space of dimension greater than one, and let T be a bounded linear operator. T has no nonzero proper closed invariant subspace if and only if every nonzero x is cyclic, meaning \overline{\operatorname{span}\{T^n x:n\ge0\}}=H.

Level
Within undergraduate level
Level justification

Linear algebra supplies norms, inner products and scalar-valued linear maps; analysis supplies suprema and norm closure. Seminorm or cyclic-vector conditions are explicitly given by norm inequalities or the closed span of iterates. These direct definitions suffice without spectral or weak-topology theory.

Proof 1: Compare every closed invariant subspace with a cyclic closure

If {\displaystyle x} is an element of the Banach space {\displaystyle H}, write [x] for the linear subspace generated by the sequence {\displaystyle \{T^{n}(x)\,:\,n\geq 0\}}. This is also called the {\displaystyle T}-cyclic subspace generated by {\displaystyle x}. From the definition it follows that {\displaystyle [x]} is a {\displaystyle T}-invariant subspace. Moreover, it is the minimal {\displaystyle T}-invariant subspace containing {\displaystyle x}: if {\displaystyle W} is another invariant subspace containing {\displaystyle x}, then necessarily {\displaystyle T^{n}(x)\in W} for all {\displaystyle n\geq 0} (since {\displaystyle W} is {\displaystyle T}-invariant), and so {\displaystyle [x]\subset W}. If {\displaystyle x} is non-zero, then {\displaystyle [x]} is not equal to {\displaystyle \{0\}}, and its closure is invariant because T is bounded. Thus its closure is either the whole space {\displaystyle H} (in which case {\displaystyle x} is said to be a cyclic vector for {\displaystyle T}) or it is a non-trivial {\displaystyle T}-invariant subspace. Therefore, if T has no nonzero proper closed invariant subspace, every nonzero vector is cyclic. Conversely, if every nonzero vector is cyclic, any nonzero closed invariant subspace W contains a nonzero x and hence contains \overline{[x]}=H, so W=H.

Within undergraduate level
Level justification

Take the span of the iterates, pass invariance to its closure by continuity and compare with any closed invariant subspace containing x. Undergraduate linear algebra and metric closure suffice with bounded operators as continuous linear maps; Banach completeness is not used.
