Statement

For an integer n\ge1, use deterministic Turing machines with n operational states, a separate Halt state, one starting state, a two-way unbounded tape over \{0,1\}, and a transition for each operational state and scanned symbol. Each transition writes a bit, moves one cell left or right, and enters a state (possibly Halt). The machine starts on an all-zero tape. Among machines that halt, \Sigma(n) is the largest number of ones left on the tape, and S(n) the largest number of transitions, including the halting transition. The function \Sigma is not Turing-computable.

Level
Within undergraduate level
Level justification

The machine model, starting configuration and score are explicitly described through finite transition rules. Understanding computability here means whether such a finite program always returns the required value; the maxima and eventual comparisons use elementary functions and quantifiers. A small machine trace is enough to illustrate the new model, without formal arithmetic or incompleteness theory.

Proof 1: Doubling, score evaluation and incrementing — outline

Suppose that Σ(n) is a computable function and let EvalΣ denote a Turing machine evaluating Σ(n). Given a tape with n 1s it will produce Σ(n) 1s on the tape and then halt. Let Increment denote a simple Turing machine searching for a first 0 on the tape and replacing it with 1. Let Double denote a Turing machine evaluating function n + n. Given a tape with n 1s it will produce 2n 1s on the tape and then halt. Let us create the composition Double | EvalΣ | Increment and let n0 be the number of states of this machine. Let Create_n0 denote a Turing machine creating n0 1s on an initially blank tape. This machine may be constructed in a trivial manner to have n0 states (the state i writes 1, moves the head right and switches to state i + 1, except the state n0, which halts). Let N denote the sum n0 + n0.

Let BadΣ denote the composition Create_n0 | Double | EvalΣ | Increment. Notice that this machine has N states. Starting with an initially blank tape it first creates a sequence of n0 1s and then doubles it, producing a sequence of N 1s. Then EvalΣ will produce Σ(N) 1s on tape, and at last Increment will replace a first 0 with 1 and then halt. Thus the score of BadΣ is strictly greater than Σ(N), which contradicts the definition of the function Σ(n).

Level justification

The contradiction combines unary machine subroutines and counts their states before constructing a machine exceeding its own maximum score. Computability, composition conventions and this diagonal argument form a modest extension of undergraduate discrete mathematics. The outline assumes compatible tape and head conventions between subroutines; checking those is an implementation obligation, not graduate mathematics.
