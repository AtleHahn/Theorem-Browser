Intuitionistic propositional consistency and classical satisfiability coincide even though intuitionistic and classical derivability differ. This separates disagreement about permissible proofs from disagreement about whether a propositional set of assumptions can be jointly consistent.

Statement

Let T be a set of propositional formulas. Then T is consistent in intuitionistic propositional logic if and only if it has a classical truth-value model. Consistency means T\nvdash\bot, where \bot denotes falsity.

Proof 1: Intuitionistic consistency and classical satisfiability — outline

Use the generalized Glivenko theorem: for every propositional \phi, T\vdash_{\mathrm{cl}}\phi if and only if T\vdash_{\mathrm{int}}\neg\neg\phi. Applying this to falsity, together with the intuitionistic equivalence \neg\neg\bot\leftrightarrow\bot, identifies the two consistency conditions. Classical propositional soundness and completeness identify classical consistency with satisfiability, giving the assertion.
