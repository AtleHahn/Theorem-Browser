Statement

Let \mathcal T be the total computable functions \mathbb N\to\mathbb N, with the subspace topology from Baire space \mathbb N^{\mathbb N}. Every extensional Boolean operation F:\mathcal T\to\{0,1\} computable from program indices is continuous, with the discrete topology on \{0,1\}.

Proof 1: Interpret finite agreement as a basic neighborhood

The set of total computable functions can be viewed as a subspace of Baire space \mathcal T\subseteq\mathbb N^{\mathbb N}. The finite-agreement form of the Kreisel–Lacombe–Shoenfield–Tseitin theorem gives, for each f, an n such that F is constant on functions agreeing with f until n. These finite-agreement sets are basic neighborhoods in the subspace topology. Thus, with the set of booleans \{0,1\} given the discrete topology, F must be continuous.

Level
Beyond undergraduate level
Level justification

Translate the finite-agreement conclusion of KLST into a basic open neighborhood. That last step is elementary topology, but the input is an extensional operation computable on indices of total programs, a specialized effective-function framework beyond the baseline.
