Statement

An arithmetical theory is effectively axiomatized when its theorems can be enumerated by an algorithm. Write T\vdash A for provability, \ulcorner A\urcorner for a sentence’s natural-number code, \bar n for the numeral for n, and Q for Robinson arithmetic. If T is an effectively axiomatized, \omega-consistent extension of Q, then there is a sentence G with T\nvdash G and T\nvdash\neg G. Here \omega-consistency means that T cannot prove \exists x R(x) while proving \neg R(\bar n) for every natural number n.

Proof 1: Diagonal fixed point and two consistency contradictions — outline

Let \operatorname{Prf}_T(n,m) be the standard arithmetized proof relation, correctly representing each concrete proof-code instance, and let

\operatorname{Prov}_T(m)=\exists n\,\operatorname{Prf}_T(n,m).

An important feature of this formula is that if a statement p is provable in the system, then \operatorname{Prov}_T(\ulcorner p\urcorner) is also provable. This is because any proof of p has a corresponding Gödel number, and its proof-code instance is verifiable in the system.

The next step in the proof is to obtain a statement which, indirectly, asserts its own unprovability. Its existence follows from the diagonal lemma, which says that for any sufficiently strong formal system and any formula F(x) with one free variable there is a statement p such that the system proves

p\leftrightarrow F(\ulcorner p\urcorner).

By letting F be the negation of \operatorname{Prov}_T(x), we obtain a sentence G such that

T\vdash G\leftrightarrow\neg\operatorname{Prov}_T(\ulcorner G\urcorner).

The sentence obtained in this way indirectly asserts that its own Gödel number is the Gödel number of an unprovable formula; it need not be literally the displayed formula on the right.

Now assume that the axiomatic system is \omega-consistent. If G were provable, then \operatorname{Prov}_T(\ulcorner G\urcorner) would be provable, as argued above. But G implies the negation of \operatorname{Prov}_T(\ulcorner G\urcorner). Thus the system would be inconsistent, proving both a statement and its negation. This contradiction shows that G cannot be provable.

If the negation of G were provable, then \operatorname{Prov}_T(\ulcorner G\urcorner) would be provable, because G was constructed to be equivalent to the negation of \operatorname{Prov}_T(\ulcorner G\urcorner). However, for each specific natural number n, n cannot be the Gödel number of a proof of G, because G is not provable. Numeralwise proof checking therefore gives

T\vdash\neg\operatorname{Prf}_T(\bar n,\ulcorner G\urcorner) \qquad\text{for every natural number }n.

Thus on one hand the system proves there is a number with a certain property—that it is the Gödel number of a proof of G—but on the other hand, for every specific number we can prove that it does not have this property. This is impossible in an \omega-consistent system. Thus the negation of G is not provable.

The statement G is therefore undecidable in our axiomatic system: it can neither be proved nor disproved within the system. To show that G is not provable only requires consistency; the stronger assumption of \omega-consistency is used to show that its negation is not provable.

Proof 2: Diophantine decision reduction — outline

Matiyasevich proved that there is no algorithm that, given a multivariate polynomial p(x_1,x_2,\ldots,x_k) with integer coefficients, determines whether there is an integer solution to the equation p=0. Because polynomials with integer coefficients, and integers themselves, are expressible in the language of arithmetic, if a multivariate integer polynomial equation p=0 does have a solution in the integers then T, as an extension of Robinson arithmetic, will prove this by verifying the finite calculation.

Moreover, suppose the system T is \omega-consistent. In that case, it will never prove that a particular polynomial equation has a solution when there is no solution in the integers: using the standard coding of finite integer tuples, each concrete purported solution is refuted by arithmetic, and a false existential solution assertion would contradict \omega-consistency.

Thus, if T were complete and \omega-consistent, it would be possible to determine algorithmically whether a polynomial equation has a solution by merely enumerating proofs of T until either “p has a solution” or “p has no solution” is found, in contradiction to Matiyasevich's theorem. Hence it follows that T cannot be \omega-consistent and complete.
