Statement

Let G be a finite simple undirected graph (edges join distinct vertices with at most one edge per pair). A Hamiltonian path visits every vertex once, and a Hamiltonian cycle returns to its start after visiting every vertex once. If every vertex of G has odd degree, then for every fixed edge uv the number of Hamiltonian cycles containing uv is even, counting cycles without an orientation or a starting vertex.

Proof 1: Hamiltonian cycles through an edge in an all-odd graph — outline

If there are no Hamiltonian cycles, their number is zero. Otherwise the graph has at least three vertices.

Fix the edge uv. Define an exchange graph H, the vertices of which are in one-to-one correspondence with the Hamiltonian paths in G beginning at u and continuing through edge uv. Two such paths p_1 and p_2 are connected by an edge in H if one may obtain p_2 by adding a new edge to the end of p_1 and removing another edge from the middle of p_1, leaving a Hamiltonian path with the same beginning. This operation is reversible, forming a symmetric relation, so H is an undirected graph.

If path p ends at vertex w, then the vertex corresponding to p in H has degree equal to the number of ways that p may be extended by a new edge that does not connect back to u. That is, the degree of this vertex in H is either \deg_G(w)-1 (an even number) if p does not form part of a Hamiltonian cycle through uv, or \deg_G(w)-2 (an odd number) if p is part of a Hamiltonian cycle through uv.

Since H has an even number of odd-degree vertices by the handshaking lemma, G must have an even number of Hamiltonian cycles through uv.
