Statement

Finite complex linear combinations of e_n(x)=e^{2\pi inx}, n\in\mathbb Z, are dense in the continuous complex-valued functions on the circle [0,1]/\{0,1\}, for the uniform norm. Equivalently, for each continuous complex function f on [0,1] with f(0)=f(1) and each \varepsilon>0, some such finite sum p satisfies |f(x)-p(x)|<\varepsilon for every x\in[0,1].

Proof 1: Apply complex density to the exponential algebra — outline

This is an application of the complex Stone–Weierstrass theorem: if X is a compact Hausdorff space and S is a separating subset of C(X,\mathbb C), then the complex unital *-algebra generated by S is dense in C(X,\mathbb C).

The set of linear combinations of functions e_n(x)=e^{2\pi inx}, n\in\mathbb Z, is dense in C([0,1]/\{0,1\}), where we identify the endpoints of the interval [0,1] to obtain a circle.

The source states this application without supplying the algebra and point-separation checks.
