Statement

For a positive integer n, let F_n be the increasing sequence of reduced fractions a/b\in[0,1] with integers b\ge1, \gcd(a,b)=1 and b\le n, including 0/1 and 1/1. The algorithm specified below outputs each term of F_n exactly once and terminates, in ascending or descending order as selected.

For ascending order initialize (a,b,c,d)=(0,1,1,n); for descending order initialize (a,b,c,d)=(1,1,n-1,n). Output a/b. While 0\le c\le n, put k=\lfloor(n+b)/d\rfloor, replace the four variables simultaneously by

(a,b,c,d)\longleftarrow(c,d,kc-a,kd-b),

and output the new a/b.

Level
High school only
Level justification

The full finite update rule is supplied in ordinary integer arithmetic.
