Statement

For Boolean formulas promised to have at most one satisfying assignment, there is a polynomial-time nondeterministic verification procedure with no accepting branch on unsatisfiable formulas and exactly one accepting branch on uniquely satisfiable formulas. Thus Unambiguous-SAT belongs to the promise version of UP.

Level
Within undergraduate level
Level justification

The promise and accepting-branch property define the needed UP meaning. A branching transition procedure adds a limited finite computational model to Boolean evaluation.

Proof 1: One branch for each truth assignment

The promise problem Unambiguous-SAT can be decided by a nondeterministic Turing machine that has at most one accepting computation path on promised inputs, thus it belongs to the promise version of the complexity class UP (the class UP as such is only defined for languages).

The source asserts this verification property without spelling out the machine.

Within undergraduate level
Level justification

Branch once for each Boolean assignment and evaluate the formula in polynomial time; the promise bounds accepting branches by one. Elementary algorithms and the explicitly described nondeterministic verification notion suffice.
