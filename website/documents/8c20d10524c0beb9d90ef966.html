Statement

Let L be a first-order language, T a set of L-sentences, and \Phi(\bar x) a set of L-formulas whose free variables lie in a possibly infinite tuple \bar x (each individual formula uses finitely many variables). The following are equivalent:

  1. Whenever A\subseteq B are L-structures satisfying T and \bar a is a tuple from A, if every formula in \Phi(\bar a) holds in B, every such formula holds in A.
  2. There is a set \Psi(\bar x) of universal L-formulas equivalent to \Phi in every model of T, for every assignment to \bar x. A universal formula has the form \forall y_1\cdots\forall y_m\,\psi, where \psi is quantifier-free; free variables are allowed. A substructure has a subset as its domain, contains the interpretations of constants, is closed under the language’s functions, and has the relations induced from the larger structure. Equivalence of the sets means satisfaction of all formulas in one set exactly when all formulas in the other set hold.
