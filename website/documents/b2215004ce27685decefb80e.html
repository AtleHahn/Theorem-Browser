One fixed computable procedure can simulate every computable partial function when supplied with a suitable program code. This establishes the universality of programmable computation and the interchangeability of programs and data, without implying that every well-defined mathematical function is computable.

Statement

There exists a partial computable function u:\mathbb N^2\rightharpoonup\mathbb N such that for every partial computable function f:\mathbb N\rightharpoonup\mathbb N there is an e\in\mathbb N with u(e,x)\simeq f(x) for all x\in\mathbb N. Here a partial function may be undefined on some inputs. Partial computable means computed by a Turing-machine program: on inputs where the function is defined the program halts with that value, and on other inputs it does not halt. The relation \simeq means either both sides are defined and equal or both are undefined. Thus the sections x\mapsto u(e,x) enumerate all partial computable functions.
