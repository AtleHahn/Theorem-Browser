Statement

Let A be Hermitian on \mathbb C^n, n\ge1, with eigenvalues \lambda_1\ge\cdots\ge\lambda_n, repeated with multiplicity. Write q_A(x)=x^*Ax for unit vectors x. Choose an orthonormal eigenbasis e_1,\ldots,e_n. Let 1\le i_1<\cdots<i_k\le n, and put V_j=\operatorname{span}(e_1,\ldots,e_{i_j}). If W\subset\mathbb C^n has dimension k and \dim(W\cap V_j)\ge j for every j, then

\operatorname{tr}_W(A)\ge\sum_{j=1}^k\lambda_{i_j},

where \operatorname{tr}_W(A)=\sum_{j=1}^k w_j^*Aw_j for any orthonormal basis of W.

Proof 1: Recursive orthogonal selection along the eigenflag

Let V_j=\operatorname{span}(e_1,\ldots,e_{i_j}). For any k-dimensional W satisfying \dim(W\cap V_j)\geq j, it remains to show that

\lambda_{i_1}(A)+\cdots+\lambda_{i_k}(A)\leq\operatorname{tr}_W(A).

To show this, we construct an orthonormal set of vectors v_1,\ldots,v_k such that v_j\in V_j\cap W. Then

\operatorname{tr}_W(A)=\sum_{j=1}^k\langle v_j,Av_j\rangle \geq\sum_{j=1}^k\lambda_{i_j}(A).

Since \dim(V_1\cap W)\geq1, we pick any unit v_1\in V_1\cap W. Next, since \dim(V_2\cap W)\geq2, we pick any unit v_2\in V_2\cap W that is perpendicular to v_1, and so on.

Level justification

Select orthonormal vectors successively in nested intersections and bound each Rayleigh quotient in its eigenvector span. Finite-dimensional Hermitian linear algebra suffices.
