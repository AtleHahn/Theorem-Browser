Statement

A graph here is a finite simple undirected graph. A cycle is a closed path with at least three distinct vertices, and a feedback vertex set meets every cycle. There exists a function f:\mathbb N_{>0}\to\mathbb N such that for each k\ge1 every graph either has k vertex-disjoint cycles or a feedback vertex set of at most f(k) vertices.

Proof 1: Specialize planar-minor packing to the triangle — outline

Use the Robertson–Seymour planar-minor packing theorem: if H is planar and \mathcal F(H) is the class of graphs containing H as a minor, then for every k a graph either has k vertex-disjoint subgraphs in \mathcal F(H) or a vertex set of bounded size meeting every such subgraph. Take H to be a triangle. The class \mathcal F(H) is exactly the class of graphs containing a cycle. A vertex set whose deletion leaves no member of this class is precisely a feedback vertex set. Thus this specialization is the cycle-packing/feedback-set theorem.
