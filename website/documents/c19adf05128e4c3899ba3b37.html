Statement

Let \Omega be an oval in a finite projective plane of order n\ge2. A projective plane is an incidence structure in which any two distinct points lie on a unique line, any two distinct lines meet at a unique point, and there are four points no three collinear. Order n means each line contains n+1 points and each point lies on n+1 lines. An oval has n+1 points, no three collinear; equivalently, it meets every line in at most two points and each oval point lies on exactly one tangent. A tangent meets \Omega in one point; a secant meets it in two.

(a) If n is odd, every point outside \Omega lies on zero or two tangents.

(b) If n is even, there is a point N outside \Omega, called the nucleus, such that the tangents to \Omega are exactly all the lines through N.

Proof 1: Count tangents using parity and a line partition

For odd n:

Let tR be the tangent to Ω at point R and let P1, ... , Pn be the remaining points of this line. For each i, the lines through Pi partition Ω into sets of cardinality 2 or 1 or 0. Since the number |Ω| = n + 1 is even, for any point Pi, there must exist at least one more tangent through that point. The total number of tangents is n + 1, hence, there are exactly two tangents through each Pi, tR and one other. Thus, for any point P not in oval Ω, if P is on any tangent to Ω it is on exactly two tangents.

For even n:

Let s be a secant, s ∩ Ω = {P0, P1} and s= {P0, P1,...,Pn}. Because |Ω| = n + 1 is odd, through any Pi, i = 2,...,n, there passes at least one tangent ti. The total number of tangents is n + 1. Hence, through any point Pi for i = 2,...,n there is exactly one tangent. If N is the point of intersection of two tangents, no secant can pass through N. Each line joining N to an oval point must therefore be a tangent, giving n+1 distinct such lines. Because n + 1, the number of tangents, is also the number of lines through any point, any line through N is a tangent.

Both parity cases partition the oval by lines through points on a fixed tangent or secant, then exhaust the total tangent count. The incidence axioms are now explicit; elementary finite counting suffices.
