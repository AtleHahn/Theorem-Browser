The finite combinatorial free-set property exactly detects specified levels of the infinite cardinal hierarchy. This shows how distinctions among sizes of infinity can be expressed through constraints on finite subsets, connecting abstract cardinality with concrete combinatorial structure.

Statement

Let n\ge1 be an integer and X a set. Then |X|\ge\aleph_n if and only if every map \Phi:[X]^n\to[X]^{<\omega} admits a subset U\subseteq X of size n+1 such that

\Phi(V)\cap(U\setminus V)=\varnothing\quad\text{for every }V\in[U]^n.

Here [X]^n is the set of n-element subsets, [X]^{<\omega} the set of all finite subsets, \aleph_0 the cardinality of the natural numbers, and \aleph_{j+1} the least infinite cardinal greater than \aleph_j. Cardinal inequality means existence of an injection from a set of the smaller cardinality into one of the larger cardinality.

Proof 1: Cardinal induction and the obstruction map (external)

The following editorial argument completes the stated scope. A supporting source is Course Notes for Machine Learning and Mathematical Logic (§3.2 Theorem 3.2.9 and proof pp.60–62; Theorem 3.2.6 p.59.).

Positive direction: restrict to a subset of X of cardinality aleph_n and replace Phi(V) by its intersection with that subset minus V; apply Levine Theorem 3.2.9 with alpha=0 and k=n. For the converse, the following additional argument applies: construct on every well-ordered set of cardinality <=aleph_{n-1} a finite-valued n-set map with no free (n+1)-set. For n=1 enumerate the set as a subset of omega and send {j} to its finite set of predecessors. Inductively work on the initial ordinal aleph_{n-1}. For each beta below it, |beta|<=aleph_{n-2}, so the induction hypothesis supplies a finite-valued map psi_beta on (n-1)-subsets of beta with no free n-set (if |beta|<n the assertion is vacuous). For an n-subset S with maximum beta, set Phi(S)=psi_beta(S minus {beta}). Given any (n+1)-set U, put beta=max U. The n-set U minus {beta} has an (n-1)-subset V with some omitted point in psi_beta(V), so S=V union {beta} witnesses nonfreeness of U. Restrict/transport this construction to any smaller X. These choices are ordinary ZFC choices; the statement does not assert a choice-free theorem. This avoids reliance on the omitted decomposition equivalence.
