Statement

Let (X,\Sigma,\mu) be a measure space with 0<\mu(X)<\infty, and let T:X\to X be measure preserving and ergodic: every measurable set invariant modulo null sets has measure zero or full measure. For f\in L^1(\mu), \frac1n\sum_{k=0}^{n-1}f(T^kx)\to\mu(X)^{-1}\int_X f\,d\mu for almost every x.

Proof 1: Use invariance and preservation of the integral

By the pointwise ergodic theorem the averages converge almost everywhere to an integrable invariant function \hat f, and \int\hat f\,d\mu=\int f\,d\mu. Ergodicity makes \hat f constant almost everywhere. Its constant value is therefore \mu(X)^{-1}\int f\,d\mu.

Proof 2: Use conditional expectation after probability normalization — outline

Normalize the measure to \nu=\mu/\mu(X). The Birkhoff–Khinchin theorem identifies the almost-sure limit of the averages with E_\nu(f\mid\mathcal C), where \mathcal C is the invariant sigma-algebra. Ergodicity makes \mathcal C trivial modulo null sets, so this conditional expectation is E_\nu f=\mu(X)^{-1}\int f\,d\mu.
