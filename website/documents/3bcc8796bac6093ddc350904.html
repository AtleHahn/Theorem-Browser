Statement

Independently draw with replacement from n\geq1 coupon types, each with probability 1/n, and let T be the number of draws until every type has appeared. Here n is an integer. For every integer r\geq0, \Pr(T>r)\leq ne^{-r/n}.

Level
High school only
Level justification

The event depends on the first r finite draws, with an explicitly given scalar bound.

Proof 1: Bound each missing coupon and use the union bound

A stronger tail estimate for the upper tail can be obtained as follows. Let Z_i^r denote the event that the i-th coupon was not picked in the first r trials. Then, for r\geq1,

P[Z_i^r]=\left(1-\frac1n\right)^r\leq e^{-r/n}.

Via a union bound over the n coupons, we obtain

P[T>r]=P\left[\bigcup_i Z_i^r\right] \leq n\cdot P[Z_1^r]\leq ne^{-r/n}.

For r=0, every coupon is initially missing, and P(T>0)=1\leq n.

Level justification

For each coupon, count the probability it is absent in r independent draws; apply the supplied exponential inequality and add the n bounds. The argument is finite probability and real exponential arithmetic, with r=0 checked separately.
