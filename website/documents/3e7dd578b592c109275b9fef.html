Statement

For a real m\times n matrix A and 1\le p,q\le\infty, write \|A\|_{p\to q}=\max_{\|x\|_p=1}\|Ax\|_q, using the usual finite-dimensional \ell_p norms. For A\in\mathbb R^{m\times n}, define \operatorname{SDP}(A)=\max\sum_{i,j}a_{ij}\langle x_i,y_j\rangle, with all x_i,y_j unit vectors in \mathbb R^{m+n}. Then \|A\|_{\infty\to1}\le\operatorname{SDP}(A)\le K_G^{\mathbb R}\|A\|_{\infty\to1}, where K_G^{\mathbb R} is the real Grothendieck constant.
