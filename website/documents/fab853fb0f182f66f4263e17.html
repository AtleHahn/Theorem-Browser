Statement

Let N=k2^n+1 with positive odd k<2^n, n\ge1. Test more than N/2 distinct integers from \{2,\ldots,N-1\}. If each fails a^{(N-1)/2}\equiv-1\pmod N, then N is composite.

Level
High school only
Level justification

The test and pigeonhole step use elementary modular arithmetic and counting.

Proof 1: Count successful bases in the stated interval

For an odd prime N, Euler’s criterion and the quadratic-nonresidue count give (N-1)/2 successful nonzero bases; none is 1, so all lie in the tested domain 2,\ldots,N-1. A set of more than N/2 failures in this domain would leave fewer than (N-1)/2 untested bases, contradicting that count. Thus N cannot be prime.

Level
High school only
Level justification

Under primality, subtract the known number of successful bases from the finite tested domain and contradict the failure count. School counting and congruences suffice.
