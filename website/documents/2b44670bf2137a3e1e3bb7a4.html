Statement

All graphs here are finite, simple and undirected. A clique is a set of pairwise adjacent vertices. A cycle is induced if no edge joins two of its nonconsecutive vertices; a graph is chordal if every induced cycle has length three. Chordality can be decided in time O(n+m) for a graph with n vertices and m edges, using standard adjacency-list algorithmic representation.

Proof 1: Linear recognition by an ordering algorithm and a perfect-elimination test

A perfect elimination ordering in a graph is an ordering of the vertices of the graph such that, for each vertex v, v and the neighbors of v that occur after v in the order form a clique. A graph is chordal if and only if it has a perfect elimination ordering.

Rose, Lueker & Tarjan (1976) (see also Habib et al. 2000) show that a perfect elimination ordering of a chordal graph may be found efficiently using an algorithm known as lexicographic breadth-first search.

Since both this lexicographic breadth first search process and the process of testing whether an ordering is a perfect elimination ordering can be performed in linear time, it is possible to recognize chordal graphs in linear time.
