Statement

Fix an admissible numbering \varphi_e of the partial computable functions \mathbb N\rightharpoonup\mathbb N. If P\subseteq\mathbb N is neither empty nor all of \mathbb N, and \varphi_m=\varphi_n implies (m\in P\iff n\in P), then P is undecidable.

Level
Beyond undergraduate level
Level justification

Beyond undergraduate under the conservative preparation rule. The complete formulation requires partial computable functions (including undefined outputs), equality of their partial graphs, an admissible numbering with universal simulation and effective parameterization, and decidability of an extensional index set. These interdependent concepts are not assumed in the standard undergraduate baseline, and learning their combined meaning cannot confidently fit approximately 30 minutes. The rating is settled conservatively rather than left provisional.

Proof 1: Self-reference and extensionality

Assume for contradiction that {\displaystyle P} is a non-trivial, extensional and computable set of natural numbers. Since {\displaystyle P} is non-trivial, there is a natural number {\displaystyle a\in P} and a natural number {\displaystyle b\notin P}. Define the partial computable function {\displaystyle Q} of {\displaystyle e} and {\displaystyle x} by {\displaystyle Q_{e}(x)=\varphi _{b}(x)} when {\displaystyle e\in P} and {\displaystyle Q_{e}(x)=\varphi _{a}(x)} when {\displaystyle e\notin P}. By Kleene's recursion theorem, there exists {\displaystyle e} such that {\displaystyle \varphi _{e}=Q_{e}}. Then, if {\displaystyle e\in P}, we have {\displaystyle \varphi _{e}=\varphi _{b}}, contradicting the extensionality of {\displaystyle P} since {\displaystyle b\notin P}, and conversely, if {\displaystyle e\notin P}, we have {\displaystyle \varphi _{e}=\varphi _{a}}, which again contradicts extensionality since {\displaystyle a\in P}.

Level
Beyond undergraduate level
Level justification

Assuming P decidable, define the total computable index map f(e)=b for e in P and f(e)=a otherwise. Kleene’s supplied recursion theorem gives an index e with phi_e=phi_f(e)=Q_e as partial functions. Each membership case then contradicts extensionality. Q itself need not be total, and the companion correctly calls it partial computable; there is no circular assumption that an arbitrary program can inspect its own index. Understanding admissible indexing, partial-function equality and the semantic fixed-point conclusion, together with the complete statement, cannot confidently fit the 30-minute preparation allowance. Assess Beyond undergraduate conservatively; proving the recursion theorem is not required.

Proof 2: Reduction from the halting problem

If we have an algorithm that decides a non-trivial property, we can construct a Turing machine that decides the halting problem.

Use natural-number program indices in the admissible numbering of the statement; write Fa = \varphi_a for the partial function computed by program a. This proof proceeds by reductio ad absurdum: we assume that there is a non-trivial property that is decided by an algorithm, and then show that it follows that we can decide the halting problem, which is not possible, and therefore a contradiction.

Write D for the supposed decision algorithm for the index set P. Let us now assume that D(a) is an algorithm that decides some non-trivial property of Fa. Without loss of generality we may assume that D(no-halt) = "no", with no-halt being the representation of an algorithm that never halts. If this is not true, then this holds for the algorithm D that computes the negation of the property P. Now, since D decides a non-trivial property, it follows that there is an index b that represents an algorithm Fb and D(b) = "yes". We can then define an algorithm H(a, i) as follows:

  1. construct an index t that represents an algorithm T(j) such that
  • T first simulates the computation of Fa(i),
  • then T simulates the computation of Fb(j) and returns its result.
  1. return D(t).

We can now show that H decides the halting problem:

  • Assume that the algorithm represented by a halts on input i. In this case Ft = Fb and, because D(b) = "yes" and the output of D(x) depends only on Fx, it follows that D(t) = "yes" and, therefore H(a, i) = "yes".
  • Assume that the algorithm represented by a does not halt on input i. In this case Ft = Fno-halt, i.e., the partial function that is never defined. Since D(no-halt) = "no" and the output of D(x) depends only on Fx, it follows that D(t) = "no" and, therefore H(a, i) = "no".

Since the halting problem is known to be undecidable, this is a contradiction and the assumption that there is an algorithm D(a) that decides a non-trivial property for the function represented by a must be false.
