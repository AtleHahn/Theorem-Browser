Statement

Let n\geq1 be an integer, t_0\in\mathbb R, y_0\in\mathbb R^n, and a,b>0. Put

R=\{(t,y)\in\mathbb R\times\mathbb R^n:|t-t_0|\leq a,\ \|y-y_0\|\leq b\}.

Suppose f:R\to\mathbb R^n satisfies:

  • y\mapsto f(t,y) is continuous for each fixed t;
  • t\mapsto f(t,y) is Lebesgue measurable for each fixed y;
  • there is a nonnegative Lebesgue-integrable function m on [t_0-a,t_0+a] such that \|f(t,y)\|\leq m(t) for every (t,y)\in R.

Then there is 0<\delta\leq a and an absolutely continuous function y:[t_0-\delta,t_0+\delta]\to\mathbb R^n whose graph lies in R, such that

y(t_0)=y_0,\qquad y'(t)=f(t,y(t))\quad\text{for Lebesgue-almost every }t\in[t_0-\delta,t_0+\delta].

All vector norms are Euclidean. Absolute continuity means that for every \varepsilon>0 there is \eta>0 such that every finite disjoint collection of intervals (s_j,t_j) in the domain with \sum_j(t_j-s_j)<\eta satisfies \sum_j\|y(t_j)-y(s_j)\|<\varepsilon.
