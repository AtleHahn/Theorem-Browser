Statement

Let A,B,C be pairwise disjoint subsets of the sphere, with A,B,C,B\cup C mutually congruent. Let \mu be a finite-valued, finitely additive nonnegative set function defined on all subsets of the sphere and invariant under these congruences. Then \mu(A\cup B\cup C)=0.

Level
Within undergraduate level
Level justification

Finite additivity and congruence invariance are explicit conditions on a nonnegative set function. The claim concerns only three disjoint sphere subsets, with no general integration or sigma-algebra construction.

Proof 1: The equal-piece finite-additivity contradiction

Congruence gives a common value t=\mu(A)=\mu(B)=\mu(C)=\mu(B\cup C). Finite additivity also gives \mu(B\cup C)=2t, so t=0 and the union has measure 3t=0.

Level justification

Use invariance to identify four finite values and finite additivity to obtain t=2t. Elementary set functions and real arithmetic suffice; neither Lebesgue integration nor the construction of paradoxical pieces is used.
