Statement

A partial order is a reflexive, antisymmetric, transitive relation \le. Distinct elements are comparable when one is below the other. A chain has every pair comparable; an antichain has no distinct comparable pair. A partition consists of disjoint subsets whose union is the whole set. Let P be any partially ordered set whose largest chain has finite size h. Then the minimum number of antichains in a partition of P is h. For the empty order both quantities are zero.

Level
Within undergraduate level
Level justification

The statement explicitly defines partial orders, chains, antichains and partitions. Finite cardinality and arbitrary sets suffice to understand the equality, without ordinal or infinite-order classification theory.

Proof 1: Use bounded chain ranks for finite height

For any element x, consider the chains that have x as their largest element, and let N(x) denote the size of the largest of these x-maximal chains. Then each set N^{-1}(i), consisting of elements that have equal values of N, is an antichain, and these antichains partition the partial order into a number of antichains equal to the size of the largest chain.

The maxima defining N(x) exist because the height is finite. For the empty order both quantities are zero.

Assign bounded integer chain ranks and use rank increase along comparable elements. Elementary undergraduate set and order reasoning suffices for a possibly infinite poset; no transfinite ranks or advanced order theory are used.
