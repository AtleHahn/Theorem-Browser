Statement

For every integer n\ge1, the largest subset of \{1,\ldots,2n\} in which no two distinct numbers divide one another has size n.

Proof 1: Upper interval and fixed odd-part chains — outline

A partial order is a reflexive, antisymmetric, transitive relation \le. Distinct elements are comparable when one is below the other. A chain has every pair comparable; an antichain has no distinct comparable pair. A partition consists of disjoint subsets whose union is the whole set.

Use finite Dilworth: maximum antichain size equals minimum chain-partition size.

If we order the integers in the interval [1, 2n] by divisibility, the subinterval [n + 1, 2n] forms an antichain with cardinality n. A partition of this partial order into n chains is easy to achieve: for each odd integer m in [1,2n], form a chain of the numbers of the form m2^i with integer i\ge0 and m2^i\le2n. Therefore, by Dilworth's theorem, the width of this partial order is n.
