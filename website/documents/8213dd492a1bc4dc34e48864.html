Statement

A graph is planar if its vertices can be drawn as distinct points in the plane and edges as simple curves meeting only at common endpoints. A subdivision replaces each edge by a path, with the new internal vertices distinct for different edges. If a finite graph G is nonplanar, every subdivision of G is nonplanar.

Level
High school only
Level justification

Planar drawing and subdivision are explicitly finite curves, vertices and paths.

Proof 1: Use each subdivision path as the original edge curve

Subdividing a graph cannot turn a nonplanar graph into a planar graph: if a subdivision of a graph G has a planar drawing, the paths of the subdivision form curves that may be used to represent the edges of G itself.

Level

Level justification

Regard each subdivision path in a hypothetical planar drawing as the original edge curve. The explicit finite graph and drawing definitions need only elementary geometric reasoning.
