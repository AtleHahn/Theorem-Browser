Busy Beaver running times eventually exceed every computable function. This demonstrates that precisely defined finite computations can produce growth beyond all effective bounds, rather than merely very large calculable values.

Review status

Statement

For an integer n\ge1, use deterministic Turing machines with n operational states, a separate Halt state, one starting state, a two-way unbounded tape over \{0,1\}, and a transition for each operational state and scanned symbol. Each transition writes a bit, moves one cell left or right, and enters a state (possibly Halt). The machine starts on an all-zero tape. Among machines that halt, \Sigma(n) is the largest number of ones left on the tape, and S(n) the largest number of transitions, including the halting transition. For every total computable f:\mathbb N\to\mathbb N, S(n)>f(n) for all sufficiently large n; in particular S is not computable.

Level
Within undergraduate level
Level justification

The machine model, starting configuration and score are explicitly described through finite transition rules. Understanding computability here means whether such a finite program always returns the required value; the maxima and eventual comparisons use elementary functions and quantifiers. A small machine trace is enough to illustrate the new model, without formal arithmetic or incompleteness theory.

Proof 1: Transfer of Radó domination through the write count

Radó’s score-growth theorem states that Σ(n) exceeds every total computable function for all sufficiently large n.

Radó showed that S is noncomputable for the same reason that Σ is noncomputable – it grows faster than any computable function. He proved this simply by noting that for each n, S(n) ≥ Σ(n). Each shift may write a 0 or a 1 on the tape, while Σ counts a subset of the shifts that wrote a 1, namely the ones that had not been overwritten by the time the Turing machine halted; consequently, S grows at least as fast as Σ, which had already been proved to grow faster than any computable function.

Level
Within undergraduate level
Level justification

Counting surviving ones gives S(n)>=Sigma(n). Applying the stated eventual-domination theorem and then substituting f=S in a contradiction requires only the definition of a total computable function and eventual inequality, a small extension of discrete mathematics.
