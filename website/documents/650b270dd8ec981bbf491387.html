Statement

Let n>1 be odd, with n-1=2^s d where s>0 and d>0 is odd. If an integer a with 1<a<n-1 satisfies a^d\not\equiv1\pmod n and a^{2^r d}\not\equiv-1\pmod n for every 0\le r<s, then n is composite.

Proof 1: A failed repeated-squaring test certifies compositeness

Use the prime-modulus property: if p is odd prime, p-1=2^sd with d odd, and p\nmid a, then either a^d\equiv1\pmod p or a^{2^rd}\equiv-1\pmod p for some 0\le r<s. The Miller–Rabin test uses this property in the following way: given an odd integer n for which primality has to be tested, write n-1=2^sd with s>0 and d odd >0, and choose a such that 1<a<n-1; then compute b=a^d\bmod n. If b is neither 1 nor -1, then square it repeatedly modulo n until you get -1 or have squared s-1 times. If the initial b\ne1 and -1 has not occurred, then n is composite and a is a witness for the compositeness of n.
