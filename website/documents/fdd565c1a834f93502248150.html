Statement

If f is holomorphic on 0<|z-w|<r and has an essential singularity at w, then in every smaller punctured disk around w it attains every complex value, with at most one exception, infinitely often.

Proof 1: Half-plane lift, periodic logarithm and removability — outline

Local auxiliary observation

Suppose F is holomorphic on a simply connected domain and omits 0 and 1. Because the domain is simply connected and the range of F omits 0, F has a holomorphic logarithm. Let G be holomorphic such that F(z)=e^{2\pi iG(z)}. Then the range of G omits all integers. By a similar argument using the quadratic formula, there is a holomorphic function H such that G(z)=\cos(H(z)). Then the range of H omits all complex numbers of the form 2\pi n\pm i\cosh^{-1}(m), where n is an integer and m is a nonnegative integer.

Any sufficiently large disk contains at least one number that the range of H omits, with a uniform radius bound. Landau's disk theorem states that on a disk of radius R centered at w, the range of H contains a disk of radius at least |H'(w)|R/72. The holomorphic-logarithm and square-root facts and Landau's theorem are prerequisites; the source leaves the quadratic-formula construction and omitted-disk estimate as sketches.

Punctured-disk argument

Suppose f is an analytic function on the punctured disk of radius r around the point w, and that f omits two values z0 and z1. By considering (f(w + rz) − z0)/(z1 − z0) we may assume without loss of generality that z0 = 0, z1 = 1, w = 0, and r = 1. The function F(z) = f(e−z) is analytic in the right half-plane Re(z) > 0. Because the right half-plane is simply connected, by the local auxiliary observation, there are analytic functions G and H defined on the right half-plane such that F(z) = e2πiG(z) and G(z) = cos(H(z)). For any w in the right half-plane, the open disk with radius Re(w) around w is contained in the domain of H. By Landau's theorem and the local omitted-value observation, there is a constant C > 0 such that |H′(w)| ≤ C / Re(w). Thus, for all real numbers x ≥ 2 and 0 ≤ y ≤ 2π, {\displaystyle |H(x+iy)|=\left|H(2+iy)+\int _{2}^{x}H'(t+iy)\,\mathrm {d} t\right|\leq |H(2+iy)|+\int _{2}^{x}{\frac {C}{t}}\,\mathrm {d} t\leq A\log x,} where A > 0 is a constant. So |G(x + iy)| ≤ xA. Next, we observe that F(z + 2πi) = F(z) in the right half-plane, which implies that G(z + 2πi) − G(z) is always an integer. Because G is continuous and its domain is connected, the difference G(z + 2πi) − G(z) = k is a constant. In other words, the function G(z) − kz / (2πi) has period 2πi. Thus, there is an analytic function g defined in the punctured disk with radius e−2 around 0 such that G(z) − kz / (2πi) = g(e−z). Using the bound on G above, for all real numbers x ≥ 2 and 0 ≤ y ≤ 2π, {\displaystyle \left|G(x+iy)-{\frac {k(x+iy)}{2\pi i}}\right|\leq x^{A}+{\frac {|k|}{2\pi }}(x+2\pi )\leq C'x^{A'}} holds, where A′ > A and C′ > 0 are constants. Because of the periodicity, this bound actually holds for all y. Thus, we have a bound |g(z)| ≤ C′(−log|z|)A′ for 0 < |z| < e−2. This bound implies zg(z)\to0 as z\to0. By Riemann's removable-singularity criterion, g extends to an analytic function in the open disk of radius e−2 around 0. Hence, G(z) − kz / (2πi) is bounded on the half-plane Re(z) ≥ 3. So F(z)e−kz is bounded on the half-plane Re(z) ≥ 3, and f(z)zk is bounded in the punctured disk of radius e−3 around 0. By Riemann's theorem on removable singularities, f(z)zk extends to an analytic function in the open disk of radius e−3 around 0. Therefore, f does not have an essential singularity at 0. Therefore, if the function f has an essential singularity at 0, the range of f in any open disk around 0 omits at most one value. If f takes a value only finitely often, then in a sufficiently small open disk around 0, f omits that value. So f(z) takes all possible complex values, except at most one, infinitely often.
