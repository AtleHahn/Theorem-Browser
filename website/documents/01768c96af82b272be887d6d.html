Statement

Let a nondegenerate Euclidean triangle have side lengths a,b,c, opposite angles \alpha,\beta,\gamma, and area \Delta. Then a^2=(b-c)^2+4\Delta\tan(\alpha/2).

Level

Level justification

The statement uses only elementary plane geometry, real algebra and trigonometry.

Proof 1: A side-square identity using the opposite half-angle — source argument

From the cosines law we have:

{\displaystyle a^{2}=b^{2}+c^{2}-2bc\cos \alpha }

{\displaystyle \alpha } being the angle between {\displaystyle b} and {\displaystyle c}. This can be transformed into:

{\displaystyle a^{2}=(b-c)^{2}+2bc(1-\cos \alpha )}

Since {\displaystyle \Delta ={\frac {1}{2}}bc\sin \alpha } we have:

{\displaystyle a^{2}=(b-c)^{2}+4\Delta {\frac {(1-\cos \alpha )}{\sin \alpha }}}

Now remember that

{\displaystyle 1-\cos \alpha =2\sin ^{2}{\frac {\alpha }{2}}}

and

{\displaystyle \sin \alpha =2\sin {\frac {\alpha }{2}}\cos {\frac {\alpha }{2}}}

Using this we get:

{\displaystyle a^{2}=(b-c)^{2}+4\Delta \tan {\frac {\alpha }{2}}}

Level justification

Rearrange the cosine rule, substitute area and use the double-angle identities to get the tangent quotient. School algebra and trigonometry suffice.
