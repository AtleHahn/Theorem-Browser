Statement

Let f:X\to Y be a function and L,R arbitrary sets. For any set A, use f(A)=\{f(x):x\in A\cap X\} , f^{-1}(B)=\{x\in X:f(x)\in B\}, and F_y=f^{-1}(\{y\})=\{x\in X:f(x)=y\}. Then f(L\setminus R)=Y\setminus\{y\in Y:L\cap F_y\subseteq R\}=f(L)\setminus\{y\in f(L):L\cap F_y\subseteq R\}.

Level
High school only
Level justification

Image and fiber are explicitly defined, and the assertion tests whether some input in L lies outside R. No infinite-cardinality or abstract set-theory machinery is involved.

Proof 1: Two fiber-membership inclusions and restriction to the image

Let {\displaystyle P:=\left\{y\in Y:L\cap F_y\subseteq R\right\}} and let {\displaystyle (\star )} denote the set equality {\displaystyle f(L\setminus R)=Y\setminus P,} which will now be proven. If {\displaystyle y\in Y\setminus P} then {\displaystyle L\cap F_y\not \subseteq R} so there exists some {\displaystyle x\in L\cap F_y\setminus R;} now {\displaystyle F_y\subseteq X} implies {\displaystyle x\in L\cap X\setminus R} so that {\displaystyle y=f(x)\in f(L\cap X\setminus R)=f(L\setminus R).} To prove the reverse inclusion {\displaystyle f(L\setminus R)\subseteq Y\setminus P,} let {\displaystyle y\in f(L\setminus R)} so that there exists some {\displaystyle x\in X\cap L\setminus R} such that {\displaystyle y=f(x).} Then {\displaystyle x\in L\cap F_y\setminus R} so that {\displaystyle L\cap F_y\not \subseteq R} and thus {\displaystyle y\not \in P,} which proves that {\displaystyle y\in Y\setminus P,} as desired. Defining {\displaystyle Q:=f(L)\cap P=\left\{y\in f(L):L\cap F_y\subseteq R\right\},} the identity {\displaystyle f(L\setminus R)=f(L)\setminus Q} follows from {\displaystyle (\star )} and the inclusions {\displaystyle f(L\setminus R)\subseteq f(L)\subseteq Y.}
