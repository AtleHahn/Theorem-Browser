Statement

A propositional formula \phi involving n variables is not a tautology exactly when it has a falsifying truth assignment. The n truth values form a certificate of length at most linear in |\phi|, verifiable in polynomial time.

Level
Within undergraduate level
Level justification

Propositional truth assignments and evaluating a finite formula are elementary discrete mathematics. Certificate length and polynomial verification mean explicit size and step bounds, adding no complexity-class reductions.

Proof 1: Evaluate the formula on a falsifying assignment — outline

Given a formula \phi in classical propositional logic with propositional variables p_1,\dots,p_n, if it is not a tautology, then this can be proven by simply giving the truth values for the propositional variables p_1,\dots,p_n, such that \phi evaluates to False. The proof size is linear in input size. Verification consists of evaluating \phi on these truth values; its routine polynomial-time bound is implicit in the source.

Level
Within undergraduate level
Level justification

Use a falsifying Boolean assignment and evaluate the formula recursively to check it in polynomial time. Undergraduate discrete mathematics and basic algorithms suffice; the complexity claim requires input-size and runtime notions beyond merely truth tables.
