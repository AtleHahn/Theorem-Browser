Statement

Let C be a closed linear subspace of a real or complex Hilbert space H. Define C^\perp=\{p\in H:\langle p,c\rangle=0\text{ for all }c\in C\}. Then C^\perp is a closed linear subspace and every x\in H has a unique decomposition x=m+p with m\in C and p\in C^\perp; that is, H=C\oplus C^\perp algebraically.

Within undergraduate level

Proof 1: Closed kernel and nearest-point residual

Use the convention that the inner product is linear in its first argument.

Proof that {\displaystyle C\cap C^{\bot }=\{0\}}: If {\displaystyle c\in C\cap C^{\bot }} then {\displaystyle 0=\langle \,c,\,c\,\rangle =\|c\|^{2},} which implies {\displaystyle c=0.} {\displaystyle \blacksquare }

Proof that {\displaystyle C^{\bot }} is a closed vector subspace of {\displaystyle H}: Let {\displaystyle P:=\prod _{c\in C}\mathbb {F} } with the product topology, where {\displaystyle \mathbb {F} } is the underlying scalar field of {\displaystyle H} and define

{\displaystyle {\begin{alignedat}{4}L:\,&H&&\to \,&&P\\&h&&\mapsto \,&&\left(\langle \,h,\,c\,\rangle \right)_{c\in C}\\\end{alignedat}}}

which is continuous and linear because this is true of each of its coordinates {\displaystyle h\mapsto \langle h,c\rangle .} The set {\displaystyle C^{\bot }=L^{-1}(0)=L^{-1}\left(\{0\}\right)} is closed in {\displaystyle H} because {\displaystyle \{0\}} is closed in {\displaystyle P} and {\displaystyle L:H\to P} is continuous. The kernel of any linear map is a vector subspace of its domain, which is why {\displaystyle C^{\bot }=\ker L} is a vector subspace of {\displaystyle H.} {\displaystyle \blacksquare }

Proof that {\displaystyle C+C^{\bot }=H}: Let {\displaystyle x\in H.} The Hilbert projection theorem guarantees the existence of a unique {\displaystyle m\in C} such that {\displaystyle \|x-m\|\leq \|x-c\|{\text{ for all }}c\in C} (or equivalently, for all {\displaystyle x-c\in x-C}). Let {\displaystyle p:=x-m} so that {\displaystyle x=m+p\in C+p} and it remains to show that {\displaystyle p\in C^{\bot }.} The inequality above can be rewritten as:

{\displaystyle \|p\|\leq \|z\|\quad {\text{ for all }}z\in x-C.}

Because {\displaystyle m\in C} and {\displaystyle C} is a vector space, {\displaystyle m+C=C} and {\displaystyle C=-C,} which implies that {\displaystyle x-C=x+C=p+m+C=p+C.} The previous inequality thus becomes

{\displaystyle \|p\|\leq \|z\|\quad {\text{ for all }}z\in p+C.}

or equivalently,

{\displaystyle \|p\|\leq \|p+c\|\quad {\text{ for all }}c\in C.}

By the variational orthogonality criterion for a linear subspace, this last statement is true if and only if {\displaystyle \langle \,p,c\,\rangle =0} for every {\displaystyle c\in C.} Thus {\displaystyle p\in C^{\bot }.} {\displaystyle \blacksquare }
