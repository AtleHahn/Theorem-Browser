Statement

Let R be a commutative Noetherian ring, M a finitely generated R-module and N\subseteq M a submodule. Here \operatorname{Ass}(L) consists of the prime ideals \operatorname{Ann}(u)=\{r:ru=0\} for nonzero u\in L. For each P\in\operatorname{Ass}(M/N) there exists Q_P\subseteq M with \operatorname{Ass}(M/Q_P)=\{P\}, and N=\bigcap_P Q_P. A submodule with this singleton quotient-associated-prime set is called P-primary.

Proof 1: Maximal submodules excluding each associated prime — outline

To show N admits a primary decomposition, by replacing M by M/N, it is enough to show this when N=0. We use the standard associated-prime facts that \operatorname{Ass}(M) is finite, that a module over a Noetherian ring is zero exactly when its associated-prime set is empty, and that

\operatorname{Ass}(U)\subseteq\operatorname{Ass}(V) \subseteq\operatorname{Ass}(U)\cup\operatorname{Ass}(W)

for an exact sequence 0\to U\to V\to W\to0. Also \operatorname{Ass}(R/P)=\{P\} for a prime P. If M=0, the empty intersection gives the result.

Now, for submodules Q_i of M,

\operatorname{Ass}\left(\bigcap_iQ_i\right) \subseteq\bigcap_i\operatorname{Ass}(Q_i), \qquad \operatorname{Ass}\left(\bigcap_iQ_i\right)\subseteq\operatorname{Ass}(M).

Thus 0 has a primary decomposition if, for each associated prime P of M, there is a primary submodule Q such that P\notin\operatorname{Ass}(Q).

Now consider the set

\{U\subseteq M:P\notin\operatorname{Ass}(U)\},

which is nonempty since zero is in it. The set has a maximal element Q since M is a Noetherian module. Since P\in\operatorname{Ass}(M), Q\ne M.

If Q is not P-primary, then, since M/Q\ne0 has an associated prime, some P'\ne P is associated with M/Q. Thus

R/P'\simeq Q'/Q

for some submodule Q'\supsetneq Q. The exact-sequence inclusion gives

\operatorname{Ass}(Q')\subseteq\operatorname{Ass}(Q)\cup\{P'\},

so P\notin\operatorname{Ass}(Q'), contradicting maximality. Thus Q is P-primary.

Taking these submodules for the finitely many P\in\operatorname{Ass}(M) gives an intersection with no associated primes, hence intersection zero. Taking preimages under the original quotient map gives the required decomposition of N.
