Statement

For every finite field F, its Brauer group \operatorname{Br}(F) is zero.

Proof 1: Apply Wedderburn to a division representative — outline

Use the division-algebra description of Brauer classes: each class is represented by a finite-dimensional central division algebra over F. Such an algebra has finitely many elements because F is finite. Wedderburn’s theorem makes every finite division ring commutative. Its center is stipulated to be F, so this division algebra is F itself and its Brauer class is trivial.
