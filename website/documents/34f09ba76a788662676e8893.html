Statement

Let B be a ball contained in an open set \Omega\subset\mathbb R^n, integer m\ge1, and \psi\in C_c^\infty(B) with \psi\ge0 and \int_B\psi=1. Multiindices have nonnegative integer components, \alpha!=\prod_i\alpha_i!, and x^\alpha=\prod_i x_i^{\alpha_i}. For x,y\in\mathbb R^n, define coefficients a_{\gamma,\beta} by (x-y)^\alpha=\sum_{\gamma+\beta=\alpha}a_{\gamma,\beta}x^\gamma y^\beta. For u\in W^{m-1,p}(\Omega), 1\le p\le\infty, define T_y^m u(x)=\sum_{|\alpha|<m}D^\alpha u(y)(x-y)^\alpha/\alpha! and Q^m u(x)=\int_B T_y^m u(x)\psi(y)\,dy. Then

{\displaystyle {\begin{aligned}Q^{m}u(x)&=\sum \limits _{\vert \alpha \vert <m}\sum \limits _{\gamma +\beta =\alpha }{\frac {1}{\alpha !}}a_{\gamma ,\beta }x^{\gamma }\int _{B}D^{\alpha }u(y)y^{\beta }\psi (y)\operatorname {d} y\\&=\sum _{|\alpha |<m}\sum _{\gamma +\beta =\alpha }{\frac {(-1)^{\vert \alpha \vert }}{\alpha !}}a_{\gamma ,\beta }x^{\gamma }\int _{B}u(y)D^{\alpha }\left[y^{\beta }\psi (y)\right]\operatorname {d} y.\end{aligned}}}
Level
Beyond undergraduate level
Level justification

The identity represents weak derivatives integrated against smooth test functions using a multiindex polynomial expansion.

Level
Beyond undergraduate level
Level justification

Expanding the finite monomials is elementary, but the proof is for Sobolev functions with weak derivatives, not classically differentiable functions. Understanding the integrals, test functions, almost-everywhere derivatives and distributional integration-by-parts identity requires measure and Sobolev theory beyond the baseline. The smooth special case would have a lower prerequisite burden.

Statement used:

If D^alpha u is a weak derivative and phi is smooth with compact support in the domain, integral D^alpha u times phi=(-1)^|alpha| integral u D^alpha phi.

Application in proof:

Use phi(y)=y^beta psi(y), which is smooth and compactly supported in B, for each finite coefficient.

Application level:

Beyond undergraduate level

Level justification:

The application is the defining weak-derivative identity in Sobolev spaces, not ordinary classical integration by parts.

Review notes:

Compact support removes boundary terms. The Sobolev derivatives are locally integrable, so every coefficient integral is defined.
