Statement

Let \mu be a finite nonnegative Borel measure on a real interval (s,t). For n\ge1, let A_n=\{(s_1,\ldots,s_n)\in(s,t)^n:s_1<\cdots<s_n\}. Then \mu^{\otimes n}(A_n)\le\mu((s,t))^n/n!, with equality when \mu is atomless. For n=0 both quantities are defined as 1.

Proof 1: Partition the product cube by coordinate order

For n=0, the claim is true by our definitions. Therefore, consider n\ge1 in the following. Put I_{s,t}=(s,t).

Let S_n denote the set of all permutations of the indices in \{1,2,\ldots,n\}. For every permutation \sigma\in S_n define

A_{n,\sigma}(s,t)= \{(s_1,\ldots,s_n)\in I_{s,t}^n: s_{\sigma(1)}<s_{\sigma(2)}<\cdots<s_{\sigma(n)}\}.

These sets are disjoint for different permutations and

\bigcup_{\sigma\in S_n}A_{n,\sigma}(s,t)\subset I_{s,t}^n.

Therefore,

\sum_{\sigma\in S_n}\mu^{\otimes n}(A_{n,\sigma}(s,t)) \le\mu^{\otimes n}(I_{s,t}^n) =\bigl(\mu(I_{s,t})\bigr)^n.

Since they all have the same measure with respect to the n-fold product of \mu, and since there are n! permutations in S_n, the claimed inequality follows.

Assume now that \mu is atomless. Then, for different indices i,j\in\{1,2,\ldots,n\}, the set

\{(s_1,\ldots,s_n)\in I_{s,t}^n:s_i=s_j\}

has measure zero with respect to the n-fold product of \mu, by an application of Fubini's theorem: each singleton section in the ith coordinate has measure zero. Since

I_{s,t}^n\subset \bigcup_{\sigma\in S_n}A_{n,\sigma}(s,t) \cup\bigcup_{1\le i<j\le n} \{(s_1,\ldots,s_n)\in I_{s,t}^n:s_i=s_j\},

the claimed equality follows.
