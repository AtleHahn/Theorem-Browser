Statement

There is a bijection between [0,2) and [0,1)^2. Here a bijection is a function assigning each target point to exactly one domain point.

Level
Within undergraduate level
Level justification

Bijections involving infinite sets and preservation of order are introductory undergraduate set-theoretic concepts. A bright US college student should be able to understand the statement after about 30 minutes of focused background research; this rating concerns understanding the claim, not proving it.

Proof 1: Digit interleaving and mutual injections — outline

Let f:[0,2)\to[0,1)^2 with f(x)=(x/2,0); this is injective.

Then for (x,y)\in[0,1)^2 one can use the expansions

x=\sum_{k=1}^{\infty}a_k\cdot10^{-k}, \qquad y=\sum_{k=1}^{\infty}b_k\cdot10^{-k}, \qquad a_k,b_k\in\{0,1,\ldots,9\},

using the representations that are not eventually nine, and now one can set

g(x,y)=\sum_{k=1}^{\infty}(10\cdot a_k+b_k)\cdot10^{-2k},

which defines an injective function [0,1)^2\to[0,2). The odd and even digits recover x and y. For example,

g\left(\frac13,\frac23\right)=0.363636\ldots=\frac4{11}.

And therefore a bijective function h can be constructed with the use of f and g^{-1}, by the Schröder–Bernstein theorem.
