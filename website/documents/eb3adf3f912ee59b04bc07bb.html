Statement

Let X\subseteq\mathbb R^n contain N\geq2 points, 0<\varepsilon<1, and 0<\delta<N^{-2}. Suppose a distribution of real k\times n matrices A satisfies \Pr(|\|Az\|^2-1|>\varepsilon)<\delta for every fixed unit vector z\in\mathbb R^n. Then some linear map f:\mathbb R^n\to\mathbb R^k satisfies (1-\varepsilon)\|u-v\|^2\leq\|f(u)-f(v)\|^2\leq(1+\varepsilon)\|u-v\|^2 for every u,v\in X.

Level
Within undergraduate level
Level justification

Matrices, unit vectors and norm distortion are undergraduate linear algebra. A distribution here assigns probabilities to matrix choices and the hypothesis bounds one event for each fixed vector; learning this elementary probability meaning is a small extension, with no random-matrix spectral or convergence theory.

Proof 1: Union bound over normalized pair differences

For each distinct pair u,v\in X, apply the distributional guarantee to z=(u-v)/\|u-v\|. The union bound over all pairs shows that the probability of any failed bound is less than N^2\delta<1. Choose a matrix for which no bound fails, and put f(x)=Ax. Multiply the unit-vector inequalities by \|u-v\|^2 and use linearity. For u=v both sides vanish.

Level
Within undergraduate level
Level justification

Normalize each finite pair difference, use the finite union bound to obtain positive success probability, then rescale using matrix linearity. Undergraduate linear algebra and elementary probability suffice; no measure-theoretic random-matrix theory is used.
