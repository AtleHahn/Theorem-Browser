Statement

For an integer r\ge1, an intersecting family of r-element subsets of a 2r-element set has at most \frac12\binom{2r}{r}=\binom{2r-1}{r-1} members. This bound is attained by choosing exactly one set from each complementary pair; these choices are precisely the maximum families.

Level
High school only
Level justification

Proof 1: Pair complementary half-size subsets — outline

Pair each r-element set with its complement, the only r-element set disjoint from it. An intersecting family contains at most one from each pair. Choosing one from every pair gives an intersecting family of half the total size, namely \binom{2r-1}{r-1}.
