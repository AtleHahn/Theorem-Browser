A supply rule generated by maximizing a fixed feasible set satisfies a zero-integral restriction around price cycles. This gives observable content to a model of rational choice, while the restriction is only a necessary consequence here and does not establish that agents actually optimize.

Statement

Let X\subseteq\mathbb R^L be bounded and let x^*(p) maximize p\cdot x over X for every price p on a differentiable closed path \gamma:[0,1]\to\mathbb R^L with bounded derivative. Then \int_0^1x^*(\gamma(s))\cdot\gamma^\prime(s)\,ds=0, with the integral understood in the envelope sense as a Lebesgue path integral.

Level
Beyond undergraduate level
Level justification

The selected supply vector need not be continuous; the asserted integral uses the measure-theoretic envelope result.

Proof 1: Substitute the linear production objective

Apply the closed-path envelope identity for the objective f(x,t)=t\cdot x. Its parameter gradient is x, so the selected gradient in that identity is the supply vector x^*(t).

Level
Beyond undergraduate level
Level justification

Substitute a linear objective into the envelope identity for a bounded optimizer selection and a Lebesgue path integral. Measurability and generalized envelope integration exceed elementary differentiable optimization and are essential to this stated generality.
