Statement

The entire function f(z)=\sin(\pi z) does not satisfy the strict exponential-type hypothesis \tau<\pi of the version of Carlson's theorem stated in the source. Here \tau is the infimum of real \alpha for which |f(re^{i\theta})|\le M e^{\alpha r} for some constant M, uniformly in \theta for all sufficiently large r.

Level
Within undergraduate level
Level justification

Complex sine has its familiar power series/exponential definition, and entire means complex differentiable everywhere. The growth parameter is explicitly an infimum of exponential bounds. Calculus and real analysis suffice after these direct definitions.

Proof 1: Compare the sine type with the strict threshold

Use the source-stated fact that \sin(\pi z) has exponential type \pi. The Carlson hypothesis in question requires type strictly less than \pi. Since the type is equal to that threshold, this function fails the hypothesis, so that version of the theorem cannot be applied to it.
