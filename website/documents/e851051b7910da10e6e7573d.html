Statement

Let f:I\to\mathbb R^d be continuous on an open interval I=(a,b), where d\ge1. If the vector integral \int_a^b f(x)h(x)\,dx is zero for every smooth compactly supported scalar function h, then f=0.

Level
Within undergraduate level
Level justification

Understanding the statement involves Continuous real functions; Smooth compactly supported test functions; Integration; Differentiation; Finite-dimensional vector-valued integration. These prerequisites fit undergraduate coursework or a brief extension of it. A bright US college student should be able to understand this statement after approximately 30 minutes of focused background research; this assesses understanding the claim, not its proof.

Proof 1: Apply the scalar result coordinate by coordinate

The scalar fundamental lemma states that a continuous real-valued function whose integral against every smooth compactly supported test function is zero must vanish.

Generalization to vector-valued functions (a,b)\to\mathbb R^d is straightforward; one applies the result for scalar functions to each coordinate separately.
