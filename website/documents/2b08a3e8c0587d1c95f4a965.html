Statement

Let f:X\to Y be constant with value y, and let L,R\subseteq X be nonempty disjoint sets. Then f(L\cap R)=\varnothing\subsetneq f(L)\cap f(R)=\{y\}.

Level

Level justification

Constant maps and intersections are elementary function/set notions.

Proof 1: Compare singleton images with the empty set

Let f:X\to Y be any constant function with image f(X)=\{y\} and suppose that L,R\subseteq X are non-empty disjoint subsets; that is, L\ne\varnothing, R\ne\varnothing, and L\cap R=\varnothing.

The containment f(L\cap R)\subsetneq f(L)\cap f(R) is strict:

\varnothing=f(\varnothing)=f(L\cap R)\ne f(L)\cap f(R) =\{y\}\cap\{y\}=\{y\}.

In words: functions might not distribute over set intersection \cap (which can be defined as the set subtraction of two sets: L\cap R=L\setminus(L\setminus R)).

Level
High school only
Level justification

The disjoint intersection has empty image, but both nonempty sets have the same singleton image, whose intersection is nonempty. This is elementary set arithmetic.
