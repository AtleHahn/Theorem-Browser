Statement

Let G=(V,E) be a finite undirected graph, allowing repeated edges and loops. Its vertices form V, and each edge has two ends attached to vertices. Write d(v) for the number of attached ends, counting a loop twice. Every odd-degree vertex has a path to a different odd-degree vertex, where a path follows successive edges between vertices.

Level
High school only
Level justification

Graph vertices, edges and degrees are locally explained; proofs use finite counting, parity and induction.

Proof 1: Every odd-degree vertex is connected to another

Apply the handshaking lemma to the connected component of the given odd-degree vertex. It has an even number of odd vertices, so it cannot have just the one given vertex. By the definition of connected component a path joins it to another odd vertex.

Level
High school only
Level justification

Apply handshaking parity within the given connected component and use its path definition. Elementary finite counting suffices.
