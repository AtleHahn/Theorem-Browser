Statement

Let V be a polynomial-time Boolean-proof verifier which, on inputs of length n, uses r(n)=O(\log n) uniformly random bits and queries at most a constant q proof bits nonadaptively. For a fixed input x, there is a polynomial-size Boolean constraint system with one constraint per random string and at most q variables per constraint, such that for every proof assignment its fraction of satisfied constraints equals V’s acceptance probability on that assignment. In particular, a proof accepted for every random string satisfies all constraints simultaneously.

Within undergraduate level
Level justification

The verifier model is specified through random bits, fixed queries and Boolean acceptance tests. Polynomial-time algorithm bounds and Boolean constraint encoding add a limited computational definition to finite counting.

Proof 1: One constraint per verifier random string — outline

Checking a constant number of bits q in a proof can be seen as evaluating a constraint in q Boolean variables on those bits of the proof. The verification algorithm is nonadaptive: the choice of bits of the proof to check depends only on the random bits and the description of the problem instance, not the actual bits of the proof.

Since the verification algorithm uses O(\log n) bits of randomness, it can be represented as a Boolean constraint system with polynomially many constraints, each corresponding to a particular value for the random bits. A proof accepted for every random string gives one assignment satisfying all constraints simultaneously. For any proof assignment, the fraction of constraints it satisfies is the fraction of random strings on which the verifier accepts, and hence, since the random bits are uniform, its acceptance probability.
