Statement

Let M be a model of Peano arithmetic presented on domain \mathbb N, with addition \oplus and distinguished codes n_0,n_1 for zero and one. For a\in M, let S_a=\{n\in\mathbb N:M\models p_n\mid a\}, where p_n is the standard nth prime interpreted in M. Then S_a is computable using \oplus as an oracle, with a,n_0,n_1 fixed parameters.

Proof 1: Search for the remainder using repeated addition

Because of the way the prime-coded set is defined, it is possible to compute its characteristic function using the addition function \oplus of M as an oracle. In particular, if n_0 is the element of M corresponding to 0, and n_1 is the element of M corresponding to 1, then for each i\in\mathbb N we can compute

n_i=\underbrace{n_1\oplus\cdots\oplus n_1}_{i\text{ times}},

using n_0 when i=0. To decide if a number n is in S_a, first compute p, the nth prime in \mathbb N. Then, search through the domain codes for an element y of M so that

a=\underbrace{y\oplus y\oplus\cdots\oplus y}_{p\text{ times}}\oplus n_i

for some 0\le i<p. Each tested equality is decidable using the addition oracle. This search will halt because division with remainder can be applied in any model of PA. Finally, we have n\in S_a if and only if the i found in the search was 0.
