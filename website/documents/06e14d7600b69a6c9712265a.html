Statement

Fix an effective programming system enumerating the partial computable functions \varphi_e:\mathbb N_0\rightharpoonup\mathbb N_0, and a Blum complexity measure (\Phi_e) for this system. For a total computable bound b:\mathbb N_0\to\mathbb N_0, define

\mathcal C_\Phi(b)=\{f:\mathbb N_0\to\mathbb N_0\text{ total computable}:\exists e\ [\varphi_e=f\text{ and }\Phi_e(x)\leq b(x)\text{ for all sufficiently large }x]\}.

For every total computable g:\mathbb N_0\to\mathbb N_0 with g(n)\geq n for every n, there is a total computable t:\mathbb N_0\to\mathbb N_0 such that

\mathcal C_\Phi(t)=\mathcal C_\Phi(g\circ t).

Here \mathbb N_0=\{0,1,2,\ldots\}. A partial computable function is one evaluated by a program, possibly not halting on some inputs; total means halting on every input. A Blum measure consists of partial numerical cost functions with the same domains as their respective programs, such that an algorithm, given e,x,c, decides whether \Phi_e(x)\leq c (false when undefined). The bound convention in this statement allows finitely many exceptional inputs for each program. The argument x is the encoded input, not its bit length. No resource-constructibility requirement on t is asserted.
