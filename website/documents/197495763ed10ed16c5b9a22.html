Statement

Over ZF, the axiom of choice is equivalent to the assertion that every directed-complete partial order with a least element has a maximal element. Directed-complete means that every nonempty directed subset has a least upper bound.

These statements quantify over arbitrary sets and partial orders and use set-theoretic choice principles, beyond the permitted elementary and calculus backgrounds.

Proof 1: Transfinite maximality and directed partial choice functions

Choice implies the maximal-element principle

Let {\displaystyle P} be a partially ordered set in which each chain, including the empty chain, has an upper bound. Define the function

{\displaystyle f:P\to P}

by {\displaystyle f(x)=x} if {\displaystyle x} is a maximal element and {\displaystyle f(x)=c(\{y\mid y>x\})} otherwise, where

{\displaystyle c:{\mathcal {P}}(P)-\{\emptyset \}\to P}

is a choice function; namely, {\displaystyle c(S)\in S}. Note a maximal element of {\displaystyle P} is exactly a fixed point of {\displaystyle f}. Thus, the proof is equivalent to finding a fixed point of {\displaystyle f}.

Informally, we are going to construct a very long sequence (transfinite sequence) by repeatedly applying {\displaystyle f}. That is, first pick some {\displaystyle x_{0}} in {\displaystyle P}, possible since {\displaystyle P} is nonempty. Then let {\displaystyle x_{1}=f(x_{0})} and then let {\displaystyle x_{2}=f(x_{1})} and so on. If we have used up all the natural numbers, then, to continue, we let

{\displaystyle x_{\omega }=c(\{{\text{upper bounds of the chain }}\,x_{0}\leq x_{1}\leq \cdots \})}

where {\displaystyle \omega =\{0,1,2,\cdots \}}. Then let {\displaystyle x_{\omega +1}=f(x_{\omega })} and so on. This procedure yields a sequence of length {\displaystyle \alpha } for each ordinal {\displaystyle \alpha },

{\displaystyle x_{0}\leq x_{1}\leq \cdots \leq x_{\omega }\leq x_{\omega +1}\leq \cdots }

Note as long as the sequence is strictly increasing, the map {\displaystyle \alpha \to P,\,\beta \mapsto x_{\beta }} is injective. But a set cannot contain a subset of greater cardinality. So, if the sequence is too long, it cannot be strictly increasing and a term in the sequence such that {\displaystyle x_{\beta }=x_{\beta +1}} is a fixed point of {\displaystyle f} (that is, a maximal element of {\displaystyle P}).

Formally, the above sequence is defined using transfinite recursion. It is exactly like the usual recursive definition of a sequence but runs over ordinals. A key difference is that an ordinal may be a limit ordinal, like {\displaystyle \omega }. For a limit ordinal {\displaystyle \alpha }, as above, we take {\displaystyle x_{\alpha }} to be some upper bound of the sequence {\displaystyle x_{\beta },\beta <\alpha } via {\displaystyle c}. (See also Transfinite recursion theorem § Example: a proof of Zorn's lemma for more details on this kind of recursive construction.) Finally, we need a sufficiently large ordinal. By the axiom of choice in the form of the well-ordering theorem, we can find an ordinal {\displaystyle \kappa } that is bijective with {\displaystyle P.} Take {\displaystyle \alpha =\kappa ^{+}}, the successor cardinal (= least ordinal whose cardinality is larger than {\displaystyle \kappa }). Then, for the reason of cardinality, {\displaystyle \kappa ^{+}\not \hookrightarrow P,\,\beta \mapsto x_{\beta }}; i.e., the sequence {\displaystyle x_{\beta }} is not strictly increasing and so some term in it is a fixed point. (Incidentally, this {\displaystyle \kappa ^{+}} is called the Hartogs number of {\displaystyle P}.)

A nonempty chain is directed, and the least element bounds the empty chain, so this establishes the principle for a dcpo with a least element.

The maximal-element principle implies choice

Given a set {\displaystyle X} of nonempty sets and its union {\displaystyle U:=\bigcup X} (which exists by the axiom of union), we want to show there is a function

{\displaystyle f:X\to U}

such that {\displaystyle f(S)\in S} for each {\displaystyle S\in X}. For that end, consider the set

{\displaystyle P=\{f:Y\to U\mid Y\subset X,f(S)\in S{\text{ for each }}S\in Y\}}.

It is partially ordered by extension; i.e., {\displaystyle f\leq g} if and only if {\displaystyle f} is the restriction of {\displaystyle g}.

Set Y=\bigcup_iY_i for the domains of the directed family below.

Let {\displaystyle f_{i}:Y_{i}\to U} be a directed set in {\displaystyle P}. For each {\displaystyle i,j}, there is a {\displaystyle k\geq i,j} by directedness. That is, the pair {\displaystyle f_{i},f_{j}} has a common extension {\displaystyle f_{k}}; in particular, {\displaystyle f_{i},f_{j}} agree on {\displaystyle Y_{i}\cap Y_{j}}. Hence, we can define {\displaystyle f} on {\displaystyle Y} by {\displaystyle f|_{Y_{i}}=f_{i}}.

The union is its least upper bound under extension, and the empty partial function is a least element. Hence, by the assumed dcpo maximal-element principle, there is a maximal element {\displaystyle f} in {\displaystyle P} that is defined on some {\displaystyle Y\subset X}. We want to show {\displaystyle Y=X}. Suppose otherwise; then there is a set {\displaystyle S\in X-Y}. As {\displaystyle S} is nonempty, it contains an element {\displaystyle s}. We can then extend {\displaystyle f} to a function {\displaystyle g} on {\displaystyle Y\cup \{S\}} by setting {\displaystyle g|_{Y}=f} and {\displaystyle g(S)=s}. (Note this step does not need the axiom of choice.) The function {\displaystyle g} is in {\displaystyle P} and {\displaystyle f<g}, a contradiction to the maximality of {\displaystyle f}. {\displaystyle \square }
