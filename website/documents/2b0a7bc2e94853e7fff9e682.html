Statement

Let G be a discrete group with identity e, let A be a finite alphabet, and give A^G its discrete-coordinate product topology. Use the left shift action (g\cdot x)(h)=x(g^{-1}h). A map f:A^G\to A^G is continuous and G-equivariant if and only if there are a finite N\subset G and \mu:A^N\to A with f(x)(g)=\mu((x(gn))_{n\in N}) for every g\in G.

Level
Within undergraduate level
Level justification

Basic topology supplies products of discrete spaces and continuity; algebra supplies the group action. The shift and finite local rule are explicitly defined coordinate operations. Equivariance means commuting with those shifts, a small extension of familiar function composition.

Proof 1: The cylinder-subcover argument on group positions — outline

The function f that uses the finite local rule to map a configuration of the cellular automaton into its successor configuration is necessarily equivariant with respect to the left shift action of G, by the assumption that all positions use the same update rule. It is also necessarily continuous in the product topology: if p is a fixed pattern, defining a fundamental open set P, then f−1(P) is defined by a finite set of patterns, the assignments to cells in the neighborhood of p that cause f to produce p.

Suppose f is a continuous G-equivariant function on the configuration space A^G. For each configuration x, let p be the pattern consisting of the single symbol that appears at the identity position e of f(x). By continuity of f, there must exist a finite pattern q in x such that, if the positions outside q are changed arbitrarily but the positions within q are fixed to their values in x, then the result of applying f remains the same at the identity position e. Equivalently, there must exist a fundamental open set Qx such that x belongs to Qx and such that for every configuration y in Qx, f(x) and f(y) have the same value at the identity position e. These fundamental open sets Qx (for all possible configurations x) form an open cover of the configuration space A^G. However, the configuration space A^G is a compact space: it is a product of finite topological spaces with the alphabet as their points, so compactness follows from Tychonoff's theorem. By compactness, every open cover has a finite subcover. The finite set of positions appearing in this finite subcover may be used as the neighborhood of the identity position e in a description of f as a cellular automaton rule. Equivariance gives f(x)(g)=f(g^{-1}\cdot x)(e), hence the local rule with inputs (x(gn))_{n\in N} in the statement.
