Statement

Enumerate the rationals of [0,1] as q_1,q_2,\ldots, and let f_n=1_{\{q_1,\ldots,q_n\}}. These functions are Riemann integrable, satisfy |f_n|\le1, and converge pointwise to 1_{\mathbb Q\cap[0,1]}, which is Lebesgue integrable but not Riemann integrable.

Level
Within undergraduate level
Level justification

Riemann integrability and pointwise convergence are baseline analysis. For the Lebesgue assertion only countable null sets and their indicator integrals add a limited measure definition.

Proof 1: Enumerate the rationals and grow finite indicator supports — outline

Use the prescribed enumeration and put value one on the first n rational points, zero elsewhere. Every rational eventually receives value one, whereas every irrational always receives zero. The limit is the Dirichlet function. The finite-support functions are Riemann integrable; the Dirichlet function is Lebesgue integrable but not Riemann integrable.

Level
Within undergraduate level
Level justification

Track the finite rational supports and use the supplied integrability facts. Undergraduate Riemann analysis and countability suffice with the single null-indicator extension: a countable set has Lebesgue measure zero and its indicator integrates to zero. No general Lebesgue convergence theorem is used.
