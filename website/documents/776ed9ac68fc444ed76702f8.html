Every first-order validity can eventually be found by exhaustive proof search. This makes validity semidecidable, while giving no terminating verdict for every invalid formula and no practical bound on search time.

Statement

In first-order predicate logic over an effectively presented signature, the set of logically valid formulas is computably enumerable: with unbounded time, an exhaustive proof search eventually proves each valid formula.

Proof 1: Completeness and proof enumeration outline

For a first-order predicate calculus, Gödel's completeness theorem states that the theorems (provable statements) are exactly the semantically valid well-formed formulas, so the valid formulas are computably enumerable: given unbounded resources, any valid formula can eventually be proven.

Level justification
