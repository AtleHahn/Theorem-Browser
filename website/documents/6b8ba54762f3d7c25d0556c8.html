Statement

Let D=\{z\in\mathbb C:|z|<1\}. For a sequence of open sets U_n\subseteq\mathbb C containing zero, let V_n be the connected component containing zero of the interior of \bigcap_{j\ge n}U_j; take V_n=\varnothing if zero is not in that interior. Its kernel is \bigcup_n V_n if this union is nonempty, and \{0\} otherwise. The sequence converges to its kernel if every subsequence has the same kernel.

Let f_n:D\to\mathbb C be injective holomorphic functions with f_n(0)=0 and f_n'(0)>0 real, and set U_n=f_n(D). Then (f_n) converges uniformly on every compact subset of D to a function f if and only if (U_n) converges to a kernel U\ne\mathbb C.

If U=\{0\} then f=0. Otherwise U is a connected open set, f is injective and holomorphic, and f(D)=U.
