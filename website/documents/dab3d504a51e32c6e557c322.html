Statement

Let n\geq1 be an integer, and let a,b\in\mathbb R^n be written in nonincreasing order. For x_1,\ldots,x_n>0, define

[a](x)=\frac1{n!}\sum_{\sigma\in S_n}\prod_{i=1}^n x_{\sigma(i)}^{a_i},

where S_n is the set of permutations of \{1,\ldots,n\}, and define [b](x) in the same way.

The inequality [a](x)\leq[b](x) holds for every positive tuple x if and only if

\sum_{i=1}^k a_i\leq\sum_{i=1}^k b_i\quad(1\leq k<n),\qquad \sum_{i=1}^n a_i=\sum_{i=1}^n b_i.

These conditions say that b majorizes a. When they hold, equality for a given positive tuple x occurs if and only if a=b or x_1=\cdots=x_n.

Sorting the exponent vectors does not change their symmetric means, so this formulation applies to arbitrary real exponent vectors after sorting.
