Statement

Let m,n>0 be integers, a,b\in\mathbb Z, g=\gcd(m,n) and M=\operatorname{lcm}(m,n)=mn/g. The congruences x\equiv a\pmod m, x\equiv b\pmod n have a solution exactly when g\mid a-b. If g=um+vn, then x_0=(avn+bum)/g is a solution in that case, and all solutions are x_0+Mt with t\in\mathbb Z.

Proof 1: The gcd Bézout formula — outline

If a\equiv b\pmod g, then this system has a unique solution modulo M=mn/g. Otherwise, it has no solutions.

If one uses Bézout's identity to write g=um+vn, then a solution is given by

x=\frac{avn+bum}{g}.

This defines an integer, as g divides both m and n.

The set of solutions forms a single congruence class modulo M. That is, any two solutions differ by a multiple of M, and adding a multiple of M to a solution gives another solution. The source leaves the verification of the two residues, the necessity of the gcd condition, and the uniqueness claim implicit.
