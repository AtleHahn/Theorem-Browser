Statement

Let R be a real closed ordered field (every positive element is a square and every odd-degree polynomial has a root). Let F=\{f_1,\ldots,f_m\} and G=\{g_1,\ldots,g_r\} be finite subsets of R[x_1,\ldots,x_n]. Write W=\{x\in R^n:f_j(x)\ge0\text{ for all }j,\ g_\ell(x)=0\text{ for all }\ell\} and

P(F,G)=\left\{\sum_{\alpha\in\{0,1\}^m}\sigma_\alpha\prod_{j=1}^m f_j^{\alpha_j}+\sum_{\ell=1}^r h_\ell g_\ell\right\},

where each \sigma_\alpha is a finite sum of squares of polynomials over R and each h_\ell is any polynomial over R. Empty products are one and empty sums zero. Let H be another finite set of polynomials. The set

\{x\in W:h(x)\ne0\text{ for all }h\in H\}

is empty if and only if there exist q\in P(F,\varnothing), g in the ideal generated by G (so g=\sum_\ell h_\ell g_\ell), and an integer s\ge0 such that

q+g+\left(\prod_{h\in H}h\right)^{2s}=0.

At exponent zero the polynomial power is one.
