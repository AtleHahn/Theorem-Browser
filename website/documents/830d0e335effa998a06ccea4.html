Statement

Let t_n count isomorphism classes of finite rooted trees with n non-leaf nodes, each non-leaf node having exactly three unordered children, and let F(t)=\sum_{n\ge0}t_nt^n. Then F(t)=1+\frac t6\bigl(F(t)^3+3F(t)F(t^2)+2F(t^3)\bigr). Equivalently t_0=1 and t_{n+1}=\tfrac16(\sum_{a+b+c=n}t_at_bt_c+3\sum_{a+2b=n}t_at_b+2\sum_{3a=n}t_a), where all indices are nonnegative integers.

Level justification

Finite rooted trees, isomorphism and ordinary generating functions are undergraduate combinatorics. Every counting convention and the equivalent recurrence is explicit, requiring no species or group-representation theory.

Proof 1: Enumerator for rooted unordered ternary trees — proof

One can view a rooted, ternary tree as a recursive object which is either a leaf or a node with three children which are themselves rooted ternary trees. The children may be permuted; the cycle index of the symmetric group S3 that acts on them is

{\displaystyle Z_{S_{3}}(t_{1},t_{2},t_{3})={\frac {t_{1}^{3}+3t_{1}t_{2}+2t_{3}}{6}}.}

The Polya enumeration theorem translates the recursive structure of rooted ternary trees into a functional equation for the generating function F(t) of rooted ternary trees by number of nodes. This is achieved by "coloring" the three children with rooted ternary trees, weighted by node number, so that the color generating function is given by {\displaystyle f(t)=F(t)} which by the enumeration theorem gives

{\displaystyle {\frac {F(t)^{3}+3F(t)F(t^{2})+2F(t^{3})}{6}}}

as the generating function for rooted ternary trees with a non-leaf root, weighted by one less than the node number (since the sum of the children weights does not take the root into account), so that

{\displaystyle F(t)=1+t\cdot {\frac {F(t)^{3}+3F(t)F(t^{2})+2F(t^{3})}{6}}.}

This is equivalent to the following recurrence formula for the number tn of rooted ternary trees with n nodes:

{\displaystyle {\begin{aligned}t_{0}&=1\\t_{n+1}&={\frac {1}{6}}\left(\sum _{a+b+c=n}t_{a}t_{b}t_{c}+3\sum _{a+2b=n}t_{a}t_{b}+2\sum _{3a=n}t_{a}\right)\end{aligned}}}

where a, b and c are nonnegative integers.
