Statement

Let p\equiv1\pmod4 be prime and let g be a primitive root modulo p, so every nonzero residue is a unique power g^k, 0\le k<p-1. The four sets C_j=\{g^{4t+j}:0\le t<(p-1)/4\}, j=0,1,2,3, partition the nonzero residues into equal parts. The quartic residues are C_0, the squares are C_0\cup C_2, and the nonsquares are C_1\cup C_3.

Level
High school only
Level justification

Primitive-root terminology is fully specified by the finite list of powers, so the statement is elementary modular arithmetic.

Proof 1: Partition the primitive-root indices modulo four — outline

Let g be the given primitive root modulo p. The first set is all the numbers whose indices with respect to this root are congruent to 0 modulo 4, the second set is all those whose indices are congruent to 1 modulo 4, etc. These are the four sets C_0,C_1,C_2,C_3, each containing (p-1)/4 numbers.

The first set is the biquadratic (quartic) residues, the third set is the quadratic residues that are not quartic residues, and the second and fourth sets are the quadratic nonresidues. The source leaves the exponent and equal-cardinality checks implicit.
