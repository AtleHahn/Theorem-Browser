Statement

Assume choice. Let P be a partially ordered set of finite width w\ge1, meaning that its largest size of a pairwise incomparable subset is w. Then the minimum number of chains partitioning P is w, where a chain is a subset whose elements are pairwise comparable.

Level
Within undergraduate level
Level justification

Partial orders, chains, antichains and countability are undergraduate set/order concepts. A chain means pairwise comparable and an antichain pairwise incomparable; selection principles, where assumed, are explicit hypotheses. These short definitions suffice for the quantified existence or partition claim.

Proof 1: Color the incomparability graph — outline

A partition into chains may be interpreted as a coloring of the incomparability graph of the partial order. This is a graph with a vertex for each element of the order and an edge for each pair of incomparable elements. Using this coloring interpretation, together with the finite Dilworth theorem (the minimum number of chains equals the maximum size of an antichain), every finite induced subgraph is w-colorable. The De Bruijn–Erdős theorem, which states that a graph is w-colorable if every finite subgraph is, gives the required partition into w chains. An antichain of size w shows that fewer chains cannot suffice.
