Statement

Let (S,d) and (S',d') be metric spaces, and let X_n,X be S-valued random elements on a common probability space. Let g:S\to S' be such that g(X_n),g(X) are random elements and the distances d(X_n,X) and d'(g(X_n),g(X)) are measurable. Let D_g be the discontinuity set of g and assume \Pr(X\in D_g)=0. If X_n\to X in probability, then g(X_n)\to g(X) in probability.

Proof 1: Use countably many measurable continuity events

Fix an arbitrary \varepsilon>0. By assumption, we have \Pr(\bigcup_{k\geq1}A_k)=1, where A_k is the event “for all n\geq1 such that d(X_n,X)\leq1/k, we have d'(g(X_n),g(X))<\varepsilon”:

A_k=\bigcap_{n\geq1}\left\{d(X_n,X)\leq\frac1k\ \Rightarrow\ d'(g(X_n),g(X))<\varepsilon\right\}.

These events are measurable by the distance-measurability assumptions; the probability-one assertion follows from continuity at X outside X\in D_g.

Now, fix an arbitrary \eta>0. Since the sequence (A_k)_{k\geq1} is non-decreasing, we have

\Pr\left(\bigcup_{k\geq1}A_k\right)=\lim_{k\to\infty}\Pr(A_k),

hence there exists k\geq1 such that \Pr(A_k)\geq1-\eta. Finally, we can write

\Pr(d'(g(X_n),g(X))\geq\varepsilon) \leq\eta+\Pr(d'(g(X_n),g(X))\geq\varepsilon\,;\,A_k) \leq\eta+\Pr\left(d(X_n,X)>\frac1k\right).

It follows that

\varlimsup_{n\to\infty}\Pr(d'(g(X_n),g(X))\geq\varepsilon) \leq\eta+0=\eta,

which shows that \Pr(d'(g(X_n),g(X))\geq\varepsilon)\to0 as n\to\infty, since \eta was arbitrary.
