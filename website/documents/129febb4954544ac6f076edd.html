Statement

Put M=7(2\cdot3^7+1). Every three-coloring of \{1,\ldots,M(2\cdot3^M+1)\} contains a monochromatic three-term arithmetic progression.

Level

Proof 1: Nested matching blocks and three-color focusing

The following focusing argument shows that W(3, 3) ≤ 7(2·37+1)(2·37·(2·37+1)+1). One begins by dividing the integers into 2·37·(2·37 + 1) + 1 groups of 7(2·37 + 1) integers each; of the first 37·(2·37 + 1) + 1 groups, two must be colored identically.

Divide each of these two groups into 2·37+1 subgroups of 7 integers each; of the first 37 + 1 subgroups in each group, two of the subgroups must be colored identically. Within each of these identical subgroups, two of the first four integers must be the same color, say red; this implies either a red progression or an element of a different color, say blue, in the same subgroup.

Since we have two identically-colored subgroups, there is a third subgroup, still in the same group that contains an element which, if either red or blue, would complete a red or blue progression, by the following focusing construction. Number the two matching subgroups b_1<b_2 starting at 0, and the matching red positions a_1<a_2 in \{1,2,3,4\}. Put a_3=2a_2-a_1\leq7. Unless a red progression has already occurred, the positions 7b_1+a_3 and 7b_2+a_3 are blue. The point 7(2b_2-b_1)+a_3 completes the red pair 7b_1+a_1,7b_2+a_2 and the blue pair 7b_1+a_3,7b_2+a_3. Suppose that this element is green. Since there is a group that is colored identically, it must contain copies of the red, blue, and green elements we have identified; we can now find a pair of red elements, a pair of blue elements, and a pair of green elements that 'focus' on the same integer, so that whatever color it is, it must complete a progression.
