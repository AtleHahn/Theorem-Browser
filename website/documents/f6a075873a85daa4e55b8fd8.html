Statement

Consider P:\mathbb R^2\to\mathbb R^2, P(R,\theta)=(R\cos\theta,R\sin\theta). At a point (R,\theta) with R\ne0 it has a continuously differentiable local inverse. At any point with R=0 it is not locally injective.

Proof 1: Compute the Jacobian determinant

Consider the plane, parametrised by polar coordinates (R,\theta). We can go to a new coordinate system (Cartesian coordinates) by defining functions x(R,\theta)=R\cos\theta and y(R,\theta)=R\sin\theta. This makes it possible given any point (R,\theta) to find corresponding Cartesian coordinates (x,y).

To convert Cartesian into polar coordinates locally, the inverse function theorem says it is sufficient to have \det J\ne0, with

J=\begin{pmatrix} \frac{\partial x(R,\theta)}{\partial R}&\frac{\partial x(R,\theta)}{\partial\theta}\\ \frac{\partial y(R,\theta)}{\partial R}&\frac{\partial y(R,\theta)}{\partial\theta} \end{pmatrix} =\begin{pmatrix} \cos\theta&-R\sin\theta\\ \sin\theta&R\cos\theta \end{pmatrix}.

Since \det J=R, conversion back to polar coordinates is locally possible if R\ne0. So it remains to check the case R=0. It is easy to see that in this case our coordinate transformation is not locally invertible: every angle gives the origin, so the value of \theta cannot be recovered even locally.
