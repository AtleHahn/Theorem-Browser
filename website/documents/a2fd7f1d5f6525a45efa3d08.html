Statement

Let X be a compact Hausdorff space. Write C(X,\mathbb F) for continuous \mathbb F-valued functions, with uniform norm \|f\|_\infty=\sup_{x\in X}|f(x)|. A subalgebra is a vector subspace closed under pointwise products. A set of functions separates points if for every x\ne y some member takes different values at x and y.

Real form. A real subalgebra A\subseteq C(X,\mathbb R) containing a nonzero constant function is uniformly dense in C(X,\mathbb R) if and only if it separates points. Density means that for every f\in C(X,\mathbb R) and \varepsilon>0 some a\in A satisfies \|f-a\|_\infty<\varepsilon.

Complex form. If S\subseteq C(X,\mathbb C) separates points, the complex unital self-adjoint algebra generated by S is uniformly dense in C(X,\mathbb C). This generated algebra consists of finite expressions made from S, the constant 1, complex scalars, sums, products and pointwise complex conjugation.

Locally compact form. For locally compact Hausdorff X, let C_0(X,\mathbb R) consist of continuous functions vanishing at infinity: for each \varepsilon>0, |f|<\varepsilon outside some compact set. A real subalgebra A is uniformly dense in C_0(X,\mathbb R) if and only if it separates points and vanishes nowhere, meaning that for each x some a\in A has a(x)\ne0. The complex analogue holds for complex subalgebras closed under conjugation.
