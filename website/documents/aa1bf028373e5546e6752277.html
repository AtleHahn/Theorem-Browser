Well-founded relational structures can be represented using set membership, even without the extensionality required for a unique transitive collapse. This illustrates the representational reach of set-theoretic foundations while distinguishing a mathematical encoding from a claim that the original objects literally are sets.

Statement

Let R be a set-like well-founded relation on a class X: for each x, the predecessors \{y:yRx\} form a set, and every nonempty subset of X has an R-minimal element. Then (X,R) is isomorphic to the membership relation restricted to some class, which need not be transitive or unique.

Proof 1: Embed, collapse, and restrict

Every well-founded set-like relation can be embedded into a well-founded set-like extensional relation. This embedding result is used as a prerequisite; extensional means that distinct elements have distinct predecessor sets.

By the Mostowski collapse lemma, a well-founded set-like extensional relation is isomorphic to membership on a transitive class. This implies the following variant: every well-founded set-like relation is isomorphic to set-membership on a (non-unique, and not necessarily transitive) class. The source leaves the restriction to the embedded copy implicit.

Level justification
