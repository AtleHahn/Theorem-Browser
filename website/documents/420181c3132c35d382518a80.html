Statement

Let X,Y\subseteq\mathbb R^n be open sets, with n\geq1. For an open set U, write \mathcal D(U)=C_c^\infty(U;\mathbb C) for its smooth compactly supported test functions, with the usual locally convex inductive-limit topology. Explicitly, for each compact C\subset U, the functions supported in C carry the seminorms \sup_{x\in C}|\partial^\alpha f(x)| for all derivative multi-indices \alpha, and \mathcal D(U) has the finest locally convex topology making all these inclusions continuous. Let \mathcal D'(U) be its continuous complex-linear dual, the distributions, with the strong dual topology of uniform convergence on bounded subsets of \mathcal D(U).

Every distribution k\in\mathcal D'(X\times Y) determines a continuous linear map K:\mathcal D(Y)\to\mathcal D'(X) by

\langle Kv,u\rangle=\langle k,u\otimes v\rangle,\qquad (u\otimes v)(x,y)=u(x)v(y),

for all u\in\mathcal D(X) and v\in\mathcal D(Y). Conversely, every such continuous linear map has exactly one distribution k satisfying this identity. The brackets denote evaluation of a distribution on a test function.
