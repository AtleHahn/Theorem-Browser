Statement

Let X be a choice set and f:X\times[0,1]\to\mathbb R. Set V(t)=\sup_{x\in X}f(x,t). Suppose each f(x,\cdot) is differentiable and absolutely continuous, and an integrable b:[0,1]\to[0,\infty) bounds |f_t(x,t)| for all x and almost every t. Suppose the supremum is attained almost everywhere. Then V is finite everywhere, and for 0\le u<v\le1, |V(v)-V(u)|\le\int_u^v b(s)\,ds.

Level
Beyond undergraduate level
Level justification

The value function ranges over an arbitrary choice set and is controlled by an integral bound for absolutely continuous objectives.

Proof 1: Compare suprema and bound objective integrals — outline

Using the definition of V, observe that for any {\displaystyle t^{\prime },t^{\prime \prime }\in \lbrack 0,1]} with {\displaystyle t^{\prime }<t^{\prime \prime }},

{\displaystyle |V(t^{\prime \prime })-V(t^{\prime })|\leq \sup _{x\in X}|f(x,t^{\prime \prime })-f(x,t^{\prime })|=\sup _{x\in X}\left\vert \int _{t^{\prime }}^{t^{\prime \prime }}f_{t}(x,t)dt\right\vert \leq \int _{t^{\prime }}^{t^{\prime \prime }}b(t)dt.}
Level
Beyond undergraduate level
Level justification

The proof represents differences of absolutely continuous objectives by Lebesgue integrals under a common integrable bound. Absolute continuity and almost-everywhere integrability are substantive measure-analysis prerequisites.
