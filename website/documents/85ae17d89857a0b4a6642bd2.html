Statement

For multitape Turing machines, let \mathrm{DTIME}(s) and \mathrm{NTIME}(s) denote the languages decidable in worst-case O(s(n)) steps on inputs of length n, deterministically and nondeterministically respectively. Nondeterministic acceptance means that at least one computation branch accepts. A function f:\mathbb N\to\mathbb N is time-constructible if a deterministic machine on input 1^n halts after exactly f(n) steps; use the source convention f(n)\ge n for these clock bounds.

Deterministic hierarchy. For every time-constructible f, a language is decidable in O(f(n)\log f(n)) time but not in o(f(n)) time. Thus

\mathrm{DTIME}(o(f(n)))\subsetneq\mathrm{DTIME}(f(n)\log f(n)).

Here the left class consists of languages having a deterministic time bound whose ratio to f(n) tends to zero. Also, for time-constructible f,g with f(n)\log f(n)=o(g(n)),

\mathrm{DTIME}(f(n))\subsetneq\mathrm{DTIME}(g(n)).

Nondeterministic hierarchy. If g is time-constructible and f:\mathbb N\to\mathbb N satisfies f(n+1)=o(g(n)), then

\mathrm{NTIME}(f(n))\subsetneq\mathrm{NTIME}(g(n)).
