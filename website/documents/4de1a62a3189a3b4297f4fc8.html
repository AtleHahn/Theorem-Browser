Statement

For an odd prime p, write (a/p)=0 if p\mid a, 1 if a is a nonzero square modulo p, and -1 otherwise. The number of ordered residue pairs (x,y) satisfying x^2+y^2\equiv2\pmod p is p-(-1/p).

Proof 1: Parametrize the conic by slopes through one fixed point

Work modulo the odd prime p. The equation x^2+y^2=2 can be solved in just the same way here as over the rational numbers: substitute x=a+1,y=at+1, where we demand that a\ne0 (leaving out the two solutions (1,\pm1)), then the original equation transforms into

a=-\frac{2(t+1)}{t^2+1}.

Here t can have any value that does not make the denominator zero—for which there are 1+\left(\frac{-1}{p}\right) excluded possibilities (i.e. 2 if -1 is a residue, 0 if not)—and also does not make a zero, which excludes one more option, t=-1. Thus there are

p-\left(1+\left(\frac{-1}{p}\right)\right)-1

possibilities for t. Each gives a unique solution with x\ne1, and conversely such a solution determines t=(y-1)/(x-1). So together with the two excluded solutions there are overall p-\left(\frac{-1}{p}\right) solutions of the original equation.

Level justification

Parametrize using the slope through (1,1), exclude zero denominators and the zero numerator, then restore the two omitted points. School algebra, prime modular division and finite counting suffice; quadratic-residue notation is explicitly defined.
