Statement

Let X be a nonempty partially ordered set in which every chain has a least upper bound, and let f:X\to X satisfy x\le f(x) for all x\in X. Then f has a fixed point. A chain is a subset totally ordered by the induced order; the completeness assumption includes the empty chain.

Level
Within undergraduate level
Level justification

Basic order, sets and suprema are familiar undergraduate concepts. Chains, dense orders and order isomorphisms are explicitly defined direct extensions. The existence assertions use those definitions alone, without transfinite proof techniques.

Proof 1: Inflationary transfinite iteration reaches a fixed point

In the following, to say that an ordinal α is embeddable in a set X is to say that there exists an injection {\displaystyle \iota:U(\alpha )\hookrightarrow X} from the underlying set of α to X. Such an injection amounts to a well-ordering of the image of \iota as a subset of X, thereby witnessing that that subset can be well-ordered.

Let β be the Hartogs number for the underlying set U(X) of the given poset X. By definition this is the set of all ordinals embeddable in U(X), itself an ordinal not embeddable in U(X) or we would have β ϵ β. (Equivalently, β is the least ordinal not embeddable in U(X), necessarily a cardinal.) Let {\displaystyle x_{0}} witness the non-emptiness of X, to serve as the basis for the following recursive construction of a chain in X.

For each ordinal {\displaystyle \alpha \in \beta } such that {\displaystyle x_{\alpha }} is defined, define {\displaystyle x_{\alpha +1}=f(x_{\alpha }).} Since f is inflationary, {\displaystyle x_{\alpha }\leq x_{\alpha +1}} in the poset X.

For each limit ordinal {\displaystyle \lambda \in \beta } such that {\displaystyle x_{\alpha }} is defined for all {\displaystyle \alpha <\lambda }, define {\displaystyle x_{\lambda }=\sup\{x_{\alpha }|\alpha <\lambda \}.} Then {\displaystyle x_{\alpha }\leq x_{\lambda }} for all {\displaystyle \alpha <\lambda }. The {\displaystyle \sup } exists by chain-completeness of the poset X.

Now if the constructed sequence is strictly increasing throughout β, this would constitute an embedding of β, the order type of that chain, in X. But that's impossible by Hartogs' Lemma.

Hence there must exist {\displaystyle \alpha <\beta } such that {\displaystyle x_{\alpha +1}=x_{\alpha }}, bringing the construction of the chain to a halt at {\displaystyle x_{\alpha }}, the promised fixed point. Q.E.D.

Proof 2: Apply the locally proved chain-bounding lemma

Chain-bounding lemma

Let P be a partially ordered set and F the set of all chains in P, including the empty chain. There is no function g:F\to P such that x<g(C) for every C\in F and every x\in C.

Let F be the set of all chains in a poset P. Assuming such {\displaystyle g} exists, let {\displaystyle C^{+}=C\cup \{g(C)\}} for each {\displaystyle C} in {\displaystyle F}. We write {\displaystyle S\trianglelefteq C} if {\displaystyle S} is an initial segment of {\displaystyle C}, meaning {\displaystyle S} is a subset and {\displaystyle y\leq x\in S,\,y\in C\Rightarrow y\in S}. Also, write {\displaystyle S\triangleleft C} if {\displaystyle S\trianglelefteq C,\,S\neq C}.

We say a chain {\displaystyle C\subset P} is good if for each {\displaystyle S\trianglelefteq C}, we have either {\displaystyle S=C} or {\displaystyle S^{+}\trianglelefteq C}. Let {\displaystyle \Gamma } be the set of all good chains in {\displaystyle P}. We claim

  1. {\displaystyle \Gamma } is totally ordered with respect to {\displaystyle \trianglelefteq }; i.e., good chains are comparable.
  2. On {\displaystyle \Gamma }, {\displaystyle \trianglelefteq } is the same as set inclusion.
  3. If {\displaystyle C} is a good chain in {\displaystyle P}, then {\displaystyle C^{+}} is a good chain in {\displaystyle P}.

For (1), given two good chains {\displaystyle C,D}, let {\displaystyle S} be the union of all chains that are both the initial segments of {\displaystyle C} and {\displaystyle D.} Clearly, {\displaystyle S} itself is an initial segment of the two; i.e., it is the largest common initial segment. If {\displaystyle S^{+}\trianglelefteq C,D}, then that would contradict the largest-ness of {\displaystyle S}. Thus, either S=C or S=D. For (2), suppose {\displaystyle C\subsetneq D}. By (1), either {\displaystyle C\triangleleft D} or {\displaystyle D\triangleleft C}, but the latter is not possible. Finally, (3) is straightforward.

We can now finish. Let {\displaystyle U} be the union of {\displaystyle \Gamma }. By (1), {\displaystyle U} is a chain. To show it is good, suppose {\displaystyle S\triangleleft U}. Let {\displaystyle x} be in {\displaystyle U-S}. Pick a good chain {\displaystyle C} containing {\displaystyle x}. Then we have

{\displaystyle S\triangleleft C}.

Indeed, if {\displaystyle y} is in {\displaystyle S}, then {\displaystyle y} is in a good chain {\displaystyle D}. If {\displaystyle D\trianglelefteq C}, then {\displaystyle y} is in {\displaystyle C}. Otherwise, by (1), {\displaystyle C\trianglelefteq D}. We have {\displaystyle y\leq x} by {\displaystyle S\triangleleft U} and so again {\displaystyle y} is in {\displaystyle C}. Hence, {\displaystyle S\subset C} and that implies {\displaystyle S\triangleleft C} as {\displaystyle S} is already an initial segment of {\displaystyle U}. Finally, {\displaystyle S^{+}\trianglelefteq C} and, since each good chain is an initial segment of U by (1) and (2), {\displaystyle S^{+}\trianglelefteq U}. This finishes the proof of the fact that {\displaystyle U} is good. Since {\displaystyle U^{+}=U} then, this is a contradiction. {\displaystyle \square }

For the chain-complete poset X, suppose the inflationary map f has no fixed point. Then g(C)=f(\sup C) is a strict upper bound of every chain C, contradicting the chain-bounding lemma just proved.

The full chain-bounding proof uses partially ordered sets, initial segments and unions of comparable chains, with each special definition supplied. It constructs the union of all good chains and shows that adjoining its strict bound would produce a larger good chain, a contradiction. These are set-and-order arguments accessible from undergraduate proof-based algebra; no ordinal recursion or independent advanced theorem is used.

Proof 3: Use a maximal element from Zorn’s lemma

By Zorn’s lemma, the nonempty chain-complete poset X has a maximal element. A maximal element is fixed by the inflationary map f, since x\le f(x) cannot be strict there.

Level

Level justification

Chain completeness supplies upper bounds for all chains, so the explicitly invoked Zorn lemma gives a maximal element. Inflationarity then forces that element to be fixed. Applying Zorn requires only undergraduate partial-order and maximality concepts; no proof of choice equivalence or transfinite machinery is used.
