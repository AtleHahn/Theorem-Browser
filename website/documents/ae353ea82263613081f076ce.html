Statement

A correspondence C:\Theta\rightrightarrows X assigns subsets of X to points of \Theta. It is upper hemicontinuous if for every \theta and open G\supseteq C(\theta), some neighborhood U of \theta satisfies C(\theta')\subseteq G for all \theta'\in U. It is lower hemicontinuous if for every open G meeting C(\theta), some such U has C(\theta')\cap G\ne\varnothing throughout U. A real function is upper semicontinuous if for every point z and \varepsilon>0 there is a neighborhood on which its values are less than its value at z plus \varepsilon. Let X,\Theta be topological spaces, let f:X\times\Theta\to\mathbb R be upper semicontinuous, and let C:\Theta\rightrightarrows X be upper hemicontinuous with nonempty compact values. Then v(\theta)=\sup_{x\in C(\theta)}f(x,\theta) is finite and upper semicontinuous.

Proof 1: Use a finite product-neighborhood cover of the feasible set

An upper semicontinuous real function on a nonempty compact set attains a finite maximum; apply this compactness theorem to each restriction f(\cdot,\theta). Write f^*(\theta)=v(\theta), and use neighborhood to mean an open set containing the point.

Fix \theta\in\Theta, and let \varepsilon>0 be arbitrary. For each x\in C(\theta), there exists a neighborhood U_x\times V_x of (\theta,x) such that whenever (\theta',x')\in U_x\times V_x, we have f(x',\theta')<f(x,\theta)+\varepsilon/2. The set of neighborhoods \{V_x:x\in C(\theta)\} covers C(\theta), which is compact, so V_{x_1},\ldots,V_{x_n} suffice. Furthermore, since C is upper hemicontinuous, there exists a neighborhood U' of \theta such that whenever \theta'\in U' it follows that C(\theta')\subseteq\bigcup_{k=1}^n V_{x_k}. Let U=U'\cap U_{x_1}\cap\cdots\cap U_{x_n}.

Then for all \theta'\in U, we have f(x',\theta')<f(x_k,\theta)+\varepsilon/2 for each x'\in C(\theta'), as x'\in V_{x_k} for some k. It follows that

f^*(\theta')=\sup_{x'\in C(\theta')}f(x',\theta') \leq\max_{k=1,\ldots,n}f(x_k,\theta)+\frac{\varepsilon}{2} \leq f^*(\theta)+\frac{\varepsilon}{2} <f^*(\theta)+\varepsilon,

which was desired.
