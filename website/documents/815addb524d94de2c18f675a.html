Statement

Let f:X\to Y be a function and L,R arbitrary sets. For any set A, use f(A)=\{f(x):x\in A\cap X\} , f^{-1}(B)=\{x\in X:f(x)\in B\}, and F_y=f^{-1}(\{y\})=\{x\in X:f(x)=y\}. Then f(X\setminus R)=f(X)\setminus f(R)\quad\Longleftrightarrow\quad f^{-1}(f(R))\subseteq R.

Level
High school only
Level justification

The explicitly defined image and preimage operations express which inputs share values. Understanding the displayed equivalence needs elementary set inclusion.

Proof 1: Cancel complements and unpack contained fibers

Put Q=\{y\in f(R):F_y\subseteq R\}. The stated domain-complement formula gives f(X\setminus R)=f(X)\setminus Q. As Q\subseteq f(R)\subseteq f(X), equality with f(X)\setminus f(R) is equivalent to Q=f(R). This says exactly that every fiber over a value in f(R) lies in R, equivalently f^{-1}(f(R))\subseteq R.

Level
High school only
Level justification

Cancel the relative complements using Q contained in f(R), then unpack each contained fiber. Elementary sets and functions suffice.
