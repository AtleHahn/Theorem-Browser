Statement

Let (\mathcal F_n)_{n=0}^N be a filtration and let A_0,\ldots,A_N be a real predictable process with A_0=0 and nonincreasing paths. Define \tau=N if A_N=0, and otherwise \tau=\min\{n\in\{0,\ldots,N-1\}:A_{n+1}<0\}. Then \tau is a stopping time.

Level
Beyond undergraduate level
Level justification

The statement requires a filtration, predictable random variables and the stopping-time definition.

Proof 1: Use the next predictable value in the event formula

For n<N, monotonicity and A_0=0 give \{\tau=n\}=\{A_n=0,A_{n+1}<0\}. Predictability makes both values measurable with respect to \mathcal F_n, so this event belongs to \mathcal F_n. The remaining value is N, hence the finite-valued random time is a stopping time.
