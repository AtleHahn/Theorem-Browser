Statement

Let A be a finite set of size n\ge1 and let k\ge1 be an integer. A linear order with n^k elements can be represented by a 2k-ary relation on A, interpreted as an order on A^k.

Level
Within undergraduate level
Level justification

Binary relations, restrictions, Cartesian powers and orders are undergraduate set concepts. Transitive closure is explicitly the smallest containing transitive relation; no specialized relation algebra is needed.

Proof 1: Order tuples lexicographically — outline

Choose a linear order L on A. Define the 2k-ary relation R to be the lexicographic order of k-tuples with respect to L. It orders the n^k tuples in A^k, as required.

Level
Within undergraduate level
Level justification

Choose an order on the finite set and order its k-tuples lexicographically; encode pairs of tuples as 2k-tuples. Elementary finite relations and Cartesian powers suffice.
