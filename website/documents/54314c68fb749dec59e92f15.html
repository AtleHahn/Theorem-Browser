Statement

A Kripke model has worlds, a relation R of accessibility and truth values for propositional atoms at each world. The formula \Box A holds at w exactly when A holds at every v with wRv. The formula a\land\neg\Box a is satisfiable, so replacing \neg\Box a by \neg a at the same world is unsound.

Level
Within undergraduate level
Level justification

A binary relation and ordinary propositional truth values suffice. The modal box is explicitly defined as universal truth over accessible points; each claim uses only this one added semantic rule, without a formal axiom system or proof coding.

Proof 1: Evaluate a two-world countermodel

If \neg\Box A is true in a world then there exists a world accessible from it where A is false. However, one cannot simply add the following rule to the propositional ones:

\frac{\neg\Box A}{\neg A}.

In propositional tableaux all formulae refer to the same truth evaluation, but the precondition of the rule above holds in one world while the consequence holds in another. Not taking this into account would generate incorrect results. For example, formula a\land\neg\Box a states that a is true in the current world and a is false in a world that is accessible from it. Simply applying conjunction expansion and the expansion rule above would produce a and \neg a, but these two formulae should not in general generate a contradiction, as they hold in different worlds.
