Statement

Let X=X_1\cup X_2 be a union of connected CW complexes meeting at one point p, with \pi_1(X,p)=\pi_1(X_1,p)*\pi_1(X_2,p). Let f:Z\to X be continuous and put Z_i=f^{-1}(X_i), W=f^{-1}(p). Suppose a path \gamma joins distinct path components of W, its image loop under f is null-homotopic, and \gamma=\gamma_1*\cdots*\gamma_m is a finite concatenation of paths lying alternately in Z_1,Z_2, each with endpoints in W. Then there is a path lying entirely in one Z_i, joining distinct path components of W, whose image loop under f is null-homotopic.

Beyond undergraduate level
Level justification

Proof 1: A null tie contains a monochromatic null tie after reduction — outline

The tie \gamma is written as \gamma_1*\gamma_2*\cdots*\gamma_m, where each \gamma_i is a curve in Z_1 or Z_2, alternating between the two. Each f(\gamma_i) is a loop based at p in X. So

[e]=[f(\gamma)]=[f(\gamma_1)]*\cdots*[f(\gamma_m)].

By the normal form theorem for the free product, [f(\gamma_j)]=[e] for some j. If this \gamma_j is a tie, meaning its endpoints lie in distinct path components of W, then we have a monochromatic null tie.

If \gamma_j is not a tie, then its endpoints are in the same path component of W=Z_1\cap Z_2. In this case we replace \gamma_j by a path in W, say \gamma_j'. For j>1 this path may be appended to \gamma_{j-1} and we get a new null tie

\gamma''=\gamma_1*\cdots*\gamma_{j-1}'*\gamma_{j+1}*\cdots*\gamma_m, \qquad \gamma_{j-1}'=\gamma_{j-1}*\gamma_j'.

If j=1, prepend \gamma_1' to the next piece instead. The case m=1 already supplies the required tie. The replacement has constant image under f; the new path is still null and has the same endpoints. Combining neighboring pieces of the same type when necessary, the number of pieces has decreased.

Thus, by induction on m, we prove the existence of a monochromatic null tie.
