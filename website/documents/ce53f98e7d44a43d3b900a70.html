Statement

For a complex n\times n matrix N, n\ge1, with columns v_1,\ldots,v_n and Euclidean norms \|v_i\|, |\det N|\le\prod_{i=1}^n\|v_i\|. If all columns are nonzero, equality holds exactly when they are pairwise orthogonal for the Hermitian inner product.

Level justification

Proof 1: Hadamard determinant inequality — source argument

The inequality is trivial if the matrix N is singular; if all columns are nonzero, equality is impossible in this case. So assume the columns of N are linearly independent. By dividing each column by its Euclidean norm, it can be seen that the result is equivalent to the special case where each column has norm 1, in other words if ei are unit vectors and M is the matrix having the ei as columns then

\left|\det M\right|\leq 1.

and equality is achieved if and only if the vectors are an orthogonal set. The general result now follows:

{\displaystyle \left|\det N\right|={\bigg (}\prod _{i=1}^{n}\|v_{i}\|{\bigg )}\left|\det M\right|\leq \prod _{i=1}^{n}\|v_{i}\|.}

To prove \lvert\det M\rvert\leq1, consider P =M*M where M* is the conjugate transpose of M, and let the eigenvalues of P be λ1, λ2, … λn. Since the length of each column of M is 1, each entry in the diagonal of P is 1, so the trace of P is n. Applying the inequality of arithmetic and geometric means,

{\displaystyle \det P=\prod _{i=1}^{n}\lambda _{i}\leq \left({1 \over n}\sum _{i=1}^{n}\lambda _{i}\right)^{n}=\left({1 \over n}\operatorname {tr} P\right)^{n}=1^{n}=1,}

so

{\displaystyle \left|\det M\right|={\sqrt {\det P}}\leq 1.}

If there is equality then each of the λi's must all be equal and their sum is n, so they must all be 1. The matrix P is Hermitian, therefore diagonalizable, so it is the identity matrix—in other words the columns of M are an orthonormal set and the columns of N are an orthogonal set.

Conversely, orthogonal unit columns give P=I, and hence equality.
