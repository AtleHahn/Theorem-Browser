Statement

Let p>q be distinct odd primes, let K=\mathbb F_{p^q}, and let N:K\to\mathbb F_p be the field norm. Put S=\{a\in K:N(a)=N(2-a)=1\}. If S is closed under inversion, then S=\{1\}.

Proof 1: Use the norm polynomial and the invariant fractional-linear map — outline

The set S is closed under x\mapsto2-x by its definition, and is closed under taking inverses by hypothesis. Thus x\mapsto1/(2-x) maps the set to itself.

If a is in the set and not equal to 1, then the polynomial

N((1-a)T+1)-1

has degree q and has at least p distinct roots given by the elements T\in\mathbb F_p, using the fact that x\mapsto1/(2-x) maps the set to itself. Here the norm polynomial means

N((1-a)T+1)=\prod_{j=0}^{q-1}\left(1+(1-a)^{p^j}T\right).

So p\leq q, contradicting the assumption p>q. Since 1\in S, it follows that S=\{1\}.
