Statement

In ordinary set theory with power sets and separation, there is no set U such that every set is an element of U.

Proof 1: A universal set would contain its larger power set

Assume there is a set containing all sets, the universal set U. By Cantor's theorem,

|\mathcal P(X)|>|X|

for any set X. On the other hand, all elements of \mathcal P(U) are sets, and thus contained in U, therefore

|\mathcal P(U)|\le|U|,

a contradiction.

Level
Within undergraduate level
Level justification

Apply Cantor cardinal comparison to the power set and observe it would be a subset of the universal set. Undergraduate introductory set theory suffices; no advanced axiomatic model theory is used.

Proof 2: Russell’s restricted diagonal subset

Assume a set of all sets U exists, and consider its Russell set, formed by separation:

R_U=\{x\in U:x\notin x\}.

Restricted comprehension in this definition entails that

R_U\in R_U\iff(R_U\in U\wedge R_U\notin R_U).

Since U contains every set, R_U\in U, leading to the contradiction

R_U\in R_U\iff R_U\notin R_U.

We can conclude from the contradiction obtained that we must reject the hypothesis that R_U\in U, thus disproving the existence of a set containing all sets.
