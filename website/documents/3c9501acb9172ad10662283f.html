Statement

A simple undirected graph has a vertex set V and edges that are unordered pairs of distinct vertices. A proper k-coloring is a map V\to\{1,\ldots,k\} assigning different values to adjacent vertices. Assume choice. If every finite subgraph of G is planar, meaning it can be drawn in the plane with no crossing edges, then G has a proper four-coloring. In particular this holds for an infinite graph drawn without crossings.

Level
Within undergraduate level
Level justification

Sets, maps and finite graph coloring describe every object in the assertion. Planarity is explicitly explained, and the conclusion simply asks for a compatible coloring on the entire possibly infinite vertex set.

Proof 1: Apply four colors on every finite subgraph

Every finite planar graph can be colored with four colors, by the four-color theorem. The De Bruijn–Erdős theorem then shows that every graph that can be drawn without crossings in the plane, finite or infinite, can be colored with four colors. More generally, every infinite graph for which all finite subgraphs are planar can again be four-colored.

Here the De Bruijn–Erdős theorem states that, when all finite subgraphs can be colored with c colors, the same is true for the whole graph.

Level justification
