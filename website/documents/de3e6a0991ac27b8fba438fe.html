Statement

For every x_0\in\mathbb R, the iteration x_{n+1}=\cos x_n (radians) converges to the unique real fixed point of cosine. If x_0=1, one may take q=0.85 in |x_n-x_*|\le \frac{q^n}{1-q}|x_1-x_0|.

Proof 1: Apply Banach’s theorem on the invariant interval — outline

The fixed-point iteration x_{n+1}=\cos x_n converges to the unique fixed point of the function f(x)=\cos x for any starting point x_0. This example does satisfy (at the latest after the first iteration step) the assumptions of the Banach fixed-point theorem, on the invariant interval [-1,1]. Any real fixed point must belong to this interval.

Hence, if we start from x_0=1, the error after n steps satisfies

|x_n-x_*|\leq\frac{q^n}{1-q}|x_1-x_0|=Cq^n,

where we can take q=0.85. When the error is less than a multiple of q^n for some constant 0<q<1, we say that we have linear convergence. The Banach fixed-point theorem allows one to obtain fixed-point iterations with linear convergence.

Level justification

After one step the iteration lies in [-1,1], where the derivative bound sin(1)<.85 makes cosine a contraction. The stated interval contraction theorem supplies convergence, uniqueness and the error bound.
