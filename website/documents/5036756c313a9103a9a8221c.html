Statement

All graphs here are finite and simple. A clique is a set of pairwise adjacent vertices, an independent set a set of pairwise nonadjacent vertices, and a proper coloring partitions vertices into independent color classes. Write \omega(G) for the largest clique size, \chi(G) for the minimum number of colors and \alpha(G) for the largest independent-set size. A graph is perfect when \chi(H)=\omega(H) for every induced subgraph H, including the empty graph with both quantities zero. Every nonempty perfect graph G has a clique K that intersects every maximum independent set of G.

Level
High school only
Level justification

Perfection, cliques and maximum independent sets are defined on finite graphs. Quantifying over all maximum subsets adds no college prerequisite.

Proof 1: Replicate maximum independent-set memberships — outline

Given a perfect graph {\displaystyle G}, form a graph {\displaystyle G^{*}} by replacing each vertex {\displaystyle v} by a clique of {\displaystyle t_{v}} vertices, where {\displaystyle t_{v}} is the number of distinct maximum independent sets in {\displaystyle G} that contain {\displaystyle v}. Delete vertices for which t_v=0; the replication lemma (clique replacement preserves perfection), together with closure under induced subgraphs, makes G^* perfect.

It is possible to correspond each of the distinct maximum independent sets in {\displaystyle G} with one of the maximum independent sets in {\displaystyle G^{*}}, in such a way that the chosen maximum independent sets in {\displaystyle G^{*}} are all disjoint and each vertex of {\displaystyle G^{*}} appears in a single chosen set; that is, {\displaystyle G^{*}} has a coloring in which each color class is a maximum independent set. Necessarily, this coloring is an optimal coloring of {\displaystyle G^{*}}. Because {\displaystyle G} is perfect, so is {\displaystyle G^{*}}, and therefore it has a maximum clique {\displaystyle K^{*}} whose size equals the number of colors in this coloring, which is the number of distinct maximum independent sets in {\displaystyle G}; necessarily, {\displaystyle K^{*}} contains a distinct representative for each of these maximum independent sets. The corresponding set {\displaystyle K} of vertices in {\displaystyle G} (the vertices whose expanded cliques in {\displaystyle G^{*}} intersect {\displaystyle K^{*}}) is a clique in {\displaystyle G} with the property that it intersects every maximum independent set in {\displaystyle G}.
