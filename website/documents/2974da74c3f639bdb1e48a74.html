Statement

Assume Zorn’s lemma. Every nonempty connected graph, possibly infinite, has a spanning tree (an acyclic connected subgraph containing every vertex).

Level
Within undergraduate level
Level justification

A spanning tree is explicitly an acyclic connected subgraph containing every vertex. Undergraduate sets and elementary graph definitions suffice; Zorn is a stated maximal-element principle whose proof is not needed to understand the existence claim.

Proof 1: Maximal tree — outline

Stated dependency

Zorn’s lemma: a partially ordered set in which every chain (including the empty chain) has an upper bound has a maximal element. A chain is a totally ordered subset; an element m is maximal if m\leq y implies m=y.

Argument

Zorn's lemma can be used to show that every connected graph has a spanning tree. The set of all sub-graphs that are trees is ordered by inclusion, and the union of a chain is an upper bound. Zorn's lemma says that a maximal tree must exist, which is a spanning tree since the graph is connected.

Level
Within undergraduate level
Level justification

Order tree subgraphs by inclusion; a chain union is acyclic because each cycle is finite and is connected because any two vertices occur together at a later member. The empty chain has a singleton tree upper bound. Zorn gives a maximal tree, extended by an edge if it misses a vertex. Basic set theory and graph paths suffice.
