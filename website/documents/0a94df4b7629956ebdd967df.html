Statement

Let X_1,X_2,\ldots be independent standard normal random variables with distribution function F(x)=\tfrac12\operatorname{erfc}(-x/\sqrt2). For every positive integer n, let c_n>0 solve n e^{-c_n^2/2}/(\sqrt{2\pi}\,c_n)=1. Put M_n=\max_{1\le j\le n}X_j. Then, for every real u, \Pr(c_n(M_n-c_n)\le u)\to\exp(-e^{-u}).

Level
Within undergraduate level
Level justification

The probability model is the explicit normal distribution, whose density is a Gaussian calculus function. Independence means a product density, and mean/variance are its weighted integrals. The displayed sample statistics and probability limits require only these closely related elementary probability definitions, without general stochastic-process theory.

Proof 1: Gumbel limit for normalized normal maxima — outline

For the standard normal distribution function

F(x)=\frac12\operatorname{erfc}\left(-\frac{x}{\sqrt2}\right),

use the normal-tail asymptotic

\log F(x)\sim-\frac{\exp(-x^2/2)}{\sqrt{2\pi}\,x} \qquad(x\to\infty).

Thus

\log(F(x)^n)=n\log F(x) \sim-\frac{n\exp(-x^2/2)}{\sqrt{2\pi}\,x},

and hence we have the approximation

F(x)^n\approx \exp\left(-\frac{n\exp(-x^2/2)}{\sqrt{2\pi}\,x}\right).

If we define c_n as the positive value that exactly satisfies

\frac{n\exp(-c_n^2/2)}{\sqrt{2\pi}\,c_n}=1,

then for x\approx c_n we find that

\frac{n\exp(-x^2/2)}{\sqrt{2\pi}\,x} \approx\exp\bigl(c_n(c_n-x)\bigr).

Letting u=c_n(x-c_n) and keeping u fixed as n\to\infty, this approximation yields

\lim_{n\to\infty}F\left(\frac{u}{c_n}+c_n\right)^n =\exp\bigl(-\exp(-u)\bigr).

Equivalently, since the independent-sample maximum has distribution function F(x)^n,

\lim_{n\to\infty} \Pr\left(\frac{\max\{X_1,\ldots,X_n\}-c_n}{1/c_n}\leq u\right) =\exp\bigl(-\exp(-u)\bigr).

The source leaves the normal-tail estimate and the checks of the near-c_n approximation implicit.
