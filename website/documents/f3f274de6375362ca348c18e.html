Statement

There is no finitely presented group with a Dehn function \delta_P satisfying \delta_P\approx(n\mapsto n^d) for a real 1<d<2. For a finite presentation P=\langle X\mid R\rangle, define \operatorname{Area}_P(w) for a freely reduced word representing the identity as the least number of conjugates of elements of R^{\pm1} whose product is w in the free group on X. Its Dehn function is \delta_P(n)=\max\{\operatorname{Area}_P(w):w=1,\ |w|\le n\}. An isoperimetric function is a nondecreasing upper bound for these areas in terms of word length. For nondecreasing functions f,g:\mathbb N\to[0,\infty), write f\preceq g if there is an integer C\ge1 such that f(n)\le Cg(Cn+C)+Cn+C for all n\ge0, and f\approx g if both dominations hold.

Proof 1: Subquadratic growth forces the linear class — outline

Use the isoperimetric-gap theorem and the characterization that a finitely presented group is word-hyperbolic if and only if its Dehn function is equivalent to the linear function.

If a finitely presented group satisfies a subquadratic isoperimetric inequality then it is word-hyperbolic. Thus there are no finitely presented groups with Dehn functions equivalent to nd with d ∈ (1,2).
