Statement

Let \mu be a finite complex Borel measure on the circle \mathbb R/(2\pi\mathbb Z). Define \widehat\mu(n)=(2\pi)^{-1}\int e^{-in\theta}\,d\mu(\theta) for integers n. If \widehat\mu(n)=0 for every negative integer n, then \mu is absolutely continuous with respect to arc-length measure d\theta: every Borel set of arc-length measure zero has \mu-measure zero.
