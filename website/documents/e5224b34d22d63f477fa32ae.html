Statement

A Kripke model has worlds, a relation R of accessibility and truth values for propositional atoms at each world. The formula \Box A holds at w exactly when A holds at every v with wRv. The assumptions P and \neg\Box(P\land Q) imply \neg\Box Q globally (when the assumptions hold at all worlds), but not locally at a single world.

Level
Within undergraduate level
Level justification

A binary relation and ordinary propositional truth values suffice. The modal box is explicitly defined as universal truth over accessible points; each claim uses only this one added semantic rule, without a formal axiom system or proof coding.

Proof 1: Compare a two-world countermodel with global premises

Local and global assumptions differ on models where the assumed formula is true in some worlds but not in others. The set \{P,\neg\Box(P\land Q)\} entails \neg\Box Q globally but not locally. Local entailment does not hold in a model consisting of two worlds making P and \neg P,Q true, respectively, and where the second is the only world accessible from the first; in the first world, the assumptions are true but \neg\Box Q is false.

This counterexample works because P can be assumed true in a world and false in another one. If however the same assumption is considered global, \neg P is not allowed in any world of the model.
