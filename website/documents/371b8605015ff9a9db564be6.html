Statement

Here a formal term is an expression built from variable, constant and function symbols, compared as written without evaluating it. A listed substitution simultaneously replaces each occurrence of its listed variables by the assigned terms, fixes all other variables, and leaves constant and function symbols unchanged; replacements are not repeated inside the inserted terms in the same application. The substitution \{x\mapsto2\}, with 2 a constant symbol, has no inverse substitution. An inverse substitution would undo the replacement on every term. In the proof, + is a formal binary function symbol.

Level
High school only
Level justification

Substitution and inverse are defined by explicit rules on written expressions.

Proof 1: A constant replacement loses the variable occurrence

The ground substitution { x ↦ 2 } cannot have an inverse due to a loss of origin information e.g. in (x+2) { x ↦ 2 } = 2+2, even if replacing constants by variables was allowed by some fictitious kind of "generalized substitutions".

Level
High school only
Level justification

Replacing a variable by a constant loses its occurrence and substitutions cannot replace that constant back. The explicitly defined finite symbol rules require only elementary symbolic reasoning.
