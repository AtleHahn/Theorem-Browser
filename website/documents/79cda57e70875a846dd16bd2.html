Statement

In ZF set theory the following five assertions are equivalent.

  1. (Zorn) If each chain in a poset {\displaystyle P} has an upper bound, then {\displaystyle P} has a maximal element.
  2. If each chain in a poset {\displaystyle P} has a least upper bound; i.e., {\displaystyle P} is chain-complete, then {\displaystyle P} has a maximal element.
  3. (Hausdorff maximal principle) The set of all chains in any poset, ordered by set inclusion, has a maximal element (that is, a maximal chain in the poset).
  4. (Tukey) Let {\displaystyle F} be a nonempty family of sets that has finite character; i.e., a set is in {\displaystyle F} if and only if each finite subset of that set is in {\displaystyle F}. Then {\displaystyle F} has a maximal element with respect to set inclusion.
  5. Let {\displaystyle F} be a family of sets such that for each chain {\displaystyle C} in {\displaystyle F}, the union of {\displaystyle C} is a subset of a set in {\displaystyle F}. Then {\displaystyle F} has a maximal element.

Level justification

Sets and partial orders supply chains, upper bounds and maximality. Well-order means every nonempty subset has a least member, and choice/Zorn is a stated principle. The explicit equivalences and fixed-point conditions require no ordinal arithmetic or forcing theory.

Proof 1: Cycle of five maximality implications

Indeed, (1) {\displaystyle \Rightarrow } (5) holds since a set in {\displaystyle F} containing the union of a chain in {\displaystyle F} is an upper bound of the chain. (5) {\displaystyle \Rightarrow } (4) is because an easy argument shows the union of a chain in {\displaystyle F} is again in {\displaystyle F}. (4) {\displaystyle \Rightarrow } (3) since the set of all chains clearly has finite character. (3) {\displaystyle \Rightarrow } (2) Let {\displaystyle C} be a maximal chain. It has a least upper bound {\displaystyle x} by the hypothesis on {\displaystyle P}. This {\displaystyle x} is a maximal element since if {\displaystyle y>x}, then {\displaystyle {\widetilde {C}}=C\cup \{y\}} is a strictly larger chain, contradicting the maximality of {\displaystyle C}. For (2) {\displaystyle \Rightarrow } (1), apply (2) to the poset of all chains (the ordering by set inclusion). As before, an upper bound of a maximal chain is a maximal element of {\displaystyle P}. {\displaystyle \square }
