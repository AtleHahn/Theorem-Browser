Statement

Let n\ge1 be an integer. Write M(a,b,c)=\begin{pmatrix}1&a&c\\0&I_n&b\\0&0&1\end{pmatrix} for the real Heisenberg group, with a,b\in\mathbb R^n and c\in\mathbb R; in the block matrix, a is written as a row and b as a column with those vector coordinates. For real h\ne0, on complex L^2(\mathbb R^n) define (U_h(M(a,b,c))\psi)(x)=e^{i(b\cdot x+hc)}\psi(x+ha). For the automorphism \alpha_h(M(a,b,c))=M(-h^{-1}b,ha,c-a\cdot b), the irreducible representations U_h and U_h\circ\alpha_h are unitarily equivalent.

Proof 1: Twist by a center-fixing automorphism

The given automorphism fixes every M(0,0,c), so the original and twisted representations have the same nontrivial central character. The fixed-central-character classification supplies a unitary intertwiner.
