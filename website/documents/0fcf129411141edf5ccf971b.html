Statement

There is an algorithm deciding whether a single-vertex crease pattern with prescribed mountain and valley assignments admits a flat folding, using O(n) arithmetic and comparison operations for n creases. The input consists of n distinct rays from an interior point of a sheet, specified in cyclic order by their positive consecutive sector angles summing to 2\pi, together with a mountain or valley label for each crease relative to a fixed side of the sheet. A flat folding respects these labels and folds all sectors into one plane without stretching, tearing or passing the sheet through itself; overlapping layers are allowed. The running-time assertion uses the usual exact-arithmetic model for the given angles: each arithmetic operation, comparison and access to a stored angle or label has unit cost. Thus the number of such operations is at most Cn+C for an absolute constant C, independently of the angle values. It is a local single-vertex decision problem.

Proof 1: Crimping and linear-time bookkeeping (proof sketch) (external)

A link to the proof can be found here (Introduction, printed pp. 1–2 (PDF pp. 2–3), spherical-link reduction and motion; Section 4, printed p. 10 (PDF p. 11), crimping algorithm and complexity; reference [12] for correctness.). The linked exposition is a proof sketch with the indicated dependencies.

The small-sphere link gives the reduction: sector angles become cycle lengths and crease labels become prescribed fold directions. Section 4 gives local crimping and linear accounting; its correctness theorem is cited to Demaine and O’Rourke, not proved there. The introduction also cites spherical Carpenter’s Rule for a collision-free motion to the flat state. The following implementation supplies the operation count: maintain a cyclic doubly linked list and a queue of eligible local crimps, discard stale entries, and update only the constant number of neighboring eligibility tests after each deletion. There are O(n) deletions and insertions, each using constant many arithmetic/comparison operations. Handle the terminal collapsed cycle by the standard crimping base case. This is a sourced proof sketch with named dependencies, not a self-contained proof.
