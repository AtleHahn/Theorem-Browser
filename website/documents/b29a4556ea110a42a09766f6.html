Statement

For any poset P, let \mathcal C be its set of chains. There is no function g:\mathcal C\to P such that g(C)>x for every x\in C and every C\in\mathcal C.

Proof 1: The chain-extension map cannot have the required fixed point — outline

Use the Bourbaki–Witt theorem: if X is a nonempty poset in which each chain has a least upper bound, then each function f:X\to X such that f(x)\ge x for every x\in X has a fixed point. The set \mathcal C of all chains in P, ordered by inclusion, is nonempty since it contains the empty chain, and the union of a chain of chains is its least upper bound.

Indeed, if such g exists, we define

\widetilde C=C\cup\{g(C)\}.

This is a chain, and C\subseteq\widetilde C. The fixed point supplied by the Bourbaki–Witt theorem gives a contradiction as C=\widetilde C, whereas g(C) is a strict upper bound of C and so cannot belong to C.
