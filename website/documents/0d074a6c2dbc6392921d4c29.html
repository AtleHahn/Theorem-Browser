Statement

Given a decision procedure for satisfiability of Boolean formulas, one can find a satisfying assignment to a satisfiable formula with m variables by at most 2m calls to that procedure and polynomial additional work, querying only formulas obtained by fixing variables. In particular, a polynomial-time decision procedure gives a polynomial-time search procedure.

Level justification

Boolean formulas, truth assignments and finite procedures suffice. The statement specifies the oracle calls and polynomial overhead; it needs no nondeterministic machine or complexity-class reductions for comprehension.

Proof 1: Fix one variable at a time

Self-reducibility describes the phenomenon that, if we can quickly test whether a SAT instance is solvable, we can almost as quickly find an explicit solution to the instance. To find a solution to an instance s, choose one of the Boolean variables x that is input to s, and make two smaller instances s0 and s1 where si denotes the formula formed by replacing x with the constant i. Once these two smaller instances have been constructed, apply the test for solvability to each of them. If one of these two tests returns that the smaller instance is satisfiable, continue solving that instance until a complete solution has been derived.

Each step fixes one variable and makes two tests, so at most 2m calls are required; the substitutions take polynomial additional work.
