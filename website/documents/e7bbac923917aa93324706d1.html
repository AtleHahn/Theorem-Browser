Statement

If every finite planar graph had an intersection representation by plane segments using at most four directions with no two segments on the same line, then every finite planar graph would have a proper coloring with at most four colors. Here an intersection representation assigns one segment to each vertex, with adjacency exactly when segments meet; a proper coloring assigns different colors to adjacent vertices.

Level
High school only
Level justification

The statement is a conditional relation between finite planar drawings, elementary line directions and the locally defined coloring condition.

Proof 1: Color the hypothesized representation

Assign one color to each direction. Segments of the same direction lie on distinct parallel lines and do not meet, so adjacent vertices have different colors. Apply this construction to the hypothesized representation of each planar graph.
