Statement

Work in ZF. Let B be a set disjoint from an infinite ordinal \beta such that there is no surjection B\to\beta. If there is a bijection f:B\cup\beta\to(B\cup\beta)^2, then B is well-orderable.

Level
Beyond undergraduate level
Level justification

The statement concerns general sets, ordinals and well-orderability in ZF; it does not assume choice.

Proof 1: Take least ordinal preimages in disjoint fibers

For every x\in B, it is impossible that \beta\times\{x\}\subseteq f[B], because otherwise we could define a surjective function from B to \beta: send b to the first coordinate of f(b) when f(b)\in\beta\times\{x\}, and to 0\in\beta otherwise.

Therefore, there exists at least one ordinal \gamma\in\beta such that f(\gamma)\in\beta\times\{x\}, so the set

S_x=\{\gamma\in\beta:f(\gamma)\in\beta\times\{x\}\}

is not empty.

We can define a new function: g(x)=\min S_x. This function is well defined since S_x is a non-empty set of ordinals, and so has a minimum. For every x,y\in B, x\ne y, the sets S_x and S_y are disjoint. Therefore, we can define a well order on B: for every x,y\in B we define

x\le y\iff g(x)\le g(y),

since the image of g, that is, g[B], is a set of ordinals and therefore well ordered.

Level
Beyond undergraduate level
Level justification

Build least ordinal preimages in disjoint fibers without invoking choice, then pull back the ordinal order. The ZF setting, ordinal comparison and surjection-versus-well-order reasoning together are not confidently a small undergraduate extension.
