Statement

A real or complex topological vector space X has a norm whose open balls generate its topology if and only if X is T_1 and has a bounded convex neighborhood of zero. A topological vector space has continuous addition and scalar multiplication; T_1 means each singleton is closed. A neighborhood of zero contains an open set containing zero. Convex means that (1-t)x+ty belongs to the set whenever x,y do and 0\le t\le1. A subset A is bounded in the topological-vector-space sense if for every open neighborhood U of zero there is a scalar \lambda with A\subseteq\lambda U.
