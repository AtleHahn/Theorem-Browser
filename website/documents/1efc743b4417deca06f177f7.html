Statement

If a,b\in\mathbb R, a\le b, and f:[a,b]\to[a,b] is continuous, there exists x\in[a,b] with f(x)=x.

Level
Within undergraduate level
Level justification

Understanding the statement involves real continuity; closed intervals; fixed points. These prerequisites fit undergraduate coursework or a brief extension of it. Proof 1: Apply the intermediate value theorem to f minus identity

Consider the function g which maps x to f(x) − x. It is ≥ 0 on a and ≤ 0 on b. By the intermediate value theorem, g has a zero in [a, b]; this zero is a fixed point.

Level
Within undergraduate level
Level justification

Subtract the identity and apply the intermediate value theorem to the endpoint signs, with the singleton case immediate. Ordinary undergraduate real analysis suffices.
