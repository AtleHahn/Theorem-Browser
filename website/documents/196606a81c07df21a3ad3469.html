Statement

For an integer n\ge1, use deterministic Turing machines with n operational states, a separate Halt state, one starting state, a two-way unbounded tape over \{0,1\}, and a transition for each operational state and scanned symbol. Each transition writes a bit, moves one cell left or right, and enters a state (possibly Halt). The machine starts on an all-zero tape. Among machines that halt, \Sigma(n) is the largest number of ones left on the tape, and S(n) the largest number of transitions, including the halting transition. Given n and an integer B\ge S(n), the value \Sigma(n) can be computed by a finite algorithm.

Level
High school only
Level justification

The statement supplies the transition rules, the maximal halting time and the maximal final count. Given the finite bound B, the claim asks for a finite recipe to find a largest count. Elementary finite enumeration and bounded repetition suffice; no general undecidability or computability theory is needed.

Proof 1: Exhaustive simulation up to the time bound

For a given n, if an upper bound B\ge S(n) is known then all n-state Turing machines can (in principle) be run for up to B steps, at which point any machine that has not yet halted will never halt. At that point, by observing which machines have halted with the most 1s on the tape (i.e., the busy beavers), one obtains from their tapes the value of Σ(n).

Level
High school only
Level justification

The machine rules are fully specified. Enumerating finitely many tables, running each for a given finite number of steps and taking the largest recorded score is elementary finite reasoning; no undecidability theorem is used.
