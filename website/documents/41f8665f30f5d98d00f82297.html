Statement

Let G,H be quasi-isometric finitely presented groups, with any finite presentations P,Q. Then \delta_P\approx\delta_Q. In particular the growth type is independent of the finite presentation of a fixed group. For a finite presentation P=\langle X\mid R\rangle, define \operatorname{Area}_P(w) for a freely reduced word representing the identity as the least number of conjugates of elements of R^{\pm1} whose product is w in the free group on X. Its Dehn function is \delta_P(n)=\max\{\operatorname{Area}_P(w):w=1,\ |w|\le n\}. An isoperimetric function is a nondecreasing upper bound for these areas in terms of word length. For nondecreasing functions f,g:\mathbb N\to[0,\infty), write f\preceq g if there is an integer C\ge1 such that f(n)\le Cg(Cn+C)+Cn+C for all n\ge0, and f\approx g if both dominations hold.

Proof 1: Transfer isoperimetric bounds and use minimality — outline

Use the following isoperimetric transfer theorem.

If G and H are quasi-isometric finitely presented groups and some finite presentation of G has an isoperimetric function f(n) then for any finite presentation of H there is an isoperimetric function equivalent to f(n). In particular, this fact holds for G = H, where the same group is given by two different finite presentations.

The Dehn function is the smallest isoperimetric function.

Consequently, for a finitely presented group the growth type of its Dehn function, in the sense defined in the statement, does not depend on the choice of a finite presentation for that group. More generally, if two finitely presented groups are quasi-isometric then their Dehn functions are equivalent.
