Statement

Let X,Y be compact Hausdorff spaces, and let T:C(X,\mathbb R)\to C(Y,\mathbb R) be a surjective isometry for the supremum distances, not necessarily linear. Then X and Y are homeomorphic. More precisely, there are a homeomorphism \varphi:Y\to X and g\in C(Y,\mathbb R) with |g(y)|=1 such that (Tf)(y)=(T0)(y)+g(y)f(\varphi(y)) for all f,y.

Level
Within undergraduate level
Level justification

Basic topology supplies compact Hausdorff spaces and homeomorphisms. Continuous functions with the supremum distance and a surjective distance-preserving map are direct analysis definitions; the explicit weighted-composition formula uses no dual or spectral theory.

Proof 1: Subtract the affine translation

Dependencies

For real normed spaces, the Mazur–Ulam theorem says that a surjective isometry is affine. The linear Banach–Stone theorem says that a surjective linear isometry S:C(X,\mathbb R)\to C(Y,\mathbb R), for compact Hausdorff X,Y, has the form (Sf)(y)=g(y)f(\varphi(y)) with a homeomorphism \varphi:Y\to X and continuous |g|=1.

Reduction

The source removes the linearity assumption by using the Mazur–Ulam theorem to show that T is affine, and so T-T(0) is a linear isometry. Apply the stated linear Banach–Stone theorem to T-T(0).

Level
Beyond undergraduate level
Level justification

Normalize an affine isometry and apply Banach–Stone for continuous-function spaces on arbitrary compact Hausdorff spaces. The general normed function-space framework and its relationship to underlying topology are not developed locally; conservatively retain beyond undergraduate provisionally rather than assume this entire framework is a small extension.
