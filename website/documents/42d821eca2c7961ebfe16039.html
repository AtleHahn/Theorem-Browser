Medium

The assertion that every infinite set has the same size as its Cartesian square is equivalent over ZF to the axiom of choice. This shows that a familiar rule of infinite arithmetic carries substantial foundational assumptions when stated for arbitrary infinite sets.

Statement

Over Zermelo–Fraenkel set theory without the axiom of choice (ZF), the following statements are equivalent:

  1. The axiom of choice: every family of nonempty sets has a function selecting an element of each set.
  2. For every infinite set A, there exists a bijection A\to A\times A.

Proof 1: Ordinal pairing and Hartogs comparability (external)

A link to the proof can be found here (Theorem6.15 and Lemma6.16 p.27; Theorems4.21 and4.26 pp.17–18; Theorem6.7 p.25).

The pairing proof in Theorem4.26 applies at every positive ordinal induction index, including finite positive indices. For the reverse direction, let \lambda be the least ordinal not injecting into A, and apply the square assumption to the disjoint union A\sqcup\lambda. Restrict the resulting injection to A\times\lambda. No row can lie entirely in A; for each a, choose the least \alpha whose image lies in \lambda. The pair consisting of \alpha and that image injects A into the well-ordered set \lambda\times\lambda, so A is well-orderable. In the Hartogs proof, using the initial ranges indexed by \beta<\alpha gives order type \alpha; the printed indexing by \beta\le\alpha instead gives \alpha+1.
