Statement

With the standard convention that constant entire functions have order 0, a constant function f(z)=c has exactly one finite asymptotic value, namely c, and violates a bound of the number of such values by twice its order. Here a finite asymptotic value is a limit of f(z) along a curve with |z|\to\infty.

Level justification

Proof 1: Compare one limiting value with zero growth order — outline

The bound by twice the order applies to polynomials only if they are not constant. A constant polynomial has 1 asymptotic value, but is of order 0. Thus the unrestricted bound would require 1\leq2\cdot0.
