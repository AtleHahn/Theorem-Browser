Statement

There is an integer n\ge2 such that whenever every unordered pair of distinct vertices of \{0,1\}^n\subset\mathbb R^n is colored with one of two colors, there are four distinct coplanar vertices with all six pairs the same color.

Proof 1: Interpret binary lines as pairs and planes as quadruples — outline

Apply the Graham–Rothschild theorem with |A|=2, r=2, m=2, k=1, and the nontrivial group action interchanging the two symbols.

For these parameters, the set of strings of length {\displaystyle n} over a binary alphabet describes the vertices of an {\displaystyle n}-dimensional hypercube, every two of which form a combinatorial line. The set of all combinatorial lines can be described as the edges of a complete graph on the vertices. The theorem states that, for a high-enough dimension {\displaystyle n}, whenever this set of edges of the complete graph is assigned two colors, there exists a monochromatic combinatorial plane: a set of four hypercube vertices that belong to a common geometric plane and have all six edges assigned the same color.
