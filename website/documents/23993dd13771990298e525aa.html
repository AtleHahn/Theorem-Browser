Statement

Let (M,g) be a smooth pseudo-Riemannian manifold of dimension n\ge3. It is locally conformally flat if every point has a neighborhood on which a positive smooth multiple of g is a flat metric. Let W be its Weyl curvature tensor and put

S=\frac{2}{n-2}\operatorname{Ric}-\frac{\operatorname{Scal}}{(n-1)(n-2)}g.

Then:

  • If n\ge4, g is locally conformally flat if and only if W=0.
  • If n=3, g is locally conformally flat if and only if S is a Codazzi tensor, meaning \nabla_kS_{ij}=\nabla_iS_{kj} for the Levi-Civita connection \nabla.

Here \operatorname{Ric} and \operatorname{Scal} are the Ricci and scalar curvatures. No global topological hypothesis is required.
