Statement

A correspondence C:\Theta\rightrightarrows X assigns subsets of X to points of \Theta. It is upper hemicontinuous if for every \theta and open G\supseteq C(\theta), some neighborhood U of \theta satisfies C(\theta')\subseteq G for all \theta'\in U. It is lower hemicontinuous if for every open G meeting C(\theta), some such U has C(\theta')\cap G\ne\varnothing throughout U. Let \Theta,X be topological spaces. Suppose A:\Theta\rightrightarrows X is compact-valued and upper hemicontinuous, and the graph \{(\theta,x):x\in B(\theta)\} of B:\Theta\rightrightarrows X is closed. Then \theta\mapsto A(\theta)\cap B(\theta) is upper hemicontinuous.

Proof 1: Cover the compact value by graph-avoiding neighborhoods

Throughout this proof, a neighborhood means an open set containing the point.

Let {\displaystyle \theta \in \Theta }, and suppose {\displaystyle G} is an open set containing {\displaystyle (A\cap B)(\theta )}. If {\displaystyle A(\theta )\subseteq G}, then the result follows immediately. Otherwise, observe that for each {\displaystyle x\in A(\theta )\setminus G} we have {\displaystyle x\notin B(\theta )}, and since {\displaystyle B} is closed there is a neighborhood {\displaystyle U_{x}\times V_{x}} of {\displaystyle (\theta ,x)} in which {\displaystyle x'\notin B(\theta ')} whenever {\displaystyle (\theta ',x')\in U_{x}\times V_{x}}. The collection of sets {\displaystyle \{G\}\cup \{V_{x}:x\in A(\theta )\setminus G\}} forms an open cover of the compact set {\displaystyle A(\theta )}, which allows us to extract a finite subcover {\displaystyle G,V_{x_{1}},\dots ,V_{x_{n}}}. By upper hemicontinuity, there is a neighborhood {\displaystyle U_{\theta }} of {\displaystyle \theta } such that for every \theta'\in U_\theta, {\displaystyle A(\theta')\subseteq G\cup V_{x_{1}}\cup \dots \cup V_{x_{n}}}. Then whenever {\displaystyle \theta '\in U_{\theta }\cap U_{x_{1}}\cap \dots \cap U_{x_{n}}}, we have {\displaystyle A(\theta ')\subseteq G\cup V_{x_{1}}\cup \dots \cup V_{x_{n}}}, and so {\displaystyle (A\cap B)(\theta ')\subseteq G}. This completes the proof. {\displaystyle \square }
