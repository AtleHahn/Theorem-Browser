Statement

For an odd prime p, write (a/p)=0 if p\mid a, 1 if a is a nonzero square modulo p, and -1 otherwise. One has (-1/p)=(-1)^{(p-1)/2}. Thus -1 is a square modulo p exactly when p\equiv1\pmod4.

Level
High school only

Proof 1: Apply Euler criterion to minus one

Euler criterion gives (-1/p)\equiv(-1)^{(p-1)/2}\pmod p. Both sides are 1 or -1; since p is odd, congruence forces equality. The exponent is even exactly when p\equiv1\pmod4.
