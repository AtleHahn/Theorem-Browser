Statement

For integers n\ge2r\ge2, let KG_{n,r} have the r-element subsets of an n-element set as vertices, with edges exactly between disjoint subsets. The maximum number of vertices with no edges between any two is \binom{n-1}{r-1}.

Level
High school only
Level justification

Vertices and edges are defined through finite subsets and disjointness; the requested maximum is a finite count.

Proof 1: Translate independence into set intersection

An independent vertex set in this graph is exactly an intersecting family of r-subsets. Apply Erdős–Ko–Rado, which bounds such a family by \binom{n-1}{r-1}. The star consisting of all r-subsets containing a fixed element has that many members, so the bound is attained.

Level
High school only
Level justification

Translate graph independence into pairwise set intersection, apply the stated bound and exhibit a star attaining it. Elementary subsets and binomial counting suffice.
