Statement

Let n≥1, x_i∈[0,1/2], γ_i∈[0,1], and ∑_{i=1}^nγ_i=1. With the convention 0^0:=0,

\frac{\prod_{i=1}^n x_i^{\gamma_i}}{\prod_{i=1}^n(1-x_i)^{\gamma_i}}\leq\frac{\sum_{i=1}^n\gamma_ix_i}{\sum_{i=1}^n\gamma_i(1-x_i)}.

Equality holds precisely when either γ_i x_i=0 for every i, or all x_i>0 and all x_i with γ_i>0 have the same value.

High school only

Proof 1: Apply strict Jensen to the log odds

Idea: Apply Jensen's inequality to the strictly concave function

{\displaystyle f(x):=\ln x-\ln(1-x)=\ln {\frac {x}{1-x}},\qquad x\in (0,{\tfrac {1}{2}}].}

Detailed proof: (a) If at least one xi is zero, then, with the stated convention 0^0=0, the left-hand side of the Ky Fan inequality is zero and the inequality is proved. Equality holds if and only if the right-hand side is also zero, which is the case when γixi = 0 for all i = 1, . . ., n.

(b) Assume now that all xi > 0. If there is an i with γi = 0, then the corresponding xi > 0 has no effect on either side of the inequality, hence the ith term can be omitted. Therefore, we may assume that γi > 0 for all i in the following. If x1 = x2 = . . . = xn, then equality holds. It remains to show strict inequality if not all xi are equal.

The function f is strictly concave on (0,⁠1/2⁠], because we have for its second derivative

{\displaystyle f''(x)=-{\frac {1}{x^{2}}}+{\frac {1}{(1-x)^{2}}}<0,\qquad x\in (0,{\tfrac {1}{2}}).}

Using the functional equation for the natural logarithm and Jensen's inequality for the strictly concave f, we obtain that

{\displaystyle {\begin{aligned}\ln {\frac {\prod _{i=1}^{n}x_{i}^{\gamma _{i}}}{\prod _{i=1}^{n}(1-x_{i})^{\gamma _{i}}}}&=\ln \prod _{i=1}^{n}{\Bigl (}{\frac {x_{i}}{1-x_{i}}}{\Bigr )}^{\gamma _{i}}\\&=\sum _{i=1}^{n}\gamma _{i}f(x_{i})\\&<f{\biggl (}\sum _{i=1}^{n}\gamma _{i}x_{i}{\biggr )}\\&=\ln {\frac {\sum _{i=1}^{n}\gamma _{i}x_{i}}{\sum _{i=1}^{n}\gamma _{i}(1-x_{i})}},\end{aligned}}}

where we used in the last step that the γi sum to one. Taking the exponential of both sides gives the Ky Fan inequality.

Within undergraduate level
Level justification

Treat zero entries separately, differentiate the log odds to establish strict concavity and apply finite weighted Jensen with equality conditions. Undergraduate differential calculus suffices.
