Statement

Let M=\begin{bmatrix}A&B\\B^*&C\end{bmatrix} be a complex Hermitian positive-semidefinite matrix with all four blocks of size m\times m. Then \det M\le\det\begin{bmatrix}\det A&\det B\\\det(B^*)&\det C\end{bmatrix}.

Level justification

Proof 1: Specialize Thompson’s block determinant inequality

If a positive-semidefinite matrix M can be partitioned in equal-size square blocks M_{ij}, then the following inequality by Thompson is valid:

\det(M)\leq\det([\det(M_{ij})]),

where [\det(M_{ij})] is the matrix whose (i,j) entry is \det(M_{ij}).

In particular, for the two-by-two block partition in the statement, the following inequality by Everitt is valid:

\det(M)\leq\det\begin{bmatrix}\det(A)&\det(B)\\\det(B^*)&\det(C)\end{bmatrix}.

Level justification

Specialize the supplied block determinant inequality to two blocks in each direction. Hermitian positive semidefinite matrices, conjugate transpose and determinants are ordinary undergraduate linear algebra.
