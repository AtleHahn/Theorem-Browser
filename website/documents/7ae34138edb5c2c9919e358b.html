Statement

If N is a complex n\times n matrix with |N_{ij}|\le1, then |\det N|\le n^{n/2}. For real N, equality holds exactly when every entry is 1 or -1 and the columns are orthogonal.

Proof 1: Determinant bound for matrices with entries in the unit disk (outline)

Hadamard's inequality states that, if N has columns v_i, then

|\det(N)|\leq\prod_{i=1}^n\|v_i\|.

If the n vectors are non-zero, equality is achieved if and only if the vectors are orthogonal. A corollary is that if the entries of an n by n matrix N are bounded by B, so |N_{ij}|\leq B for all i and j, then

|\det(N)|\leq B^n n^{n/2}.

In particular, for B=1,

|\det(N)|\leq n^{n/2}.

Equality in this bound is attained for a real matrix N if and only if N is a Hadamard matrix, that is, a matrix with entries +1 and -1 and orthogonal columns.

Level justification

Bound every column norm by sqrt(n), apply Hadamard and inspect equality in both steps. Standard finite complex linear algebra suffices.
