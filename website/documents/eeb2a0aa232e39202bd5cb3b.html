Statement

Write \operatorname{NAE}(u,v,w) when the three Boolean values are not all equal. Then for Boolean x,y,z, x\lor y\lor z\iff\exists a\in\{0,1\}:\operatorname{NAE}(0,x,a)\land\operatorname{NAE}(y,z,\neg a).

Level
High school only
Level justification

The equivalence uses only explicitly specified Boolean operations and a two-valued witness.

Proof 1: Choose the auxiliary Boolean value — outline

The ternary relation \operatorname{NAE}(x,y,z) holds if x,y,z are not all equal. The relation R(x,y,z)=x\lor y\lor z can be defined by

R(x,y,z)\iff\exists a\in\{0,1\}:\operatorname{NAE}(0,x,a)\land\operatorname{NAE}(y,z,\neg a).
Level
High school only
Level justification

For x=0 the first NAE forces a=1, and the second becomes NAE(y,z,0), equivalent to y or z. For x=1 the first is automatic and one can choose a to make the second true. Thus the identity is a finite Boolean case check.
