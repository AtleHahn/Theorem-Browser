Statement

There is no nonnegative finitely additive measure on all subsets of \mathbb R^2, invariant under all area-preserving affine transformations, that assigns the unit square measure 1.

Level
Within undergraduate level
Level justification

A finitely additive measure here is a nonnegative set function adding on disjoint pairs, explicitly on all plane subsets. Affine area-preserving maps are determinant-one linear maps plus translations. These definitions use sets and linear algebra, without general measure integration.

Proof 1: Additivity versus duplication (outline)

Use the von Neumann paradox as an external theorem: a unit square has a finite partition into sets which can be moved by area-preserving affine maps to two disjoint unit squares. Invariance preserves each piece’s measure and finite additivity preserves the total. The original square has measure 1, whereas the two disjoint unit squares have total measure 2.

Level
Within undergraduate level
Level justification

Use the supplied finite paradoxical partition and add the measures of its finitely many moved pieces to obtain 1=2. Undergraduate linear algebra and elementary set functions suffice with finite additivity as a small extension; no Lebesgue integration or construction of the paradoxical decomposition is used.
