Statement

Let A be any alphabet and let u,v,x,y be finite strings of symbols from A, including the empty string. Juxtaposition denotes concatenation and |u| is the number of symbols in u. If uv=xy, there is a finite string w such that:

  • if |u|\le|x|, then uw=x and v=wy;
  • if |u|\ge|x|, then u=xw and wv=y.

When the lengths are equal, w is empty and both descriptions hold.

Level
High school only
Level justification

Only finite sequences of symbols, equality and length comparisons are needed; the statement defines all notation.

Proof 1: Comparing prefixes (external)
