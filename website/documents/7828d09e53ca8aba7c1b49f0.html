Statement

Let x,y\in\mathbb R^n have Euclidean norm one and let 0<\varepsilon\le1. If \|x-y\|\ge\varepsilon, then \|(x+y)/2\|\le1-\varepsilon^2/8.

Level

Level justification

Proof 1: Apply the parallelogram identity and a square-root bound

For unit vectors x,y, use \tfrac12\|x+y\|^2=\|x\|^2+\|y\|^2-\tfrac12\|x-y\|^2 and \sqrt{1-u}\le1-u/2 for 0\le u\le1. If \|x-y\|\ge\varepsilon, these give \|(x+y)/2\|\le1-\varepsilon^2/8.
