Statement

Define polynomials B_0(x)=1, B_j^{\prime}(x)=jB_{j-1}(x) and \int_0^1B_j(x)\,dx=0 for j\ge1. Write b_j=B_j(1), so b_1=1/2, and P_j(x)=B_j(x-\lfloor x\rfloor). Let integers p\ge2 and 0\le m<n be given, with f\in C^p([m,n];\mathbb C) and R_p=(-1)^{p+1}\int_m^n f^{(p)}P_p/p!. Set \zeta(p)=\sum_{r=1}^{\infty}r^{-p}. Then |R_p|\le\frac{2\zeta(p)}{(2\pi)^p}\int_m^n|f^{(p)}(x)|\,dx.

Proof 1: Insert the Bernoulli polynomial bound in the remainder integral

For integers k ≥ 2, it can be shown that for 0 ≤ x ≤ 1,

{\displaystyle {\bigl |}B_{k}(x){\bigr |}\leq {\frac {2\cdot k!}{(2\pi )^{k}}}\zeta (k),}

where ζ denotes the Riemann zeta function; one approach to prove this inequality is to obtain the Fourier series for the polynomials Bk(x). Using this inequality, the size of the remainder term can be estimated as

{\displaystyle \left|R_{p}\right|\leq {\frac {2\zeta (p)}{(2\pi )^{p}}}\int _{m}^{n}\left|f^{(p)}(x)\right|\,dx.}
Level
Within undergraduate level
Level justification

Insert the supplied uniform polynomial bound into the absolute value of the remainder integral and cancel p factorial. Zeta here is only a convergent positive p-series; the suggested Fourier proof of the bound is not invoked.
