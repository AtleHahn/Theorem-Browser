Statement

Let B be a Boolean algebra and let S(B) be its set of ultrafilters, with topology having basis U_b=\{u\in S(B):b\in u\} for b\in B. Every U_b is clopen.

Level
Within undergraduate level
Level justification

Boolean algebra generalizes elementary set operations and an ultrafilter is a maximal proper upward/meet-closed collection. These linked algebraic definitions extend undergraduate topology.

Proof 1: Boolean complement of a basic open set — outline

The set U_b is open by the choice of topology. It is also closed because B is a Boolean algebra: an ultrafilter contains exactly one of b and its Boolean complement, so the complement of U_b is the corresponding basic open set.

Level justification

From elementary set algebra and topology, a Boolean ultrafilter is a maximal consistent upward-closed collection closed under meets; this is a small related extension and no existence or duality theorem is used.
