Statement

Let G be a nontrivial group such that every nonidentity element has the same finite order m. Then m is prime.

Level
Within undergraduate level
Level justification

Introductory algebra and set theory supply equivalence relations, group actions, quotients and order-preserving maps. The extra names and constructions are explicitly described using those objects, so the complete statement needs no categorical or representation-theoretic machinery.

Proof 1: Apply Cauchy inside a cyclic subgroup

Cauchy's theorem states that if a prime divides the order of a finite group, that group has an element of that prime order. Choose a nonidentity element x\in G, of order m>1. Then m must be prime, since otherwise Cauchy's theorem applied to the finite subgroup generated by x produces a nonidentity element of order less than m.

Level
Within undergraduate level
Level justification

The cyclic subgroup generated by x has order m. Apply Cauchy to a proper prime divisor if m is composite, contradicting the common order. This is introductory finite-group theory.
