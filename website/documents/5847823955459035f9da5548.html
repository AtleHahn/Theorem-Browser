Statement

For a prefix-closed tree T⊆N^{<N}, let Ext(T) be the set of its finite sequences lying on some infinite path. If T has an infinite path, it has a path computable relative to the membership oracle Ext(T).

Level
Within undergraduate level
Level justification

Infinite sequence trees and relative computability add an oracle-membership algorithm to undergraduate countability and finite algorithms. Ext(T) is explicitly defined.

Proof 1: Greedily choose an extendible successor

Whenever a subtree T of \mathbb N^{<\mathbb N} has an infinite path, a path is computable from \operatorname{Ext}(T), step by step, greedily choosing a successor in \operatorname{Ext}(T) at each step. The restriction to \operatorname{Ext}(T) ensures that this greedy process cannot get stuck. The choice can be made by testing successors in natural-number order with the membership oracle.

Level
Within undergraduate level
Level justification

At each finite prefix query successors in increasing order until the oracle says one extends to an infinite path. The definition guarantees a successful finite search each time. Elementary algorithms and sequence trees suffice with the small addition of oracle access.
