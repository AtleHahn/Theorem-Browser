Statement

A strict linear order is an irreflexive transitive relation < such that distinct elements are comparable. It is dense if x<y implies x<z<y for some z, and has no endpoints if every element has both a smaller and a larger element. An order isomorphism is a bijection preserving and reflecting <. Let L,M be nonempty countable dense linear orders without endpoints. Let c:L\to C and d:M\to D be colorings by nonempty finite or countable color sets such that every color occurs between any two distinct comparable points of its order. For each bijection \sigma:C\to D there is an order isomorphism h:L\to M satisfying d(h(x))=\sigma(c(x)) for every x\in L.

Proof 1: Match the prescribed color in each finite gap — outline

Local back-and-forth recipe

The back-and-forth construction builds up an isomorphism between any two given orders, using a greedy algorithm, in an ordering given by a countable enumeration of the two orderings. In more detail, the proof maintains two order-isomorphic finite subsets {\displaystyle A} and {\displaystyle B} of the two given orders, initially empty. It repeatedly increases the sizes of {\displaystyle A} and {\displaystyle B} by adding a new element from one order, the first missing element in its enumeration, and matching it with an order-equivalent element of the other order, proven to exist using the density and lack of endpoints of the order. The two orderings switch roles at each step: the proof finds the first missing element of the first order, adds it to {\displaystyle A}, matches it with an element of the second order, and adds it to {\displaystyle B}; then it finds the first missing element of the second order, adds it to {\displaystyle B}, matches it with an element of the first order, and adds it to {\displaystyle A}, etc. Every element of each ordering is eventually matched with an order-equivalent element of the other ordering, so the two orderings are isomorphic.

For the colored version each match is required to have the prescribed corresponding color. Every such color occurs in every open interval, as assumed.

Level justification

Alternate the two countable enumerations, extending a finite order-preserving match in the required color at each step. Density supplies matches in bounded gaps and lack of endpoints supplies intervals in end gaps. The union is a bijection. This is elementary countable set theory, without model-theoretic machinery.
