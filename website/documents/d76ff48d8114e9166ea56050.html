Statement

For an integer m\ge0, the number of colorings of the six faces of a cube with m labeled colors, identifying two colorings when a rotation carries one to the other, is (m^6+3m^4+12m^3+8m^2)/24. Colors may repeat and need not all occur.

Level
High school only
Level justification

Proof 1: Average fixed colorings by cube rotation type — outline

Burnside's lemma can compute the number of rotationally distinct colourings of the faces of a cube using m colours.

Let {\displaystyle X} be the set of m6 possible face color combinations that can be applied to a fixed cube, and let the rotation group G of the cube act on {\displaystyle X} by moving the colored faces: two colorings in {\displaystyle X} belong to the same orbit precisely when one is a rotation of the other. Rotationally distinct colorings correspond to group orbits, and can be found by counting the sizes of the fixed sets for the 24 elements of G, the colorings left unchanged by each rotation:

  • the identity element fixes all m6 colorings
  • six 90-degree face rotations each fix m3 colorings
  • three 180-degree face rotations each fix m4 colorings
  • eight 120-degree vertex rotations each fix m2 colorings
  • six 180-degree edge rotations each fix m3 colorings.

A coloring is fixed precisely when each cycle of the face permutation has a single color. By Burnside's lemma, the number of orbits is the average fixed-set size:

|X/G|=\frac{1}{24}\left(m^6+6m^3+3m^4+8m^2+6m^3\right) =\frac{1}{24}\left(m^6+3m^4+12m^3+8m^2\right).
