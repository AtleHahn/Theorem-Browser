Statement

For Boolean literals A,B,C,D and a fresh Boolean variable Z, A\lor B\lor C\lor D is true if and only if there exists a value of Z making (A\lor B\lor Z)\land(\neg Z\lor C\lor D) true. Thus replacing this clause by the displayed conjunction preserves satisfiability when Z occurs nowhere else.

Level
High school only
Level justification

The construction uses only a new truth value and two explicitly given Boolean clauses.

Proof 1: A fresh variable splits a four-literal clause — outline

Replace the clause A\lor B\lor C\lor D by (A\lor B\lor Z)\land(\neg Z\lor C\lor D), where Z is a new variable not used anywhere else. This is the supplied clause-splitting construction.

Level
High school only
Level justification

Choose the fresh Boolean value to satisfy the side whose original literals are false, and observe that if all four originals are false the two new clauses demand opposite values. This is finite Boolean case reasoning.
