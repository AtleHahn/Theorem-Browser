Statement

A Pythagorean triple means positive integers (a,b,c) with a^2+b^2=c^2; it is primitive if \gcd(a,b,c)=1. The triangle with vertices (0,0),(a,0),(0,b) has I=\frac{(a-1)(b-1)-\gcd(a,b)+1}{2} interior lattice points. For a primitive triple this is (a-1)(b-1)/2.

Proof 1: Source calculation — outline

Apply Pick’s formula K=I+B/2-1 to the source triangle of area K=ab/2. The boundary count is B=a+b+\gcd(a,b), leaving the displayed formula. In the primitive case \gcd(a,b)=1. The source leaves the lattice-segment boundary count implicit.
