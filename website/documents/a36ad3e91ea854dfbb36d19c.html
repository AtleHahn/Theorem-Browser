Statement

For a finite region of a square grid, form the graph with one vertex for each square and an edge for each pair of squares sharing a side. The region is domino-tileable if and only if this bipartite graph has a perfect matching (an edge set incident with each vertex exactly once). Consequently tileability can be decided in polynomial time in the number of squares.

Level
Within undergraduate level
Level justification

The graph and perfect-matching definitions are explicit finite combinatorics. Polynomial time means an operation bound by a fixed polynomial in the number of squares, a small algorithmic extension; the full tiling equivalence needs no advanced theory.

Proof 1: Adjacency graph reduction

Color the squares alternately black and white; every adjacency joins opposite colors, so the graph is bipartite. A domino corresponds to an edge joining its two squares. Covering each square exactly once is precisely choosing edges incident with each vertex exactly once, that is, a perfect matching. Apply a polynomial-time algorithm for bipartite perfect matching.

Within undergraduate level
Level justification

The domino-matching correspondence is elementary. The computational conclusion uses the notion of polynomial running time and a supplied matching algorithm existence theorem, a small extension of discrete mathematics; the algorithm itself need not be learned.
