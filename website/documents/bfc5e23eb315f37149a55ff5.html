Statement

The number of Eulerian circuits of a finite directed graph can be computed exactly in deterministic polynomial time. For finite undirected graphs, computing the number of Eulerian circuits is \#\mathrm P-complete under polynomial-time oracle reductions. An Eulerian circuit is a closed traversal using every edge exactly once. Edges are distinguished. Circuits are identified under cyclic rotation, and in the undirected case also under reversal; these conventions can be implemented by choosing the lexicographically least representative of each circuit class, after ordering vertex and edge labels. Inputs are explicit finite graphs encoded by vertex and edge lists, and counts are output in binary. Isolated vertices do not affect a traversal; a graph with no possible circuit has count zero. The class \#\mathrm P consists of functions counting accepting computation paths of nondeterministic polynomial-time machines. Completeness here means membership in that class and that every function in it can be computed in polynomial time with access to an oracle for the circuit-counting function. Polynomial time is measured in the input bit length.
