Statement

For a finite set X with n\geq0 elements, the number of equivalence relations on X equals B_n, the number of partitions of X into nonempty disjoint cells. In particular it equals e^{-1}\sum_{k=0}^{\infty}k^n/k!, using 0^0=1 when n=0. Equivalence means reflexivity, symmetry and transitivity as defined by xRx, xRy\Rightarrow yRx, and (xRy\land yRz)\Rightarrow xRz.

Proof 1: Counting equivalence relations by Bell numbers

Let X be a finite set with n elements. Since every equivalence relation over X corresponds to a partition of X, and vice versa, the number of equivalence relations on X equals the number of distinct partitions of X, which is the nth Bell number B_n:

B_n=\frac{1}{e}\sum_{k=0}^{\infty}\frac{k^n}{k!}

(Dobiński's formula), with 0^0=1 when n=0.

Within undergraduate level
Level justification

Identify relations with their finite classes and apply the supplied Dobinski series evaluation. The infinite factorial series and exponential constant require basic calculus series; no advanced combinatorial theory is needed.
