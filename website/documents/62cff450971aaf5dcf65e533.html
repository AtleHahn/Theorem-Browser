Statement

Let A,B\subseteq\mathbb R^n be disjoint nonempty convex sets and suppose A is open. There exist v\ne0,c\in\mathbb R with \langle v,a\rangle>c\ge\langle v,b\rangle for a\in A,b\in B. If B is also open, then \langle v,b\rangle<c.

Within undergraduate level
Level justification

Understanding the statement involves Convex sets; Open Euclidean sets; Linear functionals. These prerequisites fit undergraduate coursework or a brief extension of it. Proof 1: A separating hyperplane misses an open set — outline

Use weak hyperplane separation to obtain v\ne0 and c with \langle v,a\rangle\ge c\ge\langle v,b\rangle. A separating hyperplane cannot meet an open set lying on just one side of it. Hence equality is impossible for a\in A; if B is open, equality is impossible there as well.

Level
Within undergraduate level
Level justification

Apply the explicit finite-dimensional weak separation theorem, then perturb within an open ball to exclude equality. Undergraduate Euclidean linear algebra and topology suffice.
