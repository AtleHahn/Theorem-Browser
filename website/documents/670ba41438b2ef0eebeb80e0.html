Statement

Let K be a field, J\subseteq K[x_1,\ldots,x_n] a homogeneous ideal, n\ge1, and \mathfrak m=(x_1,\ldots,x_n). The polynomials in J have no common nonzero zero in an algebraic closure of K if and only if \mathfrak m^d\subseteq J for some integer d\ge1.

Level
Within undergraduate level
Level justification

Introductory polynomial-ideal theory supplies ideal powers and common zeros. Homogeneous means generated by homogeneous forms, and an algebraic closure provides all polynomial roots. These closely related definitions are a small extension, without projective varieties or scheme theory.

Proof 1: Apply Nullstellensatz to the coordinate powers

Hilbert's Nullstellensatz asserts that the polynomials in J have no common nonzero zero if and only if J contains a power of each x_i, or, equivalently, that \mathfrak m^d\subseteq J for some positive integer d.

Level
Beyond undergraduate level
Level justification

Apply Nullstellensatz to obtain coordinate powers, then use monomial counting for a power of the irrelevant ideal. Homogeneous ideals over arbitrary fields, algebraic-closure base change and radicals together exceed the small-extension allowance; retain conservatively.
