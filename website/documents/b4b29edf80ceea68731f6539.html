Statement

Let T be a first-order theory having an infinite model, and let (I,<) be any linearly ordered set. There is a model M\models T and distinct elements (a_i)_{i\in I} of M which are order indiscernible: for every first-order formula \varphi(x_1,\ldots,x_n) of the language of T, without additional parameters, and any two increasing index tuples i_1<\cdots<i_n and j_1<\cdots<j_n, M\models\varphi(a_{i_1},\ldots,a_{i_n})\quad\Longleftrightarrow\quad M\models\varphi(a_{j_1},\ldots,a_{j_n}). A theory is a set of sentences in a fixed first-order language and a model is a structure satisfying them.
