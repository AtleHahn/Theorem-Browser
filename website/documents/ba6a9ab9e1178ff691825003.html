Statement

For real x and integer n\ge0, (1+x)^n=\sum_{k=0}^n\binom nk x^k. For integers n\ge0 and 0\le k\le n, write \binom nk=n!/(k!(n-k)!), with 0!=1.

Level
High school only
Level justification

The formula uses elementary algebra, finite sums and factorials.

Proof 1: Set one variable equal to one

Use the binomial formula (x+y)^n=\sum_{k=0}^n\binom nk x^ky^{n-k}.

A simple variant of the binomial formula is obtained by substituting 1 for y, so that it involves only a single variable. In this form, the formula reads

{\displaystyle {\begin{aligned}(x+1)^{n}&={\binom {n}{0}}x^{0}+{\binom {n}{1}}x^{1}+{\binom {n}{2}}x^{2}+\cdots +{\binom {n}{n}}x^{n}\\[4pt]&=\sum _{k=0}^{n}{\binom {n}{k}}x^{k}.{\vphantom {\Bigg )}}\end{aligned}}}
Level
High school only
Level justification

Set y=1 in the explicitly stated finite binomial expansion. The resulting simplification uses only integer powers and finite sums.
