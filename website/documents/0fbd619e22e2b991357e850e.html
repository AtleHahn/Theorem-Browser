Statement

For a finite nonempty set V of points in Euclidean space, consider the complete graph on V, with the edge between distinct points p,q assigned weight d(p,q). A spanning tree is a connected graph on all the vertices with no cycle; a minimum spanning tree minimizes the sum of its edge weights. Replacing every edge weight by d(p,q)^2 preserves which spanning trees are minimum.

Proof 1: Preserve the edge ordering — outline

A Euclidean minimum spanning tree can be determined from the ordering between distances rather than their numerical values. Comparing squared distances gives the same ordering, since taking a square root does not change the order. Thus squared-distance comparisons produce the same minimum-spanning-tree result.

Within undergraduate level
Level justification

Use the supplied theorem that all minimum spanning trees depend only on the weak edge ordering, including ties. Squaring preserves that order on nonnegative lengths. The graph-optimization theorem is a small discrete-mathematical extension; it is essential because monotonicity alone would not compare arbitrary sums.
