Statement

A family \mathcal F of subsets of a finite set U shatters T\subseteq U when \{S\cap T:S\in\mathcal F\} is the family of all subsets of T. For |U|=n and an integer 1\leq k\leq n+1, the family of all subsets of U of size less than k has \sum_{i=0}^{k-1}\binom ni members and shatters no set of size k.

Level
High school only
Level justification

The shattering condition and family of small subsets are explicitly finite set constructions.

Proof 1: Use all subsets below the size threshold

The Sauer–Shelah bound is tight: Let the family {\displaystyle {\mathcal {F}}} be composed of all subsets of {\displaystyle U} with size less than {\displaystyle k}. Then the number of sets in {\displaystyle {\mathcal {F}}} is exactly {\textstyle \sum _{i=0}^{k-1}{\binom {n}{i}}} but it does not shatter any set of size {\displaystyle k}, because the set itself cannot be obtained as an intersection with a set in this family.

Level
High school only
Level justification

Count subsets of each size and observe that intersecting a smaller set cannot produce a k-element set. Elementary finite sets and binomial coefficients suffice.
