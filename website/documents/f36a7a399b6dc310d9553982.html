Statement

Let g:\mathbb N\to\mathbb N and h:\mathbb N^3\to\mathbb N be total computable. There is a total computable f:\mathbb N^2\to\mathbb N satisfying f(0,y)=g(y) and f(x+1,y)=h(f(x,y),x,y).

Level

Level justification

Computable here means that a finite algorithm returns the indicated integer or finite set. The constructions involve ordinary sequences, recursion and natural-number sets, familiar from undergraduate proof and algorithm practice; no program-index semantics or formal provability is needed.

Proof 1: Use a self-simulating program — outline

Suppose that g and h are total computable functions that are used in a recursive definition for a function f:

f(0,y)=g(y),f(x+1,y)=h(f(x,y),x,y).

The second recursion theorem can be used to show that such equations define a computable function, where the notion of computability does not have to allow, prima facie, for recursive definitions. Use an admissible numbering \varphi_e and standard coding of multiple inputs; \simeq denotes equality including simultaneous undefinedness.

This recursive definition can be converted into a partial computable function \varphi_F(e,x,y) that assumes e is an index to itself, to simulate recursion:

\varphi_F(e,0,y)\simeq g(y),\varphi_F(e,x+1,y)\simeq h(\varphi_e(x,y),x,y).

The second recursion theorem, applied with (x,y) coded as one input, establishes the existence of an index p such that

\varphi_p(x,y)\simeq\varphi_F(p,x,y).

Thus f=\varphi_p satisfies the given recursive definition. Since g and h are total, induction on x makes f(x,y) defined for every x,y.

Level justification

This proof uses admissible program numberings, partial-function equality and the second recursion theorem to eliminate a recursive definition. The cumulative formal computability framework is not confidently a small extension, so retain beyond undergraduate provisionally despite the elementary recursive specification.
