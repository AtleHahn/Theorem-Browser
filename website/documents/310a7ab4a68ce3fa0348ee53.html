Statement

Let U be a set with n\ge0 elements and let \mathcal A be a family of subsets such that no two distinct members contain one another. If a_k=|\{S\in\mathcal A:|S|=k\}|, then \sum_{k=0}^n a_k/\binom nk\le1.

Level justification

All objects are finite subsets and explicit counting quantities.

Proof 1: Count permutations with an initial segment in the family

We use a double counting argument, counting permutations of U in two different ways.

First, by counting all permutations of U identified with {1, …, n } directly, one finds that there are n! of them. But secondly, one can generate a permutation (i.e., an order) of the elements of U by selecting a set S in \mathcal A and choosing a permutation that sends {1, … , |S | } to S. If |S | = k, the set S is associated in this way with k!(n − k)! permutations, and in each of them the image of the first k elements of U is exactly S. Each permutation may only be associated with a single set in \mathcal A, for if two prefixes of a permutation both formed sets in \mathcal A then one would be a subset of the other. Therefore, the number of permutations that can be generated by this procedure is

{\displaystyle \sum _{S\in\mathcal A}|S|!(n-|S|)!=\sum _{k=0}^{n}a_{k}k!(n-k)!.}

Since this number is at most the total number of all permutations,

{\displaystyle \sum _{k=0}^{n}a_{k}k!(n-k)!\leq n!.}

Finally dividing the above inequality by n! leads to the result.
