Statement

Let P=(p_{ij})_{1\le i,j\le N}, N\ge1, be the transition matrix of a finite irreducible aperiodic Markov chain: p_{ij}\ge0 and \sum_jp_{ij}=1. For each state i, let \mathcal T_i be the directed spanning trees oriented toward root i, using only edges j\to k with p_{jk}>0. Define

w(T)=\prod_{(j,k)\in E(T)}p_{jk},\qquad t_i=\sum_{T\in\mathcal T_i}w(T),\qquad Z=\sum_{i=1}^Nt_i.

Then Z>0 and the stationary probability distribution is \pi_i=t_i/Z. In particular \pi P=\pi and \sum_i\pi_i=1. A directed tree toward i has one outgoing edge from each other vertex, none from i, and a directed path from each vertex to i. The one-vertex tree has weight 1. Irreducible means every state can reach every other through positive-probability transitions; aperiodic means the return-path lengths at each state have greatest common divisor 1.
