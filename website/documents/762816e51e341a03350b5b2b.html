Statement

Let p>1, 0<\alpha<1 and \beta=1-\alpha. The inequality x\leq\alpha x^p+\beta holds for every x\geq0 if and only if \alpha=1/p.

Level
High school only
Level justification

The stated scalar inequality uses only real powers and arithmetic; calculus is used by the supplied general proofs, not needed to state it.

Proof 1: Convex minimization — outline

Let {\displaystyle 0<\alpha <1} and {\displaystyle \alpha +\beta =1}. The inequality

{\displaystyle x~\leq ~\alpha x^{p}+\beta }

holds for all {\displaystyle x\geq 0} if and only if {\displaystyle \alpha =1/p}. This can be shown by convexity arguments or by simply minimizing the single-variable function.
