Statement

For an integer n\ge1, let f_1,\ldots,f_n be real functions defined on open intervals so their composition is defined near x. Define F_{a,b}=f_a\circ\cdots\circ f_b for a\le b and F_{a,b} to be the identity if b<a. If each f_k is differentiable at F_{k+1,n}(x), then (F_{1,n})^{\prime}(x)=\prod_{k=1}^n f_k^{\prime}(F_{k+1,n}(x)).

Within undergraduate level
Level justification

Understanding the statement involves real derivatives; finite function compositions; finite products. These prerequisites fit undergraduate coursework or a brief extension of it. Proof 1: Iterate the one-variable rule — outline

Group the composition as f_1\circ F_{2,n}. The two-function chain rule gives (F_{1,n})^{\prime}(x)=f_1^{\prime}(F_{2,n}(x))(F_{2,n})^{\prime}(x). Repeat the same step on the remaining composition, ending at f_n. This produces exactly the displayed product. The one-function case is the derivative itself.

Level
Within undergraduate level
Level justification

Apply the two-function chain rule repeatedly, with induction on the number of factors. Introductory undergraduate calculus suffices.
