Statement

If \theta/\pi\in\mathbb Q and \sin\theta\in\mathbb Q, then \sin\theta\in\{0,\pm\tfrac12,\pm1\}. Every value in this set occurs for a rational multiple of \pi.

Level
High school only
Level justification

Only rationality and elementary real trigonometric values are needed to understand the statements.

Mathematical Field
High School Mathematics
Required topics

Review notes

Proof 1: Cosine degree restriction and phase shift outline

Write \theta=2\pi k/n with n\ge1 and \gcd(k,n)=1. If n>2, Lehmer’s degree theorem says that 2\cos\theta has algebraic degree \varphi(n)/2, where \varphi is Euler’s totient. If the cosine is rational this degree is one. Thus n\le2 or \varphi(n)=2, so the only possible denominators are n=1,2,3,4,6. Their usual cosine values are 1,-1,-1/2,0,1/2; all occur at rational multiples of \pi. Apply this cosine classification to \theta-\pi/2, using \sin\theta=\cos(\theta-\pi/2). The shifted angle is still a rational multiple of \pi, and shifting back also supplies all five possible values.
