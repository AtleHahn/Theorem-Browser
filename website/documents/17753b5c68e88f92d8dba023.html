Statement

Let a finite undirected graph be drawn continuously in [0,1]^2, with the corners (0,1) and (1,0) as its only odd-degree vertices. Then it has a path joining those corners, and that path contains a point (t,t) on the diagonal.

Level justification

Proof 1: A path between two odd opposite square corners meets the diagonal — outline

The handshaking lemma applied to components puts the two odd vertices in the same component. A path therefore joins them. Along the continuous path the coordinate difference changes from -1 at (0,1) to 1 at (1,0), so it vanishes at a diagonal point.

Level
Within undergraduate level
Level justification

Use parity in each finite component to obtain a path and apply the intermediate value theorem to its coordinate difference. Elementary graph counting and undergraduate continuity suffice.
