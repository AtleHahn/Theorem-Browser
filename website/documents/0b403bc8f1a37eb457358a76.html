Statement

The matrix T=\begin{pmatrix}0&1&1\\1&0&1\\1&1&0\end{pmatrix} is primitive although all its diagonal entries vanish.

Proof 1: Source matrix argument

A nonnegative matrix is primitive if some positive integer power is entrywise positive. The matrix

T=\begin{pmatrix}0&1&1\\1&0&1\\1&1&0\end{pmatrix}

is an example of a primitive matrix with zero diagonal. The source gives this example without displaying the power that verifies primitivity.
