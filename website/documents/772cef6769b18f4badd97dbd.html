Statement

Define f:\mathbb R\to\mathbb R by f(x)=x+1 when x\in\mathbb Z and f(x)=x otherwise. If |x-y|=1, then |f(x)-f(y)|=1, but f does not preserve all distances.

Level
High school only
Level justification

The piecewise function and distance implication are elementary.

Proof 1: Shift precisely the integers — outline

Consider the function {\displaystyle f(x)} that returns {\displaystyle x+1} if {\displaystyle x} is an integer and returns {\displaystyle x} otherwise. This function preserves unit distances. However, it does not preserve the distances between integers and non-integers.

Level
High school only
Level justification

Two reals a unit apart are either both integers or both nonintegers, while mixed pairs can change distance. School integer arithmetic and absolute values suffice.
