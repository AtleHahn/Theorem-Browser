Statement

Let n\in\{4,5,8\}. If the graph of a smooth function f:\mathbb R^{n-1}\to\mathbb R is a minimal hypersurface in \mathbb R^n, then that graph is a hyperplane. Here the minimal-graph condition is the partial differential equation \sum_{i=1}^{n-1}\frac{\partial}{\partial x_i}\left(\frac{\partial f/\partial x_i}{\sqrt{1+\sum_{j=1}^{n-1}(\partial f/\partial x_j)^2}}\right)=0.

Proof 1: Apply the dimension-raising cone reduction — outline

There is no non-planar area-minimizing cone in \mathbb R^3 (Fleming, 1962).

De Giorgi (1965) showed that if there is no non-planar area-minimizing cone in Rn−1 then every entire minimal hypersurface graph is a hyperplane in Rn, which in particular implies that it is true in R4.

Almgren (1966) showed there are no non-planar minimizing cones in R4, thus extending this graph conclusion to R5.

Simons (1968) showed there are no non-planar minimizing cones in R7, thus extending this graph conclusion to R8.

Level
Beyond undergraduate level
Level justification

The displayed graph PDE is concrete, but the argument applies a reduction to area-minimizing hypersurface cones and their low-dimensional rigidity. Understanding the minimization category and singular cone objects requires geometric measure theory beyond the undergraduate allowance. The dependency descriptions now specify codimension one, which is essential and was abbreviated in the companion.
