Statement

Assume the axiom of choice. Let (P,\leq) be a partially ordered set such that every chain, including the empty chain, has an upper bound in P. Then P has a maximal element.

Level
Within undergraduate level
Level justification

Sets and partial orders supply chains, upper bounds and maximality. Well-order means every nonempty subset has a least member, and choice/Zorn is a stated principle. The explicit equivalences and fixed-point conditions require no ordinal arithmetic or forcing theory.

Proof 1: Transfinite recursion and cardinality

Let {\displaystyle P} be a partially ordered set in which each chain, including the empty chain, has an upper bound. Define the function

{\displaystyle f:P\to P}

by {\displaystyle f(x)=x} if {\displaystyle x} is a maximal element and {\displaystyle f(x)=c(\{y\mid y>x\})} otherwise, where

{\displaystyle c:{\mathcal {P}}(P)-\{\emptyset \}\to P}

is a choice function; namely, {\displaystyle c(S)\in S}. Note a maximal element of {\displaystyle P} is exactly a fixed point of {\displaystyle f}. Thus, the proof is equivalent to finding a fixed point of {\displaystyle f}.

Informally, we are going to construct a very long sequence (transfinite sequence) by repeatedly applying {\displaystyle f}. That is, first pick some {\displaystyle x_{0}} in {\displaystyle P}, possible since {\displaystyle P} is nonempty. Then let {\displaystyle x_{1}=f(x_{0})} and then let {\displaystyle x_{2}=f(x_{1})} and so on. If we have used up all the natural numbers, then, to continue, we let

{\displaystyle x_{\omega }=c(\{{\text{upper bounds of the chain }}\,x_{0}\leq x_{1}\leq \cdots \})}

where {\displaystyle \omega =\{0,1,2,\cdots \}}. Then let {\displaystyle x_{\omega +1}=f(x_{\omega })} and so on. This procedure yields a sequence of length {\displaystyle \alpha } for each ordinal {\displaystyle \alpha },

{\displaystyle x_{0}\leq x_{1}\leq \cdots \leq x_{\omega }\leq x_{\omega +1}\leq \cdots }

Note as long as the sequence is strictly increasing, the map {\displaystyle \alpha \to P,\,\beta \mapsto x_{\beta }} is injective. But a set cannot contain a subset of greater cardinality. So, if the sequence is too long, it cannot be strictly increasing and a term in the sequence such that {\displaystyle x_{\beta }=x_{\beta +1}} is a fixed point of {\displaystyle f} (that is, a maximal element of {\displaystyle P}).

Formally, the above sequence is defined using transfinite recursion. It is exactly like the usual recursive definition of a sequence but runs over ordinals. A key difference is that an ordinal may be a limit ordinal, like {\displaystyle \omega }. For a limit ordinal {\displaystyle \alpha }, as above, we take {\displaystyle x_{\alpha }} to be some upper bound of the sequence {\displaystyle x_{\beta },\beta <\alpha } via {\displaystyle c}. Finally, we need a sufficiently large ordinal. By the axiom of choice in the form of the well-ordering theorem, we can find an ordinal {\displaystyle \kappa } that is bijective with {\displaystyle P.} Take {\displaystyle \alpha =\kappa ^{+}}, the successor cardinal (= least ordinal whose cardinality is larger than {\displaystyle \kappa }). Then, for the reason of cardinality, {\displaystyle \kappa ^{+}\not \hookrightarrow P,\,\beta \mapsto x_{\beta }}; i.e., the sequence {\displaystyle x_{\beta }} is not strictly increasing and so some term in it is a fixed point. (Incidentally, this {\displaystyle \kappa ^{+}} is called the Hartogs number of {\displaystyle P}.)

Proof 2: Compatible well-ordered chains — outline

Let {\displaystyle P} be a partially ordered set in which each chain, including the empty chain, has an upper bound. Define the function

{\displaystyle f:P\to P}

by {\displaystyle f(x)=x} if {\displaystyle x} is a maximal element and {\displaystyle f(x)=c(\{y\mid y>x\})} otherwise, where

{\displaystyle c:{\mathcal {P}}(P)-\{\emptyset \}\to P}

is a choice function; namely, {\displaystyle c(S)\in S}. Note a maximal element of {\displaystyle P} is exactly a fixed point of {\displaystyle f}. Thus, the proof is equivalent to finding a fixed point of {\displaystyle f}.

Let {\displaystyle \Gamma } be the set of all well-ordered chains {\displaystyle C} in {\displaystyle P} such that, for each {\displaystyle x} in {\displaystyle C},

{\displaystyle x=s(\{y\in C\mid y<x\})}

where {\displaystyle g(S)=c(\{{\text{upper bounds of }}S\})} and {\displaystyle s=f\circ g}. We note {\displaystyle \Gamma } is totally ordered, with respect to the ordering by initial segments: indeed, for {\displaystyle C,D} in {\displaystyle \Gamma }, let {\displaystyle S} be the union of all common initial segments of them, which is also an initial segment. Then we easily see either {\displaystyle C=S} or {\displaystyle D=S}. Finally, let {\displaystyle U} be the union of {\displaystyle \Gamma } and then we can see {\displaystyle U} itself is in {\displaystyle \Gamma }. Since {\displaystyle s(U)\in U} and {\displaystyle g(U)} is an upper bound of {\displaystyle U},

{\displaystyle f(g(U))\leq g(U).}

That is, {\displaystyle g(U)} is a fixed point of {\displaystyle f}. {\displaystyle \square }

Proof 3: Reduction from the Hausdorff maximal principle

The Hausdorff maximal principle is an alternative formulation of Zorn's lemma asserting that every partially ordered set {\displaystyle P} has a maximal chain {\displaystyle C\subset P} with respect to set inclusion.

The usual form of Zorn's lemma follows from the Hausdorff maximal principle, since if {\displaystyle P} satisfies the hypothesis of Zorn's lemma, then its maximal chain {\displaystyle C} also has an upper bound {\displaystyle x} in {\displaystyle P}. This {\displaystyle x} is a maximal element since if {\displaystyle y>x}, then {\displaystyle {\widetilde {C}}=C\cup \{y\}} is a strictly larger chain than {\displaystyle C}, contradicting the maximality of {\displaystyle C}.

Level
Within undergraduate level
Level justification

Take the maximal chain supplied by the explicit principle and show its upper bound cannot have a strict successor. Basic order theory suffices.
