Statement

For a finite simple graph G=(V,E) with n vertices, a planar framework is a tuple p=(p_v)_{v\in V}\in(\mathbb R^2)^V. Define its rigidity matrix R(p) by (R(p)u)_{ij}=(p_i-p_j)\cdot(u_i-u_j) for each edge ij. Let r=\max_p\operatorname{rank}R(p). Frameworks satisfying \operatorname{rank}R(p)=r form an open dense subset of (\mathbb R^2)^V.

Proof 1: Avoid the zero sets of nonzero minors (outline)

If the rigidity matrix R(p) does not have max rank, then it has a set of dependent rows corresponding to a subset of edges E'\subseteq E such that for some other rigidity matrix R(q), the rows corresponding to E' are independent. Let \mathcal X_{E'} be the set of frameworks such that the rows corresponding to E' in their rigidity matrices are dependent. In other words, \mathcal X_{E'} is the set of frameworks p such that all the minors of size |E'| of these rows in R(p) are zero. Hence \mathcal X_{E'} is an algebraic zero set in \mathbb R^{2|V|}, because a minor is a polynomial in the entries of a matrix. At least one of these minor polynomials is not identically zero, since the rows are independent for some q.

Let \mathcal X be the union of these sets over all subsets of edges whose rows are independent for some framework. If R(p) does not have max rank, then p is contained in \mathcal X. Finally, \mathcal X is a finite union of sets contained in zero sets of nonzero real polynomials. Such a union has empty interior, so every neighborhood contains a maximum-rank framework.

Nonvanishing of a maximal minor persists in a neighborhood, giving openness. If the maximal rank is zero, every framework already has maximal rank.
