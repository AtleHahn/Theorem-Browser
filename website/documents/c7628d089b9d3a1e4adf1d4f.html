Statement

Let a finite simple bipartite graph have parts of sizes n,m\ge1, with degrees a_1\ge\cdots\ge a_n\ge0 in the first part and b_1,\ldots,b_m\ge0 in the second. Then \sum_i a_i=\sum_j b_j and, for each 1\le k\le n, \sum_{i=1}^k a_i\le\sum_{j=1}^m\min(b_j,k). A simple bipartite graph has at most one edge between each pair of opposite-part vertices and no other edges.

Proof 1: Shift row entries left and count prefixes — outline

Form its zero-one array with row sums b_j and column sums a_i. Shift every row’s ones to the left. This preserves row sums and cannot decrease the number of ones in any initial set of columns. After shifting, the first k positions of row j contain \min(b_j,k) ones. Hence the new prefix column sum bounds the original \sum_{i=1}^k a_i by the stated right-hand side. Both total sums count all one entries, so they are equal.

Level justification

Left-pack each binary row to maximize every prefix count, then sum the resulting minima. Both total degree sums count the same entries. This is finite counting with zero-one arrays.
