Statement

For the Whitney umbrella x^2=y^2z in characteristic zero, blowing up the origin reproduces the same singularity in one chart, whereas blowing up the singular z-axis resolves it.

Proof 1: Compare the two explicit blowup centers — outline

The Whitney umbrella x2 = y2z has singular set the z axis, most of whose point are ordinary double points, but there is a more complicated pinch point singularity at the origin, so blowing up the worst singular points suggests that one should start by blowing up the origin. However blowing up the origin reproduces the same singularity on one of the coordinate charts. So blowing up the (apparently) "worst" singular points does not improve the singularity. Instead the singularity can be resolved by blowing up along the z-axis.
