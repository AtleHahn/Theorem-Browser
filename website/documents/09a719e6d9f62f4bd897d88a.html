Likely alternative prerequisite level: Undergraduate level; lowest recorded proof level: Beyond undergraduate level. Insert the stated finite-sum definition of induction into the left inner product, exchange the sums and set t=s h s^(-1). Class invariance gives conjugate(phi(t))=conjugate(phi(h)); the sum over s contributes |G|, leaving exactly the right inner product. Statement

Let G be a finite group and H\le G. For complex class functions f,h on a finite group A, put

\langle f,h\rangle_A=\frac1{|A|}\sum_{a\in A}f(a)\overline{h(a)}.

For a class function \psi on H, define

\operatorname{Ind}_H^G\psi(t)=\frac1{|H|}\sum_{s\in G:\ s^{-1}ts\in H}\psi(s^{-1}ts).

Write \operatorname{Res}_H^G\varphi=\varphi|_H. Then, for every complex class function \varphi on G,

\langle\operatorname{Ind}_H^G\psi,\varphi\rangle_G=\langle\psi,\operatorname{Res}_H^G\varphi\rangle_H.
Level
Within undergraduate level
Level justification

Group conjugacy and finite complex sums are undergraduate concepts. Induction and restriction are defined explicitly here as operations on class functions, so the identity can be understood without constructing induced representations.

Proof 1: Induced-character summation

Every class function can be written as a linear combination of irreducible characters. As {\displaystyle \langle \cdot ,\cdot \rangle } is a sesquilinear form, we can, without loss of generality, assume {\displaystyle \psi } and {\displaystyle \varphi } to be characters of irreducible representations of {\displaystyle H} in {\displaystyle W} and of {\displaystyle G} in {\displaystyle V,} respectively. We define {\displaystyle \psi (s)=0} for all {\displaystyle s\in G\setminus H.} For characters, \overline{\varphi(t)}=\varphi(t^{-1}). Then we have

{\displaystyle {\begin{aligned}\langle {\text{Ind}}(\psi ),\varphi \rangle _{G}&={\frac {1}{|G|}}\sum _{t\in G}{\text{Ind}}(\psi )(t)\varphi (t^{-1})\\&={\frac {1}{|G|}}\sum _{t\in G}{\frac {1}{|H|}}\sum _{s\in G \atop s^{-1}ts\in H}\psi (s^{-1}ts)\varphi (t^{-1})\\&={\frac {1}{|G|}}{\frac {1}{|H|}}\sum _{t\in G}\sum _{s\in G}\psi (s^{-1}ts)\varphi ((s^{-1}ts)^{-1})\\&={\frac {1}{|G|}}{\frac {1}{|H|}}\sum _{t\in G}\sum _{s\in G}\psi (t)\varphi (t^{-1})\\&={\frac {1}{|H|}}\sum _{t\in G}\psi (t)\varphi (t^{-1})\\&={\frac {1}{|H|}}\sum _{t\in H}\psi (t)\varphi (t^{-1})\\&={\frac {1}{|H|}}\sum _{t\in H}\psi (t){\text{Res}}(\varphi )(t^{-1})\\&=\langle \psi ,{\text{Res}}(\varphi )\rangle _{H}\end{aligned}}}

In the course of this sequence of equations we used only the definition of induction on class functions and the properties of characters. {\displaystyle \Box }

Proof 2: Dimensions in the change-of-rings adjunction

For finite-dimensional complex representations W of H and U of G, use the source's change-of-rings adjunction

\operatorname{Hom}_{\mathbb C[G]}(\mathbb C[G]\otimes_{\mathbb C[H]}W,U) \cong\operatorname{Hom}_{\mathbb C[H]}(W,\operatorname{Res}U).
