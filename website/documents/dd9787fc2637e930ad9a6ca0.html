Statement

For a prime q\equiv3\pmod4 and integer r, the congruence x^2\equiv r\pmod q is solvable if and only if y^4\equiv r\pmod q is solvable.

Level
High school only
Level justification

All residue conditions are explicit integer divisibility conditions.

Proof 1: Choose the quadratic-residue sign of a square root

A fourth power is a square, and zero is both a quadratic and a quartic residue. Suppose now that r is nonzero modulo q.

Indeed, the first supplement of quadratic reciprocity states that −1 is a quadratic nonresidue (mod q), so that for any integer x not divisible by q, one of x and −x is a quadratic residue and the other one is a nonresidue. Thus, if r ≡ a2 (mod q) is a quadratic residue, then if a ≡ b2 is a residue, r ≡ a2 ≡ b4 (mod q) is a biquadratic residue, and if a is a nonresidue, −a is a residue, −a ≡ b2, and again, r ≡ (−a)2 ≡ b4 (mod q) is a biquadratic residue.
