Statement

A partial order is a reflexive, antisymmetric, transitive relation \le. Distinct elements are comparable when one is below the other. A chain has every pair comparable; an antichain has no distinct comparable pair. A partition consists of disjoint subsets whose union is the whole set. The comparability graph of a partial order has its elements as vertices and edges between distinct comparable elements. A clique is a set of pairwise adjacent vertices; a proper coloring assigns different colors at adjacent vertices. A graph is perfect if every induced subgraph has minimum color count equal to maximum clique size. An induced subgraph retains all edges between its selected vertices. The complementary graph has exactly the edges absent between distinct vertices. The complement of every finite comparability graph is perfect.

Level
High school only
Level justification

All graph, order and perfection notions are locally defined by finite sets, comparisons and color counts. No undergraduate theory is required to understand them.

Proof 1: Perfect comparability graph and complement theorem

Every comparability graph is perfect: this is essentially just Mirsky's theorem, restated in graph-theoretic terms. By the perfect graph theorem, the complement of any perfect graph is also perfect. Therefore, the complement of any comparability graph is perfect.

Proof 2: Translate cliques and color classes using Dilworth

Import Dilworth’s theorem: the largest antichain size of a finite partial order equals the minimum number of chains partitioning it. A clique in its incomparability graph is an antichain, while a color class is a chain. Thus Dilworth identifies clique number and chromatic number. Every induced subgraph is the incomparability graph of the restricted partial order, so the same equality holds for every induced subgraph.

Level
High school only
Level justification

Identify cliques as antichains and color classes as chains, apply Dilworth and repeat for restricted vertex sets. Elementary finite orders and counting suffice.
