Statement

For a positive integer n, let \varphi(n) count the integers 1\le k\le n with \gcd(k,n)=1. For each integer q>1, the sequence \varphi(1),\varphi(2),\ldots is not uniformly distributed among residue classes modulo q. Here uniform distribution would require the fraction of indices 1\le n\le N in each fixed residue class to tend to 1/q as N\to\infty.

Proof 1: Compare the density-one zero class with uniform density

For each fixed positive integer q, the divisibility q\mid\varphi(n) holds for all but o(x) values n\le x. Thus for q>1 the values cannot be uniformly distributed among the residue classes modulo q.

Level
Within undergraduate level
Level justification

Divide the exceptional-count estimate by x to see the zero residue has density one, different from 1/q. Undergraduate sequence limits and elementary congruences suffice; proving the density theorem is not required.
