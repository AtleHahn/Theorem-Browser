Statement

For a finite nonempty set X of a player’s actions, a finite nonempty set Y of opponents’ action profiles, and real payoff v(x,y), \max_{x\in X}\min_{y\in Y}v(x,y)\le\min_{y\in Y}\max_{x\in X}v(x,y).

Level
High school only
Level justification

This is a finite table of real numbers with row minima and column maxima. Game-theory terminology introduces no additional prerequisites.

Mathematical Field
Game theory, economics, social and behavioral sciences
Required topics
Finite real payoff functionsFinite maxima and minima
Review notes
none

Proof 1: Information comparison outline

Intuitively, in maximin the maximization comes after the minimization, so the player tries to maximize their value before knowing what the others will do; in minimax the maximization comes before the minimization, so the player is in a much better position—they maximize their value knowing what the others did.
