Statement

For a finite family of axis-aligned boxes in \mathbb R^3, its intersection graph has one vertex per set and edges for intersecting pairs. There is no function c of clique size alone such that every such graph satisfies \chi(G)\le c(\omega(G)), where \chi is the minimum proper vertex-color count and \omega the largest pairwise adjacent vertex set.

Level
High school only
Level justification

The statement defines intersections as graph edges, the minimum number of proper colors, and the largest set of mutually adjacent vertices. Axis-aligned boxes use elementary three-dimensional geometry. The quantified conclusion says that fixing the clique size cannot bound the number of colors across all finite families; these supplied definitions and elementary counting suffice, without a college graph-theory prerequisite.

Proof 1: Intersection graphs of boxes are not chromatically bounded

Burling (1965) constructed axis aligned boxes in {\displaystyle \mathbb {R} ^{3}} whose intersection graph is triangle-free and requires arbitrarily many colors to be properly colored. This family of graphs is then called the Burling graphs. Hence, this implies that axis aligned boxes in \mathbb R^3 are not \chi-bounded.

Level
High school only
Level justification

The statement defines the graph, coloring and clique parameters. Apply the supplied existence of triangle-free box graphs needing arbitrarily many colors: their clique size is at most two, whereas a bound depending only on clique size would give a fixed finite bound. This uses elementary finite sets and contradiction; constructing Burling graphs is not part of this proof.
