Statement

With their usual real order, A=\{x\in\mathbb R:p(x)=0\text{ for some nonzero integer-coefficient polynomial }p\} and \mathbb Q are order-isomorphic. Here order-isomorphic means that there is an increasing bijection between the two stated subsets of the real numbers.

Level
Within undergraduate level
Level justification

Countability, infinite cardinality and order isomorphisms require undergraduate set theory; explicit definitions do not make these ordinary high-school number statements. A bright US college student should be able to understand the statement after about 30 minutes of focused background research; this rating concerns understanding the claim, not proving it.

Proof 1: Apply Cantor to the algebraic real order

A strict linear order is an irreflexive transitive relation < such that distinct elements are comparable. It is dense if x<y implies x<z<y for some z, and has no endpoints if every element has both a smaller and a larger element. An order isomorphism is a bijection preserving and reflecting <. Use Cantor’s isomorphism theorem: any two nonempty countable dense linear orders without endpoints are isomorphic.

The real algebraic numbers are a countable unbounded dense linear order. They contain the rational numbers and, by Cantor’s isomorphism theorem, are again order-isomorphic to them.

Level justification

Check the explicitly defined dense-order hypotheses using rational containment and algebraic countability, then apply Cantor’s theorem. Undergraduate countability and real order suffice with order isomorphism explicitly defined.
