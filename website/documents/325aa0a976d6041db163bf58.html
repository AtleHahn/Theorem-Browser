Statement

Let A,B\subseteq X be subspaces of a topological space with X=\operatorname{int}_X A\cup\operatorname{int}_X B, and set C=A\cap B\ne\varnothing. Suppose (A,C) is (m-1)-connected for an integer m\ge2 and (B,C) is (n-1)-connected for an integer n\ge1. A pair (Y,Z) is r-connected here if every path component of Y meets Z and \pi_j(Y,Z,c) is trivial for every c\in Z and 1\le j\le r. The relative homotopy set \pi_j(Y,Z,c) consists of homotopy classes of maps (D^j,S^{j-1},*)\to(Y,Z,c), where D^j is the closed unit ball, S^{j-1}=\partial D^j, and * is a chosen boundary point, with homotopies respecting these conditions; it is a group for j\ge2. For every basepoint c\in C, inclusion induces \pi_q(A,C,c)\longrightarrow\pi_q(X,B,c), which is bijective for 1\le q<m+n-2 and surjective for q=m+n-2.

Proof 1: CW approximation and excision for triads (external)

A link to the proof can be found here (Theorem 69.3, printed p.620; full proof Section 70, pp.628–635; Theorem 68.12 for CW approximation.).

Use Wendl Theorem 69.3 and Section 70 proof, with source m=stated m-1>=1 and source n=stated n-1>=0. Theorem 68.12 and Section 70.1 explicitly give CW approximation of interior-cover triads; Section 70.4 discusses pointed sets in dimension 1. For the low-dimensional surjectivity left as Exercise 70.2, here pi_1(A,C)=0: subdivide a relative path by the interiors cover; every segment in A with endpoints in C is homotopic rel endpoints into C because (A,C) is 1-connected. The resulting path lies in B, so pi_1(X,B) is also trivial. Thus the degree-1 map is a bijection in this particular parameter range. The source’s m+n is exactly the stated m+n-2.
